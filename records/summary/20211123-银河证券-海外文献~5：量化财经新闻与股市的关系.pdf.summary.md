# 海外文献-5 量化财经新闻与股市的关系

- **source filename**: `20211123-银河证券-海外文献~5：量化财经新闻与股市的关系.pdf`
- **date**: 2021-11-23
- **institution / author**: 中国银河证券；吴俊鹏；原文作者Merve Alanyali、Helen Susannah Moat、Tobias Preis
- **extraction confidence**: high

## Core question
文献研究《金融时报》对公司的提及量，是否与该公司股票的交易量、绝对收益及方向性收益相关。报告也用滞后分析讨论新闻与市场之间可能的相互影响，但不声称已识别因果关系。

## Methods / data
- 《金融时报》2007-01-02—2012-12-31，共1,821期；DJIA在样本期涉及31家公司，交易日股票价格和成交量。
- PDF转文本后统计公司名称日提及次数；计算与成交量、绝对收益、收益的Spearman相关及-3至+3日滞后关系。
- 由于时间序列非正态，主要使用非参数检验；剔除5个无法下载日期。

## Key findings
- 全部31家公司提及量与成交量相关系数总体显著为正：中位数0.074、均值0.100，Wilcoxon检验p<0.001。
- 提及量与绝对收益也为正：中位数0.040、均值0.047，p=0.0017。
- 考虑收益方向后，相关性不显著：中位数0、均值0.002，p=0.784。
- 提及量与成交量的滞后关系仅在新闻前一天（lag=-1，p=0.014）和当天（lag=0，p=0.026）显著，其他滞后不显著。

## Quant takeaways
- 新闻提及量更适合做关注度、波动或流动性因子，不宜直接当作方向性alpha。
- 可在日内时间戳、新闻新颖度、情绪和公司固定效应基础上做预测检验，并严格滞后特征。
- 样本仅覆盖英国财经媒体和DJIA大盘股，新闻与成交量可能双向决定，交易成本和文本歧义也需处理。
