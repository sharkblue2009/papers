# 弱市赢家方能恒强：对冲基金在不同市场条件下的表现持续性

- **source filename**: `20181226-天风证券-海外文献推荐第68期.pdf`
- **date**: 2018-12-26
- **institution / author**: 天风证券研究所；吴先兴；原文作者 Sun Z.、Wang A.、Zheng L.
- **extraction confidence**: high

## Core question
论文研究对冲基金历史表现是否具有条件持续性，并区分强市场与弱市场表现所包含的技能和噪声。作者提出RET_DOWN与RET_UP，分别刻画基金在行业下行和上行月份的近期表现。

## Methods / data
- 使用Lipper TASS 1994—2014年月度数据：19,963只基金经筛选为10,695只，再剔除回填期后剩9,413只。
- 以行业价值加权收益相对历史中位数定义上下行月份；用Fung-Hsieh七因子alpha、评估比率、Sharpe及平滑调整Sharpe评估。
- 按RET_DOWN/RET_UP五分位排序，持有3个月至3年，并进行面板回归、技能代理、资金流和低摩擦子样本稳健性检验。

## Key findings
- RET_DOWN最高与最低组合的评估比率差在3个月持有期为0.71（t=11.24），3年仍为0.22（t=10.36）。
- RET_DOWN回归系数1.86、t=17.50；其增加一个标准差预测下一季度年化FH alpha增加4.87%（约数）。
- RET_UP对未来alpha、评估比率和Sharpe几乎无正向预测力，甚至控制无条件历史表现后转为负；结论在多种风格和低摩擦样本中保持。

## Quant takeaways
- 选对冲基金时可优先测试弱市条件收益，而非简单按总历史收益排序。
- 结果仍可能受风格风险、尾部风险、锁定期、回填和流动性平滑影响；需要净费用、可投资容量和实时可得信息验证。
