# 价值因子已死？

- **source filename**: `20200729-天风证券-海外文献推荐第144期.pdf`
- **date**: 2020-07-29
- **institution / author**: 天风证券；吴先兴、陈可；原文作者 Robert D. Arnott、Campbell R. Harvey、Vitali Kalesnik、Juhani T. Linnainmaa
- **extraction confidence**: high

## Core question
报告讨论价值因子在2007年以来长期跑输成长因子是否意味着结构性失效。原文把价值—成长收益差分解为相对估值变化、风格漂移和盈利能力，检验三者是否在2007年前后发生永久变化。

## Methods / data
- 使用美国股票1963年7月至2020年6月数据，按B/P构造大型与小型价值、成长组合及HML。
- 用Bootstrap对57年收益序列重采样1,000,000次，评估当前最大回撤的异常程度。
- 回归分解HML的相对估值、迁移率和盈利能力，并测试无形资产调整后的iHML及E/P、S/P等替代价值定义。

## Key findings
- 2007年以来HML相对回撤约55.0%，Bootstrap中约2.2%的模拟回撤更差；另一种统计口径给出约5.2%的概率。
- 相对估值变化解释HML月度表现约70%，回归R²约67%；估值变化斜率在2007年前后分别约0.76和0.66。
- 2007年前，风格漂移每年贡献约19.2%，盈利能力拖累约13.2%，结构性价值溢价约5.9%，接近HML长期均值6.1%。
- 2007年后HML年收益约−6.2%，传统B/P价值策略约−5.4%；无形资产调整后的iHML长期每年改善约1%，但近13年仍跑输成长。

## Quant takeaways
- 可将价值收益拆成估值均值回归与结构性溢价，避免把估值扩张误当作稳定alpha。
- 实证价值策略可测试iB/M、E/P、S/P等定义，并按估值分位数做情景分析。
- 结论依赖历史均值回复与美国样本；相对估值可能长期偏离，且B/P受无形资产和会计口径影响。
