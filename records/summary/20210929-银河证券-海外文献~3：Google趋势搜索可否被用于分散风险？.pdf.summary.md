# 海外文献-3 Google 趋势搜索可否被用于分散风险？

- **source filename**: `20210929-银河证券-海外文献~3：Google趋势搜索可否被用于分散风险？.pdf`
- **date**: 2021-09-29
- **institution / author**: 中国银河证券；吴俊鹏
- **extraction confidence**: high

## Core question
报告介绍的文献研究Google Trends搜索热度能否用于股票组合的风险分散，而不仅是预测交易量或价格。核心思路是把搜索热度视作风险代理，降低热门股票权重、提高低热度股票权重。

## Methods / data
- 道琼斯指数30只成分股；周度收盘价和周收益。
- 两类搜索词：股票代码；“stock+股票代码”。搜索热度记为V，权重按V的幂律函数调整，α从-2到2。
- 股票代码样本为2005-01-03—2013-06-24（443周）；组合每周再平衡，比较样本内、样本外标准差和Sharpe。

## Key findings
- 股票代码策略样本内α=0.1时方差最低，样本内Sharpe在α=0.6约0.075，样本外在α=2约0.09。
- 样本外Sharpe约0.09，高于道琼斯指数不足0.045；搜索策略优于等权组合和指数。
- 股票代码策略样本内累计利润109%，样本外163%，道指约38%；但无法规避2008年雷曼冲击。
- “stock+代码”样本外累计利润约88%，高于道指约62%，但4.5年约26%的超额收益可能难以覆盖周度再平衡成本。

## Quant takeaways
- 可将搜索热度作为风险暴露或拥挤度因子，测试幂律权重、分组组合与波动率目标。
- 必须使用当周可获得的搜索数据，严格区分样本内优化和下一周交易。
- 结果偏重DJIA单一市场，搜索数据归一化、代码歧义、换手和交易成本都可能削弱实盘效果。
