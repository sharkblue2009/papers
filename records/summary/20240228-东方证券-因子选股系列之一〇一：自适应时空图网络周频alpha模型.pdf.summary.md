# 20240228-东方证券-因子选股系列之一〇一：自适应时空图网络周频alpha模型

- **源文件**：`20240228-东方证券-因子选股系列之一〇一：自适应时空图网络周频alpha模型.pdf`
- **日期/机构/类型**：2024-02-28，东方证券，金融工程|专题报告

## 核心主题
- 提出将自适应时空图神经网络（ASTGNN）嵌入 RNN 的因子挖掘框架，用于周频 alpha 因子生成。

## 方法与数据
- 网络结构同时挖掘时间维度上的个股演化关系和空间维度上的个股交互关系。
- 邻接矩阵由数据驱动生成，不依赖行业分类、持仓或基本面等人工先验。
- 对 week、day、l2 等多个数据集分别生成单因子，再进行非线性加权形成综合因子，并用于指数增强。

## 关键发现
- week 数据集生成因子表现最好，RankIC 和多头收益率显著优于其他数据集，但波动和回撤也更大。
- ASTGNN 生成的单因子之间相关性普遍低于 GRU，说明挖掘到的个股关联关系更有差异化。
- 相较 GRU，ASTGNN 在各项指标上显著提升：RankIC、ICIR、RankIC>0 占比提高，最大回撤降低。
- 在中证全指、沪深 300、中证 500、中证 1000 上，模型生成因子均带来明显选股提升；在指数增强中，沪深 300 / 中证 500 / 中证 1000 的年化超额分别达到 **16.59% / 22.32% / 31.12%**（含成分股限制与换手约束）。

## 量化要点
- 图结构有助于 RNN 抽取更多信息增量。
- 邻接矩阵动态变化会提高换手率，这是模型应用时需要注意的交易层面代价。

## 局限性
- 新模型虽提升收益，但换手率上升。
- 未来市场结构变化可能影响因子稳定性。
- 报告仅提示“量化模型失效”“极端市场冲击”等风险。
