# 投资者情绪对于异象的解释是否源于“伪回归”？

- **source filename**: `20190925-天风证券-海外文献推荐第105期.pdf`
- **date**: 2019-09-25
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
论文检验投资者情绪对股票收益异象的预测是否只是持续变量造成的伪回归。研究重点是情绪与多空异象收益、空头收益和多头收益之间的联合方向与显著性是否难以由随机序列复制。

## Methods / data
- 分析11组异象，包括动量、盈利、ROE、资产增长、应计等，主要样本期为1965-08至2008-01，部分异象起始更晚。
- 使用Baker-Wurgler情绪指数及Fama-French市场、规模、价值因子，估计36个回归关系。
- 生成一阶自回归随机序列，替代情绪指数，重复模拟2亿次并比较联合t统计量与符号方向。

## Key findings
- 情绪与异象多空收益的正关系，在随机模拟中约每28,500次才出现一次；与空头收益的负关系约每105,000次出现一次。
- 同时支持前两个假设的随机序列平均约46.8万组才有一组；2亿次模拟中没有序列同时满足全部三个假设的显著性和方向性。
- 仅看符号方向时，同时满足后两个假设约每43个随机变量出现一个。
- 即使把所有异象合成单一多空策略，复制情绪结果的概率也约为1/6,580。

## Quant takeaways
- 构造情绪因子时，应使用多组合、联合假设和随机基准检验，而不是只报告单个回归t值。
- 结果支持情绪对异象空头端的影响，做空约束和套利成本应纳入策略解释。
- 模拟依赖自相关过程和既有异象集合，不能排除所有模型设定、样本选择与发表偏差。
