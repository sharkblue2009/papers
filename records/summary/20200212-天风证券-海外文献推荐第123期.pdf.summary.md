# 行业收益的可预测性：使用机器学习方法

- **source filename**: `20200212-天风证券-海外文献推荐第123期.pdf`
- **date**: 2020-02-12
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告讨论滞后行业收益能否预测未来行业收益，以及这种预测是否具有可交易的经济价值。核心机制是行业间信息逐步扩散造成价格延迟调整。

## Methods / data
- 使用Kenneth French数据库30个价值加权行业组合，月度超额收益，1959年12月至2016年12月；样本内684个月。
- 以30个滞后行业收益为候选变量，使用LASSO选择变量，再用OLS post-LASSO减轻系数收缩偏差；采用Benjamini–Hochberg方法控制多重检验。
- 样本外从1971年1月至2016年12月（564个月），按预测收益分五组，做多最高组、做空最低组，并与均值及OLS基准比较。

## Key findings
- LASSO选出167个滞后行业收益；29个行业至少选中一个预测变量，22个行业选中多个；其中82个在10%水平、53个在5%水平显著。
- post-LASSO行业轮动组合年化平均收益7.33%、夏普比率0.65，最大回撤和下行风险优于基准。
- 相对OLS基准，风险调整后的年化alpha高出200个基点以上；多空组合在主流多因子模型下实现超过8%的年化alpha，衰退期表现仍较好。

## Quant takeaways
- 可将行业滞后收益构造成稀疏的行业网络预测器，重点复验动态成分而非静态相关。
- 必须严格使用滚动样本外估计、post-LASSO及多重检验控制，避免高维行业信号过拟合。
- 报告未给出完整交易成本、容量和实时数据延迟分析；落地时需检验行业ETF可交易性及衰退期换仓成本。
