# 文档摘要

- 来源文件：`20240902-东北证券-股票投资中的赔率 胜率 DCF与PB~ROE.pdf`
- 日期：2024-09-02
- 机构：东北证券
- 类型：金融工程研究报告

## 核心主题
讨论股票投资中的“赔率/胜率”概念，并将其与 DCF 估值和 PB-ROE 框架联系起来，强调赔率与胜率并非独立。

## 方法与数据
- 主要采用理论分析与估值框架梳理，而非单纯的单因子回测。
- 讨论静态估值、历史分位数、预期估值、公允估值之间的关系。
- 以 PB_LF、PB_FY1、ROE_LY、ROE_FY1 等指标对赔率/胜率进行表征。
- 用 PB-ROE 动态关系表达“价格、盈利与估值”的统一逻辑。

## 关键发现
- 股票投资的赔率，不能只看当前估值或历史分位数，更应比较**预期估值与当前估值/公允估值的差异**。
- 股票投资的胜率不仅受宏观变量影响，也与公司个体基本面密切相关。
- DCF 可以被视为股票投资“第一性原理”的量化表达，集中体现未来现金流与折现率对价值的影响。
- PB-ROE 关系同样可统一表达赔率与胜率：预期 PB、动态 PB 与 ROE 的组合能更完整刻画投资决策。
- 报告最终强调，赔率和胜率应当结合基本面与内含价值一起看，而不是割裂判断。

## 量化要点
- 把“安全边际”理解为预期价值与当前价格之间的差异。
- 赔率更偏向估值偏离，胜率更偏向基本面兑现概率。
- 该框架适合作为多因子研究的价值判断底座。

## 局限性
- 以理论推演为主，实证验证更多是辅助性质。
- 估值和胜率的显性代理变量都只是近似量，存在较强不确定性。
