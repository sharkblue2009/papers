# PDF摘要
- 源文件：20241114-华福证券-从反弹到反转交易方案.pdf
- 日期：2024-11-14
- 机构：华福证券
- 类型：证券研究报告 / 金融工程专题
- 核心主题：区分“底部反弹”和“趋势反转”，并给出基于市场交易特征的底部择时方案。
- 方法/数据：复盘历史市场特殊时点，从成交量、换手率、热点扩散、政策与基本面等维度梳理反弹/反转差异；进一步使用技术面与价量特征工程，结合tsfresh提取高维特征并用LDA做分类，同时构建手工阈值信号做交易。
- 关键发现：反弹与反转在成交量、换手率等交易结构上有共性，通常都呈现“先高后低”，但在形态、题材承接、资金扩散和政策/基本面支撑上可区分；本次行情更偏向反转逻辑。
- 量化要点：底部反弹策略年化收益17.74%，相对指数超额10.86%；按单因子夏普筛选前20个衍生特征，若其中10个以上同时发信号则持有指数，历史上对2008、2012、2014、2019、2020等反弹节点有提示；最新截面信号为8，历史上该阈值对应较高胜率与赔率。
- 局限性：策略依赖历史形态复现，样本区间较短且对政策和市场结构变化敏感，信号在极端环境下可能失效。
- 关键词：反弹；反转；底部择时；tsfresh；LDA；价量因子；交易信号
