# 使用机器学习法推理基金配置

- **source filename**: `20200422-天风证券-海外文献推荐第133期.pdf`
- **date**: 2020-04-22
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告研究仅凭基金或ETF每日净值序列，能否从庞大候选股票池中推断组合成分，并比较延伸线性克隆法（ELC）与顺序震荡选择法（SOS）的识别能力。

## Methods / data
- 将未知组合成分视为候选股票池中的特征选择问题，以布尔分类准确率和Matthews相关系数（MCC）评价成分识别。
- 候选池为S&P 500，目标为9只行业ETF；使用含股息历史价格，12个月样本自2013年10月起。
- ELC允许因子数量和权重可变；SOS逐步加入能够提高拟合能力的候选股票，并比较运行时间。

## Key findings
- ELC准确率0.068—0.725，均值0.357；SOS为0.882—0.986，均值0.933，平均错误分类比ELC少90%。
- ELC的MCC为0.000—0.365、均值0.170；SOS为0.561—0.891、均值0.664，属于强至非常强相关。
- ELC平均运行3.38秒，SOS平均11.48秒（范围8.82—15.41秒）；设置最大100只成分、最小权重1%后两者均改善。

## Quant takeaways
- SOS适合用于ETF复制、持仓披露核验和潜在粉饰账面检测，但识别成分不等于精确估计权重。
- 应优先使用MCC等适合不平衡分类的指标，避免候选池巨大时准确率被多数类抬高。
- 方法依赖高流动性、每日价格和短期稳定持仓；基金风格变化、隐含现金和衍生品会造成识别偏差。
