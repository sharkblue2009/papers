# 分析师共同覆盖：统一的动量溢出效应

- **source filename**: `20211105-东兴证券-海外文献速览系列之十：分析师共同覆盖，统一的动量溢出效应.pdf`
- **date**: 2021-11-05
- **institution / author**: 东兴证券；高智威；原文作者Usman Ali、David Hirshleifer
- **extraction confidence**: high

## Core question
文献检验分析师共同覆盖能否统一行业、地域、客户供应链和技术联系下的动量溢出效应。核心假设是共同覆盖反映更细粒度的基本面联系，投资者有限关注导致关联公司的信息传递不充分。

## Methods / data
- 美国NYSE、Nasdaq、Amex普通股；CRSP、IBES及Compustat，1983-12—2015-12。
- 若过去12个月至少一名分析师同时覆盖两家公司，则定义为connected firms；按共同分析师人数加权CF收益。
- 月末五分位排序、价值/等权多空组合、Fama-MacBeth和跨越回归；控制市场、规模、价值、动量和短期反转。

## Key findings
- CF动量五因子alpha为月均1.68%，t=9.67，信息比率1.71；大盘股样本也显著。
- 控制CF动量后，行业、地域、客户/供应商行业和技术动量的alpha大多变为不显著或为负。
- CF多空组合价值加权、等权五因子alpha分别为月均1.19%（t=6.71）和2.10%（t=11.88）；十分位排序达1.52%和2.67%。
- 1个月策略收益约133bp、换手313%，盈亏平衡交易成本约42.5bp；12个月策略收益90bp、换手119%。

## Quant takeaways
- 可用分析师共同覆盖网络构造有向或加权溢出因子，测试其对行业动量的增量解释力。
- 实证时须滞后IBES、供应链和专利信息，并对小盘股、流动性和共同分析师数量做分层。
- 高换手和美国市场数据可得性是主要落地约束，跨市场迁移需重新验证。
