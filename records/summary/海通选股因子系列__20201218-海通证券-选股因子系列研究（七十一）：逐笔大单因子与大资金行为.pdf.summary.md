# 海通证券选股因子系列研究（七十一）：逐笔大单因子与大资金行为

- **source filename**: `20201218-海通证券-选股因子系列研究（七十一）：逐笔大单因子与大资金行为.pdf`
- **date**: 2020-12-18
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、余浩淼
- **document type**: 金融工程专题报告

## Core question
逐笔大单因子是否真的能刻画“大资金行为”，以及它能否和基金重仓、增持等资金持仓信号联动。

## Methods / data
对比交易异动股票中披露的前五大买入营业部成交占比与大单因子关系；剔除异动效应后检验大单因子；再结合基金季报里的重仓与增持组合，测试增强效果。

## Key findings
- 异动股票中披露的买入营业部集中度与大单因子相关度较高，说明大单因子确实能捕捉大资金行为。
- 交易异动股票本身长期收益偏负，剔除异动效应后，大单因子的选股效果和稳定性都明显增强。
- 基金重仓股、基金增持股在基金定期报告披露前表现较好，尤其报告前约2个月更明显。
- 用非流动性、剔除大买的大卖、正交后的大买等因子去增强上期基金重仓组合，可以在披露前两个月拿到显著正向收益。

## Quant takeaways
大单因子更像“大资金足迹”的代理变量；把异动事件和基金披露窗口剥离出去后，信号更纯、更稳定。

## Caveats
异动股票和基金披露类信号都带有事件/公告窗口属性；实际交易要防止信息滞后和样本选择偏差。
