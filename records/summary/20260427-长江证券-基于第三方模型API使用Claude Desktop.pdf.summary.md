# 研报摘要
- 源文件：20260427-长江证券-基于第三方模型API使用Claude Desktop.pdf
- 文档类型：券商 AI 投研应用点评报告
- 核心主题：通过第三方模型 API 在 Claude Desktop 中启用 Cowork/Code 能力。
- 方法/数据：基于 Anthropic 官方文档更新与智谱 API 实测，验证第三方推理接入、Claude Cowork 工作流编排和简单研报整理能力。
- 关键结论：Claude Desktop 正从单一模型入口演变为可接入第三方推理后端的本地 AI 工作台；通过 GLM API 可正常使用 Cowork/Code。
- 量化要点：报告偏应用测试，未给出严格收益指标；实测表明 GLM 驱动的 Cowork 可完成摘要、对比等基础投研任务。
- 注意事项：第三方模型接入存在数据泄露与权限风险；功能稳定性依赖 API 与平台策略。
- 关键词：Claude Desktop、第三方API、Cowork、Code、GLM、投研工具
