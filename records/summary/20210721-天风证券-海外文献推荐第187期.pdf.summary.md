# 货币政策的非对称效应

- **source filename**: `20210721-天风证券-海外文献推荐第187期.pdf`
- **date**: 2021-07-21
- **institution / author**: 天风证券研究所；吴先兴（分析师）；原文作者 Morten O. Ravn、Martin Sola
- **extraction confidence**: high

## Core question
检验货币政策冲击对实际产出的影响是否因冲击方向、大小或方差状态而不对称，并比较传统凯恩斯不对称与菜单成本机制。

## Methods / data
- 分析美国战后两组季度数据：1948—1987年以M1衡量货币政策，1960—1995年以联邦基金利率（负值）衡量。
- 建立货币政策方程与产出方程，区分正负冲击及大小冲击，并用离散状态区制转换模型刻画均值和方差变化。
- 通过似然比检验比较货币中性、正负冲击不对称、大冲击中性及“小的负冲击有效”等限制。

## Key findings
- M1样本支持负货币冲击比正冲击具有更大实际影响，但不能完全排除冲击对称或传统凯恩斯不对称。
- M1需求不稳定可能混合了货币需求与供给冲击；改用联邦基金利率后，证据更清晰。
- 联邦基金利率结果强烈支持“混合不对称”：只有小的负向货币政策冲击具有显著实际影响，大冲击及正冲击更接近中性。

## Quant takeaways
- 宏观择时可区分冲击方向、幅度和波动状态，而不能只使用货币政策变动的线性暴露。
- 结论依赖政策代理变量、样本阶段和区制设定；量化策略需做状态切换、滞后结构、识别和结构断点稳健性检验。
