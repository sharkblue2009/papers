# 基于模式聚类的短线选股模型

- **source filename**: `20110830-国信证券-数量化投资系列报告之四十二：基于模式聚类的短线选股模型.pdf`
- **date**: 2011-08-30
- **institution / author**: 国信证券；董艺婷、郑亚斌
- **extraction confidence**: high

## Core question
检验成交价格和成交量是否存在可重复的短线形态，并用模式聚类构建选股模型。研究重点是价格模式、成交量模式及价量组合对未来短线收益的预测能力。

## Methods / data
- 使用中证800历史成分股，样本期2005年3月28日至2011年3月14日；每个样本为过去3个交易日的15分钟K线，共48个点。
- 以关键点折线拟合并归一化，采用层次K-means聚类；价格得到198个中心、成交量得到194个中心。
- 以第二天开盘前1小时VWAP买入、第三天开盘前1小时VWAP卖出，持有3小时；用Average Precision组合价格和成交量模式，形成Top20/Bottom20。

## Key findings
- 共121,939个价格时间序列样本；价量组合中价格权重lambda的峰值多在0.8—0.9，20个优选模式的lambda均大于0.5。
- 样本内Top组合在0.6%交易成本下，除2005、2006、2010年外多数指标胜率超过50%；6527个VWAP样本持有3小时平均收益0.833%。
- 样本外整体下跌阶段Top组合表现受挫，Bottom组合相对更稳，说明模式效果高度依赖市场状态。

## Quant takeaways
- 价量模式应优先以价格形态为主、成交量为辅，并严格按距离排序和样本数量控制过拟合。
- 结果为样本内研究，样本外反转且缺乏完整风险指标；需加入交易成本、容量、滚动训练和不同持有期检验。
