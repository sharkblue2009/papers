# 通胀时期的最优策略

- **source filename**: `20210811-天风证券-海外文献推荐第190期.pdf`
- **date**: 2021-08-11
- **institution / author**: 天风证券研究所；吴先兴（分析师）；原文作者 M. Brière、A. Oros 等
- **extraction confidence**: high

## Core question
在通胀意外上升和通胀持续飙升时期，股票、债券、商品、另类资产及主动策略能否保护实际财富，并如何重新配置组合。

## Methods / data
- 回顾美国、英国和日本过去约95年的资产收益，区分预期与未预期通胀，并定义通胀冲击时期。
- 比较股票、债券、现金、不同商品、房地产、艺术品等被动资产，以及趋势跟踪、质量、价值等主动策略。
- 重点考察本地通胀对名义和实际收益、相关性及跨资产分散化的影响。

## Key findings
- 美国历史上8个通胀时期中，股票实际年化回报约-7%，10年期国债约-5%，而商品平均实际回报约+14%，但商品之间差异很大。
- 未预期通胀对股票和债券最不利，本地通胀冲击通常比全球通胀影响更强。
- 趋势跟踪在重大通胀冲击中提供最稳定的保护；质量和价值主动因子也有一定对冲能力。
- 另类资产和加密货币可能具有理论上的通胀对冲逻辑，但历史样本和经济机制仍不足以形成稳健结论。

## Quant takeaways
- 通胀状态应拆分为水平、意外成分和持续性，分别测试商品、久期、质量/价值和趋势信号。
- 商品的平均正收益不能替代品种级研究；需加入换仓、期货展期、流动性、通胀发布滞后和结构变化风险。
