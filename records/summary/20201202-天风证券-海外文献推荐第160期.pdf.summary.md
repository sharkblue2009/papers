# 因子的两种类型：基于因子组合的收益分解

- **source filename**: `20201202-天风证券-海外文献推荐第160期.pdf`
- **date**: 2020-12-02
- **institution / author**: 天风证券；吴先兴；原文作者 Joseph Kushner
- **extraction confidence**: high

## Core question
本文把因子组合收益拆分为基本面业绩增长和估值变化两部分，回答价值、动量、质量及V-Q因子的超额收益究竟来自企业经营改善还是市场估值重估。该分解帮助投资者识别因子的风险收益来源。

## Methods / data
- 使用美国罗素3000、标普500、富时USA和MSCI USA成分股，Compustat财务数据与Bloomberg市场数据。
- 样本为1984年6月至2015年12月；价值、质量和V-Q因子每年6月再平衡，动量因子每月再平衡。
- 每次按因子指标取前30%和后30%构造市值加权多空组合，再将收益分解为账面价值增长/分红带来的基本面收益与估值变化收益。

## Key findings
- 市场年化收益约11.5%，其中基本面收益约7.6%、估值变化约4.0%，波动率约15.1%。
- 价值因子多空收益约0.3%，动量和质量约2.3%，V-Q约4.2%；价值和V-Q主要依靠估值增长，基本面增量为负。
- 动量和质量主要从优质企业的基本面增长获利，但持仓估值下降提供负向增量。
- 分解结果不能进一步判断估值变化来自现金流预期还是折现率变化，且财报披露滞后会造成时间错配。

## Quant takeaways
- 因子组合评估应同时跟踪盈利增长、账面价值增长、分红和估值倍数变化，而非只看总收益。
- 可用分解结果做因子配置：偏好基本面收益的投资者可提高质量/动量，偏好估值修复的投资者可配置价值。
- 估值变化不等于错误定价；财报滞后、再平衡频率、行业构成和会计口径会影响分解。
