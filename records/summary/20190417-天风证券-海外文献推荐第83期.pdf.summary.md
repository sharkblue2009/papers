# 基金经理的运气与技能

- **source filename**: `20190417-天风证券-海外文献推荐第83期.pdf`
- **date**: 2019-04-17
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告讨论美国主动权益共同基金的总和收益是否接近市场基准，以及个别基金的超额收益究竟来自经理技能还是随机运气。研究用Bootstrap构造Alpha为零的反事实分布，比较真实基金横截面尾部。

## Methods / data
- 样本为1984–2006年美国主动权益共同基金，最终约3156只基金；基金规模、存续年限设定门槛以减轻孕育偏差。
- 使用CAPM、Fama-French三因子和Carhart四因子模型估计Alpha，分别考察等权和市值加权组合。
- 对残差进行有放回抽样，进行1万次Bootstrap；模拟收益保留共同时间冲击和基金间相关性，但将真实Alpha设为零。

## Key findings
- 全市场主动基金扣费前收益总体接近市场基准，扣费后等权和市值加权Alpha均为负。
- 若真实Alpha均值为零，其年化标准差约1.25%；Alpha超过1.25%的基金少于16%，超过2.5%的约2.3%。
- 净收益检验显示，真实Alpha左尾明显差于模拟分布；右尾仅少数基金接近模拟分布，只有少部分经理的技能足以覆盖成本。
- 加回管理费后，右尾出现优秀经理的迹象，但不能据此证明所有高Alpha都不是运气。

## Quant takeaways
- 基金筛选应同时报告净收益和总收益Alpha，并用Bootstrap或置换检验评估尾部是否超出纯噪声。
- 不能只看历史排名持续性；基金费用、规模门槛、样本选择和因子模型设定都会改变技能判断。
- 样本期较早且基于美国基金，实际应用还需加入交易成本、税费和实时可投资约束。
