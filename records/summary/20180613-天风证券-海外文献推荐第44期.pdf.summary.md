## Core question
本文讨论如何为对冲基金 FOF 构造更符合投资者目标的组合。核心不是单纯最大化均值—方差，而是同时提高超过积极基准的概率，并控制低于最低可接受基准时的预期遗憾。

## Methods / data
- 使用 13 个 CSFB/Tremont 对冲基金指数，包括可转债套利、股票市场中性、事件驱动、全球宏观、管理期货等。
- 样本为 1994-04 至 2003-03 的 108 个月收益；用各资产边际经验分布和历史相关矩阵，经 NORTA 生成非正态联合分布。
- 通过蒙特卡洛模拟优化“超过基准概率—下行预期遗憾”效用函数，并与传统均值—方差组合比较。

## Key findings
- 目标组合以超过 10% 年收益为积极基准、0% 为最低基准；其超过积极基准的概率与均值—方差组合接近，但波动率低约 40%。
- 目标组合约 53% 配置于可转债套利，年化波动率约 4.85%；均值—方差组合配置约 35% 全球宏观（年化波动率 12.55%）和 25% 困境债务（7.11%）。
- 相对 0% 基准的预期遗憾比均值—方差最优组合低约 53%。

## Quant takeaways
- FOF 优化可把“达标概率”和下行损失作为直接目标，适合有绝对收益考核的场景。
- 结果高度依赖边际分布、相关矩阵、历史窗口和模拟误差；应加入权重、容量、流动性和估计不确定性约束，并进行滚动样本外检验。
