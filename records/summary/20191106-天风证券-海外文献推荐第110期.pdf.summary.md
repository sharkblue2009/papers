# 时间的关联规则挖掘：美国股市中的应用

- **source filename**: `20191106-天风证券-海外文献推荐第110期.pdf`
- **date**: 2019-11-06
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
论文将时间关联规则挖掘应用于金融时间序列，寻找在移动时间窗口内重复出现、可用于交易的事件组合，并检验这些规则是否超出随机发生频率。

## Methods / data
- 时间序列数据库覆盖1994-2007年，由道琼斯工业平均指数及其代表性成分股日最高成交量、指数点位构成。
- 先用SAX和PAA把连续序列离散成符号，再以支持度、置信度筛选关联规则。
- MOWCALT提取频繁规则，MIST利用向下闭合性质递归细化规则，Z检验过滤偶然规则。
- 在多周期组合优化中，与等权和均值—方差模型比较规则学习组合表现。

## Key findings
- 模拟测试中筛出的18条规则平均胜率约66%，平均置信度约95%；发现期与测试期不同，仍保持类似结果。
- 规则触发次数相对较少，显示高置信度并不等于高交易频率。
- 组合优化结果显示，规则学习模型的最终收益、平均月收益和月度Sharpe均高于等权及均值—方差基准；提取文本未完整呈现表中所有数值。
- MIST通过只对相关高频规则继续细化，降低了规则数量指数增长带来的计算和内存成本。

## Quant takeaways
- 规则挖掘可作为事件驱动或状态识别的候选信号生成器，但必须使用独立测试区间和随机化显著性检验。
- 交易系统应同时约束单资产权重、组合风险和规则触发频率，防止少量样本支撑高置信度。
- 研究使用特定指数和少数股票，需在更广泛资产、不同窗口、滑点和多重检验下复现。
