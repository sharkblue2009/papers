# COVID-19期间共同基金的业绩表现和资金流动

- **source filename**: `20201223-天风证券-海外文献推荐第162期.pdf`
- **date**: 2020-12-23
- **institution / author**: 天风证券；吴先兴；原文作者 Lubos Pastor、M. Blair Vorsatz
- **extraction confidence**: high

## Core question
本文考察2020年COVID-19危机期间美国主动股票共同基金是否提供了投资者所需的危机保护，以及基金业绩和资金流动是否与可持续性评级、星级和投资风格有关。

## Methods / data
- 使用Morningstar Direct 2017年1月至2020年4月30日的日度数据，样本为3,626只危机期有净回报的美国主动股票基金。
- 将危机定义为2020年2月20日至4月30日，并与S&P 500、FTSE/Russell、招股说明书基准及因子基准比较。
- 以晨星可持续性评级、星级、成长/价值分类解释基金收益和净流量，使用扣费后回报。

## Key findings
- 截至4月30日，S&P 500价格指数为86.01，主动基金平均为82.45；相对FTSE/Russell基准低1.53%，相对招股说明书基准低0.94%，相对S&P 500低4.77%。
- 危机期间主动基金约流出1.3%的资产，流出速度快于长期趋势但差异不显著。
- 可持续性评级和危机前星级对危机期业绩具有单调预测力，高评级基金表现更好；成长基金优于价值基金。
- 投资者仍偏好可持续性较高、尤其环保主题的基金，显示可持续性在危机中仍被视为重要属性。

## Quant takeaways
- 基金筛选可结合危机期相对基准收益、可持续性评级与星级，但必须使用危机前信息。
- 资金流研究应区分业绩驱动、评级驱动和市场流动性冲击，并控制基金规模与风格。
- 结论只覆盖一次极端危机；评级可能与成长、行业和规模暴露共线，不能直接解释为经理能力。
