# 海外文献-4 通过量化维基百科的使用模式预测股市变动

- **source filename**: `20210929-银河证券-海外文献~4：通过量化维基百科的使用模式预测股市变动.pdf`
- **date**: 2021-09-29
- **institution / author**: 中国银河证券；吴俊鹏
- **extraction confidence**: high

## Core question
报告介绍的文献考察维基百科财经页面的浏览或编辑活跃度，能否作为投资者交易前信息收集行为的代理，并预测道琼斯指数后续走势。重点是区分浏览量信号与无关主题的流量。

## Methods / data
- Wikipedia英文页面浏览、编辑数据，2007-12-10—2012-04-30；DJIA及成分股。
- 以当周活跃度相对前Δt周均值的变化决定下周做多或做空DJIA，Δt=1—10周；每周开平仓。
- 比较285个财经页面、30只成分股页面、233个演员/电影人页面与10,000次随机策略，采用Wilcoxon和Kruskal-Wallis检验。

## Key findings
- 30只成分股页面浏览策略平均R=0.50，显著优于随机策略（p=0.005）；编辑策略平均R=-0.09且不显著。
- 285个财经页面浏览策略平均R=1.10，显著优于随机策略（p<0.001）；编辑策略平均R=0.12、p=0.19。
- 财经页面浏览减少后，下一周DJIA平均收益0.27%；浏览增加后为-0.21%，均显著偏离零。
- 2008—2011年浏览策略均显著优于随机策略；Δt从1到10周时收益仍显著为正。演员/电影人页面策略平均R=0.04、p=0.59。

## Quant takeaways
- 可把财经页面浏览变化测试为风险厌恶、信息搜寻或市场压力信号，并用滞后信号避免同步偏差。
- 需要扣除趋势、节假日和网页结构变化，加入交易成本及做空限制。
- 研究期包含金融危机，且结论依赖DJIA和页面筛选；浏览量与价格之间的因果方向仍未识别。
