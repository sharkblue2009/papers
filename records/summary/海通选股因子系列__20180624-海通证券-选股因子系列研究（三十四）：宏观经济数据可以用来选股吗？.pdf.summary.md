# 海通证券选股因子系列研究（三十四）：宏观经济数据可以用来选股吗？

- **source filename**: `20180624-海通证券-选股因子系列研究（三十四）：宏观经济数据可以用来选股吗？.pdf`
- **date**: 2018-06-24
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、吕丽颖
- **document type**: 金融工程专题报告

## Core question
把宏观经济数据从资产配置/行业轮动工具，尝试下沉到个股选股层面。

## Methods / data
用宏观敏感性（MacroBeta）刻画股票对宏观指标的暴露，并讨论宏观数据清洗、差分、Surprise 替代和组合模拟等处理方式。

## Key findings
- 宏观敏感性因子在未控制风格时看似有效，但剥离市值等风格后，单独选股能力显著下降。
- 宏观敏感性更多是在描述“股票与宏观指标的方向和强度”，不是独立 alpha。
- 正确用法是先判断宏观方向，再选正/负敏感股票构造宏观得分。
- 与企业经营更直接相关的宏观指标，其敏感性稳定性相对更好。

## Quant takeaways
- 宏观因子更适合作为风控或方向判断工具，而不是直接的选股 alpha。
- 宏观数据必须先做预处理，否则噪声和发布滞后会严重干扰结论。

## Caveats
- 若宏观判断错方向，敏感性因子可能反向拖累组合。
