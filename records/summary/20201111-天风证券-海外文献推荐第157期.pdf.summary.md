# 在分散化收益的视角下Smart Beta是否仍然Smart？

- **source filename**: `20201111-天风证券-海外文献推荐第157期.pdf`
- **date**: 2020-11-11
- **institution / author**: 天风证券；吴先兴；原文作者 Wenguang Lin、Gary C. Sanger
- **extraction confidence**: high

## Core question
本文重新检验等权和基本面加权等Smart Beta策略的超额收益来源，比较“有效因子”倾斜与分散化收益的解释力。核心结论是，另类加权策略通过再平衡提高组合分散化收益，可能完全解释其相对市值加权指数的表现。

## Methods / data
- 使用1972—2013年美国股票，构造市值加权、等权和基本面加权指数，并进行行业间及行业内分层。
- 以组合几何收益减去成分股几何收益加权平均值定义分散化收益，比较累计价值、风险收益和因子模型alpha。
- 用Fama-French三因子、Carhart四因子及加入DRET的模型检验Smart Beta收益是否仍有独立alpha。

## Key findings
- 1972—2013年等权相对基本面加权的累计价值约144.40美元，年化几何收益约12.57%，Sharpe约0.52。
- 基本面加权超额收益大部分来自行业内部，而非单纯行业配置。
- 在扣除分散化收益后，市值加权、等权和基本面加权之间的大多数alpha消失；因子倾斜不能提供额外解释。
- 结果在多个业绩指标和主流因子模型下稳健，支持再平衡和低相关持仓是主要收益来源。

## Quant takeaways
- 评价Smart Beta时应将几何收益拆为成分股收益与分散化收益，避免把再平衡溢价重复计为因子alpha。
- 可在行业内构造另类权重，比较行业中性、换手和分散化收益的边际贡献。
- 分散化收益依赖波动率、相关性和再平衡频率；交易成本、容量与样本期会显著影响可实现收益。
