# 哪种ETF能够为标普500提供下行保护？

- **source filename**: `20190904-天风证券-海外文献推荐第102期.pdf`
- **date**: 2019-09-04
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告汇总ETF.com的多篇文章，讨论收益率曲线倒挂、经济衰退担忧如何改变美国ETF资金流，并比较哪些ETF可在持有标普500的同时提供下行保护。

## Methods / data
- 观察2019年上半年美国ETP发行、2019年8月利率倒挂及ETF资金流。
- 比较企业债、黄金、必需消费、公用事业、低波ETF等资金方向。
- 介绍UTRN短期反转策略、BJUL缓冲ETF和PHDG下行对冲组合，侧重产品机制与历史表现。

## Key findings
- 10年期国债收益率短暂低于2年期；SPY下跌2.2%，TLT上涨2.1%，IEF上涨0.7%，GLD单日上涨1.1%、年初至今约18%。
- 7月12日至8月12日，HYG、LQD、VCIT分别流出13.9、13.8和9.49亿美元；GLD近30日流入21.8亿美元，USMV流入19.6亿美元。
- UTRN自2006年至今捕捉标普500上行机会约87%、下行时成功率约80%；规模约2800万美元、费率0.75%。
- BJUL提供标普500下跌前9%的缓冲，但上行收益上限约14%，每年6月重置。

## Quant takeaways
- 可将UTRN、缓冲ETF与传统指数做条件收益、回撤和成本比较，而非只看牛市收益。
- 利率倒挂并不提供精确衰退时点；应把产品缓冲、收益上限、费率和流动性纳入组合回测。
- 文中多数数据为产品报道和阶段性资金流，不能替代长期样本外风险评估。
