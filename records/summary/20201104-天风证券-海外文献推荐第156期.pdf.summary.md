# 资产配置vs.因子配置——我们能否构建一类两者兼顾的策略？

- **source filename**: `20201104-天风证券-海外文献推荐第156期.pdf`
- **date**: 2020-11-04
- **institution / author**: 天风证券；吴先兴；原文作者 Jennifer Bender、Jerry Le Sun、Rick Thomas
- **extraction confidence**: high

## Core question
本文讨论传统按股票、债券、商品等资产类别配置，能否与按宏观和风格因子配置相结合。目标是建立同时捕捉战略长期暴露与战术短期机会的多资产因子框架，缓解危机期间资产分散化失效的问题。

## Methods / data
- 将资产收益表示为宏观因子和风格因子暴露加残差，估计资产对因子的敏感度。
- 依次选择宏观状态变量与风格因子、估计暴露、构造因子模拟组合、预测因子收益，再优化因子权重和资产类别期望收益。
- 同时纳入定量预测与投资者对资产—因子关系的定性判断，形成最终组合。

## Key findings
- 报告认为少数系统因子可驱动广泛资产收益，因子配置比单纯资产类别分散更能控制共同风险。
- 框架同时适用于战略配置和战术配置，并允许对经济增长、通胀及价值、动量等暴露设定目标。
- 文本给出的实证图表显示，三类组合Sharpe比率约0.82—0.94，年化换手率约23%，信息比率约0.52—0.75。
- 结论强调因子预测模型的稳健性是落地难点，不能把历史因子溢价直接视为未来收益。

## Quant takeaways
- 可先做资产对因子的滚动时间序列回归，再在因子层面进行Black-Litterman式观点融合和优化。
- 资产配置回测应比较资产权重、因子权重及危机期风险贡献，检验分散化是否真正来自独立风险源。
- 因子定义、暴露估计和协方差预测均有模型风险；交易成本、杠杆和卖空限制会改变结果。
