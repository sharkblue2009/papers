# 研报摘要

- **来源文件**：20260317-西部证券-因子手工作坊系列（5）：知情交易的微观行为特征与因子挖掘.pdf
- **日期/机构/类型**：2026-03-17，西部证券，金融工程专题报告
- **核心问题**：能否从交易量与交易间隔的微观行为中识别知情交易者，并将其转化为可用于选股和增强的因子？
- **方法/数据**：基于“成交量分布 + 交易时间间隔”两个维度刻画知情交易者偏好“均匀下单”的行为特征，构建 IT 因子；用A股市场数据做双周频检验，并将因子用于多头选股和中证1000增强。
- **关键结论**：IT 因子能够较好捕捉知情交易痕迹，且对未来收益具有较强预测能力；相关多头组合显著跑赢基准，可直接用于指数增强。
- **量化要点**：IT 因子双周 RankIC 均值约 **0.064**；Top 100 多头组合年化收益 **25.9%**，显著跑赢万得全A；用于中证1000增强时能带来较稳定超额。
- **局限性**：数据来自第三方且可能有遗漏、滞后和误差；因子构造与筛选框架为研究团队自建，可能存在样本依赖；历史业绩不代表未来。
- **关键词**：知情交易、微观结构、交易间隔、成交量、IT因子、A股增强
