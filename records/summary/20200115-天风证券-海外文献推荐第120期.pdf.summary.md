# 共同基金业绩，管理团队与董事会

- **source filename**: `20200115-天风证券-海外文献推荐第120期.pdf`
- **date**: 2020-01-15
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
论文解释团队管理基金为何快速普及但平均业绩未必更高，重点检验董事会监督是否缓解团队中的搭便车问题，以及董事会规模和独立性是否调节团队与个人管理基金的相对表现。

## Methods / data
- 样本为1998-2007年1026只美国主动管理股票基金，剔除指数和ETF；数据来自Morningstar及基金SAI文件。
- 用团队管理虚拟变量、董事会规模对数和独立董事比例刻画治理结构。
- 以Carhart四因子alpha衡量风险调整绩效，控制基金规模、年龄、现金、换手、机构持有、投资目标和时间。
- 使用团队×董事会特征交互项、Heckman选择模型、管理风格不变样本和内生性检验。

## Key findings
- 单独比较团队与个人管理基金，绩效差异不显著；团队结构的效果取决于治理条件。
- 团队×独立董事比例交互项为正且在1%水平显著，独立董事越多，团队基金alpha越高，而个人基金可能受负面影响。
- 团队×董事会规模显示更小董事会更有利于团队监督；董事会治理交互项联合检验F=2.55、p=0.038。
- 管理结构变化、Heckman和线性内生性检验后，独立董事对团队基金的正向作用仍稳健。

## Quant takeaways
- 基金筛选可把管理结构与治理结构联合建模，而非把团队/个人作为单一风格标签。
- 需关注管理人自选、基金家族制度、董事会定义和Carhart alpha窗口，避免治理变量内生偏差。
- 研究样本止于2007年，监管规则和团队化趋势变化后应重新验证交互效应。
