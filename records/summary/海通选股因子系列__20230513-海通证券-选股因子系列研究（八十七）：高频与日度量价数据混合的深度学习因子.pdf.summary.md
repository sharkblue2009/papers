# 海通证券选股因子系列研究（八十七）：高频与日度量价数据混合的深度学习因子

- **source filename**: `20230513-海通证券-选股因子系列研究（八十七）：高频与日度量价数据混合的深度学习因子.pdf`
- **date**: 2023-05-13
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 金融工程专题报告

## Core question
把高频特征和日度量价特征放在一起训练，是否能比“只做高频”挖掘出更多增量 alpha。

## Methods / data
将 **26 个日频特征** 与 **64 个 60 分钟频特征** 一起输入深度学习模型，并延长训练迭代周期，形成混频因子；同时比较与线性加权复合、以及正交层生成多因子的方案；并在中证500、中证1000增强组合中测试。

## Key findings
- 5日和10日预测标签下，混频因子都表现出较强的周度选股能力。
- 周均 IC 约 **0.10**，TOP10% 和 TOP100 多头组合的多路径平均年化超额收益约 **30%** 和 **35%**。
- 因子在 **中证800/1000之外**、以及**成交额高、市值居中**的股票上更强；在沪深300成分中也能保持正贡献，但相对弱一些。
- 把低频与高频特征一起输入深度学习模型，通常优于只做后验线性复合；混频训练能拿到更高的 IC，整体 ICIR、RankIC、胜率也较均衡。
- 用混频因子做指数增强时，**中证500** 在无成分股约束下年化超额最高可到 **22%**，加约束后降至 **16%**；**中证1000** 约在 **25%** 左右，受成分约束影响较小。
- 另一个扩展是通过正交层一次性生成多个互相正交的增量因子，32 个因子在周频上仍可取得约 **0.03-0.04** 的 IC 和 **5%-12%** 的 TOP10%超额。

## Quant takeaways
混频模型说明：高频与日度信息并不是替代关系，而是互补关系；在更接近真实交易和更长训练窗口下，日度信息能给高频模型带来显著增量。

## Caveats
对标的池和成分股约束较敏感；约束越强，增强组合的收益越容易被压缩。
