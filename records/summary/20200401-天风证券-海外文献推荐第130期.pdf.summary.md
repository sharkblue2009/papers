# 什么时候基金管理技能更有价值？

- **source filename**: `20200401-天风证券-海外文献推荐第130期.pdf`
- **date**: 2020-04-01
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: medium

## Core question
报告考察基金经理的选股技能何时更有价值，尤其是在投资者情绪高涨、股票收益分散和经济扩张等噪声较多、错误定价更明显的环境中，经验与选择性是否能转化为持续alpha。

## Methods / data
- 使用Bloomberg主动管理美国股票共同基金数据，1990年1月至2014年12月，先以24个月窗口估计选择性和过去alpha。
- 以CAPM、FF3和FFC模型计算基金alpha，结合BW、UM等情绪指标、股票收益分散度和CFNAI经济状态分组。
- 用11个市场异常识别错误定价，并使用Barras等人的“错误发现率”方法区分技能与幸运偏差；同时检验资金流入影响。

## Key findings
- 高选择性基金在扩张期风险调整收益4.11%（p=0.024），衰退期为3.54%（p=0.055），并在高情绪、高收益分散时期优于同业。
- 选择性×情绪交互项系数0.172（p=0.032），表明高情绪期高技能经理的alpha更高；低选择性组合在CAPM、FF3和FFC下alpha显著为负。
- 前期资金流入与随后alpha显著负相关，说明规模扩张会增加投资压力；错误发现率检验后，高情绪期的技能结论仍成立。

## Quant takeaways
- 选基金时可将主动份额/选择性与情绪、横截面分散度联合排序，而不是只看无条件历史alpha。
- 需要处理幸存者偏差、费用、流量冲击和经理更替，并避免把高波动或彩票暴露当作技能。
