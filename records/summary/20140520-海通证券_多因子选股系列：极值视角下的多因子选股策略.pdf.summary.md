# 海通证券多因子选股系列：极值视角下的多因子选股策略

- **date**: 2014-05-20
- **institution / author**: 海通证券研究所；金融工程分析师张欣慰
- **extraction confidence**: high

## Core question
把“极值视角”正式用于多因子选股：既保留传统相关性筛选的优势，又避免漏掉只在极端区间有效的因子。

## Methods / data
- 在中证500和沪深300样本空间里，用极值组检验因子有效性。
- 每期多空头各选 50 只股票，构建长期回测。
- 用随机抽样分布做微观层面的稳定性对照。

## Key findings
- 中证500样本空间：多空策略年化收益 **37.42%**，月胜率 **81.25%**，信息比率 **2.66**。
- 沪深300样本空间：多空策略年化收益 **19.2%**，月胜率 **59.38%**，信息比率 **1.30**。
- 微观层面，精选多头/空头组合分位点相对随机分布呈明显右偏/左偏；中证500里多头有 **57.3%** 的股票跑赢中位数，空头有 **57.3%** 跑输中位数。
- 结论是：极值法能抓到一些传统单调/相关测试可能遗漏的有效因子。

## Quant takeaways
- 因子筛选时，把注意力放在**极端分位**，尤其适合做长短组合。
- 极值法对中证500这类中小盘更强，对沪深300也有一定效果但弱一些。
- 微观稳定性评估很重要：不仅看组合净值，还看持仓股票是否真的集中在高质量/低质量端。

## Limitations
- 阈值和样本空间选择会影响筛选结果。
- 对大盘股效果较中盘弱，说明方法也有风格依赖。
