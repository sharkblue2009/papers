# 基金经理的因子择时能力

- **source filename**: `20210922-东兴证券-海外文献速览系列之八：基金经理的因子择时能力.pdf`
- **date**: 2021-09-22
- **institution / author**: 东兴证券；高智威；原文作者 Albert Jakob Osinga、Marc B.J. Schauten、Remco C.J. Zwinkels
- **extraction confidence**: high

## Core question
研究对冲基金经理能否随时间调整对市场、规模、债券、信用、趋势跟踪和新兴市场等因子的暴露以获取因子溢价，并检验择时能力的决定因素、持续性和业绩价值。

## Methods / data
- 使用TASS/Lipper对冲基金月度数据，1994年1月至2018年1月；删除前18个月回填期，要求至少36个月收益和平均管理资产1000万美元。
- 以Fung-Hsieh八因子模型为基准，考察持仓暴露变化与未来收益的关系，并用横截面回归、资金流和持久性分析验证。
- 样本含5434只基金，覆盖9类权益导向策略；另做因子集合、衍生品、规模及非流动性控制的稳健性检验。

## Key findings
- 约34%的对冲基金至少在一个因子上具有显著择时能力；市场、SMB和债券—国库券利差择时比例分别约9.2%、15%和9.6%。
- 更好的择时常见于运行时间较长、使用衍生品、无锁定期且无有效审计日期的基金。
- 按择时能力构建的Fung-Hsieh多空策略年化4.45%；最好与最差基金的样本外Alpha差约4.32%/年，择时能力对未来Alpha有预测性。

## Quant takeaways
- 基金评价不应只看市场Beta，应在多因子框架中区分静态暴露与动态择时。
- 因子集合选择会改变结论，基金观测期有限且策略异质性强；需防止模型错设、幸存者偏差和多因子多重检验。
