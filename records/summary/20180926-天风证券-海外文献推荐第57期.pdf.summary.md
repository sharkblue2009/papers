# 海外文献推荐第57期

- **source filename**: `20180926-天风证券-海外文献推荐第57期.pdf`
- **date**: 2018-09-26
- **institution / author**: 天风证券；吴先兴
- **extraction confidence**: high

## Core question
本文研究金融数据提供者是否承担信息中介角色：First Call 传播公司业绩信息的速度，是否会改变公告日的价格、成交量、流动性和公告后的价格漂移。

## Methods / data
- 样本来自 First Call、Compustat 和市场数据，覆盖 1995-01 至 2011-06；初始有 254,972 条业绩公告，清理后保留 102,759 条。
- 以 First Call 激活日相对公司公告日是否至少延迟一个交易日作为核心变量，计算两日即时 CAR、60 日公告后 CAR、异常成交量、买卖价差和深度。
- 通过延迟传播日的异常收益、倾向得分匹配、IBES 数据和分析师建议公告做识别与稳健性检验。

## Key findings
- 约 20% 的业绩公告被 First Call 延迟至少一个交易日。
- 延迟传播时，两日即时异常股价反应弱约 20%，但公告后约三个月的价格漂移增强约 60%。
- 延迟传播对应两日平均异常成交量下降约 10%，公告窗口的异常买卖价差更大、市场深度更低。
- 延迟传播当天聚集更强价格波动；使用 IBES 独有数据也得到相似结论，分析师建议延迟时也表现为较弱即时反应和较强后续反应。

## Quant takeaways
- 数据供应商的时间戳可作为事件驱动和信息扩散研究的关键变量，适合检验“即时反应—后续漂移”。
- 实盘使用时必须处理公告时间、数据校验延迟、媒体传播和公司公告重叠；延迟本身可能与信息复杂度或公司特征内生相关。
