# 用机器学习揭示共同基金的隐含信息

- **source filename**: `20220121-天风证券-海外文献推荐第208期.pdf`
- **date**: 2022-01-21
- **institution / author**: 天风证券；吴先兴、韩乾；原文作者 Zhang, A. L.
- **extraction confidence**: high

## Core question
研究共同基金股东信中的非结构化文本能否揭示经理人的前瞻性私人信息，并据此识别未来业绩较好的基金。核心是把文本信息与未来Alpha、晨星评级及资金流联系起来。

## Methods / data
- 使用SEC EDGAR中2006—2018年的N-CSR/N-CSRS股东信，CRSP基金收益与特征、Thomson Reuters持仓、MFLINKS及Trimtabs日度资金流。
- 2006—2014年训练，2015—2018年测试；先用BERT提取句子语义，再以含LSTM的循环神经网络按未来Fama-French-Carhart四因子Alpha分三组预测。
- Alpha用披露后180天日超额收益回归截距年化；考察3天、5天、6个月、12个月和24个月流量及晨星评级。

## Key findings
- 预测为“知情”的基金未来年化异常收益高出“不知情”基金80—88个基点。
- 知情基金未来晨星评级高约0.1个标准差，更可能获得评级提升。
- 披露后6个月流入差异1.59%—1.82%，1年为2.84%—3.00%，2年为4.49%—4.63%；0—3天流入11.5—13.5bp，0—5天为23.4—24.5bp。
- 高风险基金中，知情组年化风险调整收益高1.32%—1.40%。

## Quant takeaways
- 可将BERT文本嵌入与严格时间切分结合，构造基金筛选信号，并检验文本相对持仓和历史技能的增量信息。
- 需要控制披露选择偏差、基金风格和文本长度；样本集中于美国主动股票基金，模型迁移到A股需重新训练。
