# 捕获比率究竟在共同基金业绩中捕获了什么？

- **source filename**: `20210818-天风证券-海外文献推荐第191期.pdf`
- **date**: 2021-08-18
- **institution / author**: 天风证券研究所；吴先兴（分析师）；原文作者 Friesen、Sapp
- **extraction confidence**: medium

## Core question
检验共同基金常用的上行/下行捕获比率究竟反映基金经理的择时和选股能力，还是仅仅反映基金对市场的Beta暴露，并评估其样本外预测能力。

## Methods / data
- 使用1990—2019年共同基金月度收益和基准指数，分别计算市场上涨与下跌月份的捕获比率。
- 将捕获比率与CAPM beta、基金历史表现及未来1年、3年、5年收益进行回归和相关性比较。
- 通过样本内和样本外分析评估短期指标是否能延伸为长期基金筛选信号。

## Key findings
- 上行、下行及总捕获比率与Beta高度相关，相关回归的R²最高约0.88—0.93，说明捕获比率大部分只是捕捉市场敏感度。
- 捕获比率对未来1年基金业绩具有一定预测力，但预测能力在3年和5年持有期明显减弱，甚至转为负相关。
- 仅按捕获比率评价管理能力会把系统性Beta误认为主动alpha，且忽略基金风格、市场状态和基准选择。

## Quant takeaways
- 基金筛选应先把捕获比率分解为Beta、残差收益和条件暴露，再与费用、规模、风格漂移及回撤联合评估。
- 可回测“捕获比率残差+滚动alpha”指标，但必须避免用全样本估计Beta、幸存者偏差和短期噪声造成的排名反转。
