# 美国ESG 基金发展概览

- **source filename**: `20181219-天风证券-海外文献推荐第67期.pdf`
- **date**: 2018-12-19
- **institution / author**: 天风证券研究所；吴先兴；原文作者 Jon Hale（Morningstar Research）
- **extraction confidence**: high

## Core question
报告识别截至2017年底的美国ESG开放式基金和ETP，梳理其发行、资金流、费率、投资类别、业绩及晨星ESG评级，判断ESG基金是否已形成有竞争力且可区分的产品市场。

## Methods / data
- 依据招募说明书是否使用ESG准则、主题或可衡量影响筛选基金，覆盖主动/被动、股票、债券和资产配置产品。
- 比较ESG基金与同类传统基金的费率、2017年收益和晨星ESG评级，并观察新发、转型和被动产品趋势。
- 研究覆盖56个晨星类别，报告主体识别225只基金和ETP；结论部分另写约235只，存在口径差异。

## Key findings
- 2017年新成立40只ESG基金，2015—2017年共102只；被动型约占ESG基金30%，近三年新发基金中40%为被动。
- 2017年54%的ESG基金在同类中排名前50%；全球大市值类别18只全年基金中16只超过22.5%的发达市场指数，7只新兴市场基金超过35.5%指数。
- 80%的ESG基金获晨星四星及以上评级；ESG基金ETF费率整体高于普通ETF，开放式基金费率与传统基金相近。

## Quant takeaways
- ESG可作为产品筛选、风格暴露和资金流研究维度，但不能把高评级直接等同于alpha。
- 业绩比较受牛市、类别、费率、成立年限和筛选口径影响；应使用同类基准、净费用收益和长期样本。
