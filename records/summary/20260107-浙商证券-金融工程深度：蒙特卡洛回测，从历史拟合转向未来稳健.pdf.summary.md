# 报告摘要

- 源文件：20260107-浙商证券-金融工程深度：蒙特卡洛回测，从历史拟合转向未来稳健.pdf
- 日期/机构/类型：2026-01-07 / 浙商证券 / 金融工程深度报告
- 核心问题：蒙特卡洛回测能否替代“单一历史路径”回测，帮助量化策略从追求历史拟合转向追求未来稳健。
- 方法与数据：使用非参数蒙特卡洛模拟、残差 Bootstrap 和几何布朗运动（GBM）三类价格模拟方法，对 A 股风格 ETF 进行路径生成，并在动量+波动率双因子轮动策略上比较历史回测与模拟回测。
- 关键结论：历史路径往往像“幸运路径”，在模拟分布中处于较高分位；GBM 能很好复现波动率和相关性，但普遍低估收益，尤其对成长和小盘风格；单一历史最优参数在模拟路径中未必稳健，另一些参数的风险收益更平滑。
- 量化要点：策略评估应参考模拟分布而不是只看历史最优点，参数筛选可优先看夏普中位数、稳定性与分位数表现；MC 回测更像稳健性压力测试而非单点拟合。
- 局限性：模拟结果依赖价格过程假设，GBM 无法捕捉尾部跳跃和非正态特征；非参数方法也可能破坏时间序列结构。
- 关键词：蒙特卡洛回测；路径依赖；GBM；Bootstrap；风格轮动；稳健性
