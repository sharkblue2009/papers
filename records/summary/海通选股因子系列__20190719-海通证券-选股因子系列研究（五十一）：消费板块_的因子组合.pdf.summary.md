# 海通证券选股因子系列研究（五十一）：消费板块的因子组合

- **source filename**: `20190719-海通证券-选股因子系列研究（五十一）：消费板块_的因子组合.pdf`
- **date**: 2019-07-19
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、罗蕾
- **document type**: 金融工程专题报告

## Core question
研究消费板块内部如何构造更有效、更稳健的因子组合。

## Methods / data
比较消费板块与其他板块的整体表现、单因子表现、因子相关性以及多因子组合效果。

## Key findings
- 消费板块市值加权表现明显强于其他板块，尤其大盘股更突出。
- 市值和流动性因子在消费板块最强；估值、盈利、增长等也有效。
- “小市值+流动性+盈利”收益高，但风格偏离大、黑天鹅风险更高。
- “盈利+增长+价值”更稳健，在主动基金排名中更稳定。

## Quant takeaways
- 行业内最优因子组合通常与全市场不同。
- 消费板块是一个适合做风格和质量叠加的板块。

## Caveats
- 强收益组合可能更依赖特定风格窗口。
