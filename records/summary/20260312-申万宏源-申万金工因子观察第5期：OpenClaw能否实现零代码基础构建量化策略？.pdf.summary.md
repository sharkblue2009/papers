# 20260312-申万宏源-申万金工因子观察第5期：OpenClaw能否实现零代码基础构建量化策略？

- 来源文件：`20260312-申万宏源-申万金工因子观察第5期：OpenClaw能否实现零代码基础构建量化策略？.pdf`
- 日期/机构/类型：2026-03-12，申万宏源，权益量化研究报告
- 核心问题：OpenClaw 能否让量化策略构建真正接近“零代码”？
- 方法/数据：实测 OpenClaw 的三类任务：基于想法的简易回溯、中证 500 多因子选股、机器学习（GRU）策略；并让其通过 API 拉取数据、生成代码、完成因子测算与结果导出。
- 主要结论：OpenClaw 确实能显著降低数据与代码门槛，部分简单任务可完成，但当前仍存在大量低级错误、执行不稳定与分析能力不足的问题，离“好用”还有距离。
- 量化要点：
  - 中证 500 内因子测算结果（示例）：成长 IC 0.34%，市值 IC -1.94%，动量 IC 0.65%，反转 IC 1.18%，低波 IC 1.91%，低流动性 IC 0.91%
  - 报告明确指出：OpenClaw 可完成部分因子测算、策略构建与 GRU 机器学习流程，但执行质量不稳定
- 局限性：对提示词理解偏差、排序反向、文件发送失败、偶发“罢工”与幻觉，且因子逻辑分析能力不足。
- 关键词：OpenClaw、零代码、量化策略、因子测算、AI Coding、GRU、自动化投研
