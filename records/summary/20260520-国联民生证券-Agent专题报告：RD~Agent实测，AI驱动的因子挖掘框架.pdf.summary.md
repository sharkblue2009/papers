# RD-Agent 实测：AI 驱动的因子挖掘框架

- 原文路径：papers/broker/202610/20260520-国联民生证券-Agent专题报告：RD~Agent实测，AI驱动的因子挖掘框架.pdf
- 系列：Agent专题报告

- 主题：financial machine learning methodology、deep learning and pattern recognition、factor and stock selection

## 核心结论
- 报告在 Wind A 股约 5792 只股票、165 个字段上测试 RD-Agent，采用训练、验证、测试分离的因子研究流程。
- 样本划分为 2016—2023 年训练集、2024 年验证集及 2025—2026 年测试集，强调通过时间隔离检验泛化能力。
- 实测完成 36 个有效 Loop，因子 IC 从 0.0621 提升至 0.0699，并实现 11 次 SOTA 更新。
- GLM-V5.1 的整体表现优于 DeepSeek-V3.2，但模型仍存在代码错误、过拟合、IC 与实盘表现脱钩及运行稳定性问题。

## 方法要点
RD-Agent 将因子研究拆分为数据理解、因子构造、代码执行、回测评价和迭代优化等环节，由 Agent 自动提出研究假设并根据评价结果继续搜索。报告对字段进行统一管理，以 IC 等指标作为因子筛选和迭代反馈，使用时间切分避免将未来信息直接带入训练。测试重点不只是单个因子的数值表现，也包括自动化研究流程的有效 Loop 数量、因子改进幅度和模型之间的差异。

## 结果与局限
实验显示，Agent 可以在较少人工干预下持续生成并优化因子，且不同基础模型的研究质量存在差异。但报告指出，自动生成代码可能无法运行或产生隐蔽错误，反复迭代也可能围绕验证集过拟合；较高 IC 不一定转化为稳定的交易收益，实盘还会受到容量、成本、数据延迟和市场状态变化影响。框架的运行稳定性、结果可复现性以及从研究指标到真实组合表现的映射仍需进一步验证。
