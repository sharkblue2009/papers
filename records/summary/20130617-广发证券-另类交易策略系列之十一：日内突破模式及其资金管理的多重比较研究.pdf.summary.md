# 日内突破模式及其资金管理的多重比较研究

- **source filename**: `20130617-广发证券-另类交易策略系列之十一：日内突破模式及其资金管理的多重比较研究.pdf`
- **date**: 2013-06-17
- **institution / author**: 广发证券；安宁宁
- **extraction confidence**: high

## Core question
比较开盘区间突破策略的区间定义与止损/止盈方式，寻找在沪深300股指期货日内交易中更稳健的组合，并检验参数在样本外是否稳定。

## Methods / data
- 使用股指期货当月合约2010年4月16日至2013年5月24日的2分钟K线；手续费单边万分之0.3、冲击成本0.4点、杠杆1倍。
- 区间宽度采用开盘价比例、10日平均真实波动区间或DRange三种方式；出场采用固定止损、盈利后移至成本价、跟踪止盈三种方式，共9个策略。
- 既做全样本参数优化，也以2010—2011年为样本内、其余为样本外，并比较累计收益、胜率、赔率和回撤。

## Key findings
- 最优参数的f大致为0.145、0.3—0.5、0.15—0.2；不跟踪止盈的止损r约0.3%—0.4%，跟踪止盈约0.8%。
- DT05累计收益113.89%、胜率28%、赔率4.04、最大回撤-4.34%；DT08为112.83%、28%、4.15、-5.74%。
- 各策略日均交易低于1次，胜率30%—50%；样本外最大回撤约-5%至-8%，DRange模式总体较优。

## Quant takeaways
- DRange配合盈利后把止损移至成本价较有价值；跟踪止盈未明显提高收益。
- 参数按全样本优化存在前视风险，且策略收益随市场波动下降和拥挤可能衰减，实盘需纳入冲击、容量和延迟。
