# 基金经理把握选股时机的能力及其与业绩的关系

- **source filename**: `20210527-东兴证券-海外文献速览系列之四：基金经理把握选股时机的能力及其与业绩的关系.pdf`
- **date**: 2021-05-27
- **institution / author**: 东兴证券；高智威；原文作者 George J. Jiang、Gulnara R. Zaynutdinova、Huacheng Zhang
- **extraction confidence**: high

## Core question
区分“会选股”和“会在有选股机会时交易”，构造选股择时能力指标，检验其是否真实存在、能否预测基金业绩，以及哪些基金特征与该能力相关。

## Methods / data
- 使用CRSP无生存偏差基金、Thomson Reuters持仓和CRSP股票数据，样本为1984—2018年4239只基金、606,316个基金月度观察。
- 以主动比重/换手率衡量基金活跃度，以个股CAPM或Fama-French-Carhart四因子Alpha的平均值衡量未来选股机会，回归活跃度对下一期机会估计择时系数。
- 使用四阶Newey-West、10,000次Bootstrapping、工具变量及控制业绩、现金流和其他择时能力做稳健性检验。

## Key findings
- 约31%的基金择时系数t值≥1.96，约13%的基金t值<-1.96；前99%、97%、95%、90%分位t值分别达7.63、5.83、5.21、4.18。
- 积极择时基金业绩高于消极择时基金，且择时价值超出单纯选股能力；基金经理使用的信息并非主要来自宏观变量。
- 年轻基金、基金家族规模较大者择时更强；高周转率基金择时更差，资金流与择时能力正相关。

## Quant takeaways
- 可把基金交易活跃度条件化于未来横截面机会，作为经理技能和基金筛选指标。
- 择时系数依赖机会度量、基金活跃度定义和样本长度；交易成本、内生性与多重检验仍需严格控制。
