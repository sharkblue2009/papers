# 模式识别选股模型的优化——支撑线和压力线的组合识别

- **source filename**: `20111226-国信证券-金融工程专题研究：模式识别选股模型的优化，支撑线和压力线的组合识别.pdf`
- **date**: 2011-12-26
- **institution / author**: 国信证券；董艺婷、郑亚斌
- **extraction confidence**: high

## Core question
将支撑线、压力线的技术分析规则量化，研究其斜率、有效时间及换手率/量能配合与后期收益的关系，并为模式识别选股策略提供特征。

## Methods / data
- 对中证800历史成分股2005年3月25日至2010年10月14日的价格走势提取关键点，采用自底向上的分段线性表示；关键点数以11个作为拟合与压缩折中。
- 根据相对高低点绘制最近的支撑线/压力线，提取两线斜率、有效时间及上涨/下跌阶段换手率。
- 共633,442个样本；靠近支撑线做多、靠近压力线做空，并在触及另一条线或达到有效时间时平仓。

## Key findings
- 得到39,528个看涨样本和46,931个看跌样本。
- 不计手续费时，看涨总体准确率58.61%、看跌46.71%；双边交易手续费0.30%时分别为57.50%和45.66%。
- 看涨样本中“压力线斜率>支撑线斜率>0且上涨换手率更高”占33.29%；看跌样本中“支撑线<0、压力线>0且上涨换手率更高”占20.45%。

## Quant takeaways
- 支撑/压力组合对上涨判断优于下跌判断，换手率方向与通道形态存在交互效应。
- 结果主要是分类准确率而非可直接交易的净收益；应进一步加入突破、止损、滑点和样本外滚动验证。
