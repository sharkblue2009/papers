# 高频交易竞争

- **source filename**: `20200318-天风证券-海外文献推荐第128期.pdf`
- **date**: 2020-03-18
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告研究高频交易商进入同一交易平台后，竞争是否改善股票流动性，重点检验买卖价差变化，并区分高频交易竞争的“价格竞争”与“数量竞争”解释。

## Methods / data
- 使用加拿大Alpha交易系统2008年11月7日至2012年9月25日的毫秒级订单簿数据，选取市值最大的279只股票，并以TSX作比较市场。
- 以隔夜头寸低于15%、两周内至少40%时间切换信号定义HFT；共识别1121个进入事件。
- 对每个进入事件取前1个月和后3个月数据，以市值、成交额、价格、波动率和价差匹配控制组，进行DID事件研究。

## Key findings
- HFT进入后Alpha平台价差收窄；被动型第二家HFT进入后价差缩小38bp，第三家再缩小4bp，主动型对应约2bp和4bp。
- 第三家HFT进入时Alpha平均价差约175bp、TSX约100bp；第四家进入前后两者均约50bp。
- 竞争越激烈，HHI越低，非HFT交易者有效价差和已实现价差均显著改善，支持数量竞争而非价格竞争机制。

## Quant takeaways
- 订单簿研究可用HFT进入事件、HHI和DID识别竞争对流动性的边际影响。
- 需区分被动做市和主动交易者，并控制股票、平台和时间固定效应。
- 结论来自加拿大单一平台的大盘股样本，不能直接外推至低流动性股票或不同撮合规则市场。
