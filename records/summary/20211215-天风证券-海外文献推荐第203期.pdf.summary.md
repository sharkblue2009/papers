# 高收益债券适合主动管理

- **source filename**: `20211215-天风证券-海外文献推荐第203期.pdf`
- **date**: 2021-12-15
- **institution / author**: 天风证券研究所；吴先兴、惠政宝（分析师）；原文作者 Morningstar Research
- **extraction confidence**: high

## Core question
评估高收益债券市场是否比核心债券市场更适合主动管理，并从费用、流动性、ETF溢折价、市场价值加权和错误定价角度比较主动与被动投资。

## Methods / data
- 比较晨星高收益债券分类与中期核心债券分类的主动基金存活和跑赢被动平均水平的比例。
- 分析高收益债券的交易流动性、基金净值与市场价格偏离、信用评级分层和市场价值加权的风险。
- 讨论主动经理在信用选择、流动性管理、发行人筛选和错误定价识别方面的潜在优势。

## Key findings
- 截至2020年12月的过去10年，晨星高收益分类中42.3%的主动基金存活并跑赢该类别被动基金平均水平；中期核心债券类别仅27.9%。
- 高收益债券市场流动性较弱，ETF价格可能出现明显溢价或折价，单纯按市值加权会增加对大规模发行人和高负债发行人的暴露。
- 文本列示的被动高收益基准FALN过去10年年化超额约2.6%，但报告仍认为信用筛选和流动性管理支持主动方式。
- 主动管理的优势并不等于所有主动基金都能取胜，费用和经理能力仍是决定净收益的关键。

## Quant takeaways
- 高收益债券策略应把违约、流动性、交易价差、ETF折溢价和信用迁移纳入风险模型，而非只看指数收益。
- 可比较主动基金与FALN等被动基准的费用后alpha，并控制幸存者偏差、评级暴露、久期和市场环境。
