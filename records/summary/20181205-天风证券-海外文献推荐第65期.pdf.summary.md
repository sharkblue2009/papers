# 通过VaR Black-Litterman 模型构建FOF 投资绝对收益组合

- **source filename**: `20181205-天风证券-海外文献推荐第65期.pdf`
- **date**: 2018-12-05
- **institution / author**: 天风证券研究所；吴先兴；原文作者 Miguel A. Lejeune
- **extraction confidence**: medium

## Core question
报告讨论如何为有风险控制目标的FOF构建绝对收益组合，在组合收益最大化之外，同时处理VaR、波动率、分散化、买入阈值、流动性、币种和资产上下限等现实约束。

## Methods / data
- 备选资产涵盖存款、政府及公司债、权益区域、商品、币种和事件驱动等基金类别。
- 以Black-Litterman将市场均衡收益与专家绝对或相对观点融合，缓解历史均值估计误差。
- 目标为最大化预期季度收益，加入非卖空、预算、分类上下限、流动性和整数买入约束，以及组合波动率和VaR概率约束。
- 通过分位数确定性等价、Cantelli及单边切比雪夫等不等式，将随机非凸问题转为可计算的确定性或近似问题。

## Key findings
- VaR约束示例为在95%置信水平下，组合损失不超过初始资本的5%或10%。
- 报告没有提供独立样本的收益、Sharpe或回撤回测；其主要结论是模型在计算速度和稳定性方面表现良好，并可在更广分布假设下保持凸性或得到近似解。

## Quant takeaways
- 可将Black-Litterman作为收益收缩层，再把风险预算、最低持仓和流动性约束直接纳入FOF优化。
- VaR并不满足次可加性，不能替代分散化约束；真实收益肥尾、参数误差和交易成本会使正态分位数结果偏乐观。
