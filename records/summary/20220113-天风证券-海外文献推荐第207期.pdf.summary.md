# 适合中国市场的规模和价值因子

- **source filename**: `20220113-天风证券-海外文献推荐第207期.pdf`
- **date**: 2022-01-13
- **institution / author**: 天风证券研究所；吴先兴（分析师）；原文作者 Liu、Stambaugh、Yuan
- **extraction confidence**: high

## Core question
检验经典Fama-French三因子模型在中国A股的解释缺陷，并构建更适合中国市场规模与价值特征的CH3模型。

## Methods / data
- 使用中国A股数据比较CAPM、FF3和CH3对常见收益因子的解释能力。
- CH3在规模因子构造中剔除市值最小30%的股票，以降低微盘股和交易噪声影响；以EP替代BM构造价值因子。
- 在CH3基础上加入换手率因子形成中国四因子模型CH4，并通过Fama-MacBeth及因子回归比较模型定价误差。

## Key findings
- 中国市场小市值股票存在较强的微盘效应和流动性/交易噪声，直接采用FF3规模因子可能导致解释偏差。
- CH3相较FF3对中国市场常见收益因子的解释效果更好，说明剔除最小30%股票并使用EP有助于改善因子定义。
- CH4进一步加入换手率后，能够捕捉中国市场的交易活跃度差异，模型对部分因子收益的解释继续改善。
- 报告结论是中国市场的规模和价值因子不宜机械照搬美国定义，需结合市场结构与投资者交易特征。

## Quant takeaways
- A股因子回测可优先比较FF3、CH3和CH4的残差、定价误差和样本外解释力，并单独报告微盘股贡献。
- 需控制涨跌停、停牌、流动性、换手率和数据可得性；模型改善未必意味着可交易alpha，交易成本和容量是关键检验。
