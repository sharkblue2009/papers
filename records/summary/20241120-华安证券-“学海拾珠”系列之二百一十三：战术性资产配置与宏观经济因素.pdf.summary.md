# 研报摘要

- 来源文件：20241120-华安证券-“学海拾珠”系列之二百一十三：战术性资产配置与宏观经济因素.pdf
- 日期：2024-11-20
- 机构：华安证券
- 类型：证券研究报告 / 金融工程 / 学海拾珠系列

## 核心主题
比较战术性资产配置（TAA）在不同宏观环境中的有效性，重点评估基于 Eta 定价模型与经济环境评级（ECR）的资产配置方法，及其与均值-方差优化（MVO）结合后的表现。

## 方法与数据
- 使用 Eta 因子模型刻画资产对宏观经济因素的暴露。
- 以 ECR（Economic Condition Rating）对经济环境进行有利/中性/不利划分。
- 构建并比较 ECR-MVO、MIN、ECR-EW、EW 等组合。
- 研究基于海外资产与 ETF 数据，覆盖较长历史区间，并按半年调仓评估。

## 关键结论
- ECR-MVO 在长期表现最好，兼顾较高收益与较低风险。
- MIN 策略在不同阶段的风险收益比表现突出，尤其适合抑制宏观因子冲击。
- 在金融危机及高波动阶段，ECR-MVO 和 MIN 相对更稳健。
- 相比简单等权组合，加入经济环境筛选后组合效率提升明显。

## 量化要点
- 战术配置并非只追求收益，更重要的是在宏观状态切换时控制回撤。
- 低波动资产与经济环境过滤可作为组合防守层。
- 半年频再平衡是文中可操作性较强的实现方式。

## 局限性
- 结论主要基于海外历史样本，迁移到本地市场需重新检验。
- 宏观状态识别依赖模型设定，若经济结构变化可能失效。
