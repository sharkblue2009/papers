# 主动ETF或将何去何从?

- **source filename**: `20190424-天风证券-海外文献推荐第84期.pdf`
- **date**: 2019-04-24
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告汇总Vanguard主动因子ETF、Eaton Vance的ETMF和非透明主动ETF的发展，分析主动ETF相对传统共同基金的成本、流动性和税收优势，以及每日披露持仓造成的Alpha稀释问题。

## Methods / data
- 采用Vanguard、ETF.com和晨星等公开资料，比较产品发行、退市、资产规模、资金流、费率和主动/被动配置。
- 重点观察2018年前后的美国主动ETF市场，并介绍ETMF按日终净值加减折溢价交易、季度或延迟披露持仓的结构。
- 以Vanguard主动因子ETF和EVSTC等案例说明产品采纳、投顾教育和透明度约束。

## Key findings
- 截至2018年2月28日，60家发行人共发行208只主动ETF；2008年至当时累计发行271只、退市68只。
- 主动ETF数量约占ETF的11%，资产规模占比不足1.2%；主动债券ETF约占主动ETF规模的75%。
- ETMF结构已有15只产品、总规模约1.35亿美元；EVSTC费率0.65%，低于传统共同基金但高于普通ETF平均水平。
- Vanguard六只主动因子ETF中，多因子VFMF相对更受欢迎；报告指出低费率、透明和可交易性是长期扩张前提。

## Quant takeaways
- 研究主动ETF时应将产品结构、披露频率、折溢价、流动性和实际费用纳入回测，而不能只比较指数收益。
- 非透明结构可能保护策略，但会引入做市、估值和投资者理解成本；需监测资产流入是否可持续。
- 样本主要为行业报道和早期市场数据，不能直接推断长期Alpha或产品存活率。
