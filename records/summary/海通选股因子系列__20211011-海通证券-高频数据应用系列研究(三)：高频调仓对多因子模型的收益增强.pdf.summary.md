# 海通证券高频数据应用系列研究（三）：高频调仓对多因子模型的收益增强

- **source filename**: `20211011-海通证券-高频数据应用系列研究(三)：高频调仓对多因子模型的收益增强.pdf`
- **date**: 2021-10-11
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 金融工程专题报告

## Core question
把高频因子纳入周度/日度调仓后，是否能提升多因子增强组合的收益；以及如何在收益和换手之间做权衡。

## Methods / data
以中证500增强思路为主，比较月度、周度、日度调仓；并测试三种降换手思路：延长因子计算窗口、拉长收益预测窗口、提高目标函数惩罚系数（fee）。

## Key findings
- 部分高收益公募中证500增强基金在 2020H2 的换手率很高，提示高频调仓可能有帮助。
- 在约束选股范围后，周度调仓相较月度调仓明显改善超额收益：年化从 **14.7%/17.5%** 提升到 **15.5%/19.5%**（不同设定下），但换手也从 **6-7 倍** 提升到 **15-16 倍**。
- 三种控换手方法里，**延长高频因子计算窗口** 的性价比最好；
  - 拉长收益预测窗口主要降换手，收益改善不明显；
  - 提高 fee 会同时压低收益和换手，不推荐。
- 日度调仓在月度基础上进一步提升超额收益，改善幅度约 **2.6-4.7 个百分点**，但年化换手升至 **12-15 倍**。

## Quant takeaways
高频因子的价值不只在于“更快”，还在于“更适合更短的再平衡周期”；但收益增厚往往伴随显著换手成本。

## Caveats
对交易成本极其敏感；实际可行性取决于流动性、成分约束和执行能力。
