# 海通证券选股因子系列研究（八十）：股票久期的定义、溢价及应用

- **source filename**: `20220606-海通证券-选股因子系列研究（八十）：股票久期的定义、溢价及应用.pdf`
- **date**: 2022-06-06
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、罗蕾
- **document type**: 金融工程专题报告

## Core question
能否把债券久期的思想迁移到股票上，用“股票久期”刻画风险、估值和收益之间的关系，并用于选股/增强。

## Methods / data
构建两类指标：
- **隐含久期**：基于公司未来现金流折现，和 PB/PE、盈利、增长相关；
- **债券相似度**：不直接预测现金流，而是统计意义上衡量股票与债券的相似性。
再考察它们与波动率、beta、利率变动、收益率曲线和指数增强表现的关系。

## Key findings
- 隐含久期与 PB/PE 高相关；高盈利、低增长公司久期短，高增长、低盈利公司久期长。
- 隐含久期是有效的风险刻画指标，对未来波动率/beta 具有增量解释能力。
- **长久期股票的未来收益更低**：无论隐含久期还是债券相似度，都与股票收益负相关。
- 2013-2022.04，隐含久期因子年化多空收益约 **9.8%**，但多头效应弱、空头效应强；债券相似度因子年化多空收益约 **4.5%**，且相对更平滑。
- 将久期类因子纳入指数增强，可降低波动率和相对回撤，提升收益风险比。

## Quant takeaways
股票久期本质上是把“高估值/高增长的远期现金流”显式量化：它既能解释风险，也能解释为什么一些“魅力股”长期回报偏低。

## Caveats
久期与估值高度相关，且效果会随利率环境变化；对现金流假设和市场风格依赖较强。
