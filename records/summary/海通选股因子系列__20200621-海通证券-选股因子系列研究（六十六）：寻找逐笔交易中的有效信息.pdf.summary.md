# 海通证券选股因子系列研究（六十六）：寻找逐笔交易中的有效信息

- **source filename**: `20200621-海通证券-选股因子系列研究（六十六）：寻找逐笔交易中的有效信息.pdf`
- **date**: 2020-06-21
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、余浩淼
- **document type**: 金融工程专题报告

## Core question
逐笔成交里到底哪些信息最有效，尤其是“大单”与“普通单”混在一起时，是否会掩盖真正的信号。

## Methods / data
按订单成交额大小筛出大单，比较大买/大卖成交占比、大单资金净流入率、大单推动涨幅等因子；再用“是否有大单参与”过滤逐笔成交，重构分钟K线并重新计算传统高频因子。

## Key findings
- 大买成交金额占比揭示的大资金动向具有较强选股效果，未来上涨概率更高。
- 大卖成交占比本身并不对称地强，只有在对手方不是大资金时，对未来下跌才更有解释力。
- “买大单 + 卖小单”与“大买、大卖共同成交”所包含的信息不同，前者更像信息优势买盘，后者更像真正的大资金共识成交。
- 用大单过滤后重构K线，平均单笔流出金额占比、大单资金净流入率、大单推动涨幅等因子表现往往更好。

## Quant takeaways
逐笔数据里最有用的不是“所有成交”，而是能区分资金量级与对手方结构的那部分成交；过滤再重构，比原样统计更有信息密度。

## Caveats
大单定义和过滤规则会影响结果；重构K线虽然更纯，但成交信息保留量也会下降。
