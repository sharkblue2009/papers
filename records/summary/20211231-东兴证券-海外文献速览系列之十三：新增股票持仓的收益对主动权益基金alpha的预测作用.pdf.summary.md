# 新增股票持仓的收益对主动权益基金alpha的预测作用

- **source filename**: `20211231-东兴证券-海外文献速览系列之十三：新增股票持仓的收益对主动权益基金alpha的预测作用.pdf`
- **date**: 2021-12-31
- **institution / author**: 东兴证券；高智威；原文作者Viktoriya Lantushenko、Edward Nelling
- **extraction confidence**: high

## Core question
文献考察基金从未持有过的新股票，其后续收益是否比现有或曾持有股票更能预测基金未来alpha。假设是新增持仓需要更多搜索与分析努力，因而更能揭示主动管理能力。

## Methods / data
- 美国主动权益基金，CRSP、Thomson持仓、MFLINKS和股票收益数据；1990—2015年，最终1,521只基金。
- 每季度将持仓分为新增、以前持有后重新买入、现有三类，计算原始、市场调整和DGTW调整收益。
- 用下一季度Carhart四因子alpha做面板回归，控制规模、年龄、费用、换手、资金流和股票数量，并比较Active Share、ICI、R²、Return Gap。

## Key findings
- 新增持仓收益显著预测下一季度基金alpha，曾持有和现有持仓收益不能稳定预测。
- 新增持仓收益每增加一个标准差，Carhart四因子alpha年化增加约0.39%—0.49%。
- 按新增持仓收益分十分位，最高与最低组合的四因子alpha差为每季度1.26%。
- 新增持仓收益与Active Share、ICI、基金R²和Return Gap相关性低（约1.54%、-0.36%、-1.55%、-1.32%），加入这些指标后仍显著。

## Quant takeaways
- 可从基金持仓变更构造“新信息交易”信号，并与基金筛选、经理更替和组合拥挤度结合。
- 必须使用披露滞后后的持仓，剔除IPO和孵化期，区分主动买入与资金流驱动的被动扩仓。
- 持仓披露低频、基金风格和美国市场制度限制外推；新增持仓收益仍需扣除基金费用和交易成本。
