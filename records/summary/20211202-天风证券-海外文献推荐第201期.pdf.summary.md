# 贝叶斯模型在共同基金投资中的应用：中国市场实证

- **source filename**: `20211202-天风证券-海外文献推荐第201期.pdf`
- **date**: 2021-12-02
- **institution / author**: 天风证券研究所；吴先兴（分析师）、韩乾（联系人）；原文作者 Tu、Wang
- **extraction confidence**: high

## Core question
检验在中国共同基金投资中，将非基准资产、较长历史数据以及对错误定价和基金经理能力的先验观点纳入贝叶斯模型，能否改善基金评价与组合构建。

## Methods / data
- 样本包括714只中国共同基金：成长型218只、价值型309只、平衡型187只。
- 在CAPM和Fama-French定价模型基础上，将基金能力、定价误差和历史信息纳入先验分布，构建最大夏普比率和最优基金组合。
- 使用3个月和6个月持有期进行回测，并比较不同先验、模型替代和基金组合收益。

## Key findings
- 融合额外信息和先验观点可提高基金业绩评估的准确性，并改善基金组合构建。
- 贝叶斯组合在中国共同基金市场的回测表现有效；结果在成长、价值和平衡基金类别中均被讨论。
- CAPM与Fama-French模型替代测试支持定价模型先验对组合权重和收益差异有实质影响。
- 组合收益差异说明，单纯依据历史样本排序不如将基金经理能力与资产定价信息联合纳入。

## Quant takeaways
- 可把基金alpha、因子暴露和经理能力先验放入层次贝叶斯模型，输出权重后再进行滚动样本外验证。
- 关键风险是先验主观性、基金风格漂移、短持有期噪声、交易成本和中国市场制度变化；应做先验敏感性与权重集中度约束。
