# 摘要
- 源文件：20241125-江海证券-量化投资组合管理研究系列之（四）：组合优化器与指增组合的构建.pdf
- 日期/机构/类型：2024-11-25，江海证券研究发展部，金融工程研究报告/量化投资组合管理系列
- 核心主题：在既有复合选股因子基础上，构建通用型组合优化器，并将其用于沪深300/中证500指数增强组合构建。
- 方法/数据：围绕最小风险、最大收益、最大夏普、最小跟踪误差、风险平价、因子值/标准分/IR最大化等目标，结合约束与权重边界进行优化；回测比较日度、周度、月度调仓表现。
- 关键发现：
  - 沪深300增强：周度调仓年化收益10.1%，年化超额7.2%，夏普0.48，最大回撤由基准46.3%降至37.1%。
  - 中证500增强：周度调仓年化收益8.7%，年化超额6.5%，夏普0.31，最大回撤由64.8%降至48.1%。
  - 周度调仓整体优于日度调仓，且样本外增强效果更明显。
- 量化要点：组合优化器可兼容多种目标函数；指增策略中需同时平衡超额收益、跟踪误差与回撤。
- 局限性：历史回测结果可能受市场环境变化、参数估计误差和模型假设影响，未来表现可能失效。
- 关键词：组合优化器、指数增强、跟踪误差、风险平价、复合因子、沪深300、中证500
