# 收益率非对称性的新的度量方式

- **source filename**: `20210321-东兴证券-海外文献速览系列之一：收益率非对称性的新的度量方式.pdf`
- **date**: 2021-03-21
- **institution / author**: 东兴证券；高智威；原文作者 Patil 等
- **extraction confidence**: high

## Core question
传统三阶矩偏度易受异常值影响，且在尾部主导时可能无法识别分布非对称性。文献提出基于概率密度与分布函数相关性的Asym指标，并检验其对横截面股票收益的预测能力。

## Methods / data
- 使用NYSE、AMEX和NASDAQ股票的CRSP收益及CRSP/Compustat财务数据，样本为1963年1月至2014年12月、612个月。
- 以滚动窗口日收益通过核密度估计计算Asym，Asym取值[-1,1]；控制规模、账面市值比、动量、短期反转、流动性、特质波动、彩票需求及多种偏度。
- 进行五分位组合、滞后收益预测、双因子组合和Fama-MacBeth回归。

## Key findings
- Asym与规模、偏度、特质偏度相关系数分别为0.57、0.53和0.51，但约44%的Asym与偏度符号相反，说明包含增量信息。
- 60个月窗口下，当前极端分位股票下月保持状态的概率超过92%，因子具有较强持续性。
- Asym与未来收益显著负相关，可预测最长12个月收益；按因子构建的多空策略月收益1.72%，控制其他因子后仍显著。

## Quant takeaways
- Asym可作为偏度因子的稳健替代或补充，尤其适合研究尾部形态。
- 需在A股检验流动性、涨跌停和卖空约束影响，并避免核带宽、窗口长度和微小股票异常值造成的结果不稳。
