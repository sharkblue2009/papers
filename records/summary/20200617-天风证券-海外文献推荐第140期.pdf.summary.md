# 价值平均策略、美元成本平均策略以及随机投资方式的收益对比——基于多市场历史数据的实证检验

- **source filename**: `20200617-天风证券-海外文献推荐第140期.pdf`
- **date**: 2020-06-17
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告比较价值平均（VA）、美元成本平均（DCA）和随机投资在不同市场、投资期限和价格走势下的内部收益率，检验VA的“低买高卖”规则是否优于普通定投。

## Methods / data
- 使用S&P 500（1871—2002）、道琼斯（1932—2002）、FTSE 100（1984—2002）、XAU（1983—2002）和道琼斯商品指数（1980—2002）。
- 以5年、10年和20年滚动窗口计算IRR；随机投资有50%概率投资，投资时为DCA金额的150%或250%。
- 比较上涨、下跌和震荡市场，并以历史数据检验早期模拟研究结论。

## Key findings
- VA在S&P 500不同期限中收益排名第一的比例总体73%，DCA为23%；VA在5、10、20年窗口排名第一的比例分别为54%、92%和100%。
- 各市场平均IRR通常VA最高，优势在5年约1%—2%或更少，10年约3%—4%或更多，且长期和上涨市场更明显。
- DCA相对随机投资没有稳定优势；作者指出历史样本下VA优势虽不大，统计显著性仍不足。

## Quant takeaways
- VA本质是带有动态现金流和止盈规则的再平衡策略，不能仅用平均买入成本判断收益。
- 回测需明确现金流预算、卖出后的再投资、税费、杠杆和极端下跌时的追加资金需求。
- 结果依赖长期指数历史与预期收益设定；实盘应做现金约束、交易成本和不同再平衡频率压力测试。
