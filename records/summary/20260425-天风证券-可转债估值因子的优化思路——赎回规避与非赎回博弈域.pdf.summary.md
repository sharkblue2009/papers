# PDF总结
- **来源文件**：20260425-天风证券-可转债估值因子的优化思路——赎回规避与非赎回博弈域.pdf
- **文档类型**：天风证券 金融工程专题报告 / 可转债因子研究
- **核心主题**：通过识别非赎回博弈域，优化可转债低估策略。
- **方法/数据**：统计赎回条件满足前后的转债表现，定义未来30天内无法满足赎回条件的“非赎回博弈域”；在偏股、平衡转债中比较赎回域/非赎回域的低估因子表现，并叠加正股动量改造策略。
- **关键发现**：市场对赎回预期已较充分，低估策略容易踩中未来赎回债；在非赎回博弈域中低估因子显著改善；优化后低估策略2018年以来年化约17.1%，超额约6.4%，叠加正股动量后年化17.4%、超额6.7%。
- **量化要点**：平价约130附近为赎回博弈强区间，低估因子在该区间承压明显。
- **局限性**：结论依赖历史样本与统计划分，未来赎回制度或市场环境变化可能导致失效。
- **关键词**：可转债；赎回规避；非赎回博弈域；低估因子；正股动量；估值优化
