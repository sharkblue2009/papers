# 研报摘要
- 源文件：20260430-国金证券-大模型赋能投研之二十：从金融文本数据到投研工作流——金融Skills体系介绍.pdf
- 文档类型：券商 AI 投研应用专题报告
- 核心主题：介绍 Skills 体系及其在金融投研工作流中的应用。
- 方法/数据：基于 OpenClaw、Cowork 类 Agent 的使用经验，梳理 Skills 的定义、构建方式、选择机制，并汇总 19 个金融相关 skills。
- 关键结论：Skills 已成为主流 Agent 的核心载体；其渐进式披露机制更省上下文，适合把文本数据、PDF 解析、Office 交互、投研任务串成工作流。
- 量化要点：本篇偏方法论与工具清单，未给出严格量化收益；强调技能数量存在有效上限，过多反而影响选择精度。
- 注意事项：模型调用和技能选择存在随机性；Agent 工具有信息泄露、文件丢失等风险。
- 关键词：Skills、OpenClaw、Agent、投研工作流、渐进式披露、金融工具
