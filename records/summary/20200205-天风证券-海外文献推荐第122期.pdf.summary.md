# Capital Group 2020年市场展望

- **source filename**: `20200205-天风证券-海外文献推荐第122期.pdf`
- **date**: 2020-02-05
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: medium

## Core question
报告从宏观、股票和债券三层面讨论2020年大选、贸易不确定性、后经济周期和低利率环境下的资产配置方向，重点是如何在波动上升时保持组合平衡。

## Methods / data
- 回顾1932年以来美国大选年标普500平均累计收益，并观察截至2019-11-30的全球市场、货币政策和行业图表。
- 结合制造业、消费、失业率、工资、信用评级、分红和全球股票表现提出情景判断。
- 债券部分比较核心债、企业债、国债和市政债的历史信用利差、相对价值和分散效果。
- 文中为机构展望和历史图表分析，并非统一的可复现预测模型。

## Key findings
- 报告认为大选初选阶段波动较高，但长期持有通常优于离场；消费强劲时，制造业放缓未必导致衰退。
- 自2010年以来，全球排名靠前股票中约74%位于美国以外；新兴市场收益中公司自身特征解释度由1992年的36%升至约65%。
- 后经济周期和低利率环境下，持续分红、高质量、具定价权的公司更适合防守；企业债估值偏高，超额回报空间有限。
- 核心债可降低股票波动，市政债相对企业债的税后价值改善，但大选年仍可能波动。

## Quant takeaways
- 可将政治、制造业、消费和货币政策拆成情景变量，做全球股票、核心债和市政债的条件配置。
- “74%”“65%”等图表数字是报告引用的历史描述，不应直接当作未来收益预测。
- 机构展望存在主观判断和时间截面偏差，需用滚动样本、估值分位、信用利差和交易成本验证。
