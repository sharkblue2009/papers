# 海通证券选股因子系列研究（十）：基于机构持股信息的 Portable Alpha 策略增强

- **date**: 2015-02-27
- **institution / author**: 海通证券研究所；沈泽承
- **extraction confidence**: high

## Core question
机构持股信息是否真的能提供 alpha，以及如何把这部分收益嫁接到现有策略中（Portable Alpha）。

## Methods / data
- 用上市公司、基金公司、理财产品等年报/半年报披露信息，将股票分为“有机构持股 / 无机构持股”。
- 样本期为 **2008H2–2014H1**，按半年调仓。
- 比较原始组合收益、做市值控制的 Monte Carlo 配对收益，以及 Portable Alpha 嫁接效果。

## Key findings
- 机构持股范围不断扩大，但持股比例显著下降。
- 原始对比里，**无机构持股组合**看起来优于有机构持股组合，年化超额约 **8%**，但主要是小市值效应。
- 做市值控制后，**有机构持股组合反而更强**，年化超额约 **3%**，说明机构选股具有正向能力。
- 策略超额收益较稳定，但在特定报告期有较大回撤，**不适合作为单策略**。
- Portable Alpha 思路可以把这部分超额“嫁接”到别的策略上，提高收益而不明显增加换手和不稳定性。

## Quant takeaways
- 机构持股信息要先做**市值中性化**，否则容易被小盘效应误导。
- 机构持股可作为**alpha sleeve**，更适合增强而非独立运行。
- 半年频率的披露数据适合做中低频策略。

## Limitations
- 披露频率低，信号更新慢。
- 回撤在某些报告期较大，单独运行不够稳。
