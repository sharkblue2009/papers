# 海通证券选股因子的分解：股票的共性与个性

- **source filename**: `20190617-海通证券-选股因子的分解：股票的共性与个性.pdf`
- **date**: 2019-06-17
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、沈泽承
- **document type**: 金融工程专题报告

## Core question
把常见因子拆成“共性”与“个性”部分，观察分解后是否更稳定、更有选股价值。

## Methods / data
将收益率、波动率、财务指标和行业信息分别做市场/风格/行业/个股分解，再比较分解前后选股效果。

## Key findings
- 收益率中剥离市场和风格后，剩余个股部分的反转更稳健。
- 波动率里，系统性波动与未来收益正相关，特质波动率与未来收益负相关。
- 财务指标剥离风格与行业后，剩余个体部分通常更稳定。
- 行业信息可通过行业排序因子重新补回，避免分解时丢失行业层信息。

## Quant takeaways
- 分解的本质是把可解释的共性和真正有用的个性拆开。
- 很多“有效因子”其实来自更纯净的 idiosyncratic 部分。

## Caveats
- 统计分解依赖模型设定，分解方法本身会影响结果。

## Keywords
因子分解, 共性与个性, 系统性波动, 特质收益, 行业信息
