# 海外文献-7 基于Tweet的舆情交易策略，用社交媒体文本挖掘和稀疏矩阵分解预测股市波动

## Core question
文献研究不做情绪分类、而直接利用StockTwits词频结构，能否预测股票涨跌并形成交易策略。方法试图从大量社交媒体文本中提取潜在因子，避免正负情绪词分类错误。

## Methods / data
- StockTwits约4,500万条消息，2011-01-01—2015-08-31；文本清洗、停用词剔除、按日及日内聚合。
- 标普500成分股最终420只；1173个日频交易日，TAQ提供3519个日内观测。
- 构造词频-文档矩阵，以稀疏矩阵分解（SMF）提取10个潜在因子；与历史价格、AR和随机模型比较，并做2014—2015样本外测试。

## Key findings
- 样本内方向准确率70.12%，精确率68.93%，召回率75.05%；样本外日频准确率为51.37%，仍优于基准模型。
- 基于预测方向等权买入的策略，报告给出Sharpe约1.35、年化收益约1.18（原文口径未明确，标记为approx.）；加权策略收益与ETF相近。
- 2013年表现最弱，2014—2015改善；预测准确率与收益幅度正相关。
- 日内预测未稳定优于基准，2014、2015年甚至低于随机模型；未计交易成本。

## Quant takeaways
- 可把文本潜因子用于方向分类或横截面收益预测，并与词频漂移、消息原创性和滞后时间结合。
- 应以严格滚动训练、交易成本和容量约束复核51.37%的小幅预测优势。
- StockTwits转发和信息延迟可能削弱日内alpha；样本期牛市环境、无风险利率近零等因素限制外推。
