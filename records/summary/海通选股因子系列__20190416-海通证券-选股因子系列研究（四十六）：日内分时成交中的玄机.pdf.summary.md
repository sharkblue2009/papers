# 海通证券选股因子系列研究（四十六）：日内分时成交中的玄机

- **source filename**: `20190416-海通证券-选股因子系列研究（四十六）：日内分时成交中的玄机.pdf`
- **date**: 2019-04-16
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、姚石
- **document type**: 金融工程专题报告

## Core question
利用日内 1 分钟成交笔数与成交金额，挖掘分时成交中可交易的 alpha。

## Methods / data
构建平均单笔成交金额、资金净流入率、大单驱动涨幅等日内因子，并检验正交后、双重分组和多因子增益。

## Key findings
- 平均单笔流出金额占比等因子显著，且在正交后仍保留较强选股能力。
- 大单资金净流入率和大单驱动涨幅通常呈负向选股效果，反映大单行为与后续回报的关系。
- 把日内分时成交因子加入多因子模型后，IC、IR 和收益都能提升。
- 说明“成交笔数”比只看成交额更能刻画日内信息。

## Quant takeaways
- 分钟级成交结构里存在可持续的补充 alpha。
- 日内结构因子对传统低频因子有增量信息。

## Caveats
- 高频特征对样本窗口和交易成本较敏感。

## Keywords
