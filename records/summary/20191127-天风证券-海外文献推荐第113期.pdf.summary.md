# 基于DEA方法的共同基金业绩预测

- **source filename**: `20191127-天风证券-海外文献推荐第113期.pdf`
- **date**: 2019-11-27
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
论文利用数据包络分析（DEA）在多输入、多输出条件下筛选未来表现较好的共同基金，试图克服仅依赖CAPM或单一收益指标评价基金的局限。

## Methods / data
- 样本为2006-2015年印度46只无负荷股票型基金，数据来自Morningstar及Moneycontrol，包含大盘和中小盘基金。
- 以费率、换手率和波动率为投入，以不同期限收益率和资本流动为产出。
- 分别使用CRS、VRS和IRS模型计算效率，在3年、5年和10年维度各取前25%，再交叉验证并按波动率排序。
- 以未来六个月的评级和收益表现检验预测效果；负收益或数据缺失基金被剔除。

## Key findings
- 三年大盘基金中，超过76%的筛选基金高于同类平均收益，且最佳基金波动率低于同类平均。
- 五年大盘基金中，超过53%高于同类平均，最佳基金波动率低于高波动组。
- 十年大盘基金中，超过55%高于同类平均，筛选基金整体波动率较低；小盘基金结果类似。
- 全部类别平均约74%的筛选基金高于同类平均，报告认为收益和稳定性均较好。

## Quant takeaways
- DEA适合把收益、风险、成本和资金流同时纳入基金筛选，可作为多目标效率排序工具。
- 实证规模仅46只印度基金，且剔除负收益，存在选择偏差；应在更大样本中做滚动样本外验证。
- 需补充费用、申赎冲击、基金存活偏差和基准调整，避免把静态效率误认为可交易alpha。
