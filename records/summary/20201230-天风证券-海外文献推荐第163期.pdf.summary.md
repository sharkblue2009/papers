# 从实体经济角度对股市未来长期收益进行预测

- **source filename**: `20201230-天风证券-海外文献推荐第163期.pdf`
- **date**: 2020-12-30
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告介绍 Ibbotson 与 Chen 对美国长期股票收益的供给端分解，考察通胀、盈利、股息、估值、账面价值、ROE 和人均 GDP 如何共同解释股票回报，并据此预测可持续的长期权益收益与风险溢价。

## Methods / data
- 使用美国 1926—2000 年股票、长期国债、CPI、每股收益、股息、账面价值、ROE 与人均 GDP 数据。
- 比较六种收益分解：基本要素、资本利得与收益、盈利、股息、账面权益回报率、人均 GDP。
- 采用供给端盈利模型和股利模型预测长期总回报，并区分几何与算术风险溢价。

## Key findings
- 样本期股票复合年回报率 10.70%，算术平均回报率 12.56%，年化标准差 19.67%；历史权益风险溢价约 5.24 个百分点。
- 实际 EPS 年均增长 1.75%，实际账面价值增长 1.46%，ROE 增长 0.31%；PE 增长仅贡献总回报约 1.25 个百分点。
- 股息率由 1926 年初 5.15%降至 2000 年末 1.10%，支付率由 46.68%降至 31.78%。
- 供给端盈利模型给出的长期回报约 9.37%，几何风险溢价 3.97 个百分点、算术风险溢价 5.90 个百分点；股利模型估计约 5.44%。

## Quant takeaways
- 长期权益回报预测可从通胀、实际盈利增长和当前收益率出发，避免把估值扩张误当作可持续收益。
- 低股息率不应单独被解释为低盈利能力；支付率变化和回购等资本分配方式必须纳入。
- 研究基于美国历史长样本，参数与制度环境可能变化；PE 与股利模型差异也显示估值预期仍是主要不确定性。
