# 20240220-海通证券-选股因子系列研究（九十五）：冲击成本的预测和应用

- **source filename**: `20240220-海通证券-选股因子系列研究（九十五）：冲击成本的预测和应用.pdf`
- **date**: 2024-02-20
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、余浩淼
- **document type**: 金融工程专题报告

## Core question
能否用可观测的订单/成交特征预测冲击成本；如果把预测冲击成本纳入回测，因子选股能力会如何变化。

## Methods / data
- 定义 4 个市场冲击指标：净委买增额、大单净买入金额、净主动买入金额、大单主动净买入金额。
- 以 VWAP 相对开盘价的涨跌幅作为冲击成本。
- 对冲击指标与冲击成本分别做中性化后，采用最简单的 OLS 线性回归进行预测。
- 分别考察开盘后半小时内成交与全天成交两种情形。
- 将预测冲击成本纳入月度/周度换仓的因子收益中，观察 IC 变化。

## Key findings
- 冲击成本和市场冲击指标具有稳定正相关关系；中性化后相关性进一步改善，预测更稳。
- 回归模型的平均 R2 约为：
  - **0.310**（开盘后半小时内成交）
  - **0.365**（全天成交）
- 对因子选股能力的影响并不单向：
  - 基本面因子、手工高频因子以及反转类因子整体受影响较小
  - 换手、特质波动、非流动性等因子的 IC 对冲击成本更敏感
- 随着下单金额增大，特质波动、非流动性、换手等因子的 IC 下降更明显；例如成交金额增大到较高水平时，换手因子的 IC 下降接近 5%。
- 一个重要结论是：**减去预测冲击成本不一定削弱 IC**。部分高冲击成本股票被合理惩罚后，反而让某些因子的选股能力更强。
- 但当周度下单金额过大时，模型预测边界可能被突破，IC 会出现剧烈波动，说明冲击成本模型本身也有上限。

## Quant takeaways
- 这篇把研究重点从“因子有没有 alpha”推进到“**因子在真实交易约束下还剩多少 alpha**”。
- 交易成本不只是要从收益中扣除，更可以作为一个**显式建模对象**进入预测和组合设计。
- 研究重心开始明显转向**组合可交易性**和**执行层可实现性**。

## Caveats
- 模型是简单线性回归，预测能力有限，复杂交易行为和多档挂单未被充分覆盖。
- 当下单金额或交易行为超出训练分布时，预测冲击成本的可靠性会明显下降。
