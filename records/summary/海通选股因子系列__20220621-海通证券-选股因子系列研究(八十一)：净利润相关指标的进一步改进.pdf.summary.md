# 海通证券选股因子系列研究（八十一）：净利润相关指标的进一步改进

- **source filename**: `20220621-海通证券-选股因子系列研究(八十一)：净利润相关指标的进一步改进.pdf`
- **date**: 2022-06-21
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、余浩淼
- **document type**: 金融工程专题报告

## Core question
如何同时提升净利润相关因子（尤其 ROE、SUE）的**可用性**、**可靠性**和**有效性**，让基本面信号更适合量化选股。

## Methods / data
- 用业绩快报/预告与一致预期 ROE 预测当期真实 ROE，再用 ROE 历史波动率倒数加权，缓解披露滞后；
- 通过“剔除单一行业”的方式度量行业对 ROE 因子有效性的影响，并据此降低拖累行业权重；
- 以同样思路改进 SUE 因子；
- 将改进后的因子放入基本面多因子和指数增强组合中检验。

## Key findings
- 最新披露 ROE 存在时滞，用预测值替代后可明显改善选股。
- 波动率倒数加权能降低预测误差较大的股票影响，进一步增强稳健性。
- 通过行业层面的权重调整，ROE 与 SUE 的因子溢价和多空收益都能提升。
- 改进后的 ROE/SUE 能显著增强基本面多因子组合，尤其在配合高评级机构家数时，对全市场多头和指数增强都更有帮助。

## Quant takeaways
这篇报告延续了海通对“财务因子不是直接拿来用，而是先修正数据时滞和横截面异质性再用”的方法论。

## Caveats
依赖一致预期覆盖度、财报披露节奏和历史行业稳定性；行业权重修正存在过拟合历史样本的风险。
