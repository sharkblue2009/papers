# 隐含波动率指数与股指收益之间的相关性

- **source filename**: `20200901-天风证券-海外文献推荐第149期.pdf`
- **date**: 2020-09-01
- **institution / author**: 天风证券；吴先兴；原文作者 Pierre Giot
- **extraction confidence**: high

## Core question
本文检验VIX、VXN等隐含波动率指数是否不仅反映恐慌，还能预测标的股指未来收益。研究特别关注高隐含波动率在低波动环境中是否意味着过度抛售和中长期买入机会。

## Methods / data
- 研究S&P 100及VIX、Nasdaq 100及VXN的日度对数变化。
- 样本覆盖1994年8月至2003年1月，并划分为1994—1997低波动牛市、1997—2000高波动牛市和2000—2003高波动熊市。
- 用OLS及正负收益虚拟变量检验同期关系；按隐含波动率历史分位点触发1、5、10、60天多头收益，并做回归验证。

## Key findings
- 股指收益与隐含波动率变化显著负相关，且负收益对应的波动率上升幅度大于正收益对应的下降幅度。
- S&P 100的不对称关系在低波动子时期更强；高波动环境下VIX/VXN对负收益的边际反应减弱。
- 极高隐含波动率触发的多头策略在较长期持有期显示正向前瞻收益，极低水平则倾向对应负收益，但证据被报告评价为粗略。
- 结论主要支持“低波动市场中波动率突升具有前瞻性”，并非所有高VIX环境都可机械买入。

## Quant takeaways
- 可用VIX/VXN自身历史分位数和波动状态做条件反转或风险开关。
- 需要分离同期价格冲击与未来收益预测，并按持有期、波动状态和指数类型分层。
- 样本较早且只覆盖美国指数；高波动期的交易成本、期权期限结构和制度变化可能削弱信号。
