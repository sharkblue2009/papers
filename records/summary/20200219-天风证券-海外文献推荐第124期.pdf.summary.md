# 基差动量

- **source filename**: `20200219-天风证券-海外文献推荐第124期.pdf`
- **date**: 2020-02-19
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告研究期货期限结构斜率与曲率变化形成的“基差动量”是否能预测商品现货收益和期限溢价，并检验其是否代表投机者与金融中介清算能力受损时的定价风险补偿。

## Methods / data
- 使用CRB商品期货数据，覆盖1959年7月至2014年2月，重点研究21种商品及第一、第二近期期货，并用第三、第四近期期货做稳健性检验。
- 基差动量定义为最近月与次近月期货动量之差；按信号分组构造High4-Low4组合，比较基差和传统动量。
- 进行时间序列、横截面、固定效应及资产定价检验，并考察库存、持仓、波动率、流动性、中介资本和下行风险解释。

## Key findings
- 高、低基差动量组合的近月年均收益分别为18.38%（t=6.73）和4.08%（t=6.43），多空夏普比率约0.9。
- 基差动量一标准差上升对应近月收益增加10.23%、套利收益增加2.29%；联合控制基差和动量后仍稳健。
- 基差动量同时预测现货溢价和期限溢价，曲率变化贡献更大；其风险溢价与波动率和非流动性风险一致，市场压力上升时策略可能亏损。

## Quant takeaways
- 可直接用近、次近月合约动量差构造商品横截面因子，并分解斜率与曲率贡献。
- 需要按到期日和商品流动性分层，避免把库存、便利收益或单一动量误当成基差动量。
- 策略对波动率、流动性和中介资本风险敏感，实测时应加入保证金、展期和极端行情压力测试。
