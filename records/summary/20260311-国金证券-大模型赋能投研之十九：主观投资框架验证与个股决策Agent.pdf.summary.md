# 20260311-国金证券-大模型赋能投研之十九：主观投资框架验证与个股决策Agent

- 来源文件：`20260311-国金证券-大模型赋能投研之十九：主观投资框架验证与个股决策Agent.pdf`
- 日期/机构/类型：2026-03-11，国金证券，金融工程专题报告
- 核心问题：能否用大模型提取、验证并量化主观投研逻辑，并形成可用于选股的 Agent？
- 方法/数据：从研报与新闻中自动提取“核心驱动要素→传导路径→投资结论”的思维链（CoT）；采用滚动单链回测筛选优质逻辑；再用这些逻辑对个股进行符合度判断，构建联合投票与加权选股策略。
- 主要结论：大模型可辅助提炼主观投资框架并形成可交易信号；CoT 联合选股优于无 CoT 基准，且加权方案在风险控制上更好。
- 量化要点：
  - 多思维链联合投票策略：年化超额收益 17.16%，信息比率 0.48
  - 信息比率加权策略：信息比率提升至 0.51
  - 报告还给出个股投研顾问 Agent，可输出“看涨/中性/看跌”诊断
- 局限性：研报信息滞后、逻辑提取存在随机性与幻觉风险，且示例回测以申万一级行业医药生物历史数据为主。
- 关键词：大模型、思维链、主动投研、CoT、个股 Agent、联合投票、加权选股
