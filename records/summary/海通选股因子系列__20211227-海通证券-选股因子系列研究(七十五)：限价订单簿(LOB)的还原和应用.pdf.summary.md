# 海通证券选股因子系列研究（七十五）：限价订单簿（LOB）的还原和应用

- **source filename**: `20211227-海通证券-选股因子系列研究(七十五)：限价订单簿(LOB)的还原和应用.pdf`
- **date**: 2021-12-27
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、余浩淼
- **document type**: 金融工程专题报告

## Core question
在沪深两市 Level2 逐笔委托/逐笔成交数据齐备后，如何还原限价订单簿，并将其用于更真实的撮合、执行优化和高频因子挖掘。

## Methods / data
用逐笔委托与逐笔成交重建连续竞价阶段的盘口；构建模拟撮合系统；用若干 LOB 衍生指标预测 3 秒限价单成交概率，并据此改进 TWAP；同时从 LOB 中分解买入意愿等高频特征。

## Key findings
- 逐笔还原的 LOB 能把订单簿更新频率提升到 **0.01 秒以内**，并减少快照行情的迟滞问题。
- 传统回测往往低估交易成本，引入模拟撮合后更接近真实执行。
- 基于 4 个 LOB 衍生指标预测成交概率，可提高限价单成交率、降低强制成交比例。
- 对 **京东方A** 和 **证券ETF**，改进后的 TWAP 策略相对简单市价/限价 TWAP，日均可下降约 **0.3-1.4bp** 成本。
- LOB 还能继续拆出更细的高频行为特征，用于高频因子挖掘；作者明确把深度学习视作下一步方向。

## Quant takeaways
这是从“逐笔数据”走向“可执行订单簿”的关键一步：先还原微观结构，再把它用于执行优化和因子提取。

## Caveats
对数据完整性、撮合规则和执行假设敏感；交易成本、冲击成本与真实盘口深度都可能改变结论。
