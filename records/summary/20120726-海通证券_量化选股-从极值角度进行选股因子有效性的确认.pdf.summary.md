# 海通证券量化选股：从极值角度进行选股因子有效性的确认（换手率实证）

- **source filename**: `20120726-海通证券_量化选股-从极值角度进行选股因子有效性的确认.pdf`
- **date**: 2012-07-26
- **institution / author**: 海通证券金融工程团队；元数据/页眉可见吴先兴、张欣慰
- **extraction confidence**: high

## Core question
判断选股因子是否应该从“极值组”而不是全样本单调性去验证，并用换手率变化做实证。

## Methods / data
- 定义“换手率变动”为最近一日换手率相对过去两周均值的变化。
- 每周一分成 40 组，持有 1 周，观察不同极端组的后续表现。
- 额外把换手率与一致预期数据结合，测试复合选股模型。

## Key findings
- 传统的线性相关/单调性方法未必能识别真实有效因子；**极端组**的收益差更符合实盘逻辑。
- **换手率缩量**：单独看有一定推动作用，但频繁换仓会被交易成本侵蚀；与一致预期结合后，费后月度胜率约 **66%**，月度超额收益约 **1.79%**。
- **换手率放量**：更强、更稳定，能筛出持续跑输大盘的股票。以“最近一天相对过去两周均换手率放量最大的一组、持有 1 周”为例，2008H1/2009/2010/2011/2012H1 平均超额分别约 **-18.8% / -93.38% / -17.85% / -34.0% / -24.54%**，信息比率 **3.19**。

## Quant takeaways
- 因子研究应优先关注**极端值能否产生可交易的分层收益**，而不是强行要求中间组也单调。
- 高换手率可作为**选空头**信号；缩量则更偏向正向、但需要更长持有期和辅助因子。
- 把交易成本纳入极值因子验证，否则容易高估短周期信号。

## Limitations
- 高换手率信号更适合短线/做空侧，单独做多并不稳。
- 收益对持有周期和样本期较敏感，成本假设会显著影响结论。
