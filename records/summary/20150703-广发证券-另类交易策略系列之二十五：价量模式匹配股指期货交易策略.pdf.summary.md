# 价量模式匹配股指期货交易策略

- **source filename**: `20150703-广发证券-另类交易策略系列之二十五：价量模式匹配股指期货交易策略.pdf`
- **date**: 2015-07-03
- **institution / author**: 广发证券；张超、文巧钧
- **extraction confidence**: high

## Core question
用动态时间规整在历史数据中寻找与当前股指期货价格—成交量走势相似的片段，并用相似片段的后续收益预测下一交易日方向，检验价量联合匹配的交易价值。

## Methods / data
- 使用股指期货当月和次月连续合约2010年4月16日至2015年4月30日日收盘价和日成交量；2011—2012年用于参数选择，2013年起样本外回测。
- 价格按最新收盘价、成交量按50日均值标准化，采用右端对齐的多变量DTW，按距离倒数加权前k个历史片段。
- 每日收盘建仓、次日收盘平仓，反向波动1%止损；双边手续费万分之2，不计杠杆和冲击成本。

## Key findings
- 最优序列长度L=11；样本内累计收益80.5%、年化40.3%、最大回撤-8.8%，样本外累计82.7%、年化35.5%、最大回撤-12.8%。
- 样本外交易561次，胜率49.7%，单次平均盈利1.09%、亏损-0.85%，盈亏比1.29；方向预测准确率55.3%。
- 价量策略全样本累计收益率82.7%（样本外口径），明显优于仅成交量匹配；混合策略II累计89.4%、最大回撤-9.4%。

## Quant takeaways
- DTW能容纳形态时间伸缩，适合非线性模式匹配；成交量必须处理交割日和趋势性放大。
- 结果对窗口长度敏感，且预测准确率仅略高于50%；需防止相似片段重叠、数据窥探和交易容量不足。
