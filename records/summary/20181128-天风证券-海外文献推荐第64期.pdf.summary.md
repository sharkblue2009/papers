# 基金的alpha 源自基金经理的管理能力吗？

- **source filename**: `20181128-天风证券-海外文献推荐第64期.pdf`
- **date**: 2018-11-28
- **institution / author**: 天风证券研究所；吴先兴；原文作者 Qang Bu
- **extraction confidence**: high

## Core question
报告用长期持续跑赢市场的基金样本，区分基金alpha来自经理能力还是随机运气。研究同时考察不同市场状态下alpha的一致性、收益分布和资产配置变化。

## Methods / data
- 样本为1993年1月至2012年12月的美国股票型基金，排除指数、主题和混合基金；476只基金均至少有20年历史。
- 用20年Carhart四因子模型估计alpha，并将每月随机抽样基金作为“纯运气”对照；再分为1993—1997、1998—2002、2003—2007、2008—2012四段。
- 用二次规划估计无风险资产及六类规模—风格组合的持仓权重，比较主动型与自助抽样型基金。

## Key findings
- 8只长期表现优异基金的月alpha为0.163%—0.358%，p值0.004—0.032；主动管理组合全样本月alpha为0.272%。
- 主动型基金在四个子区间均有显著alpha，而自助抽样型主要仅在1998—2002年显著。
- 主动型收益均值0.7955%、标准差4.5544%、Sharpe 0.1747；自助抽样型均值0.8463%、标准差4.8991%、Sharpe 0.1728。主动型持仓随时间调整，整体约35.03%为大盘平衡股。

## Quant takeaways
- 长窗口、分状态稳定性和持仓穿透比单次alpha更适合识别能力。
- 结论依赖存活样本、因子模型和二次规划设定；实际应用仍需考虑费用、容量、基金风格漂移与样本选择。
