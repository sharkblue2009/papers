# 海通证券选股因子系列研究（六十四）：基于直观逻辑和机器学习的高频数据低频化应用

- **source filename**: `20200424-海通证券-选股因子系列研究（六十四）：基于直观逻辑和机器学习的高频数据低频化应用.pdf`
- **date**: 2020-04-24
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 金融工程专题报告

## Core question
能否把委托、成交等不同层级的高频信息混合起来，做成更适合低频选股的因子。

## Methods / data
把盘口委托中的“未释放交易意愿”与逐笔成交中的“已发生主动买入”合并，构造买入意愿占比、日内买入意愿强度等因子；同时用机器学习自动挖掘一些低频化特征，再做正交和增强组合回测。

## Key findings
- 开盘后买入意愿占比最强，月均IC超0.03、ICIR高于3、月胜率约85%，月均多空收益约0.98%。
- 日内买入意愿强度类因子整体更强，因子月均IC普遍高于0.03，ICIR普遍高于2.5。
- 买入意愿类因子普遍优于仅看净主买的版本，说明“委托意愿 + 已成交行为”的组合信息更完整。
- 一些机器挖掘因子（如Alpha_1、Alpha_4、Alpha_6）带有较明确的经济逻辑，也能在正交后保持较强选股能力。
- 在中证500增强里，引入开盘后日内买入意愿强度、Alpha_2、开盘后买入意愿占比、Alpha_4 等因子，对组合改善较明显。

## Quant takeaways
高频数据低频化最有效的方式不是单纯降采样，而是把“意愿”与“成交”两个层面的信息拼起来，再用机器学习做补充。

## Caveats
机器挖掘因子虽有效，但要防过拟合；组合改善对原始模型结构仍有依赖。
