# 研报摘要
- 源文件：20241007-华泰证券-金工深度研究：大模型本地部署手册.pdf
- 日期/机构/类型：2024-10-07｜华泰证券（华泰研究）｜金工深度研究
- 核心主题：面向个人与企业的本地大模型部署实用手册，覆盖大模型本地运行、前端网页应用、后端推理库以及本地化应用框架。
- 方法/数据：以部署流程讲解为主，从“前后端是否存在”将方案分为三类；逐一示范 Ollama、LM Studio、ChatGPT Next Web、llama.cpp，以及 AnythingLLM、Dify 等应用框架。
- 关键发现：本地部署能降低对云端 API 的依赖，提升隐私、安全和成本控制能力；不同框架分别适合集成式、轻量化前端、纯后端推理和 RAG/多智能体应用场景。
- 量化要点：本文不含回测或收益指标，主要提供模型格式、安装方式、API 调用、并发能力和应用搭建的操作参数。
- 局限性：工具版本迭代快，部署细节可能随版本变化；大模型输出存在准确性波动，需结合场景谨慎选择。
- 关键词：本地部署、Ollama、LM Studio、llama.cpp、AnythingLLM、Dify、RAG、多智能体
