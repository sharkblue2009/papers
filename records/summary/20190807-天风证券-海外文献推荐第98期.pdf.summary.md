# 低波动需要很少的交易

- **source filename**: `20190807-天风证券-海外文献推荐第98期.pdf`
- **date**: 2019-08-07
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
文章研究低波动组合的风险降低幅度与换手率之间的关系，并检验价值、动量等因子暴露是否也存在边际收益递减。核心观点是，超过必要水平的交易可能只带来很少的额外风险或Alpha改善。

## Methods / data
- 汇总89篇低波动研究中的21组结果，并用1989–2013年全球流动性最好的3000只股票做模拟。
- 每月从过去3年波动率最低股票中等权持有500只；改变卖出阈值，形成8组换手水平，考察波动减少和CAPM Alpha。
- 进一步以PE和过去第2至第12个月收益构造价值、动量暴露，并与低波策略组合。

## Key findings
- 21篇研究平均波动减少26%（区间19%–37%），平均换手50%（区间19%–119%）；约30%换手已足以实现约25%风险降低。
- 模拟中换手11%–32%时，波动降低22%–28%；前10%换手带来约22.5%风险减少，第二个10%仅增加约3.5%。
- 模拟Alpha约5.3%–6.5%，换手与风险降低呈凸关系；回归R²由约90%提高到97%时，对数换手系数约0.05。
- 全球低波股票平均年换手约77%，高波动股票约281%；低波股票交易成本约11bp，全部股票平均约14bp。

## Quant takeaways
- 低波指数设计可设置缓冲区和较低换手，单边30%换手与11bp交易成本约产生7bp/年成本。
- 价值和动量能在较低交易量下提高Alpha，但边际收益也递减；多因子融合通常优于单独追求高暴露。
- 若低波产品年换手超过30%，应要求额外的风险或收益证据，并纳入容量、冲击成本和税费。
