# 海通证券选股因子系列研究（二十四）：基于拟合优度和波动率调整的因子溢价估计

- **source filename**: `20170828-海通证券-选股因子系列研究（二十四）：基于拟合优度和波动率调整的因子溢价估计.pdf`
- **date**: 2017-08-28
- **document type**: 金融工程专题报告

## Core question
如何改进因子溢价预测：固定窗口是否太粗糙，能否用拟合优度和波动率对加权衰减进行动态调整。

## Methods / data
- 对比 **固定窗口等权移动平均**、**指数加权移动平均** 和改进版本。
- 用 **拟合优度** 估计当前异质性并决定衰减速度；再用 **波动率** 对因子溢价值做调整。
- 重点比较平均收益、波动性、回撤和收益风险表现。

## Key findings
- 固定窗口过长会滞后，过短会噪音太多；指数加权更灵活。
- 基于拟合优度动态设定衰减速度，能在不明显损失平均预测能力的前提下 **显著降低波动性**。
- 再叠加波动率调整后，因子溢价预测的收益风险表现进一步改善。
- 改进模型的逻辑是：牺牲部分高收益阶段，换取失效阶段更好的回撤控制和风险平滑。

## Quant takeaways
- 因子溢价预测本质上是一个 **稳定性-敏感性** 的平衡问题。
- 不要只追求预测收益最高，也要追求预测序列更平滑、更可用。
- 适合把这套方法用在因子轮动和因子择时的输入端。

## Caveats
- 在因子失效后若出现快速反弹，改进模型可能会明显落后等权法。
- 更适合风格切换频繁、追求回撤控制的场景。
