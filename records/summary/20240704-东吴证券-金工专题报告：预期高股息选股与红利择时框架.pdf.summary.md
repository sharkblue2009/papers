# 核心主题
围绕“预期股息率”构建高股息选股策略，并叠加红利风格择时框架，以提升红利资产的收益和回撤表现。

# 方法与数据
- 预期股息率分两阶段构造：
  - 年报公告日至 10 月底：依据年报已披露分红计算。
  - 10 月底至次年年报公告日：使用三季报财务数据预测年度分红。
- 在沪深300成份股中，结合反转因子与盈利因子筛选高股息股票。
- 红利择时使用五个信号：PPI 同比、M2 同比、M1-M2 剪刀差、美国10年期国债收益率、红利股成交额占比。

# 主要结论
- 预期股息率优于历史股息率，更适合做前瞻性红利选股。
- 红利择时能有效规避 2019-2021 年红利风格回撤，并抓住近年的强势期。
- 将高股息选股与择时结合后，整体收益和风险指标明显改善。

# 量化要点
- 预期高股息组合：2009-02 至 2024-05，年化收益 14.00%，信息比率 0.64，最大回撤 34.76%。
- 红利风格择时纯多头：年化收益 5.23%，夏普 0.61；多空年化收益 7.43%，夏普 0.71，月胜率 56.82%。
- 结合择时后的策略：年化收益 8.69%，夏普 1.10，波动率 7.92%，最大回撤 15.44%。

# 局限性
- 依赖未来分红预测，若盈利或分红政策变化，效果可能下降。
- 回测结果受市场风格变化、交易成本与样本偏误影响。
