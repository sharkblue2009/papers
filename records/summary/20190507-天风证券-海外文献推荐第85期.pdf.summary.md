# 原油期货市场的知情交易

- **source filename**: `20190507-天风证券-海外文献推荐第85期.pdf`
- **date**: 2019-05-07
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
研究EIA每周原油库存公告前，WTI期货是否出现与信息泄露或知情交易一致的价格和订单行为。重点检验库存实际值显著高于分析师预期时，公告前的订单不平衡与价格变化。

## Methods / data
- 样本为2007–2014年NYMEX-CME近月WTI期货，EIA通常在周三10:30公布库存。
- 将EIA库存实际值与Bloomberg分析师预期比较，定义正、负向及3σ/4σ超预期事件。
- 用2分钟和5分钟成交量构造买卖订单不平衡，比较公告前后收益、累计收益和订单不平衡，并做不同阈值及窗口的稳健性检验。

## Key findings
- 当库存高于预期时，公告前约2小时出现显著买卖订单失衡，模式在不同超预期定义和指标下基本稳健。
- 公告前WTI价格平均下跌约0.25%；公告后价格对信息存在过度反应，随后数小时部分回补。
- 典型案例中，库存意外增加导致公告后油价数分钟内下跌近6美元；这属于单日极端事件，不代表平均效应。
- 结果与知情交易一致，但作者明确指出，也可能是交易者更擅长预测库存或整合持续供需信息，不能视为泄密的明确证明。

## Quant takeaways
- 可将库存 surprise、事件时间和2/5分钟订单流结合，构造公告前异常交易监控或事件策略。
- 回测必须处理公告时钟、期货换月、流动性时段、交易成本和极端价格跳跃。
- 订单失衡是相关证据而非因果证据；应加入API公告、供需新闻和预测修正等替代解释。
