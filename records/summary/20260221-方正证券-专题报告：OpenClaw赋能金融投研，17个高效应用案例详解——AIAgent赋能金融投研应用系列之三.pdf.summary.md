# OpenClaw 赋能金融投研：17 个高效应用案例详解 摘要

- **来源文件**：20260221-方正证券-专题报告：OpenClaw赋能金融投研，17个高效应用案例详解——AIAgent赋能金融投研应用系列之三.pdf
- **日期/机构/类型**：2026-02-21，方正证券，专题报告/AI Agent 应用案例

## 核心问题
OpenClaw 在金融投研中能落地哪些高效场景，能否真正从“对话”走向“做事”。

## 方法与数据
- 通过 17 个应用案例验证 OpenClaw 的执行能力。
- 场景包括：浏览器检索、skills 安装、邮件管理、本地文件管理、任务提醒、PPT/研究报告生成、接管浏览器、对接同花顺/Mi筐/Wind API、PB-ROE 选股、杯柄形态选股、股票分析、因子挖掘与回测。
- 展示在腾讯云、本地 Windows、飞书等不同部署组合上的使用效果。

## 关键发现
- OpenClaw 能显著降低工具与工作流搭建门槛，适合主动投研与量化投研场景。
- 其价值在于把 LLM 的认知能力和本地执行能力结合起来。
- 风险主要来自权限、网络安全和模型幻觉。

## 量化要点
- 报告没有统一金融回测结果，但展示了多个量化/自动化案例。
- GitHub 星标超过 **21.5 万**。
- 核心量化意义在于提效，而非直接收益指标。

## 局限性
- 很多案例属于演示性质，未必可直接复制到生产环境。
- 依赖外部接口、技能包与本地权限配置。
