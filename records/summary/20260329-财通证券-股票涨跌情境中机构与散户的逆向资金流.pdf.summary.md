# PDF总结

- 来源文件：20260329-财通证券-股票涨跌情境中机构与散户的逆向资金流.pdf
- 日期 / 机构 / 类型：2026-03-29，财通证券，金融工程专题报告 / 选股因子
- 核心问题：资金流因子的有效性是否取决于市场情境，且如何通过“情境-行为”匹配构建更强的资金流选股因子。
- 方法与数据：基于 Wind 资金流分类，比较大单/小单、单数/金额、买入/卖出占比；在上涨/下跌情境和市值分域中做绩效统计；构建 IRCF 因子，并扩展出一套 regime-behavior 因子体系。
- 关键结论：单数优于金额，小单卖出在下跌情境中最强，大单因子更接近情境无关；IRCF 通过“下跌看小单卖出、上涨看大单买入、大票只看小单”显著提升表现。
- 量化要点：IRCF 自 2017 年以来多空年化收益约 25.8%，多头超额 9.6%，多头 IR 2.13，月度 IC 均值 7.1%，ICIR 3.29，IC 胜率 85.2%；资金流综合因子多头超额约 9.9%。
- 局限性：因子有效性依赖市场风格与情境，存在失效风险；历史规律不代表未来。
- 关键词：资金流因子、机构与散户、情境匹配、IRCF、小单卖出、大单买入、选股因子
