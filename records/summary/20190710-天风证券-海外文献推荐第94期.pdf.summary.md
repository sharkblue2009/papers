# 趋势信号强度与CTA策略表现

- **source filename**: `20190710-天风证券-海外文献推荐第94期.pdf`
- **date**: 2019-07-10
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
文章提出自适应时间序列动量（ATSMOM）因子，用多个回看窗口的信号综合衡量趋势强度，模拟趋势增强时加仓、趋势减弱时减仓的CTA，并检验其作为CTA资产基准和Alpha评估工具的有效性。

## Methods / data
- 期货数据包含四类资产98个合约的日收盘价、持仓量和成交量，样本为1990年1月至2015年9月；CTA基金收益来自BarclayHedge，覆盖1994年1月至2015年9月。
- 综合多个短、中、长期TSMOM信号，形成连续信号强度；加入合约交易成本、汇率、信号延迟等现实摩擦。
- 将ATSMOM与管理人指数、传统TSMOM、速度因子及其他风险因子回归，并做基金特征面板分析。

## Key findings
- ATSMOM比传统二元TSMOM更能解释基于管理人的CTA指数收益，并通过动态敞口提高趋势明显市场的配置。
- 速度因子（做多长期、做空短期动量）也能解释CTA收益；在速度因子上的暴露较高的CTA表现更好。
- CTA风险调整收益具有动量：前一年表现强的基金下一年往往更强；业绩与基金规模负相关、与基金年限正相关。
- 同期资金流、较高管理费和绩效费并不预示更高Alpha；报告未给出统一的策略Sharpe数值。

## Quant takeaways
- ATSMOM可作为CTA横截面基准或管理人筛选因子，重点比较增量Alpha而非简单超额收益。
- 组合实现需处理合约换月、汇率、交易延迟、容量和市场冲击；大基金可能面临更高隐藏成本。
- 信号强度平滑能降低二元信号频繁反转，但参数集合仍需滚动样本外和成本敏感性检验。
