# 海通证券选股因子系列研究（五十）：个股加权方式对比

- **source filename**: `20190618-海通证券-选股因子系列研究（五十）：个股加权方式对比.pdf`
- **date**: 2019-06-18
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、罗蕾
- **document type**: 金融工程专题报告

## Core question
比较多因子组合中不同个股加权方式对收益、换手率和资金容量的影响。

## Methods / data
对比等权、市值加权、方差倒数加权、因子相关加权（含连续倾斜）等权重方案，并测试容量约束。

## Key findings
- 因子相关加权收益最好，连续倾斜通常优于离散分位或 zscore 映射。
- 连续倾斜虽然收益高，但换手率也最高，资金容量最小。
- 资金容量与收益存在明显权衡，容量越大，收益往往越低。
- 设置最低容量门槛后，策略更适合实盘。

## Quant takeaways
- 权重设计是收益、换手和容量三者的平衡问题。
- 连续倾斜是更灵活的加权思路，但不一定最适合大资金。

## Caveats
- 高收益方案未必有足够容量，落地要先看交易约束。

## Keywords
个股加权, 连续倾斜, 方差倒数, 换手率, 资金容量
