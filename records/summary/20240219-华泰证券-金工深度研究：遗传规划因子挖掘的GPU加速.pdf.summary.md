# 20240219-华泰证券-金工深度研究：遗传规划因子挖掘的GPU加速

- **源文件**：`20240219-华泰证券-金工深度研究：遗传规划因子挖掘的GPU加速.pdf`
- **日期/机构/类型**：2024-02-19，华泰证券，金工深度研究

## 核心主题
- 使用GPU加速遗传规划（Genetic Programming, GP）因子挖掘流程，提升量化因子生成效率。

## 方法与数据
- 基于DEAP开源框架，使用 **PyTorch + CUDA** 拓展算子与适应度函数。
- 在 **Intel Core i9-13900KF + NVIDIA RTX 4090** 环境下测试。
- 将GP流程拆分为因子值计算、IC值计算、选择/交叉/变异等环节，分别评估加速效果。

## 关键发现
- GPU对遗传规划核心流程的加速非常明显：
  - 全流程加速约 **7~9倍**（合理种群规模下）
  - 因子值计算与IC值计算环节加速尤为显著
- 在种群数量 **30/100/300** 时，全流程加速约 **4.4/7.9/8.1倍**；核心环节加速约 **4.6/7.7/8.9倍**。
- 单次计算单因子全历史因子值和IC值：
  - CPU约 **8.5秒 / 0.8秒**
  - GPU约 **1秒 / 0.0007秒**
- 正式实验中，5轮挖掘、每轮进化3代，共得到 **350个** 符合入库条件的因子，总耗时约 **12.4小时**。
- 高频出现的优质组合为 **ts_grouping_sortavg + turn** 特征。

## 量化要点
- 大规模矩阵运算是GP挖掘的主要耗时来源，GPU化价值高。
- PyTorch+CUDA路线改写成本相对低、数据流更连贯，适合工程落地。

## 局限性
- GP因子可解释性较弱，存在过拟合和失效风险。
- 历史经验总结型因子，样本外表现不确定。
