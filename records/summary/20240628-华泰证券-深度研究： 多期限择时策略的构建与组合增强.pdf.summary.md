# 摘要
- 源文件：20240628-华泰证券-深度研究： 多期限择时策略的构建与组合增强.pdf
- 机构：华泰证券
- 日期：2024-06-28
- 类型：深度研究
- 主题：构建覆盖不同持有期限的时序择时策略，并通过多策略组合提升稳健性与收益。
- 方法/数据：在全球主要股票、债券、商品、外汇及行业指数上构建不同期限的择时策略，包括基于经济周期的长周期择时、HP滤波去噪、中短期双均线和布林带策略；再对不同期限策略做等权与加权组合。
- 主要结论：
  1. 不同资产在不同期限上具有不同的收益结构，单一择时框架难以覆盖所有场景。
  2. 长周期与HP滤波策略通常能更显著提升夏普比率，短期趋势策略更擅长控制回撤。
  3. 不同期限策略的等权组合可提升稳健性，并能一定程度对抗过拟合。
  4. 通过按资产趋势强弱或观点置信度加权，组合收益通常优于简单等权。
  5. 最新信号整体偏多股票和商品资产。
- 量化要点：
  - 多期限、多资产联合框架有助于形成通用择时体系。
  - 组合加权方式是提升收益与稳健性的关键。
- 局限：
  - 周期规律基于历史数据，短期市场情绪和结构变化可能导致信号失效。
- 关键词：时序择时、HP滤波、双均线、布林带、多策略组合。
