# ESG整合：价值，成长和动量

- **source filename**: `20220210-天风证券-海外文献推荐第210期.pdf`
- **date**: 2022-02-10
- **institution / author**: 天风证券；吴先兴、惠政宝；原文作者 Lars Kaiser
- **extraction confidence**: high

## Core question
考察ESG标准加入传统价值、成长和动量投资后，能否提高可持续性而不牺牲财务表现，并分析ESG整合对风险和风险调整收益的影响。

## Methods / data
- 使用Asset4数据库2002—2015年欧洲1072家公司和美国1756家公司，修剪异常值后为965家欧洲、1620家美国公司。
- 价值和成长依据晨星风格箱的多维指标，动量为跳过最近一个月的过去12个月收益；ESG分为环境、社会、治理，并按公司规模、行业、年份及欧洲国家效应调整。
- 每年6月用滞后6个月数据重平衡市值加权五分位组合，持有随后12个月，比较单一风格与ESG综合组合。

## Key findings
- 2003年7月至2016年6月，美国（欧洲）价值溢价约1.99%（0.21%）/年，动量溢价约3.26%（6.69%）/年。
- 原始ESG高低组合收益差异总体偏负，但调整规模和行业后，ENV、SOC、CGV高低溢价接近零，风险下降特征仍保留。
- ESG整合使美国各策略风险调整收益提高；欧洲主要是成长策略受益。美国组合ENV+SOC评级提高约30%—70%、CGV提高18%—43%；欧洲分别提高25%—40%和40%—60%，且未显著牺牲业绩。

## Quant takeaways
- ESG信号应先做规模、行业和地区中性化，避免把大盘或行业暴露误当作可持续性Alpha。
- 可测试不同风格的联合排序，但需关注年度低频调仓、ESG测度差异及美国/欧洲市场结构差异。
