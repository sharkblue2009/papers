# PDF摘要
- 源文件：20241119-湘财证券-超预期股票精选策略改进.pdf
- 日期：2024-11-19
- 机构：湘财证券研究所
- 类型：金融工程研究 / 一般报告
- 核心主题：在Wind全A市场内改进“超预期”股票精选框架，重构底层超预期股票池并叠加增强因子，形成更稳健的PEAD类选股策略。
- 方法/数据：检验净利润同比超预期、分析师超预期等因子；按因子排序构建TOP250与TOP250-500底层股票池；在池内按增强因子选出前30只股票等权组合，月末调仓，交易成本按0.15%计。
- 关键发现：净利润同比超预期因子表现最好，分析师超预期因子也有较强的多空收益；扩展到Wind全A后，改进后的超预期精选策略较原版更适合当前市场环境。
- 量化要点：净利润同比超预期因子IC均值约0.02、ICIR约0.45，多空年化收益约9.19%；分析师超预期因子多空年化收益约12.02%；最终超预期精选策略2019.01-2024.11.15年化收益约20.21%，超额收益约11.87%，截至2024-11-15当年绝对收益约14.42%，相对Wind全A超额约2.25%。
- 局限性：持仓数量较少导致波动和回撤偏大，且超预期策略对市场风格和景气周期较敏感。
- 关键词：超预期；PEAD；分析师预期；Wind全A；股票池；增强策略；选股
