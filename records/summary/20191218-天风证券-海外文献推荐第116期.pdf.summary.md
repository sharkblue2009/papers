# 更高的因子有效性评价标准

- **source filename**: `20191218-天风证券-海外文献推荐第116期.pdf`
- **date**: 2019-12-18
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
论文讨论在大量数据挖掘、选择性发表和未公开检验存在时，传统t统计量临界值是否仍足以认定一个新因子有效，并提出面向因子发现历史的多重检验框架。

## Methods / data
- 收集1967年以来资产定价顶刊及工作论文中提出新因子的313篇文章，其中250篇已发表、63篇工作论文。
- 汇总316个代表性因子，并按公共/特质及金融、宏观、微观结构、行为、会计等类别分类。
- 在不可观察的未发表检验背景下，调整p值和t统计量，比较Bonferroni、Holm、BHY等多重检验方法。
- 根据因子挖掘速度外推历史临界值至2032年，并讨论第一类和第二类错误。

## Key findings
- 传统约2.0的t统计量门槛在多重检验和发表偏差下过低；一个新的经验因子建议至少满足t>3.0。
- 研究认为许多文献发现的新因子可能并不是真实有效，因子数量很可能因未公开失败检验而被低估。
- 经济理论驱动的因子可使用相对较低门槛，但即便如此，t=2仍被认为不足。
- 无条件检验可能掩盖状态依赖性：某因子只在特定经济环境有效时，统一临界值仍需谨慎解释。

## Quant takeaways
- 因子研究应报告发现过程、候选因子数量、样本外复现和多重检验调整，而不只报告单一t值。
- 可把t>3作为经验筛选门槛，再结合经济机制、容量、换手和危机表现判断可交易性。
- 该框架依赖发表文献和对未观测检验数量的假设，不能替代真正的跨市场、跨时期复制。
