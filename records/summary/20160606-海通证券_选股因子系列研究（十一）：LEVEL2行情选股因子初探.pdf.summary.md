# 海通证券选股因子系列研究（十一）：LEVEL2行情选股因子初探

- **source filename**: `20160606-海通证券_选股因子系列研究（十一）：LEVEL2行情选股因子初探.pdf`
- **date**: 2016-06-06
- **document type**: 金融工程专题报告

## Core question
Level2 逐笔/委托成交数据能否构造出可用于中短期选股的因子，尤其是成交占比和净买入类指标是否有稳定 alpha。

## Methods / data
- 使用 **Level2 逐笔成交数据**，从成交金额大小和成交方向两个维度构造因子。
- 重点检验两类指标：**成交占比类**（连续竞价、超大单/大单/中单/小单成交占比）与**净买入比率类**。
- 回测采用月度持有视角，并进一步做市值、前期收益率（反转）和换手率的风险特征分析。
- 通过横截面回归取残差，剔除常见风险暴露后再检验因子有效性。

## Key findings
- **成交占比类因子显著更强**：连续竞价、中单、小单成交占比越高，次月收益越高；超大单、大单成交占比则越低越好。
- 这类因子的多空区分度很强，年化收益普遍在 **22%+**，其中连续竞价成交占比、超大单成交占比的多空年化收益超过 **27%**，月胜率超过 **70%**。
- **净买入比率类因子偏弱**：多数年化收益低于 **6%**，只有尾盘净买入比率接近 **10%**。
- 成交占比类因子与 **小市值、前期低涨幅、低换手** 明显相关，但在剔除这些暴露后仍保留较好 alpha。

## Quant takeaways
- Level2 不是只适合做超短线，高频成交结构也能提炼成可月度持有的选股因子。
- 优先关注 **“成交结构”而非“净买入方向”**：成交占比类比净买入比率更稳定、更有区分度。
- 实盘中可先做市值/反转/换手中性化，再使用成交占比类因子提高独立性。

## Caveats
- 因子对市场流动性和政策环境敏感，成交数据质量也会影响稳定性。
- 结论主要基于历史回测，交易成本和极端流动性冲击未必完全充分反映。
