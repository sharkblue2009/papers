# 文档摘要

- 来源文件：`20240831-开源证券-开源量化评论（100）：基金持仓与业绩视角下的选股策略.pdf`
- 日期：2024-08-31
- 机构：开源证券
- 类型：开源量化评论

## 核心主题
从公募基金持仓和基金业绩两个维度构建选股因子，用基金 Sharpe 表现来修正传统基金持仓因子的有效性。

## 方法与数据
- 不再只看“基金是否持有某股票”，而是结合基金自身业绩，用基金复权净值的 **Sharpe 比率** 构造股票因子。
- 使用（半）年报的全持仓数据和季报重仓股数据，同时区分静态持仓、持仓变化、增持、减持等情形。
- 对每只股票，计算持有/增持/减持它的基金 Sharpe 均值，作为该股票的基金 Sharpe 因子。
- 还讨论了基金增减配与流动性、交易拥挤度及未来收益分布的关系。

## 关键发现
- 仅基于基金持仓的因子并不总是有效，但把“基金业绩”纳入后，选股效果明显更好。
- 重仓股静态持仓算出的基金 Sharpe 因子更适合大盘；全持仓静态持仓则对大盘和小盘都适用。
- 动态持仓中的**增持股票**通常更优，说明资金流入和业绩筛选能互补。
- 两个因子等权合成后，小盘效果更好；在中证500与中证1000中，多空年化收益分别可达 **8.8%** 与 **10.2%**。
- 在沪深300样本池中，正交化后合成因子可将多头超额年化收益从 **5.8%** 提升到 **8.2%**。
- 因子收益主要来自夏普比率较低的基金，暗示“业绩较差基金的持仓更有延续性”这一经验规律。

## 量化要点
- 基金持仓信息本身不够，必须结合基金业绩做分层筛选。
- 通过静态/动态持仓、增持/减持拆分，可更细致地刻画基金行为。
- 适合与市值、行业中性化一起使用，提升稳定性。

## 局限性
- 基于历史持仓披露，存在时滞；未来持仓变化未必同步。
- 市场结构改变后，基金业绩与选股有效性的关系可能变化。
