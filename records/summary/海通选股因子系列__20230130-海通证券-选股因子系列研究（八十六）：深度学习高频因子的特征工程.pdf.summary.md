# 海通证券选股因子系列研究（八十六）：深度学习高频因子的特征工程

- **source filename**: `20230130-海通证券-选股因子系列研究（八十六）：深度学习高频因子的特征工程.pdf`
- **date**: 2023-01-30
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 金融工程专题报告

## Core question
深度学习高频因子的特征工程应该如何做：特征怎么构建、怎么处理、怎么归因、怎么筛选，才能更稳健地提升选股效果。

## Methods / data
以原始高频成交与盘口信息为基础，按“原始数据 → 分钟级基础指标 → 目标频率衍生指标”的框架构造特征；比较分布调整、极值处理、标准化、积分梯度归因，以及静态/动态特征筛选；并将不同特征集用于中证500和中证1000增强回测。

## Key findings
- 高频深度学习因子的关键不只是模型结构，特征工程本身就能显著影响结果。
- 对偏态明显的特征做分布调整、对极值做截断、再做标准化，通常有助于训练稳定性和预测效果。
- 特征数从 **176** 精简到 **128/64** 后，IC通常不降、年化多头超额收益反而更好；继续压缩到 **32** 时，可能开始损失有效信息。
- 特征筛选是有益的：可去冗余、缩短训练时间、减少计算资源，并提升模型表现，但“过度精简”会伤害效果。
- 单截面标准化和跨截面标准化的差异不大，说明该类高频模型对标准化方式不算特别敏感。

## Quant takeaways
这篇报告的核心结论是：深度学习高频因子不是“直接喂数据”就够了，特征工程的质量决定了模型上限；适度压缩特征集往往比盲目追求大而全更有效。

## Caveats
结论基于历史样本回测；高频因子仍会受到交易成本、流动性和市场状态变化影响。
