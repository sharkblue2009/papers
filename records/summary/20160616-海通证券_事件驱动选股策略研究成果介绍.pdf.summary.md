# 事件驱动选股策略研究成果介绍

- **source filename**: `20160616-海通证券_事件驱动选股策略研究成果介绍.pdf`
- **date**: 2016-06-16
- **document type**: 中期策略报告

## Core question
如何把事件驱动机会做成可选股、可跟踪、可组合的策略，尤其是调研、高送转和业绩预增这类事件是否具备稳定超额收益。

## Methods / data
- 从海通事件驱动研究积累中，筛选出三个更具参与价值的主题：**上市公司调研事件**、**潜伏利好之业绩预增**、**高送转预测模型**。
- 结合历史事件数据、业绩预告信息、分析师覆盖与机构关注度等信息做筛选。
- 高送转部分同时考察“有能力高送转”和“有意愿高送转”两类因子，并构建打分/预测模型。

## Key findings
- **调研事件反映市场热度**：被机构调研的公司通常已进入买方视野，后续更容易继续获得资金关注。
- **业绩预增的“潜伏”逻辑有效**：在净利润下限、同比增速下限等条件上进一步筛选后，策略表现较好。
- **高送转预测模型命中率高**：年报高送转中，得分最高的 **50 只股票平均命中率约 66%**；前 **10 只/20 只** 的命中率约 **82%/78%**。
- 前期有 **分析师覆盖** 的股票、以及 **基金重仓较少** 的股票，后续收益和胜率往往更好，说明“人气热度”和“增量资金空间”都重要。

## Quant takeaways
- 事件驱动可作为传统因子的补充层，尤其适合做 **热度/预期差** 交易。
- 选股上可优先关注：调研密度、业绩预告上修、送转预期打分，以及机构覆盖度变化。
- “前期已有热度”与“后续继续有热度”是两个不同维度，适合做组合式打分。

## Caveats
- 事件策略依赖事件披露节奏和市场情绪，时间敏感性强。
- 业绩预增、高送转等主题容易受监管和市场风格变化影响。
