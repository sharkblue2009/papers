# 海通证券选股因子系列研究（五十九）：基于逐笔成交数据的高频因子梳理

- **source filename**: `20200223-海通证券-选股因子系列研究（五十九）：基于逐笔成交数据的高频因子梳理.pdf`
- **date**: 2020-02-23
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 金融工程专题报告

## Core question
把前几篇逐笔成交相关研究中筛出来的有效高频因子做一次系统梳理，看看哪些信号最稳、在哪些指数范围内更有效。

## Methods / data
整理前期逐笔因子（如大买成交金额占比、盘中主买占比、尾盘知情主买占比、买单集中度等），在正交低频因子后做月度、半月度、周度回测，并比较全市场、中证800、中证500、沪深300范围内的差异及因子间相关性。

## Key findings
- 正交后逐笔因子整体仍有显著月度选股能力，月均IC约0.03~0.04，除买单集中度外年化ICIR多高于2。
- 因子在中证800内更稳健；在中证500内多数因子减弱；在沪深300内大买成交金额占比和盘中主买占比仍较强。
- 提高调仓频率通常能增强ICIR和多空收益，但从半月度再到周度，只有少数因子继续改善。
- 逐笔因子与市值、估值、前期涨幅、换手率等常规技术/风格因子存在相关性，且部分逐笔因子之间也有共线性。
- 逐笔因子可加入指数增强组合，提升多头端收益，但效果取决于原有模型结构与风控约束。

## Quant takeaways
逐笔成交里确实有可交易信号，但“有效”并不等于“通用”：需要按指数范围、换仓频率和与既有因子的关系来筛。

## Caveats
高频信号对交易成本、样本区间和数据质量较敏感；组合增益并非对任意模型都稳定。
