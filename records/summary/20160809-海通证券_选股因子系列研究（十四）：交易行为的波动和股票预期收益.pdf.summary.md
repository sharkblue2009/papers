# 海通证券选股因子系列研究（十四）：交易行为的波动和股票预期收益

- **source filename**: `20160809-海通证券_选股因子系列研究（十四）：交易行为的波动和股票预期收益.pdf`
- **date**: 2016-08-09
- **document type**: 金融工程专题报告

## Core question
交易行为本身的“波动性”是否比交易行为均值更能解释股票未来收益。

## Methods / data
- 用过去 **20 日日换手率的变异系数**（标准差/均值）定义交易行为波动性。
- 采用分组法与横截面回归两种方式检验其与未来收益的关系。
- 与日均换手率及常见风险因子（市值、反转、净市率）对照，并做交叉分组和多元回归。

## Key findings
- 换手率变异系数是一个明显的 **反转型因子**：波动越大，未来收益越低。
- 在 5/10/15 个交易日持有期下，首尾组合收益差都显著为正；相较于日均换手率，这一信号更强。
- 市值、反转、净市率等传统因子无法完全解释该效应，多元回归中该变量系数稳定显著，加入后模型 R² 进一步提升。
- 结论上，**换手率变异系数比日均换手率更有效**。

## Quant takeaways
- 交易行为的“二阶矩”能提供比均值更独立的信息，适合做流动性/情绪型 alpha。
- 对于换手类因子，不只看均值，也要看波动稳定性。
- 可把该因子作为独立信号或与流动性、反转因子组合使用。

## Caveats
- 因子对流动性和市场状态敏感，回测期外稳定性需继续验证。
- 主要检验的是历史统计相关，未直接覆盖冲击成本。
