# 基于Boruta的特征选择

- **source filename**: `20191016-天风证券-海外文献推荐第107期.pdf`
- **date**: 2019-10-16
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
论文提出Boruta算法，目标不是只找出让某个模型损失最小的最小特征集，而是识别所有与因变量相关、重要性超过随机噪声的特征，从而提高解释性和特征筛选稳定性。

## Methods / data
- Boruta以随机森林为包装器，为每个真实特征生成打乱后的“影子特征”。
- 每轮计算随机森林重要性Z-Score，以影子特征最大值作为基准，并通过双侧检验将特征确认、拒绝或暂不确定。
- 在Madelon数据集上使用2000个对象、500个原始属性，并加入500至3500个随机噪声属性，在64个测试集上检验可伸缩性。
- 在UCI/mlbench臭氧数据上验证筛选结果，并在Madelon任务上恢复真实信息属性。

## Key findings
- 属性数量增加时运行时间呈近乎线性扩展；样本量增加带来的时间增长略快但整体接近线性。
- 臭氧数据12个属性中，3个被拒绝，其中2个在第一轮后被拒绝、1个在最后被拒绝，其余被确认。
- Madelon实验确认20个重要属性，属性数量减少约96%。
- 单次随机森林的重要性分数波动较大；多轮影子特征比较比单次运行更稳定。

## Quant takeaways
- 金融特征研究可用Boruta区分“超过随机基准的相关特征”和仅对某个模型有用的特征。
- 应保留时间切分、purged CV和滚动稳定性检验，避免把跨期信息泄露带入随机森林。
- Boruta筛的是相关性而非因果性；高度相关特征可能共同入选，仍需经济解释、替代效应和交易成本测试。
