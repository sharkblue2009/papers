# PDF总结
- **来源文件**：20260422-源达信息-金融工程研究：重要股东增持单因子策略研究.pdf
- **文档类型**：源达信息 金融工程研究报告
- **核心主题**：基于“重要股东增持”事件构建单因子选股策略。
- **方法/数据**：因子定义为“二级市场交易区间增持市值 / 公司总市值”；统计竞价、大宗、盘后定价、可转债转股等增持路径；在全A样本中剔除ST/退市及部分行业，按因子排序每年4月/10月调仓选前10等权。
- **关键发现**：因子在熊市后期、中小盘、部分行业更有效；2014.04.30-2026.03.31 Top10组合总回报423.43%，年化14.72%，相对沪深300超额317.26%；2024年9月24日后阶段收益显著爆发。
- **量化要点**：市值约60亿-150亿区间 Rank IC 均值约0.05，正比例75%；农林牧渔、建筑装饰、电气设备表现较强。
- **局限性**：回测未充分考虑真实交易成本与样本外失效风险；行业分化明显，不能简单泛化。
- **关键词**：重要股东增持；单因子；Rank IC；中小盘；事件因子；选股策略
