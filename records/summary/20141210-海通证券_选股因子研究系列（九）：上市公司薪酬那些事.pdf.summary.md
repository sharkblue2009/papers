# 海通证券选股因子研究系列（九）：上市公司薪酬那些事

- **source filename**: `20141210-海通证券_选股因子研究系列（九）：上市公司薪酬那些事.pdf`
- **date**: 2014-12-10
- **institution / author**: 海通证券研究所；高道德、郑雅斌、沈泽承
- **extraction confidence**: high

## Core question
上市公司薪酬支出/增长能否成为反映经营扩张和员工激励的选股因子。

## Methods / data
- 使用沪深两市 **2636 只个股**财报数据，覆盖 2006 年年报至 2014 年三季报。
- 指标包括：应付职工薪酬、已付职工薪酬、员工人数，并构造薪酬增速、人均薪酬增速、连续增长期数。
- 采用滚动财务年方法消除季节性，并做行业控制。

## Key findings
- **应付职工薪酬增速**具有显著多空区分能力；**已付职工薪酬**不显著。
- 行业控制后，应付薪酬增速仍显著，说明不是单纯行业偏离。
- 在 **TMT** 行业效果最强，符合“人力成本占比高、薪酬更能代表经营状态”的逻辑。
- 连续增长期数虽呈上升趋势，但由于样本稀少，显著性和稳健性不足，不适合作为单策略。
- 代表性回测里，应付薪酬增速的多头/空头月均收益分别约 **1.66% / 1.22%**，多空 **0.44%**；人均应付薪酬增速更强，多空约 **0.48%**，t 值 **3.26**。

## Quant takeaways
- 薪酬因子更像是**成长/激励信号**，尤其适用于非周期、知识密集型行业。
- 优先考虑 **应付薪酬增速** 与 **人均应付薪酬增速**，而不是已付薪酬。
- 可把该信号用于“挖掘牛股”，但不宜单独高频运行。

## Limitations
- 标的数量较少，连续增长类指标不稳。
- 策略总体收益不高，更适合作为基本面补充因子。
