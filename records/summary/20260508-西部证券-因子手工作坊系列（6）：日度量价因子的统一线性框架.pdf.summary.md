# 西部证券：日度量价因子的统一线性框架
- Source file: `20260508-西部证券-因子手工作坊系列（6）：日度量价因子的统一线性框架.pdf`
- Document type: 证券研究报告 / 金工专题报告

## 核心主题
借鉴统一线性框架，从完整日收益率序列与换手率序列中提取日度量价信息，构造更稳健的量价因子。

## 方法与数据
- 基于 2015.01-2026.03 的样本区间
- 从月内完整日收益率序列构造 DRI（Daily Return Information）因子
- 用换手率序列替换收益率序列构造 DTI（Daily Turnover Information）因子
- 将 DRI 与 DTI 等权复合为 DMI_2 因子，并做双重排序、Fama-MacBeth 回归、时间序列回归检验

## 关键结论
- DRI 因子：IC 0.056，胜率 71.63%，年化 ICIR 1.830；多空年化收益 21.80%，多头年化超额 8.93%
- DTI 因子：IC 均值 0.064，年化 ICIR 2.382；多空年化收益 26.47%
- DMI_2 因子表现最好：IC 均值 0.070，ICIR 2.473；多空年化收益约 29.28%
- 这些因子明显优于短期反转、最高单日收益率等简单函数类量价因子
- DMI_2 与 Barra 风格因子相关性较低，说明捕捉了较独立的信息

## 对量化研究的启发
- 不必只依赖预设函数形式，直接让日内序列“发声”可以提高信息利用率
- 量价因子可以用统一线性框架做更可解释的提取
- 适合扩展到更多日频/序列型特征

## 局限与注意事项
- 仍存在模型结构风险、因子重叠风险和样本外风险
- 结果依赖历史区间，需警惕回测过拟合
- 因子组合未必在所有市场状态下都稳定
