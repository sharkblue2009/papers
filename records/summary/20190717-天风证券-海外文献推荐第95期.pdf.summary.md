# 防御性质的因子择时

- **source filename**: `20190717-天风证券-海外文献推荐第95期.pdf`
- **date**: 2019-07-17
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
文章提出“防御性因子择时”：不追求持续预测一阶收益，而是在因子相关性升高、风险承受能力骤降或估值异常昂贵时降低风险暴露，避免组合遭遇极端损失。

## Methods / data
- 构建经济增长、实际利率、通胀、信用、新兴市场和流动性六类宏观风险因子；2014年4月至2017年12月14类全球资产的前3个主成分解释约82%、前6个约92%。
- 设定基准组合风险预算：增长30%、实际利率30%，通胀/信用/新兴市场/流动性各约10%，目标波动率10%。
- 使用风险承受度指标RTI、因子组合多样化比率和相对历史均值的估值指标进行预警。

## Key findings
- RTI用收益排名与波动率排名的相关性刻画风险偏好；负值通常对应风险厌恶和压力阶段。
- 多样化比率在因子相关性上升时下降，可提示分散化收益正在减弱；估值分数为正表示相对历史偏低估，负值表示偏高估。
- 欧债危机（2010、2012）、美联储2013年收紧流动性和中国2015年经济冲击四个案例中，三类指标均显示一定预警功能。
- 报告主要提供框架和案例图示，未给出统一收益、Sharpe或回撤提升数值。

## Quant takeaways
- 可将RTI、相关性/多样化和估值作为低频风险开关，而不是高频择时信号。
- 防御调整应有明确阈值、交易成本和恢复规则，避免在压力期追涨杀跌。
- 宏观因子定义和估值锚点高度依赖市场；需做跨市场、长样本和触发频率的样本外验证。
