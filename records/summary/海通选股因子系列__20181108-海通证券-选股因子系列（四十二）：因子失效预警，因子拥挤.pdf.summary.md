# 海通证券选股因子系列（四十二）：因子失效预警，因子拥挤

- **date**: 2018-11-08
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 金融工程专题报告

## Core question
研究如何度量因子拥挤度，并用它来做因子失效预警。

## Methods / data
借鉴海外文献，用持仓/交易数据构造拥挤度指标，重点测试交易数据类指标对未来因子收益和收益波动的预测能力。

## Key findings
- 大多数因子的拥挤度与未来 6-24 个月因子收益负相关，拥挤越高，未来收益越差。
- 对收益波动的预测在 A 股中不如海外文献稳定，但部分指标仍有效。
- 复合拥挤度比单一拥挤度更稳健，因子进入高拥挤状态后，往往意味着收益减弱甚至回撤。
- 低拥挤状态通常对应更好的后续收益空间。

## Quant takeaways
- 拥挤度是因子失效预警的重要辅助指标。
- 交易数据比持仓数据更及时，但通常只能间接反映拥挤。

## Caveats
- 拥挤度不是精确择时器，更适合做风险监控。
