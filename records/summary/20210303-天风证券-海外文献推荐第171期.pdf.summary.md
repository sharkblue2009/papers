# Smart beta 和多因子组合的最优混合

- **source filename**: `20210303-天风证券-海外文献推荐第171期.pdf`
- **date**: 2021-03-03
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告提出基于基础 Smart beta 因子（ESB）评估和配置 Advanced beta 的框架，研究如何同时处理因子暴露、残差 alpha、杠杆/去杠杆和主动风险预算，从而优化单因子与多因子策略的混合。

## Methods / data
- 以 MSCI 全球价值、规模、动量指数作为 ESB，建立候选 Advanced beta 对 ESB 暴露和残差收益的因子模型。
- 通过均值—方差效用优化总回报或主动收益，允许对 ESB 和 Advanced beta 进行配置，并单独调整隐含杠杆。
- 案例设定 70%股票、30%债券，使用 1997—2015 年月度收益估计风险，主动风险预算为 3%。

## Key findings
- 仅 ESB 组合预期主动收益 1.4%，信息比 0.48；仅 Advanced beta 组合预期主动收益 1.5%。
- 混合组合预期主动收益提高至 1.8%（不做杠杆调整）或 2.1%（做杠杆调整），主动收益/风险比约 0.61 或 0.68。
- 价值与动量负相关，配置二者可带来较强分散化；规模因子与二者相关性较低，具有补充作用。
- 低波动等含有市场去杠杆的策略会消耗主动风险预算，若不识别其隐含 beta，可能改变原有战略资产配置。

## Quant takeaways
- 评估新 Smart beta 时应先回归已有 ESB，区分重复暴露与真正残差 alpha。
- 组合优化需显式处理中性化或补偿杠杆/去杠杆，并用前瞻收益、风险和相关性假设做敏感性分析。
- 案例结果依赖主观预期收益和协方差，实际投资还需加入约束、交易成本、容量和估计误差。
