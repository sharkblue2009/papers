# 晨星共同基金的评价与选择模型

- **source filename**: `20190410-天风证券-海外文献推荐第82期.pdf`
- **date**: 2019-04-10
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告回顾晨星用于评价和筛选股票型共同基金的星级、分析师评级、五大支柱、上下捕获率和管理评级，并讨论这些指标能否预测未来业绩。核心是把多项评级组合成可执行的基金筛选流程。

## Methods / data
- 依据文献回顾晨星3年、5年、10年风险调整收益及费用加权评级；星级按基金存续期组合不同期限权重。
- 以标普500等基准计算1、3、5、10、15年上捕获率和下捕获率，并结合过程、绩效、人员、公司、价格五支柱与管理评级。
- 评级有效性研究比较样本外收益、历史平均收益、Alpha和Sharpe；案例测试2013年5月的先锋国内权益基金。

## Key findings
- 星级分布约为五星10%、四星22.5%、三星35%、二星22.5%、一星10%。
- 低于三星的基金通常未来表现较差；但没有充分统计证据证明五星基金稳定优于四星基金。
- 管理评级A/B相对D/F基金，2001年1月至2004年7月每月高19–23bp，2004年9月至2006年12月高10–16bp。
- 先锋案例中6只基金最终仅2只同时满足捕获率等筛选条件。

## Quant takeaways
- 可将评级拆成历史风险调整绩效、前瞻管理质量和上涨/下跌阶段行为三层信号，再做滚动样本外检验。
- 星级更适合作为排除低质量基金的过滤器，不宜直接当作买卖信号；分析师评级目标期限较长，短期验证力有限。
- 需控制幸存者偏差、评级内生性、费用和风格暴露，并检验多重筛选后样本容量是否过小。
