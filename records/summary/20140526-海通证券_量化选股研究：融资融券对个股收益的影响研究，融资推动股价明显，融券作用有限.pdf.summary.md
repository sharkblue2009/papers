## Core question
融资融券数据到底能不能做选股因子？融资和融券哪一边更有信息含量？

## Methods / data
- 用 2011-01-01 至 2014-02-11 的个股收益做回归。
- 定义融资增速、融资余额占比、融券增速、融券余额占比以及净额类指标。
- 回测时按融资增速排序，买入前 n 只，持有 c 天；基准是融资融券标的股构成的虚拟等权指数。

## Key findings
- **融资增速** 比融资余额更有解释力，且显著性更强；较长观察/持有期（如 2 个月以上）更有效。
- 融资增速组合的超额收益主要来自 **2012Q4 之后**，与融资标的扩容和资金流入加快同步。
- 融资因子对**中小盘**更有效，在沪深300里效果一般。
- **融券**总体规模小，更多体现情绪层面；融券余额/增速对收益的解释不稳定，不适合作为主因子。
- 融资融券净额本质上仍主要由融资驱动，净额指标并没有比融资增速更好。

## Quant takeaways
- 可直接用**融资增速**做因子，尤其在中小盘和较长持有期上。
- 交易制度下“融资强、融券弱”的结构意味着：不要把净额当作对称信号。
- 该类因子更适合做**趋势确认**而不是超短线。

## Limitations
- 融券券源受限，数据结构性噪音较大。
- 因子效果对时间阶段敏感，2013 之后更明显。
