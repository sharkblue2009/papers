# 平均偏度是有用的！

- **source filename**: `20190403-天风证券-海外文献推荐第81期.pdf`
- **date**: 2019-04-03
- **institution / author**: 天风证券研究所；吴先兴；原文作者 Eric Jondeau、Qunzi Zhang、Xiaoneng Zhu
- **extraction confidence**: high

## Core question
论文研究个股收益偏度的横截面平均值能否预测下个月市场超额收益。理论机制是投资者偏好正偏度股票，导致其可能被高估，平均偏度上升后未来市场收益反而偏低。

## Methods / data
- 使用CRSP股票日度价格和市值加权CRSP市场指数，剔除当月至少少于5日收益、前月无市值、非流动性最差0.1%及价格低于1美元的股票。
- 计算个股月度方差和标准化偏度，再构造等权与市值加权平均偏度；市场超额收益减一个月国债利率。
- 以滞后平均偏度预测下月市场收益，控制市场方差、市场偏度、规模、个股和市场流动性、股息收益率、信用利差、期限利差及经济周期。

## Key findings
- 市值加权平均偏度的预测回归系数显著为负，单变量回归p值为0.4%，最高调整R²约0.79%。
- 平均偏度提高一个标准差，预测下月市场超额收益下降约0.55%（\(-0.1441\times0.038\)）。
- 预测能力并非由小盘、低价或低流动性股票造成；控制公司规模、市场流动性和经济周期后仍成立，且优于报告比较的其他经济金融预测指标。

## Quant takeaways
- 可把平均偏度作为市场择时或风险状态变量，并与市场收益、波动率和流动性共同建模。
- 偏度对日度微观结构噪声敏感，需固定股票过滤、滞后信息和加权方式；样本外稳定性、交易成本及偏度因子拥挤仍需验证。
