# 海通证券选股因子研究系列（十）：基于波段划分的动态反转因子

- **source filename**: `20151224-海通证券-选股因子研究系列（十）：基于波段划分的动态反转因子.pdf`
- **date**: 2015-12-24
- **institution / author**: 海通证券研究所；高道德、袁林青
- **extraction confidence**: high

## Core question
能否根据市场所处波段，动态选择反转因子的回看窗口，从而比固定 1 个月/3 个月反转更强。

## Methods / data
- 用 **万得全A指数**代表市场，并借鉴 Osler & Chang (1995) 的方法做波段划分。
- 使用 2008-01-04 至 2015-10-30 数据，20 个交易日调仓，剔除停牌/涨停/跌停干扰。
- 对比月度反转与动态反转的多空组合、行业中性组合，并做指数与标准差倍数敏感性分析。

## Key findings
- 动态反转在**行业中性组合**上明显优于月度反转：年化收益约 **22% vs 19%**，最大回撤 **15% vs 22%**。
- 在全市场前后 10% 多空上，动态反转与月度反转表现接近，年化都约 **27%**，最大回撤约 **17%**。
- 波段划分指数很关键：
  - 基于 **沪深300** 的动态反转明显不佳；
  - 基于 **中证500** 的效果接近；
  - 基于 **万得全A** 最稳定、提升最明显。
- 标准差倍数过小会让波段太敏感，导致窗口过短，反而削弱反转效果。

## Quant takeaways
- 反转因子不是固定窗口越短越好，应该**跟着市场阶段动态切换**。
- 做行业中性策略时，这种动态窗口法更容易体现优势。
- 可进一步扩展到行业指数或个股价格层面的动态反转，但主结论仍以全市场波段划分为佳。

## Limitations
- 波段划分参数敏感，尤其是标准差倍数。
- 在不同指数基准下效果差异大，说明方法依赖市场代表性选择。
