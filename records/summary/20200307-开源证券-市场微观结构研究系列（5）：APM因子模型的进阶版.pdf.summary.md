# APM因子模型的进阶版——市场微观结构研究系列（5）

- **date**: 2020-03-07
- **institution / author**: 开源证券；魏建榕、苏俊豪
- **extraction confidence**: high

## Core question
研究原始APM因子在2019年连续回撤的原因，并利用更细的日内时段重新构造因子。核心假设是隔夜、上午和下午交易行为包含不同的信息量。

## Methods / data
- 原始APM用过去20日股票与指数上午/下午收益回归残差之差构造，并横截面剔除20日动量。
- 将收益拆为隔夜、9:30—10:30、10:30—11:30、13:00—14:00、14:00—15:00五段，考察与未来20日收益的ICIR。
- 全市场五分组多空回测，剔除市值和行业；比较APMraw、APMnew及OVP/AVP等变体。

## Key findings
- APMraw样本内（2013年5月—2016年10月）年化15.90%、最大回撤2.52%、IR 2.84、月胜率78.6%；样本外年化6.41%、最大回撤5.72%。
- APMnew年化收益12.81%、ICIR 3.17、最大回撤2.32%、月胜率81.25%，优于APMraw的10.99%、2.07、5.72%和70%。
- OVP年化18.04%、ICIR 4.17、最大回撤2.21%、月胜率86.25%，显著优于AVP的3.00%、0.15、11.32%和53.75%。

## Quant takeaways
- 隔夜收益是更稳定的正向预测成分，可作为日内微观结构因子重构的优先候选。
- 需按指数成分和市场状态做样本外验证；报告显示中证500效果较好、沪深300一般，且历史日内规律可能变化。
