# 风格中性FOF：分散投资还是成本重负

- **source filename**: `20190213-天风证券-海外文献推荐第74期.pdf`
- **date**: 2019-02-13
- **institution / author**: 天风证券研究所；吴先兴；原文作者 Michael Stein、Svetlozar T. Rachev
- **extraction confidence**: high

## Core question
论文检验同时配置价值和成长基金的风格中性FOF，究竟能否改善风险调整收益，还是只得到分散化收益并承担额外费用。研究还比较价值FOF、成长FOF与50/50中性FOF。

## Methods / data
- 从晨星数据库选取美国大盘价值基金和成长基金，最终为25只价值、56只成长基金；样本期2003-07-01至2008-06-30。
- 构造2—24只基金的三类FOF，每种风格各占50%，与S&P500比较；用261周收益形成209个52周滚动窗口。
- 比较均值、标准差、偏度、峰度及Rachev比率，尾部参数示例为收益40%、风险1%。

## Key findings
- 投资6—8只基金即可明显降低收益标准差；风格中性FOF的平均收益大致是价值和成长FOF的平均。
- 中性FOF多数时期相对基准表现不占优，R比率通常被价值或成长FOF覆盖，未显示独特的风险调整超额收益。
- 混合风格能减少最坏结果，但也牺牲最好的结果；额外FOF费用会进一步压低净表现。

## Quant takeaways
- 中性配置可作为降低风格和尾部暴露的工具，而非天然alpha来源；择时切换价值/成长比例可能更有意义。
- 样本短且跨越金融危机，基金幸存者偏差、费用、风格漂移和基金选择能力需在更长样本中复核。
