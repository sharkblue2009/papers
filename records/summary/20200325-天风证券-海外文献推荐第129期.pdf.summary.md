# “懒惰”的投资者——不可忽视的财报措辞变化

- **source filename**: `20200325-天风证券-海外文献推荐第129期.pdf`
- **date**: 2020-03-25
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: medium

## Core question
报告研究投资者是否忽视财报文本与历史文本之间的措辞、结构变化，以及这种被忽视的信息能否预测公司未来经营和股票收益。核心机制是数字信息易比较，而文本变化不易被系统处理。

## Methods / data
- 使用SEC的10-K、10-K405、10-KSB和10-Q文本，样本期1995—2014年；剔除表格和图片。
- 以Cosine、Jaccard、最小编辑距离和简单差分四种指标衡量本期与去年同期报告的相似性。
- 按相似性五分位分组，公告后下月建仓、持有3个月、每月调仓，并用Fama-French及动量、流动性因子和Fama-MacBeth回归检验。

## Key findings
- “变化最大”与“变化最小”组合的等权多空收益约0.18%—0.38%/月，市值加权最高约0.56%/月。
- 买入无变化、卖出变化股票在下一年获得约0.35%—0.58%月度超额收益，年收益约7%（t=3.59），效应持续18个月且无反转。
- 管理层、诉讼和风险因素文本变化尤其重要；变化还能预测未来盈利、新闻和破产风险，公告窗口本身没有明显价格反应。

## Quant takeaways
- 可将10-K/10-Q相似度、编辑距离和章节级变化做成文本因子，并单独监控CEO/CFO、诉讼和风险段落。
- 需要防止文档发布日期、文本清洗和行业报告格式变化造成的伪信号。
- 报告文本有轻微OCR/编码噪声；实际研究仍应使用原始SEC文件并纳入借券、交易成本和容量约束。
