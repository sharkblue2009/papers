# 大银行具有更高的价值吗？

- **source filename**: `20191204-天风证券-海外文献推荐第114期.pdf`
- **date**: 2019-12-04
- **institution / author**: 天风证券；吴先兴（分析师）、何青青（联系人）
- **extraction confidence**: high

## Core question
论文检验“大而不倒”（TBTF）是否使大型银行获得更高估值。研究同时考察银行规模与估值、风险、盈利和危机表现，判断大型银行的规模优势是否足以抵消监管、代理和政治成本。

## Methods / data
- 样本为1987-2017年194家上市银行控股公司，共1914个观察；资产以2010年不变美元计，要求超过10亿美元且存款占资产至少10%。
- 将资产超过500亿美元定义为TBTF，100亿至500亿美元作为小型银行。
- 使用Tobin’s Q和市净比（MB）估值，并控制ROA、ROE、股票波动、尾部风险、z-score、杠杆和收入多样化。
- 采用固定效应、分段线性、非参数、工具变量和收购跨越门槛事件检验。

## Key findings
- 全样本平均Tobin’s Q为1.065；大型银行平均估值低于小银行，但简单均值差异不显著。
- 1987-2006年及较长样本中，TBTF银行估值与规模总体负相关，未发现规模扩大带来估值溢价。
- 危机期间规模与估值的负关系较小，TBTF银行估值下降幅度相对较低，但仍不随规模上升。
- 负相关不能由ROA、ROE、波动、尾部风险、困境风险或股权贴现率解释，市场低估交易活动贡献只能部分解释；收购跨过TBTF门槛会损害股东财富。

## Quant takeaways
- 银行因子模型应允许规模效应在危机和正常状态下切换，并同时纳入监管门槛变量。
- 估值回归需处理规模内生性、门槛非线性及收购自选择，不能仅比较大、小银行均值。
- 结论基于美国大型上市银行，外推至非上市银行、其他国家或新监管周期需谨慎。
