# 使用深度神经网络提升时间序列动量策略

- **source filename**: `20200101-天风证券-海外文献推荐第118期.pdf`
- **date**: 2020-01-01
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
论文将深度神经网络直接用于时间序列动量头寸生成，比较传统趋势强度—头寸映射与直接学习目标仓位的差异，并评估交易成本对优势的侵蚀。

## Methods / data
- 使用Pinnacle Data Corp CLC的88个连续期货合约，涵盖商品、固定收益和货币，数据1990-2015年。
- 模型包括岭回归、MLP、WaveNet和LSTM；输入为不同期限波动率标准化收益及MACD特征。
- 每5年重新校准并固定未来5年权重，形成1995-2015年完全样本外回测。
- 评价收益、正收益比例、波动、最大回撤、Sharpe、Sortino、Calmar和换手；另做交易成本与换手率正则化。

## Key findings
- 以Sharpe为目标的LSTM优于所有基准，比最佳神经网络MLP提升约44%，相对Sgn(Return)基准提升超过两倍。
- WaveNet弱于基准和简单线性模型；直接学习头寸优于先预测趋势再映射头寸。
- 机器学习策略换手约为多头基准的10倍；基准可承受约5bp交易成本，多数机器学习模型约4bp。
- 在2-3bp成本下Sharpe最优LSTM仍表现最好；换手正则化LSTM在10bp极端成本下仍有显著效果。

## Quant takeaways
- 可用直接头寸输出和Sharpe目标替代先预测收益再定仓位，但应采用滚动再训练和严格样本外评估。
- 交易成本、容量和换手是核心约束；未经正则化的深度动量优势可能被成本吞噬。
- 88个期货池和特定特征设计仍有限，需在不同资产、成本、杠杆和危机阶段复现。
