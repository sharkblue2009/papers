# 海通证券选股因子系列研究（五十三）：上市公司股价关系网因子

- **source filename**: `20190824-海通证券-选股因子系列研究（五十三）：上市公司股价关系网因子.pdf`
- **date**: 2019-08-24
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、张振岗、梁镇
- **document type**: 金融工程专题报告

## Core question
把上市公司看成网络节点，挖掘股价相关性和产业关系中的网络因子。

## Methods / data
用股价相关性、主营业务收入和行业/概念板块关系构造度、中心性、溢出效应等图论因子。

## Key findings
- 度和中心性因子显著有效，中心性尤强；短期高相关溢出更偏反转，长期溢出更偏动量。
- 主营业务收入网络的溢出效应较弱。
- 将股价相关性与行业/概念板块叠加后，动量溢出因子效果还能进一步提升。
- 说明“关系网络”能提供传统财务因子之外的增量信息。

## Quant takeaways
- 股票并非孤立资产，网络结构本身就能形成选股信号。
- 短周期和长周期网络信号方向可能不同。

## Caveats
- 网络构造方式会显著影响结果，需谨慎设定邻接关系。
