# 海通证券选股因子系列研究（五十六）：买卖单数据中的Alpha

- **source filename**: `20191107-海通证券-选股因子系列研究（五十六）：买卖单数据中的Alpha.pdf`
- **date**: 2019-11-07
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青、余浩淼
- **document type**: 金融工程专题报告

## Core question
把逐笔成交中的买卖序号合成为买卖单数据，提取更细的日内交易结构信息。

## Methods / data
基于买卖单数据构造大单成交金额占比、买卖集中度等因子，并检验正交前后、不同指数范围和不同调仓频率。

## Key findings
- 大买成交金额占比、大买大卖差值等因子正交后仍显著有效。
- 集中度因子也有较强选股能力，且在正交前后都较稳定。
- 大单金额占比类因子在中大盘范围仍有效；集中度因子更偏中小盘。
- 在更高调仓频率下，部分月度有效因子仍能维持，甚至更稳。

## Quant takeaways
- 从“笔”到“单”的重构，能挖出 BS 标志之外的新信息。
- 买卖单结构是刻画日内 alpha 的重要补充。

## Caveats
- 高频数据对样本期、盘口质量和交易成本较敏感。
