# 高频交易策略的风险测度与微调

- **source filename**: `20190101-天风证券-海外文献推荐第69期.pdf`
- **date**: 2019-01-01
- **institution / author**: 天风证券研究所；吴先兴；原文作者 Álvaro Cartea、Sebastian Jaimungal
- **extraction confidence**: high

## Core question
报告研究做市型高频交易中，资金和仓位限制如何改变最优报价、收益与风险，并提出适用于多类策略的风险度量。核心是把预期利润与最终仓位、持仓路径风险相匹配。

## Methods / data
- 以中间价扩散、买卖订单泊松到达和有限库存构建HJB最优报价模型；报价成交概率随价差指数衰减。
- 目标函数包含最终财富、最终库存惩罚α和全程库存惩罚φ；模拟设T=10秒、κ±=25、σ=1，并考虑对称/非对称订单到达。
- 风险指标为最终PnL方差、最终仓位方差和存续期仓位方差；通过模拟比较α、φ、库存上下限等参数。

## Key findings
- 提高φ会同时降低策略收益和三类风险，但在一定范围内收益下降较小、风险下降较明显。
- 提高α主要降低最终仓位风险；当α较大时可在收益近似不变下明显降低风险，整体影响弱于φ。
- 对称市场下库存均值回复至零；订单到达不对称时均值回复点偏离零，增加φ可使其更接近零。

## Quant takeaways
- 实盘做市应同时监控PnL波动、终端库存和库存路径波动，而不能只看收益Sharpe。
- 该结果基于模拟而非真实订单簿数据；应加入价差跳变、撮合排队、冲击、手续费、延迟和库存限额后再校准。
