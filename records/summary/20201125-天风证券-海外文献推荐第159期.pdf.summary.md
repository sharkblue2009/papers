# 估计分析师预期偏差新方法——投资者是否过度依赖分析师预期

- **source filename**: `20201125-天风证券-海外文献推荐第159期.pdf`
- **date**: 2020-11-25
- **institution / author**: 天风证券；吴先兴；原文作者 Erik C. So
- **extraction confidence**: high

## Core question
本文指出传统分析师预测偏差估计会因分析师私人信息和动机产生偏误，提出用公司历史基本面直接预测未来盈利，再与分析师一致预期比较。研究检验投资者是否过度重视分析师预测、低估可预测的偏差。

## Methods / data
- 以滞后收益、账面价值、应计收益、资产增长、股息和价格等基本面变量，估计公司特征盈利预测。
- 定义“特征预测乐观程度”为特征预测减去分析师一致预期，并按五分位构造多空策略。
- 比较特征方法与传统预测误差回归，控制Fama-French因子、公告漂移、动量、应计异常和价值策略。

## Key findings
- 特征预测乐观度最高五分位多头、最低五分位空头的无条件样本外策略，年均回报约5.8%。
- 在股价对盈利消息更敏感的公司中，年均回报约9.4%；小公司、历史盈利失望或透明度低的公司信号更强。
- 特征预测高于一致预期的公司随后更可能实现超预期，分析师也会向特征预测方向修正。
- 结果支持投资者过度依赖分析师预测，且收益在风险调整和横截面控制后仍存在；文本未给出完整显著性表格。

## Quant takeaways
- 可用基本面盈利预测与一致预期之差构造事件前横截面信号，并结合公告漂移交易。
- 必须严格使用公告前可得信息，滚动估计模型，避免把未来财报或修正信息带入。
- 分析师覆盖、信息透明度、规模和交易成本会影响可实现性；方法的预测误差仍可能随行业和时期变化。
