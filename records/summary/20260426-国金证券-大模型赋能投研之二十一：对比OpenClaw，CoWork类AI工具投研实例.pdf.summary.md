# PDF总结
- **来源文件**：20260426-国金证券-大模型赋能投研之二十一：对比OpenClaw，CoWork类AI工具投研实例.pdf
- **文档类型**：国金证券 金融工程专题报告 / AI投研工具测评
- **核心主题**：对比 OpenClaw 与 CoWork 类 AI 工具，并验证其在投研流程中的应用。
- **方法/数据**：测试 WorkBuddy、Trae SOLO、QoderWork、Codex Desktop 等工具；比较基础功能、子智能体、远程连接、提示词迭代和知识库整合；并用金融插件与机构模板做实战案例。
- **关键发现**：国产工具生态与海外工具各有优势，海外完成能力更强但国产适配通信与生态更便利；CoWork 工具在命令足够完善时可高效完成投研任务，尤其适合日常跟踪、晨报、点评和深度报告生产。
- **量化要点**：重点是工具能力评测，不含传统量化收益指标。
- **局限性**：结论受提示词、模型版本与插件可用性影响；存在安全、版权与模型随机性风险。
- **关键词**：CoWork；OpenClaw；Claude；Codex；投研自动化；知识库；金融插件
