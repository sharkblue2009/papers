# 核心主题
从“分红金额 = 净利润 × 红利支付率”出发，分别从预期和景气度两条路径预测企业未来分红增长，并构建红利增长组合。

# 方法与数据
- 预期视角：使用一致预期数据，同时用最新一期财报净利润累计同比、ROE 稳定性对预期值做修正。
- 景气度视角：从净利润同比加速、ROE 同比加速两个角度筛选成长性更强的企业。
- 将四个子视角合并，得到分红增长预测股票池。
- 再按股息率排序，选取前 50 只构建组合。

# 主要结论
- 四个子视角下，分红增长预测胜率均超过 70%。
- 合并后总体上每年 4、8、10 月底的预测胜率约 71%，且可获得较大的股票样本池。
- 基于股息率加权的红利增长组合表现优于中证红利。

# 量化要点
- 红利增长组合年化收益 19.48%，高于中证红利全收益的 11.33%。
- 2019 年以来组合相对红利指数的平均年超额约 7.35%。

# 局限性
- 依赖一致预期与财报数据，存在分析师预期偏误和数据滞后问题。
- 盈利与分红政策变化会影响模型稳定性。
