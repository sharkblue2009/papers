# 20260204-方正证券-专题报告：个人AI助理OpenClaw部署及其在金融投研中的应用研究——AIAgent赋能金融投研应用系列之二

- **源文件**：20260204-方正证券-专题报告：个人AI助理OpenClaw部署及其在金融投研中的应用研究——AIAgent赋能金融投研应用系列之二.pdf
- **日期/机构/类型**：2026-02-04；方正证券；专题报告
- **核心问题**：OpenClaw 这类可主动执行的 AI Agent 如何部署，以及它在金融投研中能做到什么、风险在哪里。
- **方法/数据**：以腾讯云 Lighthouse 一键部署为例，结合文件管理、会议纪要整理、研究报告复现、API 接入、盯盘监控、条件选股和小盘价值组合构建等实测场景。
- **关键发现**：OpenClaw 采用 Gateway-Agent-Skills-Memory 分层架构，具备较强的本地应用操作与任务拆解能力；在隔离环境中，它可显著降低重复性投研和工具链构建成本，但高权限也意味着更高的安全与合规要求。
- **量化要点**：AI Agent 更适合作为投研“执行层”和“流程自动化层”，尤其适合数据整理、规则化筛选和策略原型搭建；实际落地应严格控制权限、环境隔离与数据访问范围。
- **局限性**：存在幻觉、误操作、权限越界和数据污染风险；案例偏演示和测试性质，不构成投资建议。
- **关键词**：AI Agent、OpenClaw、云部署、金融投研、自动化、合规、安全
