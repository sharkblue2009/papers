# 高频报价：买价和卖价的短期波动性

- **source filename**: `20190313-天风证券-海外文献推荐第78期.pdf`
- **date**: 2019-03-13
- **institution / author**: 天风证券研究所；吴先兴；原文作者 Joel Hasbrouck
- **extraction confidence**: high

## Core question
论文研究亚秒级美国股票买卖报价为何出现短期波动，以及这种波动如何形成执行价格风险和快速交易者的相对优势。

## Methods / data
- 使用2011年4月美国150只股票的NYSE综合报价和NBBO毫秒级数据，剔除开收盘影响后取9:45—15:45，并做±5%缩尾。
- 延迟从50毫秒逐步扩展至约55分钟，计算报价方差比、残差方差比、延迟执行风险和相对收益。
- 以报价方数量和HHI衡量做市竞争，结合价格变化偏度检验混合策略与Edgeworth周期解释。

## Key findings
- 50毫秒买价方差比均值0.557，表示相对随机游走的短期波动约高80%；1秒以下买/卖报价残差方差比约0.6，中点约0.8。
- 延迟窗口越长，余差波动率和快速交易者相对收益越高；示例路径中完美选择执行时间与平均执行价相差0.15美元。
- 交易量越大的股票报价波动和相对延迟收益越高；HHI结果显示竞争越激烈，报价越不稳定，支持Edgeworth周期而非简单操纵模型。

## Quant takeaways
- 执行回测应模拟毫秒级延迟、随机成交时点和报价路径，而不能只用日内中间价。
- 样本仅覆盖一个月和150只股票；报价队列、订单取消、市场冲击和交易场所差异仍需进一步验证。
