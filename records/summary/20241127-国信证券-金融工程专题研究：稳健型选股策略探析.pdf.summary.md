# 摘要
- 源文件：20241127-国信证券-金融工程专题研究：稳健型选股策略探析.pdf
- 日期/机构/类型：2024-11-27，国信证券，金融工程专题研究
- 核心主题：从“低波动、低估值、低换手、高股息”四类特征出发，构建稳健型选股池与增强组合。
- 方法/数据：先分析高真实收益基金持股特征，再提炼稳健复合因子；用动量、成长、分析师预期、股息率、高频等因子对稳健股票池做增强；组合采用月度调仓，并设置行业权重上限15%、个股权重上限3%。
- 关键发现：
  - 稳健股票池年化收益13.81%，相对中证800全收益年化超额7.31%，回撤和波动低于基准。
  - 增强复合因子月度RankIC均值7.83%，年化RankICIR为1.64。
  - 稳健精选组合自2012年以来年化收益26.53%，年化超额分别为15.14%（对中证红利全收益）和13.17%（对红利低波100全收益），并具备较强创新高能力。
- 量化要点：稳健风格并不等于低收益，低波、低估值、低换手、高股息的多因子合成可同时兼顾收益与回撤控制。
- 局限性：策略表现依赖市场风格和因子环境，存在阶段性失效风险。
- 关键词：稳健选股、低波动、高股息、低估值、低换手、因子增强
