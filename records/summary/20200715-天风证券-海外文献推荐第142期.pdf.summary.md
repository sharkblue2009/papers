# ESG投资：从罪恶股到Smart Beta

- **source filename**: `20200715-天风证券-海外文献推荐第142期.pdf`
- **date**: 2020-07-15
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告研究基于ESG评分排除低分股票如何影响全球被动组合和Smart Beta策略的收益、风险、因子暴露及地区/行业配置，重点区分行业调整评分与直接排除法。

## Methods / data
- 使用MSCI ESG公司评分，样本为2007年1月至2017年12月；覆盖MSCI ACWI及美国、欧洲、太平洋和新兴市场。
- ESG分数为0—10，分别构造行业调整后的E/S/G评分组合和剔除最低分股票的组合，并比较四因子、FF5、规模和动量Smart Beta策略。
- 评估收益、波动率、夏普、跟踪偏离、地区/行业权重和alpha。

## Key findings
- 美国剔除环境得分最低50%后，年化收益9%升至9.6%，波动率14.7%降至14.4%，夏普0.57升至0.62，环境分数5.7升至6.9。
- ESG筛选通常提升评分且未降低经风险调整表现，但会造成区域和行业倾斜；美国环境筛选相对基准低配能源4.6%、高配信息技术4.6%。
- 全球Smart Beta示例中，组合波动率由24.8%降至23.2%，夏普由0.12升至0.23；加入FF5后部分alpha下降，发展中国家和美国甚至可能为负。

## Quant takeaways
- ESG因子回测必须同时报告行业/地区中性结果、传统因子暴露、跟踪误差和成本，不能把评分提升等同于alpha。
- 行业调整评分适合减少“罪恶行业”机械剔除造成的偏差；直接排除法更容易引入风格和估值暴露。
- ESG数据覆盖、评分变更、治理与环境标准的方向可能不同，需做时间点滞后和供应商稳健性测试。
