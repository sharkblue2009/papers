# 收益预测性：来自中美两国供应链的证据

- **source filename**: `20190612-天风证券-海外文献推荐第90期.pdf`
- **date**: 2019-06-12
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
研究跨国客户—供应商关系中的信息传播是否能预测股票收益。核心发现是，中国客户上月的收益能预测其美国供应商本月收益，而反向关系并不显著，说明供应链信息可能存在跨市场传播迟滞。

## Methods / data
- 使用2009–2015年中美供应链样本，客户名单来自美国公司年报中披露的销售额超过10%的主要客户；收益覆盖2010年7月至2017年6月。
- 共形成173个供应链样本；每月按中国客户上月收益，将美国供应商分为正收益和负收益组合，等权或市值加权、月度再平衡。
- 用Fama-MacBeth回归控制供应商滞后收益、行业收益、市值、B/M及客户行业收益；再用PSM匹配非客户对照企业，并检验供应商对客户的反向预测。

## Key findings
- 做多客户上月正收益供应商、做空客户上月负收益供应商，等权多空组合月度异常收益约2.179%。
- Fama-MacBeth中客户收益系数约0.247，表示客户收益每增加1%，供应商收益约增加0.247%。
- PSM伪客户样本中预测能力消失，支持效应来自真实客户—供应商关系；反向预测不显著。
- 报告结论处另写多空异常收益2.719%，与前文2.179%不一致，数值应视为原文口径冲突。

## Quant takeaways
- 可构造供应链滞后收益、公告时点和关系强度因子，但必须用年报披露滞后日而非事后关系数据。
- 需要控制行业、规模、价值、动量、汇率、跨境交易成本和样本稀疏性。
- PSM支持关系链解释，但173个样本较小；应做滚动样本外、交易容量和关系退出测试。
