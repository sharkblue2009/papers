# 20260311-西部证券-用隔夜交易策略增强指数增强

- 来源文件：`20260311-西部证券-用隔夜交易策略增强指数增强.pdf`
- 日期/机构/类型：2026-03-11，西部证券，研发中心研究报告
- 核心问题：能否通过预测隔夜收益并进行隔夜交易，增强指数增强策略？
- 方法/数据：测试多类能预测隔夜收益的因子并合成复合因子；在指数复制和现有指数增强框架中叠加隔夜交易策略，评估不同指数与交易条件下的效果。
- 主要结论：复合因子与隔夜收益显著负相关，隔夜交易策略本身稳定，叠加到指数增强后能形成明显的超额提升且跟踪误差较低。
- 量化要点：
  - 合成因子 Rank IC 为 -0.1687
  - 指数复制基础上加入隔夜交易策略后，不同指数可获得约 4%-7% 的超额收益，跟踪误差约 1.2%
  - 在已有指数增强模型上再叠加后，超额收益可进一步提高 2%-5%
  - 考虑交易条件后结论仍较稳健
- 局限性：隔夜效应可能受市场风格与交易成本影响，历史测算不保证未来延续。
- 关键词：隔夜收益、指数增强、复合因子、交易策略、超额收益、跟踪误差
