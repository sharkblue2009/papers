## 核心主题
把财经新闻与大语言模型/RAG 结合，构建本地化检索增强生成系统，并用于市场择时、行业轮动及二者复合策略。

## 方法与数据
- 使用 2023 年之后的财经新闻数据，避免训练污染。
- 构建本地 RAG 系统，结合向量检索与大模型推理。
- 设定温度为 0、top_k 为 1，降低输出随机性。
- 以多种模型测试市场择时与行业轮动信号，重点比较 qwen:14b、Mixtral 8x7B、GPT-3.5、GPT-4。

## 关键发现
- LLM 能较好从海量新闻中提取市场趋势和行业主题信息。
- 在市场择时任务上，Mixtral 表现最好。
- 将择时与行业轮动叠加后，策略表现进一步改善。

## 量化结果
- **市场择时策略**：Mixtral 多空年化收益 **13.49%**，IR **1.03**，最大回撤 **9.32%**，择时准确率 **60.66%**。
- **行业轮动策略**：Mixtral 年化收益 **1.81%**，最大回撤 **33.33%**，IR **0.08**，相对基准 alpha **8.5%**。
- **行业轮动 + 择时**：年化收益 **16.20%**，最大回撤 **7.51%**，相对基准年化 alpha **22.9%**。
- 数据规模：**50万+** 新闻样本，日样本中位数 **1061** 条。

## 局限性
- 模型对计算资源、提示词和参数设定较敏感。
- 历史新闻样本与市场结构变化会影响泛化能力。
- 结果存在随机性和区间依赖。
