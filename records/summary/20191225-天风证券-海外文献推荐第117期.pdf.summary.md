# 机器学习基金失败的十大原因及应对策略

- **source filename**: `20191225-天风证券-海外文献推荐第117期.pdf`
- **date**: 2019-12-25
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
文章从金融机器学习实践出发，归纳量化基金失败的十类常见原因，并给出从团队分工、样本构造、标签、验证到回测过拟合的替代方案。

## Methods / data
- 建议采用元策略式团队：数据、清洗、特征、模型、基础设施和回测分别监控。
- 用成交额时钟替代机械时间K线，以分数阶差分在平稳性和记忆性之间折中。
- 用三界线标签替代固定持有期标签，分离方向预测与仓位控制，并采用meta-labeling。
- 对重叠标签使用独特性权重和时序bootstrap；交叉验证使用数据清洗、purging和embargo。
- 通过多路径交叉验证和收缩Sharpe降低滚动回测及反复试验造成的过拟合。

## Key findings
- 在5%标准偏误下，重复约20次就可能得到一个看似有效但实际无效的策略。
- 标普500示例中，分数阶差分d=0.4后可拒绝单位根，且与原始价格相关性超过0.995；一阶差分相关性仅约0.05。
- 固定时间标签忽略波动率和路径依赖；三界线用动态止盈、止损和时间界线改善标签质量。
- 文章强调特征重要性是研究工具，回测本身不是研究工具；随机滚动路径应被视为分布而非单一路径。

## Quant takeaways
- 建模顺序应是标签、样本权重、验证、特征重要性、组合与成本，而不是不断试算法找高Sharpe。
- 任何金融ML回测都应检查重叠标签、泄露、embargo、参数搜索次数和PBO/收缩Sharpe。
- 文中是方法论总结而非统一实证策略，具体收益优势需在目标市场独立复现。
