# 识别导致价值/成长溢价的预期偏差效应：一种基本面分析方法

- **source filename**: `20200928-天风证券-海外文献推荐第152期.pdf`
- **date**: 2020-09-28
- **institution / author**: 天风证券；吴先兴、陈奕；原文作者 Joseph D. Piotroski、Erik C. So
- **extraction confidence**: high

## Core question
本文检验价值/成长溢价究竟是风险补偿还是错误业绩预期修正。研究将Piotroski的财务报表评分FSCORE与价值/成长分类结合，考察基本面改善或恶化与价格隐含预期冲突时，收益是否最强。

## Methods / data
- 使用CRSP与Compustat的1972—2008年美国股票，形成117,412个公司年度观测。
- FSCORE由盈利能力、杠杆/流动性和经营效率九个二元信号构成；价值/成长用BM、EP、CP、销售增长、换手率及综合CV衡量。
- 每年6月建仓，次年7月开始持有一年，做规模调整收益、盈利公告收益、分析师预测误差与修正检验。

## Key findings
- 高FSCORE组合原始年均收益19.12%，低FSCORE组合6.62%；规模调整收益分别为5.50%和−4.33%。
- 高FSCORE组合规模调整后正收益比例47.78%，低FSCORE为35.24%，差异在1%水平显著。
- 预期不一致的价值/成长策略平均年收益约11%—19%；综合CV下年均规模调整收益约16%，两年累计约25.97%。
- 低FSCORE成长股规模调整收益约−11.04%，高FSCORE价值股约8.39%；不一致策略37年中33年为正。

## Quant takeaways
- 可把FSCORE作为价值因子的条件过滤器，重点交易“价格隐含预期”与近期基本面趋势冲突的股票。
- 建仓应使用最新可得财报并留出披露滞后；年频再平衡可降低交易成本。
- 结果支持定价错误解释，但FSCORE与价值指标相关，仍需控制规模、动量、SUE及公告漂移。
