# 海通证券选股因子系列研究（四十三）：因子拥挤度的改进

- **source filename**: `20190129-海通证券-选股因子系列研究（四十三）：因子拥挤度的改进.pdf`
- **date**: 2019-01-29
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 金融工程专题报告

## Core question
在前期拥挤度框架上做改进，提升配对相关性和因子波动率类指标的实用性。

## Methods / data
改造配对相关性、因子波动率等指标，尝试引入特质收益和不同定义方式，比较原始与正交因子集合上的表现。

## Key findings
- 用特质收益计算配对相关性后，部分因子上的正相关和波动预测能力更明显。
- 因子波动率类指标中，“多头/市场”版本具有一定预测力，但通常弱于“多头/空头”版本。
- 在原始与正交因子集合上，改进后的指标整体更稳，但不同因子间依旧存在差异。
- 改进重点不是制造新因子，而是让拥挤度监控更稳定。

## Quant takeaways
- 拥挤度指标需要尽量剔除噪声与共性暴露。
- 特质收益是让拥挤监控更贴近“因子本身”的关键。

## Caveats
- 不同因子、不同定义下的稳定性差别仍然很大。
