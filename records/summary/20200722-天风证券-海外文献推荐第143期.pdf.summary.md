# 关于低风险投资的事实与误区

- **source filename**: `20200722-天风证券-海外文献推荐第143期.pdf`
- **date**: 2020-07-22
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告系统梳理低风险投资的五个事实和五个误区，检验低beta、低波动、质量和其他低风险策略是否具有长期、样本外、跨市场的风险调整收益，以及其在下行市场中的局限。

## Methods / data
- 使用1931年以来美国月度统计风险因子和1957年以来基本面风险因子，研究6类统计风险因子与4类基本面风险因子。
- 比较BAB（市场中性）、SMR（美元中性）、SMRMN、BAC、IVOL、MAX和QMJ等策略，并计算收益、CAPM/FF6 alpha、夏普及信息比率。
- 检查样本内外、国家、行业、资产类别、利率暴露、交易成本和美国暴跌期表现。

## Key findings
- 低风险策略普遍有正alpha且多数显著；BAB夏普比率0.75、QMJ为0.59，SMR接近0但beta约−0.8，低风险策略alpha普遍超过3%。
- 各国CAPM alpha约6%—20%，BAB在多数国家和行业、不同资产类别均有效；排除小盘和计入交易成本后仍有表现。
- 低风险策略在下行市场可能亏损，不能简单宣称“低风险必然高收益”；债券beta、行业暴露和市场中性设计会影响结果。

## Quant takeaways
- 实盘应区分美元中性与beta中性：低风险多空策略需要适当杠杆和高风险腿去杠杆。
- 低风险因子适合与价值、质量和动量组合，但必须监控拥挤、利率、融资和做空成本。
- 跨市场历史结果不能替代本地样本外验证；回测需报告极端回撤、容量和真实交易费用。
