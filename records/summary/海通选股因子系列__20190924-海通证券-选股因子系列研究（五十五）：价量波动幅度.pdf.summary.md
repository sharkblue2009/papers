# 海通证券选股因子系列研究（五十五）：价量波动幅度

- **source filename**: `20190924-海通证券-选股因子系列研究（五十五）：价量波动幅度.pdf`
- **date**: 2019-09-24
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、罗蕾
- **document type**: 金融工程专题报告

## Core question
研究股价振幅和换手率波幅是否能补充传统价量因子。

## Methods / data
构造股价振幅、换手率波幅，测试不同观察期/持有期、不同风格和多因子模型中的增量价值。

## Key findings
- 股价振幅与未来收益显著正相关，且 1-6 个月观察期都较稳健。
- 但振幅因子衰减较快，持有期超过 3 个月后多空收益不再显著。
- 换手率波幅与未来收益显著负相关，空头端更强。
- 把价量波幅纳入 9 因子模型后，整体 IC 表现可以提升。

## Quant takeaways
- “幅度”本身也是信息，能补足传统涨跌幅、换手和波动率。
- 价量波动幅度更像短中期因子，不适合过长持有。

## Caveats
- 因子衰减较快，交易成本和持有期是关键。
