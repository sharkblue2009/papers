# 左尾动量：股票市场坏消息的不充分反应

- **source filename**: `20210707-天风证券-海外文献推荐第185期.pdf`
- **date**: 2021-07-07
- **institution / author**: 天风证券研究所；吴先兴（分析师）；原文作者 Y. Atilgan、T.G. Bali、K.O. Demirtas 等
- **extraction confidence**: high

## Core question
检验个股左尾风险是否预测未来截面收益，并解释为何高左尾风险股票反而获得更低收益。

## Methods / data
- 使用CRSP日/月收益、Compustat财务数据及French因子，样本为1962—2014年美股，平均每月约3038只股票、约190万条观测。
- 以VaR和ES衡量过去一年或一个月的极端损失，按VaR排序构建十分位组合，使用市值加权、等权、FFCPS及双变量组合检验。
- 进一步按Delta VaR、机构持股和国际市场分组验证机制。

## Key findings
- VaR1十分位多空组合市值加权收益差为-0.78%/月（t=-2.34）；FFCPS alpha差为-0.94%/月（t=-4.42）。等权收益差约-0.66%/月，alpha差约-0.80%。
- 高VaR组合VaR1均值从0.0268升至0.1168，市场beta从0.40升至1.26；高风险组合规模更小、流动性更差、特异波动更高。
- 最近发生大额日度损失的Delta VaR为正组多空收益差-0.90%/月（t=-2.72）；个人投资者更活跃组的收益差达-1.40%/月。
- 国际样本多空收益差-1.44%/月，因子调整alpha约-1.42%/月。

## Quant takeaways
- 可将VaR/ES作为反向风险信号，测试“低左尾风险多、高左尾风险空”或仅做多低风险组合。
- 需控制规模、beta、流动性、特异波动和卖空约束，并考虑交易成本；该异象被解释为投资者低估坏消息持续性。
