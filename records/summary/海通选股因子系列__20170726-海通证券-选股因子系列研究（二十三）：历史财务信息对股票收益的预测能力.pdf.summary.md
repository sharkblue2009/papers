# 海通证券选股因子系列研究（二十三）：历史财务信息对股票收益的预测能力

- **source filename**: `20170726-海通证券-选股因子系列研究（二十三）：历史财务信息对股票收益的预测能力.pdf`
- **date**: 2017-07-26
- **document type**: 金融工程专题报告

## Core question
历史财务信息能否像 Piotroski F-Score 那样形成一个可交易的综合基本面因子，并预测未来收益。

## Methods / data
- 基于 **Piotroski (2000)** 思路构建历史财务综合因子。
- 通过分组收益、相关系数、横截面回归和多因子模型检验选股能力。
- 对比位序加总与 zscore 加总两种构建方式，并比较全市场、沪深300、中证500等范围。

## Key findings
- 综合基本面因子单因子效果显著：最高 1/10 组合相对最低 1/10 组合月均超额约 **1.74%**，月胜率逾 **70%**。
- 横截面回归结果一致：因子每提高 1 个标准差，月均收益约提高 **0.47%**。
- 加入该因子后，收益率预测模型精度明显提升，且比仅加入 ROE/dROE 更有效。
- 位序加总与 zscore 加总效果差异不大，在全市场、沪深300、中证500中均有效。

## Quant takeaways
- 历史财务信息的“持续改善”本身就是一个有效信号，不只是单期静态指标。
- 构建综合基本面时，简单稳健的加总方式已经足够可用。
- 该类因子适合做中低频价值/质量增强。

## Caveats
- 依赖财报可得性和会计规则稳定性。
- 需要警惕因子历史规律失效或模型失效。
