# 晨星债基风格箱构建方法论

- **source filename**: `20200415-天风证券-海外文献推荐第132期.pdf`
- **date**: 2020-04-15
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告说明如何用利率敏感度和信贷质量构建债券基金3×3风格箱，使基金的久期和信用风险暴露能够被统一、直观地分类。

## Methods / data
- 横轴为基金平均有效久期：美国应税债基按Morningstar Core Bond Index有效久期的25%—75%、75%—125%和125%以上划分；非美应税债基阈值为3.5年和6年，市政债基为4.5年和7年。
- 纵轴为信贷质量，依据债券评级权重计算；低质量低于BBB，中等为BBB至AA以下，高质量为AA及以上。
- 不直接平均评级，而是先将评级通过凸违约率曲线映射为违约率，加权后再映射回评级；90%AAA+10%CCC示例的实际违约率接近BB。

## Key findings
- 评级违约率非线性，简单平均会系统性低估含低评级债券组合的真实风险。
- 期限小于92天的债券工具被归为现金；有效久期需纳入提前偿付、期权、衍生品和基金持仓影响。
- 违约率函数以AAA、CCC端点和凸参数θ刻画，晨星认为θ=0.9是企业债的合理拟合值。

## Quant takeaways
- 风格箱可作为债基筛选、风险预算和组合暴露监控的标准化接口。
- 量化建模时应使用违约概率加权而非评级数值简单平均，并保留评级来源、缺失评级和衍生品调整。
- 这是分类方法论而非收益回测；阈值会随基准久期、评级迁移和市场制度变化，需要定期校准。
