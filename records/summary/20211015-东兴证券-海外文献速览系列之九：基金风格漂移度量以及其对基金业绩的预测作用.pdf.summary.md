# 基金风格漂移度量以及其对基金业绩的预测作用

- **source filename**: `20211015-东兴证券-海外文献速览系列之九：基金风格漂移度量以及其对基金业绩的预测作用.pdf`
- **date**: 2021-10-15
- **institution / author**: 东兴证券；高智威；原文作者Yezhou Sha
- **extraction confidence**: high

## Core question
文献研究中国主动权益基金的风格漂移如何度量，以及风格漂移能否预测基金未来收益。作者以持股为基础的HBSA方法替代回报风格分析，区分被动风格漂移、主动风格漂移及其波动性。

## Methods / data
- CSMAR股票特征与RESSET基金持仓；2000-01—2018-06，共145,846个基金月度观察。
- 以市值、行业调整BM和12个月动量构造DGTW风格；用风格变化的标准差构造HBSA-SD、PSD和ASD。
- 主动基金按SD五分位分组，2005-01起形成组合并持有3个月；用Carhart四因子等模型做风险调整。

## Key findings
- 风格漂移总体集中在零并均值回归；被动漂移主要由持股市值变化驱动，主动漂移多为负，显示基金经理有平衡风格暴露的行为。
- 高SD与低SD组合的原始月收益差为3.03%；但Carhart调整后高低alpha差仅0.012%，t=0.20，不显著。
- 月度风格漂移仍能预测下月横截面基金收益，控制滞后收益、动量、规模和基金公司规模后结论保持。
- 6、12月底ASD均值约-0.747，其他月份约-0.557，披露频率造成的偏差存在但相对基金异质性较小。

## Quant takeaways
- 可将持仓特征变化拆成主动与被动部分，检验风格漂移是否只是隐藏的规模、价值或动量暴露。
- 风格漂移信号适合与Carhart/DGTW调整后的基金收益、换手和公司固定效应联合测试。
- 半年持仓披露会漏掉高频交易；原始溢价被共同风险解释，不能直接视为经理技能。
