# 历史收益的顺序与股票的截面收益

- **source filename**: `20210202-天风证券-海外文献推荐第168期.pdf`
- **date**: 2021-02-02
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告提出历史收益的“时间顺序”是否包含传统收益分布、动量和反转因子之外的信息，并检验近期收益较高还是远期收益较高对未来股票横截面收益的预测能力。

## Methods / data
- 构造月度 CROM（日收益与距月末交易日距离的相关系数）和年度 CROA（月收益与时间距离的相关系数），取值 -1 至 1。
- 每月末按 CROM、CROA 分十组，以 NYSE 股票确定分位点并进行市值加权，考察未来一个月收益。
- 使用 Fama-MacBeth 回归，并控制资产定价因子、微观特征、短期反转、动量及套利限制指标 ILLIQ、IVOL、MAX。

## Key findings
- 高 CROM 组合相对低 CROM 组合月度超额收益 0.81%，年化约 10.16%。
- 高 CROA 组合月度超额收益 0.96%；控制短期反转后仍为 0.75%，CROA 与短期反转相关系数约 -0.4。
- 在高非流动性股票中，CROM 五分位多空月度超额收益 1.31%，低非流动性组仅 0.44%，高套利限制组约为低组的 3 倍。
- CROM 在各类 Fama-MacBeth 规格下仍显著，控制周度和日度反转后也未完全消失。

## Quant takeaways
- 可把收益—时间相关系数作为动量/反转之外的新截面特征，并测试月度与年度持有期。
- 重点关注非流动性和高特质风险股票，但需将交易成本、容量和微观结构偏差纳入回测。
- 部分 CROA 收益与短期反转重叠，因子正交化及跨市场样本外检验是必要的。
