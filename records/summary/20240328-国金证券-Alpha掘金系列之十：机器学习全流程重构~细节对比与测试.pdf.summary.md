# 研报摘要
- 来源文件：20240328-国金证券-Alpha掘金系列之十：机器学习全流程重构~细节对比与测试.pdf
- 日期：2024-03-28
- 机构：国金证券
- 类型：金融工程专题 / Alpha 掘金系列
- 核心主题：系统比较机器学习选股的关键训练细节，重构从数据预处理到模型训练、损失函数和集成算法的完整流程。
- 方法/数据：对比了截面/时序数据预处理、全A样本与成分股样本、一次性/滚动/扩展训练、分类与回归、MSE与IC损失、GBDT/DART/RF等设置；最终结合 GBDT 与 NN 构建指数增强因子与策略。
- 关键结论：截面与时序模型适合不同预处理；训练样本区间和训练方式需要按市场环境与基准分情形选择；回归模型优于分类模型；把损失函数直接改成 IC 并未显著提升效果；DART 对过拟合控制更优。
- 量化要点：改进后因子在沪深300、中证500、中证1000上均有较强表现，其中中证1000最突出；指数增强策略年化超额收益可观，且回撤受控。
- 局限性：模型对样本区间、基准与市场环境较敏感；历史回测结果不等于实盘表现，存在交易成本与失效风险。
- 关键词：机器学习选股、数据预处理、滚动训练、回归模型、IC损失、DART、指数增强
