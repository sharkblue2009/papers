# 粘性预期与盈利异象

- **source filename**: `20191211-天风证券-海外文献推荐第115期.pdf`
- **date**: 2019-12-11
- **institution / author**: 天风证券；吴先兴（分析师）、陈可（联系人）
- **extraction confidence**: medium

## Core question
论文用分析师盈利预期的粘性解释盈利能力异象：分析师更新信念过慢，导致高盈利公司的未来盈利被低估，随后形成可预测的盈利和收益。

## Methods / data
- 建立粘性预期模型，令当前预期由过去信念与理性预期按粘性参数加权；用预测修订和预测误差识别粘性。
- 使用I/B/E/S分析师EPS预测、公司盈利和股票收益，检验过去盈利对未来预测误差的预测关系。
- 按分析师粘性、公司盈利持续性及盈利动量、收益动量排序，比较盈利异象强弱。
- 通过稳健性检验和蒙特卡洛模拟评估结果是否可由理性预期或抽样噪音解释。

## Key findings
- 数据支持三个方向：平均而言分析师对高盈利公司的未来收益预测偏误更大；分析师粘性越高，盈利异象越强；盈利越持续，异象越明显。
- 模型还预测盈利变化和过去收益应与后续预测误差及收益相关，报告称这些预测均在数据中出现。
- 粘性预期为盈利、盈利动量和收益动量提供了统一的非贝叶斯反应不足解释。
- 提取文本未完整呈现样本区间、回归系数、IC或组合Sharpe，具体数值不宜外推。

## Quant takeaways
- 可将分析师预测修订速度、预测误差和盈利持续性结合，构造条件化盈利因子，而非只用静态ROE或利润率。
- 回测应按分析师覆盖、预测粘性和盈利持续性分层，并控制公告时点与修订可得性。
- 预期粘性可能与分析师选择、信息披露频率和行业结构混杂，需要样本外及交易成本检验。
