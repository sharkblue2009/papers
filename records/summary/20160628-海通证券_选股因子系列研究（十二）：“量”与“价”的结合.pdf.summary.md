# 海通证券选股因子系列研究（十二）：“量”与“价”的结合

- **source filename**: `20160628-海通证券_选股因子系列研究（十二）：“量”与“价”的结合.pdf`
- **date**: 2016-06-28
- **document type**: 金融工程专题报告

## Core question
量价关系能否被直接量化成选股因子，量价同向/背离的短期结构是否具有持续 alpha。

## Methods / data
- 把短期量价走势划分为 **量价同向** 与 **量价背离**，并用 **量价相关性** 度量程度。
- 以约 **半个月换仓周期** 做回测，考察分组收益、多空组合、Rank IC/IC，以及 Fama-French 风险归因。
- 进一步检验因子的市值暴露和在不同年度的稳定性，并与反转等常见风险因子结合分析。

## Key findings
- 量价相关性因子在半个月周期下表现较好，具备明显 alpha；控制常见风险因子后依然有效。
- 因子具有较强 **空头效应**：多空收益约 **1.07%**，其中空头端贡献约 **70%**。
- 组合层面表现稳健：全样本年化收益约 **29%**，最大回撤约 **16%**，IR 约 **2.55**，胜率约 **72%**。
- 该因子有轻微 **大市值暴露**，但暴露不算极端；年度上呈现较强的“**熊市强、牛市弱**”特征。

## Quant takeaways
- 量价关系不只是“价量齐升/背离”的口号，可以直接做成相关性因子。
- 该因子更适合和反转、行业中性、风险剔除一起使用，尤其可当作空头侧信号。
- 在市场偏弱时，量价背离往往更有解释力，适合做防御型 alpha。

## Caveats
- 因子收益有明显的市场状态依赖，牛市中效果会弱一些。
- 回测周期和样本区间较关键，短期窗口设置会影响效果。
