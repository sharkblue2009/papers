# 自进化 Skill：选股策略的自动迭代

- 系列：金工深度研究
- 日期：2026-05-25
- 主题：financial machine learning methodology、factor and stock selection

## 核心结论
- 报告提出由策略协议、版本管理和样本隔离组成的三层自进化 Skill 框架，用于让选股策略自动迭代。
- 数据划分为 2014—2018 年训练集、2018—2020 年验证集和 2020—2026 年测试集，以降低迭代过程中的信息泄漏风险。
- 稳健低波价值策略测试集年化收益由 13.47% 提升至 15.67%，夏普比率由 0.69 提升至 0.89。
- 同一策略的波动率由 19.46% 降至 17.58%，换手率由 10.66 降至 8.70。

## 方法要点
策略协议负责明确目标、数据、约束、评价指标和可执行规则；版本管理记录每次策略修改及其结果；样本隔离将训练、验证和测试过程分开，避免自动迭代直接使用测试集反馈。系统以稳健低波价值策略为例，根据回测结果对因子、组合约束和交易规则进行多轮修改，并比较迭代前后的收益、夏普、波动率和换手率。

## 结果与局限
案例结果显示，自进化机制不仅提高了测试集年化收益和夏普，也降低了波动率和换手率，说明自动迭代并非只追求收益指标。不过，自动搜索仍可能在训练或验证样本中反复试错并形成隐性过拟合，版本记录和样本隔离只能降低而不能完全消除这一风险。测试期市场风格、成本假设和策略容量会影响结果，策略在未来市场状态变化、交易约束变化或数据分布漂移下的稳定性仍需持续检验。
