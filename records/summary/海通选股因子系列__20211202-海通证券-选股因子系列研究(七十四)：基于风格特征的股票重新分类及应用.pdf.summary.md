# 海通证券选股因子系列研究（七十四）：基于风格特征的股票重新分类及应用

- **date**: 2021-12-02
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、罗蕾
- **document type**: 金融工程专题报告

## Core question
仅按行业分类是否足够；能否基于风格特征重新分类股票，并据此改进因子中性化和发现新的动量溢出现象。

## Methods / data
用市值、估值、盈利、关注度等风格特征，采用 K-means 对股票重新分类；比较风格中性化与行业中性化的效果；再检验风格分类层面的动量溢出效应。

## Key findings
- 行业分类能刻画业务相似性，但不一定代表风格相似；风格分类提供了另一种更贴近因子研究的分组方式。
- 在多因子模型里，**风格类别中性** 可在行业中性基础上进一步提升因子表现与稳定性，且不明显增加风险。
- 风格中性组合的年度收益分布更均匀，信息比和收益回撤比也更好。
- A 股存在明显的 **风格分类动量溢出效应**：高风格动量组合的月均收益显著更高。
- 风格动量与行业动量相对独立，放入同一截面回归后依然显著为正。

## Quant takeaways
“分类方式”本身可以成为风险控制和收益增强的一部分；风格分组并不是行业分组的替代，而是补充。

## Caveats
K-means 分类结果依赖样本期和特征设定；动量溢出关系也可能随市场风格变化而弱化。
