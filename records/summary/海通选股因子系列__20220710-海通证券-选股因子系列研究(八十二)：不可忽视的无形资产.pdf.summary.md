# 海通证券选股因子系列研究（八十二）：不可忽视的无形资产

- **source filename**: `20220710-海通证券-选股因子系列研究(八十二)：不可忽视的无形资产.pdf`
- **date**: 2022-07-10
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、罗蕾
- **document type**: 金融工程专题报告

## Core question
把企业内部创造但未充分体现在资产负债表上的无形资产纳入估值框架，是否能让价值因子更公平、更有效。

## Methods / data
估算 A 股公司的无形资产存量，并据此构建**无形资产调整后的 PB 因子（PB_INT）**；比较 PB_INT 与传统 PB、PE、股息率等估值因子；再将 PB_INT 用于低估值、价值和指数增强组合。

## Key findings
- 无形资产是企业资本的重要组成部分，尤其对研发、品牌、知识资本驱动的公司不能忽视。
- PB_INT 与传统 PB 的 IC 走势高度相似，但在 PB 因子表现好时更稳、波动更低；PB 因子失效时回撤也更小。
- 线性剥离其他常见因子后，PB_INT 仍有显著 alpha，说明其不只是 PB 的简单替代。
- 在消费+TMT 等行业，无形资产占比高的股票 2019 年以来超额逐渐显现。
- 用 PB_INT 替代 PB 构建价值/增强组合，可提升公平性和稳定性，尤其对研发和广告投入大的公司更合理。

## Quant takeaways
核心思想是把“会计表内的账面资本”扩展成“账面资本 + 无形资本”，这样估值比较才不会系统性低估轻资产、强研发企业。

## Caveats
无形资产估算依赖会计假设，行业差异和数据可得性会影响结果；该因子与传统估值高度相关，边际增量主要在修正而非颠覆。
