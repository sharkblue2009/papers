# 海通证券选股因子系列研究（六十九）：高频因子的现实与幻想

- **source filename**: `20200730-海通证券-选股因子系列研究（六十九）：高频因子的现实与幻想.pdf`
- **date**: 2020-07-30
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青、姚石、罗蕾、余浩淼
- **document type**: 金融工程专题报告

## Core question
系统梳理Level2高频数据能提炼出哪些稳定因子，以及这些因子如何真正放进指数增强模型。

## Methods / data
从Level2的分钟K线、盘口快照、委托队列、成交明细四类数据出发，整理分钟成交因子、TICK委托因子、逐笔成交因子，以及委托+成交融合因子，并在沪深300/500/800增强中检验。

## Key findings
- 分钟高频因子（高频偏度、下行波动占比、尾盘成交占比、量价相关性、改进反转、平均单笔流出金额占比、大单推动涨幅）月均Rank IC都在3%以上，ICIR都大于3。
- TICK委托因子中，开盘后净委买增额占比最强，月均Rank IC约4.19%，ICIR约4.24。
- 逐笔成交因子里，开盘后净主买强度、大买成交占比、知情主卖占比等都较强。
- 委托+成交融合得到的买入意愿占比和买入意愿强度更强，月均Rank IC分别约4.34%和5.07%。
- 高频因子与低频增强结合后，沪深300/500/800的年化超额都能提升2.6%以上，且时间序列上较稳定。

## Quant takeaways
高频因子的“现实”是：在合适的数据层级和组合结构里，它们确实能稳定加分；“幻想”则是把它们当成单独万能因子。

## Caveats
因子失效、模型误设和历史规律漂移都很常见；需要结合空头剔除、正交和多因子组合使用。
