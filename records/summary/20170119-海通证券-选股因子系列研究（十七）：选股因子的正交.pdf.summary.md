# 海通证券选股因子系列研究（十七）：选股因子的正交

- **source filename**: `20170119-海通证券-选股因子系列研究（十七）：选股因子的正交.pdf`
- **date**: 2017-01-19
- **document type**: 金融工程专题报告

## Core question
在多因子模型中，如何通过正交化处理控制因子暴露、缓解因子间相关性波动，并提升组合表现。

## Methods / data
- 先展示因子截面相关性的 **时间波动性**，以市值与反转为例说明长期低相关并不代表各时期稳定。
- 用 **线性回归残差** 对新因子做正交，并采用“逐步添加变量、逐步正交”的方式构造正交因子集合。
- 比较等权多因子模型与最大化收益预期模型在正交前后的表现。
- 另借鉴逐步回归，用收益预测模型 R² 来确定正交顺序，形成动态正交方案。

## Key findings
- 因子相关性在不同阶段波动很大，直接等权叠加可能导致对某个风格的隐含暴露失控。
- **逐步正交**后，模型在复合因子 IC、ICIR、多头超额收益、信息比率和月度胜率上普遍改善。
- 在等权模型中，因子数越多，正交带来的边际提升会减弱；在最大化收益预期模型中，这种问题缓解更好。
- 用 R² 确定正交顺序的动态方案有一定效果，但整体弱于固定正交顺序。

## Quant takeaways
- 正交不是装饰，而是多因子暴露控制的基础工程。
- 当因子池变大时，先正交再做权重优化更稳妥。
- 动态正交可作为扩展思路，但不要期待它完全替代固定的强因子筛选。

## Caveats
- 正交只处理线性相关性，非线性相关仍可能存在。
- 正交顺序本身会影响结果，特别是在弱因子较多时。
