- **source filename**: `20200707-海通证券-选股因子系列研究（六十八）：基金重仓超配因子及其对指数增强组合的影响.pdf`
- **date**: 2020-07-07
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、罗蕾
- **document type**: 金融工程专题报告

## Core question
基金重仓股中的“超配”部分是否能形成可交易的选股因子，以及它对指数增强策略有什么影响。

## Methods / data
基于基金季报，定义基金重仓超配个股（持仓市值占比高于基准指数权重），分基金池、分业绩、分市场环境回测，并分析将超配因子加入增强组合的效果。

## Key findings
- 公募基金更倾向于超配大市值、高估值股票，行业上偏医药、计算机、电子、食品饮料、军工等。
- 超配个股有一定收益延续性，季报披露后继续持有仍能获得超额。
- 但超配因子方向波动较大，月度溢价并不总是同向，因此直接加入增强模型的提升有限。
- 使用不同基金池会明显改变结果；业绩靠前的基金池从静态多空收益看更强，但从增强策略改进看，业绩靠后的基金池有时更有利于方向稳定性。
- 对超配因子做简单择时（只用预测为正的部分）可把沪深300/中证500增强年化超额提升0.6%以上。

## Quant takeaways
“基金超配”更像一个带时变方向的资金偏好信号，单独做多不一定稳，但经过基金池筛选和简单择时后，能变成可用的增强输入。

## Caveats
持仓数据披露滞后、方向切换快、基金池选择敏感，都会影响可交易性。
