# 2019美国目标日期基金市场概览

- **source filename**: `20190619-天风证券-海外文献推荐第91期.pdf`
- **date**: 2019-06-19
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告从规模、资金流、竞争格局、管理结构和业绩比较美国目标日期基金（TDF），分析低费率、主动/被动配置和基金经理安排如何重塑退休投资产品市场。

## Methods / data
- 使用Morningstar 2019年目标日期基金市场数据，比较2009–2018年资产规模、净流入、费率和市场份额。
- 按费率、底层主动基金占比和基金公司分组，观察资金流向；另比较基金经理数量、任期、风险共担及系列收益和Sharpe。
- 重点分析63个目标日期系列以及Vanguard、Fidelity、BlackRock等主要供应商。

## Key findings
- 2018年TDF平均亏损6.22%，市场规模降至约1.09万亿美元，但仍有约550亿美元净流入；相较2008年规模约增长近5倍。
- 费率低于0.20%的产品净流入约570亿美元，0.61%–0.80%产品净流出约290亿美元；市场平均费率降至0.62%。
- Vanguard 2018年市场份额约37%，规模约3962亿美元，净流入约408亿美元；7家供应商合计占约90%市场。
- 低费率系列通常吸引更多资金，但报告强调低费率并不保证高收益，主动/被动和组合结构仍重要。

## Quant takeaways
- TDF研究应同时建模生命周期下滑轨道、底层资产风险、费用和现金流，而非只比较单年收益。
- 低费率可作为资金流预测变量，但需控制供应商品牌、渠道、默认退休计划和历史业绩。
- 2018年市场下跌影响显著，Sharpe和过往收益存在时点依赖；应使用完整周期及风险调整指标。
