# 文献启示录第2期：通胀预期指标

- **date**: 2021-04-18
- **institution / author**: 太平洋证券；徐玉宁、王西之
- **extraction confidence**: high

## Core question
报告讨论如何从盈亏平衡通胀率（BEI）中剥离流动性溢价和通胀风险溢价，并构建跨期限、跨来源的通胀预期指标。目标是避免把TIPS市场摩擦误判为真实通胀预期。

## Methods / data
- D’Amico、Kim和Wei的无套利仿射期限结构模型：名义利率、实际利率和通胀预期由隐含因子驱动，流动性溢价为共同因子。
- 使用周度名义国债、TIPS收益率、月度季调CPI，并加入调查预期和3个月国库券收益率。
- Haubrich等用7状态变量估计1—30年通胀预期期限结构；Ahn和Fulton用21个指标动态因子模型构造CIE。

## Key findings
- TIPS流动性溢价约解释BEI变动的30%—40%，是2001—2004上行及2008—2009 V型反转的重要驱动。
- 2020年3月BEI触底后的反弹主要来自TIPS流动性溢价；2021年2月后通胀预期升至约2%，通胀风险溢价转正。
- 短期预期更受油气价格和消费者预期影响，长期预期更稳定并受货币政策影响。
- CIE按居民、专业预测者、市场参与者约30%/40%/30%权重，2020年3月约1.93%，后升至约2.04%。

## Quant takeaways
- 宏观交易中应将BEI拆分为真实预期、流动性溢价和风险溢价，避免直接使用原始利差。
- 可把期限结构斜率、CIE共同因子及调查/市场指标分歧用于利率和通胀资产配置。
- 模型依赖状态变量、样本和流动性假设；市场压力期分解结果尤其需要稳健性检验。
