# Skills 的设置与使用 摘要

- **来源文件**：20260217-华创证券-【点评报告】量化看市场系列之五：如何叫你的AI更聪明、运行更有效率~Skills的设置与使用.pdf
- **日期/机构/类型**：2026-02-17，华创证券，点评报告/AI 应用方法论

## 核心问题
什么是 AI Skills，如何用“技能模块”方式让 AI 更聪明、更可控、更高效，并把经验沉淀为可复用能力。

## 方法与数据
- 解释 Skills 的三部分：metadata、instruction、resource。
- 对比 Prompt、Function Call/MCP 与 Skills 的差异。
- 给出 Skills 模板，以及在 Cursor 中安装 Skills 的方法。

## 关键发现
- Skills 本质上是可复用、低 token、确定性强的“数字岗位说明书”。
- 适合把行业经验、工作流和代码封装成可调用能力。
- 风险重点在于安装来源和潜在恶意代码。

## 量化要点
- 没有金融回测数据。
- 主要“量化收益”是 token 消耗更低、执行确定性更高、复用成本更低。

## 局限性
- 报告偏方法论与产品认知，不涉及可验证投资绩效。
- Skills 质量取决于设计与资源完整性。
