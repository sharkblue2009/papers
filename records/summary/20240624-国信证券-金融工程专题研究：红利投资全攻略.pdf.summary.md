# 摘要
- 源文件：20240624-国信证券-金融工程专题研究：红利投资全攻略.pdf
- 机构：国信证券
- 日期：2024-06-24
- 类型：金融工程专题研究
- 主题：系统梳理红利投资框架、分红机制、红利因子与红利增强策略。
- 方法/数据：基于A股分红数据、红利类指数和基金表现，分析分红流程、事件研究（潜伏高股息组合）、“股息+”因子构建，以及中证红利指数增强组合和股债固收+组合。
- 主要结论：
  1. 红利风格长期具备较高性价比，波动和回撤通常显著低于成长风格。
  2. “潜伏高股息组合”在每年 5-7 月表现突出，3 个月内相对中证红利全收益指数平均超额收益 6.95%。
  3. 预期股息率因子优于传统 LYR/TTM 股息率因子，RankIC 均值 4.9%，年化 RankICIR 3.01，月胜率 84.9%。
  4. 中证红利指数增强组合自 2014 年以来年化收益 24.20%，相对全收益指数年化超额 10.43%，信息比 2.13。
  5. 复合后的红利增强与固收+组合表现稳健，适合偏防守型配置。
- 量化要点：
  - 可围绕分红预案、除息窗口和预期股息率构建事件与因子双驱动策略。
  - 红利增强策略可与债券资产组合，形成稳健收益框架。
- 局限：
  - 依赖分红制度、样本期与市场风格，且事件驱动策略受交易约束与除息日变化影响。
- 关键词：红利投资、预期股息率、指数增强、事件研究、固收+。
