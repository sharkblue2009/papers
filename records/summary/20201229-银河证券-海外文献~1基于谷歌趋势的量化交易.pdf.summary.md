# 基于谷歌趋势的量化交易

- **source filename**: `20201229-银河证券-海外文献~1基于谷歌趋势的量化交易.pdf`
- **date**: 2020-12-29
- **institution / author**: 中国银河证券；吴俊鹏；原文作者 Tobias Preis、Helen Susannah Moat、H. Eugene Stanley
- **extraction confidence**: high

## Core question
研究金融相关词汇的Google Trends搜索量是否能在股价大幅波动前提供投资者关注和担忧的早期预警，并据此构建道琼斯指数择时策略。

## Methods / data
- 使用2004—2011年DJIA周收盘价和98个搜索词的Google Trends数据，搜索量按连续三周平均并计算相对变化。
- 当滞后搜索量变化为正时下一周做空DJIA，为负时做多；采用对数收益，不计交易费用，允许做空。
- 以美国用户和全球用户数据比较，并与买入持有及用价格变化择时的Dow Jones策略对照；随机策略用1000次模拟构造基准。

## Key findings
- “debt”策略（窗口Δt=30周）使组合价值提高326%。
- 美国搜索数据策略平均收益指标为0.6、t=8.65、df=97、p<0.001，显著高于随机策略；全球数据平均为0.43，显著弱于美国数据。
- 买入持有收益16%，Dow Jones策略33%；搜索量下降的多头策略均值0.41、t=11.41，搜索量上升的空头策略均值0.19、t=5.28，均显著高于随机策略。

## Quant takeaways
- 搜索数据可作为情绪/关注度状态变量，但词选择、窗口和地区口径影响很大。
- 原研究不计交易成本且样本期较短，需防止关键词筛选和回测期选择偏差，并在现代搜索接口变化后重新验证。
