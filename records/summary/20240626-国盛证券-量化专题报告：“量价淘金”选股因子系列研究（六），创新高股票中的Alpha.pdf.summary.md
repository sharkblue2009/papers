# 摘要
- 源文件：20240626-国盛证券-量化专题报告：“量价淘金”选股因子系列研究（六），创新高股票中的Alpha.pdf
- 机构：国盛证券
- 日期：2024-06-26
- 类型：量化专题报告
- 主题：研究“创新高”事件背后的持续超额收益，并从量价与基本面中筛选更优的新高股票。
- 方法/数据：基于中证800成分股，统计创新高事件后的长期超额表现；从时序角度筛除“假突破/诱多”，从截面角度结合涨跌幅、换手率、一致预期上调等因子筛样本；采用资金通道法构建可落地组合。
- 主要结论：
  1. 创新高股票在新高后长期仍可能产生正超额收益，例如新高后 240 个交易日相对中证800平均超额 6.37%。
  2. 该类机会具有“低胜率、高赔率”特征，需进一步筛选样本以提升稳健性。
  3. 放量创新高、突破后反应不足、基本面更优的样本，后续超额收益更显著。
  4. 2014 年以来创新高组合年化收益 12.76%，相对中证800全收益指数年化超额 5.82%。
- 量化要点：
  - 创新高并不等于追高风险，关键在于识别突破质量与后续持续性。
  - 量价和一致预期类因子可用于过滤高质量突破样本。
- 局限：
  - 事件驱动策略受市场牛熊阶段影响较大，牛市尾声和熊市中易失效。
- 关键词：创新高、事件驱动、量价筛选、基本面筛选、超额收益。
