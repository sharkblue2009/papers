# 基金的交易成本、持仓特征与业绩的关系

- **source filename**: `20210620-东兴证券-海外文献速览系列之五：基金的交易成本、持仓特征与业绩的关系.pdf`
- **date**: 2021-06-20
- **institution / author**: 东兴证券；高智威、赵妍；原文作者 Jeffrey A. Busse、Tarun Chordia、Lei Jiang、Yuehua Tang
- **extraction confidence**: high

## Core question
基于真实逐笔交易数据，研究基金规模、交易成本、持仓流动性和基金业绩之间的内生联系，解释规模增长为何可能压缩投资机会和回报。

## Methods / data
- 合并CRSP基金数据库、晨星风格、Thomson Reuters持仓和Abel Noser实际交易数据；最终为1999年1月至2011年9月的583只主动美国股票基金。
- 将交易成本分解为执行差额、当日开盘价成本和前一日收盘价成本，分别在交易单据和基金层面回归。
- 研究基金TNA、交易频率、持仓市值/流动性、现金流与未来持仓变化及基金总回报的关系。

## Key findings
- 控制投资风格后，大型基金交易成本百分比低于小基金，但交易频率更低且更倾向持有大市值、高流动性股票。
- 随基金规模增长，持仓逐渐向流动性更强的股票倾斜，以主动避免更高交易成本；这也减少了小盘、低流动性错误定价机会。
- 大型基金总回报低于中小基金，部分可由持仓组合特征和交易成本约束解释；具体收益差异数字在摘录中未给出。

## Quant takeaways
- 基金回测应把容量、交易成本和持仓流动性作为联立问题，而不是只按历史Alpha排序。
- Abel Noser客户可能存在选择偏差；国内研究需重建真实成交成本并考虑基金规模、换手和市场冲击的共同内生性。
