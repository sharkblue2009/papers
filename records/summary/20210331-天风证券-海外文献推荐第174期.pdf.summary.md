# 解决规模效应的问题

- **source filename**: `20210331-天风证券-海外文献推荐第174期.pdf`
- **date**: 2021-03-31
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: medium

## Core question
报告重新评估规模溢价，重点检验控制质量（quality-minus-junk）暴露后美国 SMB 是否恢复 alpha，并进一步判断规模本身是否可交易，以及小盘暴露能否增强价值、动量等其他因子。

## Methods / data
- 使用 Kenneth French、AQR 和 q-factor 数据库，比较 SMB、HML、WML、RMW、CMA、QMJ、IA、ROE、EG 等因子。
- 美国样本为 1963 年 7 月至 2019 年 12 月或 1967 年起；国际样本约为 1990/1993 年至 2019 年。
- 采用 2×3、2×3×3 排序构造标准及质量条件规模因子，并对因子多头、空头和小盘权重进行回归归因。

## Key findings
- 美国原始 SMB 月均 0.19%，t=1.68；控制市场后降至 0.08%，控制滞后 beta 后仅 0.02%。
- 加入 RMW 后 alpha 为每月 0.22%，t=2.05；控制 QMJ 后为 0.42%，t=3.98；扩展 q 模型下达 0.60%，t=4.90。
- 国际市场即使控制 QMJ，规模溢价大多仍统计不显著；美国是明显例外。
- 美国规模 alpha 主要由质量因子空头端驱动，事前质量条件规模组合无法稳定捕捉；但小盘权重可显著增强其他因子 alpha。

## Quant takeaways
- 规模因子研究必须同时报告质量暴露、做多/做空归因和事前可交易实现，避免把事后回归 alpha 当作可获取收益。
- 多头策略可把小盘作为价值、动量等因子的催化剂，而非单独押注规模溢价。
- 规模效应具有明显地域差异；文档存在少量 OCR 乱码，具体表格数值仍应回看原始数据。
