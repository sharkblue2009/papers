# 横截面与时间序列因子模型比较

- **source filename**: `20200429-天风证券-海外文献推荐第134期.pdf`
- **date**: 2020-04-29
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告把Fama-MacBeth横截面回归斜率构造成与Fama-French时间序列因子对应的因子，比较横截面因子与传统时间序列因子解释股票组合平均收益的能力。

## Methods / data
- 样本为1963年7月至2018年8月的662个月度收益，围绕规模、账面市值比、盈利、投资和动量构造横截面（CS）与时间序列（TS）因子。
- 比较固定载荷和时变载荷的时间序列模型，使用5×5特征排序的100个组合及110个异象组合。
- 以调整后的拟合度、定价误差、GRS等指标评价模型表现。

## Key findings
- 仅使用CS因子的时间序列模型整体优于使用TS因子的模型；无论载荷固定还是时变，该结论均成立。
- CS因子模型对100个5×5组合和110个异象组合的平均收益解释更好，优势主要来自CS因子本身，而非载荷时变。
- 时变载荷能吸收更多左手边组合收益方差、提高拟合度，但对定价误差的改善通常较小；动量排序仍是难点。

## Quant takeaways
- 因子研究可将每期截面回归斜率直接视作可交易因子，并与传统TS因子并列比较。
- 应区分“解释收益波动”和“降低定价误差”，不能仅凭更高R²判断模型更优。
- CS因子需要实时特征值；若特征不可及时获得，时变载荷会引入实施和前视偏差。
