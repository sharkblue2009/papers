# 海通证券选股因子系列研究（十六）：选股因子空头收益的转化

- **source filename**: `20160830-海通证券_选股因子系列研究（十六）：选股因子空头收益的转化.pdf`
- **date**: 2016-08-30
- **document type**: 金融工程专题报告

## Core question
A 股因子普遍存在空头收益，如何把这种“空头效应”转化为可用的选股收益。

## Methods / data
- 统计多种常见选股因子的 **多头/空头收益占比**，比较空头端是否更强。
- 单因子层面尝试 **逆向剔除**：根据因子值筛掉最差一端股票，再在剩余股票中随机选股。
- 多因子层面用 **复合因子 ICIR** 解释因子收益转化，并讨论正交化处理。

## Key findings
- A 股多数选股因子具有较强的 **空头效应**；在 IC 较高的因子中，很多因子的空头收益占比都超过 **70%**。
- **逆向剔除** 可以较好利用空头效应：把因子最差的一端剔掉后，剩余股票的随机组合更容易获得较高收益分位数。
- 在多因子模型中，因子收益能否转化不仅取决于因子本身，还取决于 **因子间 IC 协方差** 和权重设置。
- **正交因子**更适合该分析框架，也能有效剔除“合成型”选股因子。

## Quant takeaways
- 如果因子多头端不强，但空头端很强，可考虑做“**剔除差股票**”而不是强行做多。
- 多因子系统里要同时看单因子 IC、因子间协方差和权重，不要只看单因子胜率。
- 正交处理对解释空头收益转化尤其有用。

## Caveats
- 结果依赖历史样本和模拟抽样设定，真实交易成本与流动性约束可能削弱可得收益。
- 空头收益转化在 A 股受做空限制，落地方式更偏“选股过滤”而不是直接做空。
