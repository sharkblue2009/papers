# 摘要

- **源文件**：20240215-长江证券-事件驱动新思路：外溢效应与因子化.pdf
- **日期 / 机构 / 类型**：2024-02-15｜长江证券｜金融工程深度报告
- **核心主题**：把传统事件驱动从“事件影响本股”扩展为“事件影响外溢到其他股票”，并将外溢效应因子化。
- **方法与数据**：基于涨停事件、领涨事件、高管增持事件、负向业绩预告等，定义事件股（场源）、事件信号强度与股票距离，构建“场强/距离”式外溢效应因子，再将多个事件因子等权合成为综合因子。
- **主要结论**：事件外溢效应能够显著扩展事件驱动策略的覆盖面和有效时间窗，并可与传统多因子模型结合。综合因子在统计上具备较强的选股能力。
- **量化要点**：事件外溢效应综合因子平均 **RankIC 为 9.79%**，年化 **ICIR 为 2.36**；涨停、领涨、高管增持、负向业绩预告等外溢因子均表现较好。
- **局限性**：研究基于历史样本与回测，未来外溢关系未必稳定；事件定义、距离度量和参数设定会影响结果。
- **关键词**：事件驱动、外溢效应、因子化、涨停事件、领涨事件、高管增持、业绩预告
