# 海通证券量化研究新思维（一）：对选股因子择时

- **source filename**: `20170407-海通证券-量化研究新思维（一）：对选股因子择时.pdf`
- **date**: 2017-04-07
- **document type**: 金融工程专题报告

## Core question
如何在因子收益预测中加入“环境变量”，把因子择时做得更灵活、更贴近市场状态。

## Methods / data
- 提出用 **条件变量** 预测因子未来 IC / 收益，如 VIX、市场环境、日历效应等。
- 讨论三类应用：**因子择时**、**经济周期下的资产配置**、**机构关注度/AIA 指标**、以及 **波动率管理组合**。
- 以海外和跨资产思路为主，更多是方法论与研究框架展示。

## Key findings
- 传统用过去 24/36 个月均值预测 IC 的方法太“慢”，很难及时反映市场状态变化。
- 加入条件变量后，反转等因子的权重可以根据市场环境动态调整，比如 VIX 低位时提高反转权重。
- 经济周期、机构关注度和波动率管理都能显著改善风险调整后表现，文中给出的示意结果显示组合夏普可明显优于传统方式。

## Quant takeaways
- 因子择时的核心不是“猜方向”，而是 **用外生状态变量修正因子收益/协方差预期**。
- 可以把市场状态拆成宏观、微观和因子自身三个层次来做。
- 波动率管理和机构关注度可作为很多因子组合的“外层风控层”。

## Caveats
- 本篇偏思路与方法介绍，具体可交易细节与样本外验证较少。
- 海外案例向国内迁移时要注意市场结构差异。
