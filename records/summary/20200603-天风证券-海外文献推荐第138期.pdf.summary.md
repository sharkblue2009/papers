# 心情Beta与股票收益的季节性

- **source filename**: `20200603-天风证券-海外文献推荐第138期.pdf`
- **date**: 2020-06-03
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告提出投资者心情的季节性变化可以统一解释月份、工作日及股票横截面的季节性收益。核心变量是心情Beta：资产收益对高、低情绪时期市场收益的敏感度。

## Methods / data
- 使用NYSE、AMEX和NASDAQ普通股，1963年1月至2016年12月；测试完整个股横截面、94个BW组合和79个KLN组合。
- 将1月、3月定义为高情绪月，9月、10月为低情绪月；周五和周一分别代表高、低情绪日，检验重复与反转。
- 用10年滚动窗口（至少40个观测）估计心情Beta，再做Fama-MacBeth回归，控制市场Beta和Sentiment Beta。

## Key findings
- 同一情绪月份的相对表现可重复至少10年，不同情绪月份则出现反转；工作日层面也观察到周五强、周一弱及相应重复/反转。
- 高心情Beta股票在未来高情绪期表现更高、低情绪期表现更低，且在控制市场Beta、Sentiment Beta和公司特征后仍有增量解释力。
- 基于心情Beta的多空策略日度alpha约0.08%—0.17%，月度和工作日检验均取得正收益。

## Quant takeaways
- 可把情绪状态与季节性横截面因子结合，按预期情绪方向动态反转或持有高/低心情Beta。
- 需要避免日历效应数据挖掘，并处理月初、周末、节假日和交易成本造成的微观结构偏差。
- 情绪代理和季节性状态在不同国家可能不同，实盘应做滚动估计、容量和跨市场稳健性测试。
