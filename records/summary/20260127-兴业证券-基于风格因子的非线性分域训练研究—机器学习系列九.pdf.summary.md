# PDF摘要
- Source file: `20260127-兴业证券-基于风格因子的非线性分域训练研究—机器学习系列九.pdf`
- 日期 / 机构 / 类型: 2026-01-27，兴业证券经济与金融研究院，定量研究专题报告
- 核心问题: 将“分域训练”引入风格因子与 XGB 因子框架，能否提升股票池内有效性并增强指数增强表现？
- 方法/数据: 以面板树（以节点组合夏普比率为目标）进行滚动分域，再结合 XGB 对抗训练；进一步从“全集”改造为“代表域”样本集，降低风格相关性；在沪深 300、中证 500、中证 1000 等增强场景检验。
- 主要发现: 分域训练因子在全市场周度测试中 Rank IC 约 0.122，改造后约 0.123，风格相关性继续下降；指数增强 2015 年以来年化超额收益约为沪深 300 的 12.8%、中证 500 的 17.5%、中证 1000 的 24.1%，且回撤收窄。
- 量化要点: 该方法兼顾收益与稳健性，尤其在中证 1000 上增厚效果最明显，显示出对风格因子的“局部优化+分域学习”价值。
- 局限性: 依赖历史样本与市场结构，市场风格切换时模型可能失效。
- 关键词: 面板树, 分域训练, XGB, 对抗训练, 风格因子, 指数增强
