# 决策疲劳和启发式分析师预测

- **source filename**: `20210127-天风证券-海外文献推荐第167期.pdf`
- **date**: 2021-01-27
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告考察卖方分析师在同一天连续发布多次盈利预测后是否出现决策疲劳，并检验疲劳是否降低预测精度、增强从众与重复发布行为，以及削弱市场对预测修正的反应。

## Methods / data
- 使用 IBES 2002—2015 年分析师盈利预测，限定工作日 9:00—19:00 发布的实时预测，共 386,924 个样本，分析师平均每天发布 1.3 次预测。
- 以当天已发布预测数加一的对数作为 Decision Rank，控制覆盖股票数、中介商规模、从业年限，并使用分析师—日期等固定效应。
- 被解释变量包括相对预测准确度、Herding、Reissue、Rounding，以及预测修正后三日累计异常收益 CAR。

## Key findings
- 在加入分析师—日期固定效应后，Decision Rank 系数为 -0.067，5%水平显著，表明后续预测准确度下降。
- 从众回归系数为 0.086，5%水平显著；重复发布的边际效应均值 0.262，一单位标准差提升使重复发布概率提高约 8.2%。
- 对 1—10 美元 EPS 预测，预测排序越靠后，舍入预测概率越高。
- Decision Rank 与预测修正的交互项显著为负，说明疲劳越强，市场对修正信息的三日反应越弱。

## Quant takeaways
- 分析师预测事件因子可加入发布顺序、当天工作量等行为变量，识别信息质量和市场反应差异。
- 构建预测策略时应控制分析师、公司和日期固定效应，并区分首次预测与重复发布。
- 预测顺序并非完全随机，尽管稳健性检验支持疲劳解释，内生排序和未观测工作压力仍是限制。
