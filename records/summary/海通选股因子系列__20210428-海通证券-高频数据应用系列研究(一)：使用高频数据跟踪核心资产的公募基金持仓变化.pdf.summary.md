# 海通证券高频数据应用系列研究（一）：使用高频数据跟踪核心资产的公募基金持仓变化

- **source filename**: `20210428-海通证券-高频数据应用系列研究(一)：使用高频数据跟踪核心资产的公募基金持仓变化.pdf`
- **date**: 2021-04-28
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 金融工程专题报告

## Core question
能否用高频微观交易数据持续跟踪公募基金在个股上的持仓占比变化，并把这种跟踪结果用于后续选股/行业研究。

## Methods / data
使用高频数据构造与公募持仓变化相关的解释变量，建立回归模型来预估个股公募基金持仓占比；再按宽基指数、行业板块、初始持仓占比等维度分组建模，并做滚动样本外检验。

## Key findings
- 高频数据可以较好地跟踪机构交易行为，并用于预估个股公募基金持仓占比。
- 全市场模型样本外表现：**R² 均值 18.4%**，**样本外相关性均值 0.44**。
- 分范围建模后效果更好：
  - **沪深300**：样本外 R² 均值 **28.3%**，相关性均值 **0.56**。
  - 科技 / 消费 / 工业板块也相对较好。
  - 期初公募持仓占比较高的股票范围效果更优，样本外 R² 均值可达 **30.3%**，相关性均值 **0.58**。
- 该框架不仅能跟踪个股，还可向上合成行业、风格、因子组合层面的持仓预估。

## Quant takeaways
高频数据不仅能做alpha，还能做“持仓状态估计器”，为后续基金行为、行业配置与风格轮动提供基础变量。

## Caveats
持仓预估依赖样本区间和分组方式；真实应用还要考虑披露滞后、流动性与政策环境变化。
