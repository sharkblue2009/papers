# 海外文献推荐 第05期

- **date**: 2017-06-28
- **institution / author**: 天风证券研究所；吴先兴
- **extraction confidence**: high

## Core question
本期研究国际机构投资组合集中度、投资者价值/成长风格来源、卖空比例的收益预测能力，以及毛盈利能力如何改进价值策略。

## Methods / data
- 使用 72 个国家、10,771 个机构投资者的持股数据，以国家和行业层面三种集中度指标解释风险调整收益。
- 结合投资者个人特征、生物学偏见、宏观经历和成长环境分析价值/成长风格。
- 对卖空比例做 1973:01—2014:12 样本内、1990:01—2014:12 样本外预测回归、嵌套检验和资产配置。
- 以毛利/资产衡量毛盈利能力，比较毛盈利组合、B/M 价值组合及其他异常策略。

## Key findings
- 全球机构组合集中度与风险调整收益正相关，支持信息优势理论，而非充分分散化必然最优。
- 卖空比例样本内和样本外预测收益的 R² 分别为 12.89% 和 13.24%；均值—方差投资者每年可获得约 300 个基点收益。
- 毛盈利能力与 B/M 对截面收益有相近作用，控制盈利能力可显著改善价值策略，尤其在大市值、高流动性股票中。
- 投资风格同时受生物学、行为对冲需求及早期宏观环境影响。

## Quant takeaways
- 可把国家/行业集中度作为信息优势或主动程度的检验维度，而不是简单把集中视为风险。
- 卖空比例和毛盈利因子需做样本外、交易成本和现金流渠道分解；价值策略应控制盈利能力以避免把盈利质量误当价值。
