# 研报摘要

- **来源文件**：20260318-西南证券-从眼到手：OpenClaw如何改变投资研究模式.pdf
- **日期/机构/类型**：2026-03-18，西南证券，AI大模型投研应用系列
- **核心问题**：OpenClaw 作为开源自主智能体，如何改变投研工作流、降低工具门槛并提升研究执行效率？
- **方法/数据**：介绍 OpenClaw 的三层架构、WSL2 部署方式、飞书/终端/浏览器交互方式，以及在投研中的数据抓取、分析和报告生成实践；并以深度学习因子选股案例展示自动化研究流程。
- **关键结论**：OpenClaw 使投研从“对话工具”走向“执行工具”，在信息搜集、数据分析、报告输出方面能显著降低操作门槛；但当前模型仍会出现脚本逻辑错误、数据处理偏差与幻觉，必须人工复核。
- **量化要点**：报告强调其可调用 Tushare、同花顺等接口批量取数，内置 Python 沙盒支持 Pandas/Matplotlib；深度学习选股案例中可自动完成训练、回测和净值/夏普图生成，但部分结果需人工纠错。
- **局限性**：大模型生成代码和结论存在幻觉与误判风险；本地部署权限较高，若隔离不当可能带来文件误删和数据泄露风险；结论仅供技术探讨。
- **关键词**：OpenClaw、智能体、投研自动化、WSL2、飞书、技能、数据分析
