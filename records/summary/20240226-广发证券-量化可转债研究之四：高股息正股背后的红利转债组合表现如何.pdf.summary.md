# 20240226-广发证券-量化可转债研究之四：高股息正股背后的红利转债组合表现如何

- **源文件**：`20240226-广发证券-量化可转债研究之四：高股息正股背后的红利转债组合表现如何.pdf`
- **日期/机构/类型**：2024-02-26，广发证券，金融工程|专题报告

## 核心主题
- 研究“高股息正股背后的红利转债”是否能在可转债市场中复制 A 股红利因子的收益风险特征，并进一步构造“红利+”可转债组合。

## 方法与数据
- 使用 Wind 数据，筛选正股股息率大于 3% 的可转债样本。
- 按股息率加权，分层构建偏股层、中性层、偏债层红利可转债组合。
- 进一步按市值占比构造每月再平衡的分层加权组合。
- 同时测试红利 + 低波动、红利 + 质量、红利 + 价值等风格叠加组合。

## 关键发现
- 2020 年 5 月以来，偏债层/中性层/偏股层组合年化收益率分别为 **4.95% / 5.38% / 6.32%**，最大回撤分别为 **9.84% / 10.24% / 37.59%**。
- 分层加权红利转债组合年化收益率 **5.44%**，最大回撤 **14.66%**，夏普比率 **0.51**，分年度收益均优于中证转债指数。
- 在“红利+”组合中，红利价值组合表现最稳，红利低波组合显著降回撤但收益偏弱，红利质量组合受样本较少影响偶然性较强。

## 量化要点
- 红利可转债思路的核心是用正股股息率筛选，再通过分层与加权控制偏股/偏债暴露。
- 组合表现随着样本数量增加而更稳定，报告指出近 2 年转债数量上升到约 50 只后，策略开始更稳定跑赢中证转债指数。
- “红利+价值”是收益与风险兼顾最均衡的叠加方向。

## 局限性
- 可转债样本数量仍有限，尤其某些“红利+”细分策略存在统计样本不足问题。
- 结果依赖历史数据，市场环境变化后可能失效。
- 报告不构成投资建议。
