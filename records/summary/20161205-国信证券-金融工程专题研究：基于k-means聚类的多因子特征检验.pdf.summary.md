# 基于K-Means聚类的多因子特征检验

- **source filename**: `20161205-国信证券-金融工程专题研究：基于k-means聚类的多因子特征检验.pdf`
- **date**: 2016-12-05
- **institution / author**: 国信证券；邹璐、黄志文、陈镜竹
- **extraction confidence**: high

## Core question
检验把全A股票按市值和波动率聚类后，因子的统计特征和收益预测能力是否出现异质性，并据此改进多因子选股。

## Methods / data
- 使用全A股票，按标准化后的市值与过去一年日频波动率做K-means，比较不同簇数后取k=5；聚类结果覆盖2011—2016等年度。
- 五类分别对应低市值高/中/低波动、高市值高/低波动；考察69个因子的均值、方差、月度IC（2009—2016）及前40%对后40%的多空收益。
- 依据2009—2011年IC均值和多空胜率在各簇筛选因子，构建前后30%的等权或IC加权组合。

## Key findings
- 全A整体不显著的EP、BP在低市值高波动簇（1号）中出现显著正收益；动量、换手率、波动率因子在小市值簇更显著，大市值低波动簇较弱。
- ROE和营收增长率在五类中的单因子收益均高于全A基准，1、4号高波动及5号大市值簇表现更强。
- 在相同选股数量（总数30%）下，聚类后多空组合更稳定，月度夏普率接近全A组合的2倍。

## Quant takeaways
- 因子有效性应按市值—波动率状态条件化，聚类可作为因子路由或动态加权的简单实现。
- 聚类簇和因子筛选使用历史窗口，需防止状态漂移、簇标签不稳定以及因子选择带来的数据挖掘偏差。
