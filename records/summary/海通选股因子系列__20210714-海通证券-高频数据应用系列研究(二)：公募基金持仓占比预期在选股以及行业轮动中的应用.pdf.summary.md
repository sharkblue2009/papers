# 海通证券高频数据应用系列研究（二）：公募基金持仓占比预期在选股以及行业轮动中的应用

- **date**: 2021-07-14
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 金融工程专题报告

## Core question
上一期构建的“公募持仓预期”是否能直接转化为选股因子，并进一步用于行业轮动。

## Methods / data
基于前期对个股公募基金持仓占比的高频预估，构建两类选股因子：1）预期持仓占比水平；2）预期持仓占比相对历史的变化；并将个股预期向上合成为行业预期，用于行业轮动策略。

## Key findings
- 个股层面的公募持仓预期拟合效果较好，行业层面同样成立。
- **预期持仓占比因子** 在 **沪深300** 和 **中证800** 内均有显著选股能力；正交后能力下降但仍有效。
- **预期持仓占比变化因子** 截面区分度一般，但多头效应较强。
- 基于行业预期构建的三类行业轮动策略表现都不错：
  - 策略1（选预期持仓占比高的行业）：年化多空收益 **16.96%**，年化多头超额 **11.67%**。
  - 策略2（选相对 1 季度前披露提升更大的行业）：年化多空收益 **13.96%**，年化多头超额 **8.55%**。
  - 策略3（选相对最新季报差值更大的行业）：年化多空收益 **12.01%**，年化多头超额 **9.70%**。
- 2021 年以来的多头超额在若干策略中继续保持正贡献。

## Quant takeaways
这篇把“持仓跟踪”推进到“持仓预期可交易化”，并同时打开了选股和行业轮动两条应用路径。

## Caveats
策略依赖持仓预估精度与基金行为延续性；行业轮动还会受到风格切换和交易成本影响。
