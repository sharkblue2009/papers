# 基于基金选股能力与择时能力的平价模型

- **source filename**: `20220210-东兴证券-海外文献速览系列之十五：基于基金选股能力与择时能力的平价模型.pdf`
- **date**: 2022-02-10
- **institution / author**: 东兴证券；高智威；原文作者Weiyi Liu、Yangyi Liu、Ronghua Luo、Yue Ding
- **extraction confidence**: high

## Core question
文献提出能力平价模型，把基金经理的选股能力与市场择时能力纳入基金组合配置，而不是只优化收益和波动。模型在最大化两种能力总贡献的同时，以惩罚项控制两者失衡。

## Methods / data
- WIND中国主动股票及股票型混合基金；2006-01—2017-12，699只基金、2,917个交易日。
- 用Treynor-Mazuy模型估计alpha选股能力和二次项择时能力；滚动250日估计，比较EW、MV、Markowitz、最大Sharpe、RP及沪深300。
- 交易成本0.3%、基准再平衡60日；测试惩罚系数、交易成本、再平衡周期及FF3/4/5/6绩效归因。

## Key findings
- 能力平价组合Sharpe约1.02，其他比较模型最高约0.40，沪深300约0.18；累计收益约为最佳比较模型5倍、指数近10倍，MDD绝对值最低。
- 交易成本提高会削弱显著性，但AP在不同成本设置下仍占优；再平衡周期越长，收益和显著性下降。
- 组合对SMB、UMD正暴露，对HML负暴露，偏向小盘、成长和动量；多数FF模型下alpha仍显著为正。
- 选股与择时能力常负相关；约95%的基金有正选股能力，97%有负择时能力。

## Quant takeaways
- 可把能力平价视作基金层面的多目标优化，与风险平价、能力动量和稳健约束比较。
- 估计窗口、惩罚系数、基金存续偏差和再平衡时点应严格样本外处理。
- 结果可能主要承载小盘、成长、动量暴露；需进一步中性化、加入流动性和容量约束。
