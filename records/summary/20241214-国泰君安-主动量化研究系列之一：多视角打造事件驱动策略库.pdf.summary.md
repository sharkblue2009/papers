# 20241214-国泰君安-主动量化研究系列之一：多视角打造事件驱动策略库

- **来源文件**：20241214-国泰君安-主动量化研究系列之一：多视角打造事件驱动策略库.pdf
- **日期/机构/类型**：2024-12-14，国泰君安，数量化专题/主动量化研究系列之一
- **核心主题**：在传统成长选股难度上升的背景下，构建多类型事件驱动策略库，作为主动选股的补充。
- **方法/数据**：围绕公开披露和可追踪信息，整理六类事件策略：产品涨价、平稳创新高、指数成分调整、盈利超预期、日历效应、入通（Stock Connect）。数据包括产品现货价格、个股价格、财报、分析师预期、成分股调整和南北向资金相关信息。
- **主要发现**：产品涨价适合低关注度标的；平稳创新高可捕捉趋势延续；指数成分调整可做被动资金驱动的事件套利；盈利超预期和日历效应可捕捉公告后漂移与季节性关注；入通策略利用南下资金增量。事件驱动策略库可作为主动权益方法论的重要补充。
- **量化要点**：将事件按定价逻辑拆解并模块化，可形成可组合的选股库，适合在传统基本面Alpha衰减时使用。
- **局限性**：基于历史公开信息与模拟构建，实际交易中可能受流动性、成本和制度变化影响。
- **关键词**：事件驱动、主动量化、产品涨价、盈利超预期、指数调整、入通
