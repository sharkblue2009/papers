# 海通证券金融工程专题选股因子系列研究（二十八）：一致预期质量分析

- **source filename**: `20171027-海通证券-金融工程专题选股因子系列研究（二十八）：一致预期质量分析.pdf`
- **date**: 2017-10-27
- **document type**: 金融工程专题报告

## Core question
朝阳永续与 WIND 的一致预期数据，谁更准确、更适合做因子和选股策略。

## Methods / data
- 比较两家数据商的 **报告覆盖量、股票覆盖率、预测准确度**。
- 重点看极值预测、不同市值股票上的准确度，以及与业绩预测相关因子的 IC 和策略收益。
- 对比单因子与多因子策略表现。

## Key findings
- 朝阳永续收录报告更多、覆盖更广；WIND 覆盖少一些，但近年来质量提升快。
- 若不清洗极值，WIND 的预测准确度更稳；若能先剔除不靠谱极值，朝阳永续清洗后的质量反而更好。
- 大市值股票上的预测准确度近年提升明显，尤其是 WIND。
- 因子 IC 层面两家差异不大，但做全市场收益预测和多因子策略时，**朝阳永续整体更优**，与其覆盖率高、非极值预测较好有关。

## Quant takeaways
- 一致预期数据的使用，核心不是“哪家更大”，而是 **覆盖率 + 极值处理 + 策略类型** 的匹配。
- 若做因子型策略，数据清洗很重要；若做事件型策略，也要关注覆盖广度。
- 数据源选择应按策略目标定制，不存在绝对赢家。

## Caveats
- 数据商结构和覆盖会持续变化，历史结论会漂移。
- 极值剔除规则本身会影响可重复性。
