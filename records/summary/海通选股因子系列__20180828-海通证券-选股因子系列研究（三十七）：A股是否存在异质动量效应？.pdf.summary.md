# 海通证券选股因子系列研究（三十七）：A股是否存在异质动量效应？

- **source filename**: `20180828-海通证券-选股因子系列研究（三十七）：A股是否存在异质动量效应？.pdf`
- **date**: 2018-08-28
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、罗蕾
- **document type**: 金融工程专题报告

## Core question
检验 A 股是否存在剥离市场共同因素后的“异质动量”（残差动量）效应。

## Methods / data
以残差收益构造 IMom 因子，分析全市场、行业内以及不同市场状态下的分组收益和回测表现。

## Key findings
- A 股存在显著异质动量：残差动量越高，次月收益越优，且加入多因子模型后可提升收益/信息比。
- 异质动量在大盘股中更强，行业层面也普遍存在，但强弱差异明显。
- 在“下跌市后转上涨”的情景中，IMom 失效甚至转负；“上涨市后转下跌”时仍较稳健。
- 说明动量并非静态因子，而是强烈依赖市场状态。

## Quant takeaways
- 残差动量是 A 股里值得保留的技术因子之一，但需要做状态识别。
- 市场转折期是动量最容易失效的阶段。

## Caveats
- 因子状态切换快，若不做环境过滤，回撤会很大。

## Keywords
异质动量, 残差动量, 市场状态, 大盘股, 行业内选股
