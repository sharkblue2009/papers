# 情绪交易与对冲基金收益

- **source filename**: `20210714-天风证券-海外文献推荐第186期.pdf`
- **date**: 2021-07-14
- **institution / author**: 天风证券研究所；吴先兴（分析师）；原文作者 Chen Y、Han B、Pan J
- **extraction confidence**: high

## Core question
研究对冲基金对投资者情绪变化的暴露是否能预测未来收益，以及这种关系来自情绪风险溢价还是管理者的择时能力。

## Methods / data
- 使用Lipper TASS中1994—2018年、4073只美股权益对冲基金，剔除新入库前12个月、规模低于500万美元及少于30个收益观测的基金。
- 用Baker-Wurgler情绪变化指数及消费者情绪、FEARS指数衡量情绪；以36个月滚动回归估计情绪beta。
- 按情绪beta十分位构建等权组合，控制Fung-Hsieh七因子、动量、流动性和宏观风险因子，并用Fama-MacBeth及Henriksson-Merton模型检验情绪择时。

## Key findings
- 情绪beta最高组月度超额收益0.58%（t=3.48）、alpha 0.51%（t=2.98）；最低组alpha为-0.08%，高低组alpha差0.59%/月（t=3.55）。
- Fama-MacBeth中，超额收益和alpha对情绪beta系数分别为0.17（t=3.03）和0.14（t=3.31）。
- 高管理能力基金的高低情绪beta收益差0.41%/月、alpha差0.71%/月；约13.82%基金的情绪择时t值超过1.65。

## Quant takeaways
- 可将情绪beta作为基金筛选或风格暴露变量，但需使用滚动估计、幸存者偏差控制和多因子风险中和。
- 结果更支持复杂、动态的情绪交易和择时能力，而非单纯持有情绪beta股票；样本外稳定性与高换手成本仍需验证。
