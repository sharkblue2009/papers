# 报告摘要

- 源文件：20260112-财通证券-红利选股的战略三角：进攻、防守和交易.pdf
- 日期/机构/类型：2026-01-12 / 财通证券 / 金融工程专题报告
- 核心问题：如何在红利资产中构建一个兼具进攻、防守和交易三重属性的选股框架，并提升不同市场环境下的适应性。
- 方法与数据：围绕高股息股票池构建三类互补策略：进攻端用景气趋势因子，防守端用质量稳健因子，交易端用深度学习量价因子；并进一步组合成“红利攻守弈”与“固收+”配置方案。
- 关键结论：红利资产长期具备较低波动和稳定收益特征，不同红利指数相关性较低；进攻端年化超额约 13.4%，防守端年化超额约 12.1%，交易端年化超额约 16.9%；组合后的“红利攻守弈”年化收益 27.3%、超额 14.7%、信息比 1.78。
- 量化要点：红利策略不应只看高股息，还要区分“股息+成长”“股息+质量”“股息+交易”三条路径；组合化比单一红利因子更能适应风格轮动。
- 局限性：历史测算依赖市场风格延续，且一致预期、量价模型与交易成本都会影响实盘效果。
- 关键词：红利策略；战略三角；景气趋势；质量稳健；量价增强；固收+
