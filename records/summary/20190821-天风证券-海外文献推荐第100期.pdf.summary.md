# 便宜不一定好：论高费率共同基金的优越表现

- **source filename**: `20190821-天风证券-海外文献推荐第100期.pdf`
- **date**: 2019-08-21
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
文章重新审视共同基金费率与业绩的关系，指出传统结论可能遗漏盈利能力和投资因子。高费率基金偏好低营业利润率、高投资率股票，若不控制这些暴露，基金经理能力会被低估。

## Methods / data
- 将CRSP无幸存者偏差基金与Thomson Reuters持仓通过MFLINKS连接，样本为1980–2014年美国国内股票基金，最终2463只基金。
- 要求基金至少5年收益历史、至少70%且不超过130%的股票资产比例、至少10只股票和约1500万美元实际资产。
- 按费率十分位比较CAPM、三因子、四因子和Fama-French五因子Alpha，并控制基金规模、年限、换手和基金家族；分析持仓股票的盈利、投资和估值特征。

## Key findings
- 五因子模型下，高费率与低费率基金的费前Alpha差异约年化0.9%，t值约4.0。
- CAPM、三因子和四因子模型下，费率越高的扣费后业绩越差；加入盈利和投资因子后，这种负相关消失。
- 高费率基金偏好低营业利润率、高投资率股票，这些股票在传统模型中产生较大负Alpha。
- 结论认为高费率基金扣费前表现更好，扣费后也不逊于低费率基金，但报告未给出统一的净Alpha数值。

## Quant takeaways
- 基金筛选不可只按费率排序，应控制盈利、投资、规模、风格和持仓差异，再比较净Alpha。
- 费率可能是管理技能或复杂策略的价格，但也可能反映销售渠道、估值难度和生存偏差。
- 研究使用持仓和五年滚动回归，实盘需处理披露滞后、基金合并/清算、交易成本及因子模型不稳定。
