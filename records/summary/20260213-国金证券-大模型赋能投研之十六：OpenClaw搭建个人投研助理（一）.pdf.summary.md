# OpenClaw 搭建个人投研助理（一） 摘要

- **来源文件**：20260213-国金证券-大模型赋能投研之十六：OpenClaw搭建个人投研助理（一）.pdf
- **日期/机构/类型**：2026-02-13，国金证券，金融工程专题/AI Agent 应用报告

## 核心问题
如何部署并使用 OpenClaw，把大模型能力变成可执行的个人投研助理，并在金融投研场景中落地。

## 方法与数据
- 介绍 OpenClaw 的部署方法（WSL2、云服务器等）。
- 演示模型配置、飞书接入、Skills 模块设置。
- 用自动发邮件、网页抓取、投研周报生成等案例验证其工作流能力。

## 关键发现
- OpenClaw 通过纯对话即可串联工具、工作流与定时任务，显著降低使用门槛。
- 对非专业用户也能快速上手，适合投研信息获取、数据整理和自动化执行。
- 主要风险在于信息安全、权限控制和模型幻觉。

## 量化要点
- 报告没有金融资产回测。
- 重点量化指标是工作流自动化能力与使用门槛下降，而非收益表现。

## 局限性
- 结果依赖模型能力与外部工具接口稳定性。
- 金融场景中需要额外控制权限、网络与数据安全。
- 大模型输出具有随机性。

OpenClaw、AI Agent、投研助手、Skills、自动化工作流、飞书、WSL2
