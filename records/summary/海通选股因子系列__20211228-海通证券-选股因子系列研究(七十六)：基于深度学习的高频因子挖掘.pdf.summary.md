# 海通证券选股因子系列研究（七十六）：基于深度学习的高频因子挖掘

- **source filename**: `20211228-海通证券-选股因子系列研究(七十六)：基于深度学习的高频因子挖掘.pdf`
- **date**: 2021-12-28
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 金融工程专题报告

## Core question
当传统逻辑型高频因子逐渐接近可挖掘边界时，能否用深度学习从高频序列中继续挖出新的 alpha。

## Methods / data
使用 **RNN+NN** 框架，从 30 分钟级别高频序列中提取周度因子；对比 **GRU+NN** 与 **LSTM+NN**；检验原始因子与正交因子表现，并将因子纳入中证500增强模型。

## Key findings
- 深度学习高频因子周度选股能力很强：周均 **IC 约 0.08**，胜率 **80%+**，周均多空收益约 **1.5%**。
- 正交后仍然有效：周均 **IC 约 0.07**，胜率进一步升至 **90%** 左右，周均多空收益约 **1.4%**。
- 在 **沪深300** 内单独训练也有效，但强度略弱于全市场训练。
- **LSTM+NN** 并未明显优于 **GRU+NN**，复杂结构不一定带来更好的因子。
- 将该因子加入中证500增强后，模型年化超额可从约 **26%** 提升到 **32%**，最高增加约 **6 个百分点**。

## Quant takeaways
深度学习的作用不是简单替代逻辑因子，而是把高频序列中非线性、时序性的残差信息重新编码成可交易信号。

## Caveats
模型复杂度上升会增加过拟合与训练不稳定风险；收益对样本期和交易成本仍敏感。
