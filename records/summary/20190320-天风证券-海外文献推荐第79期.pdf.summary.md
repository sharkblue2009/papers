# 不确定性、动量和盈利能力

- **source filename**: `20190320-天风证券-海外文献推荐第79期.pdf`
- **date**: 2019-03-20
- **institution / author**: 天风证券研究所；吴先兴；原文作者 Claire Y.C. Liang、Robert ZhangYang Tang、Xiaowei Xu
- **extraction confidence**: high

## Core question
论文用分析师盈利预期误差构造不确定性指标UNC，检验其是否解释价格动量、意外盈利和盈利能力异象，并考察这些策略在不同市场状态下的隐含押注。

## Methods / data
- 使用IBES 1983—2013年分析师FY1 EPS预期，以预测误差方差经价格标准化构造UNC。
- 每月按UNC、价格动量MOM、SUE、OP和ROE分五组，计算等权和市值加权多空收益；以UNC回归控制并做Fama-MacBeth检验。
- 进一步用特质波动率IVOL和分析师分歧DISP替代UNC，并按上涨/下跌市场分组。

## Key findings
- MOM等权/市值加权多空收益1.337%/0.949%，控制UNC后降至0.304%/0.389%，衰减77%/59%且不再显著。
- OP收益0.882%/0.771%，控制后降至0.279%/0.324%；ROE收益1.471%/0.635%，控制后降至0.559%/0.217%，分别衰减约61%—68%。
- UNC解释SUE约45%、ROE约61%的收益；其在下跌市场更强，IVOL可作不完全替代，DISP解释力较弱。

## Quant takeaways
- 动量和盈利因子组合应加入不确定性暴露、下行市场敏感度和分析师覆盖筛选。
- UNC依赖预测数据且可能存在小盘、流动性和覆盖偏差；需做滞后处理、行业中性、费用和容量检验。
