# 核心主题
通过“多期限残差”与改进的低延迟趋势线，优化多期限动量/反转类选股因子，并检验其在不同股票池和 Barra 中性化后的稳健性。

# 方法与数据
- 使用 2010 年至 2024 年 3 月的沪深 A 股数据。
- 以近期截面回归残差均值构造因子。
- 结合改进的低延迟趋势线，形成多期限动量与反转框架。
- 进一步做 Barra 相关因子中性化与稳健性检验。

# 主要结论
- 因子在全市场、创业板、中证500、中证1000 等股票池中都保持较强选股能力。
- Barra 中性化后，因子仍保留较好的分组单调性和风险收益表现。
- 说明残差信息可显著补充传统多期限动量/反转因子。

# 量化要点
- 全市场 Rank IC 均值 -4.14%，胜率 67.92%，多头年化收益 20.13%，Sharpe 0.64；多空年化收益 14.16%，Sharpe 1.33。
- 中证500 多头年化收益 12.49%，Sharpe 0.42。
- Barra 中性化后，全市场 Rank IC 均值 -2.98%，胜率 60.81%，多头年化收益 17.42%。

# 局限性
- 因子参数与调仓频率可能影响结果，仍需做进一步样本外验证。
- 历史统计规律未必能稳定延续。
