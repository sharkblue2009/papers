# 筹码分布中的Alpha：交易行为的非对称性选股

- **source filename**: `长江证券_20160904_筹码分布中的Alpha：交易行为的非对称性选股.pdf`
- **date**: 2016-09-04
- **institution / author**: 长江证券金融工程团队；覃川桃；联系人林志朋、杨靖凤
- **extraction confidence**: high

## Core question
报告详细检验筹码分布形态与股票未来收益的关系，并强调市场整体处于盈利筹码还是亏损筹码状态时，因子方向可能发生切换。最终构造状态条件化的形态综合因子P。

## Methods / data
- 用成交均价和换手率估计筹码分布，计算ARC、VRC、SRC、KRC；全部A股，2007-01—2016-08。
- 月度调仓、十组等权、双边成本0.3%；以MARC>0或<0将样本划为Updata/Lowdata。
- 用过去24个月分别拟合两种状态的“下期收益~四因子”回归，按当期状态外推P，并比较沪深300、中小板、中证500和全市场等权。

## Key findings
- ARC因子最小组年化超额9.2%、IR 1.01，最大组超额-17.7%、IR -1.70；ARC多空年化30.31%。
- Updata中收益与ARC、SRC正相关，与VRC、KRC负相关；Lowdata中ARC、SRC、KRC为负相关，VRC为正相关。
- P首组年化收益40.2%，相对全市场等权年化超额18.7%、月胜率72.2%、IR 1.96；末组超额-17.1%、IR -1.87。
- P首组相对中小板、中证500、沪深300年化超额分别29.41%、24.94%、35.92%；2015年相对指数仍有较大回撤。

## Quant takeaways
- 可将MARC作为市场状态变量，做条件因子、门控模型或regime-switching组合。
- 状态切换需使用滚动窗口和滞后信息，并检验参数稳定性、状态误判与交易成本。
- 因子有一定市值暴露，且历史区间包含特定行情；必须做市值/行业中性和真实容量测试。
