# 媒体报道和投资效率

- **source filename**: `20211223-天风证券-海外文献推荐第204期.pdf`
- **date**: 2021-12-23
- **institution / author**: 天风证券研究所；吴先兴（分析师）；原文作者 Chen、Dong、Jiang、Xu
- **extraction confidence**: high

## Core question
研究媒体曝光如何影响企业投资不足与过度投资，并区分媒体的信息中介、监督、信息传播和CEO过度自信渠道。

## Methods / data
- 使用美国4686家公司、30281个公司年观测，样本期为2001—2018年。
- 以RavenPack媒体报道数量、新闻情绪和新颖性衡量媒体覆盖，以投资不足/过度投资及资本支出、研发、收购衡量投资效率。
- 使用公司固定效应、控制变量及公司总部到最近道琼斯分支距离的工具变量；进一步检验信息不对称、治理和CEO过度自信的调节/中介效应。

## Key findings
- 媒体覆盖减少投资不足，但增加过度投资；由于方向相反，对全样本投资低效率绝对值的净影响不显著。
- 信息不对称较高、公司治理较弱的公司中，媒体对减少投资不足的作用更强。
- 媒体报道会放大CEO过度自信，进而增加过度投资；媒体覆盖还显著提高总投资、资本支出、研发和收购支出。
- 投资相关和非投资相关新闻都能减少投资不足，但非投资新闻显著增加过度投资；重复新闻的传播作用强于突发新闻。

## Quant takeaways
- 新闻覆盖和情绪可作为公司投资效率与资本配置风险信号，但方向取决于信息不对称、治理和管理层行为。
- 可将报道数量、情绪、重复度与财务质量结合做事件或横截面回测；需控制反向因果、媒体选择偏差、行业周期和文本口径变化。
