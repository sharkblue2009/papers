# 债券收益下限与资产配置：债券在资产配置中所扮演的角色将于何时受到危及？

- **source filename**: `20210908-天风证券-海外文献推荐第193期.pdf`
- **date**: 2021-09-08
- **institution / author**: 天风证券研究所；吴先兴（分析师）；原文作者 A. Ilmanen、M. Chaves
- **extraction confidence**: high

## Core question
如果债券收益率存在不可突破的下限，债券未来收益、与风险资产的负相关性以及其在风险平衡组合中的分散化作用何时会被削弱。

## Methods / data
- 建立债券收益率、预期回报和相关性的资本市场假设，分别考察收益率下限对债券回报和组合分散化的影响。
- 将下限设为当前正常水平以下50bp、100bp等情景，并比较传统风险平衡资产配置与无下限基准。
- 重点分析久期、债券预期收益、风险贡献和股票债券相关性变化。

## Key findings
- 只有当债券收益率下限低于当前主流水平约50bp时，债券在资产配置中的收益和分散化角色才会受到实质影响。
- 当下限设为当前正常水平100bp或更低时，传统风险平衡组合表现接近无收益率下限情景。
- 因此，收益率“有下限”本身不是充分条件，关键取决于下限距离当前水平、初始久期和未来利率路径。
- 报告认为2021年初债券收益率上行后，收益率进一步下降100bp的可能性相对上升，但仍依赖宏观状态。

## Quant takeaways
- 资产配置模型应加入收益率下限、久期非线性、通胀和债券股票相关性状态，而非简单把债券预期收益截断。
- 可做50bp/100bp情景压力测试和滚动风险平价回测；需关注再平衡、负利率、信用债与国债差异及模型参数不确定性。
