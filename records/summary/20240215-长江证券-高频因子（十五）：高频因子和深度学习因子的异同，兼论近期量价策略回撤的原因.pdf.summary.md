# 摘要

- **源文件**：20240215-长江证券-高频因子（十五）：高频因子和深度学习因子的异同，兼论近期量价策略回撤的原因.pdf
- **日期 / 机构 / 类型**：2024-02-15｜长江证券｜金融工程深度报告
- **核心主题**：比较高频因子体系与深度学习因子的收益来源，并解释近期量价类策略和深度学习增强策略回撤的原因。
- **方法与数据**：将高频因子体系拆解为波动、非流动性、量价相关性、加权偏度、空头意愿等收益来源，并与深度学习因子进行对照；同时分析沪深 300 / 中证 500 / 中证 1000 增强策略在不同时间窗口的表现与风格暴露。
- **主要结论**：深度学习因子的主要收益来自高频因子体系；近期回撤的关键在于体系内外收益来源衰减，尤其是**非流动性**、**波动**和**空头意愿**相关收益下滑。残差深度学习因子的额外收益近期下降更明显，因此深度学习策略回撤更大。
- **量化要点**：过去一年深度学习增强策略表现一度更好，但近期衰减更大；近期量价策略回撤主要集中在中证 1000，且放开规模暴露后组合普遍对规模因子形成负暴露。
- **局限性**：该分解依赖既有因子定义和样本阶段，市场结构变化可能导致收益来源迁移；历史回撤成因不一定长期成立。
- **关键词**：高频因子、深度学习因子、量价策略、回撤分析、非流动性、空头意愿
