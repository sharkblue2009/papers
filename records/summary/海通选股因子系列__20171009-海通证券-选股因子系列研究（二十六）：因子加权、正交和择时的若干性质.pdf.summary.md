# 海通证券选股因子系列研究（二十六）：因子加权、正交和择时的若干性质

- **source filename**: `20171009-海通证券-选股因子系列研究（二十六）：因子加权、正交和择时的若干性质.pdf`
- **date**: 2017-10-09
- **document type**: 金融工程专题报告

## Core question
因子加权、正交与择时之间有哪些理论等价关系，如何把多因子模型写得更简洁、更易于实现。

## Methods / data
- 推导 **最大化复合因子 IC 加权** 与 **Fama-MacBeth 回归** 的等价性。
- 证明在 Fama-MacBeth 框架中加入正交新因子不改变原模型溢价估计。
- 说明 Qian (2012) 的因子择时模型可等价成“因子溢价对条件变量回归”。

## Key findings
- 在 z-score 假设下，最大化复合因子 IC 加权法可直接用回归替代。
- 正交新因子不会改变原模型溢价估计，因此新因子的边际贡献更容易判断。
- 因子择时模型本质上就是在预测因子溢价，回归表达更直观、实现也更简单。
- 但条件变量过多会带来过拟合风险，实际应用需要约束。

## Quant takeaways
- 这是一篇偏“方法论”的报告：帮助统一多因子、正交和择时的数学视角。
- 实务上可以直接用回归框架实现权重优化和择时。
- 对因子工程而言，理论等价关系能减少重复建模。

## Caveats
- 结论依赖线性与 z-score 等假设。
- 正交解决的是线性共线，不解决非线性关系。
