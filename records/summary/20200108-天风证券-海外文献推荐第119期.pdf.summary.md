# 节假日前的公告效应

- **source filename**: `20200108-天风证券-海外文献推荐第119期.pdf`
- **date**: 2020-01-08
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
论文研究公司在节假日前发布回购、增发、并购和盈余公告时，投资者是否因可预见的情绪上升而产生更积极的价格反应，并检验公告后的反转。

## Methods / data
- 样本覆盖1984-2012年NYSE、AMEX和NASDAQ、股价高于1美元的非金融公司。
- 选择13个美国主要节假日，构造公告日及下一交易日的CAR(0,1)，市场模型估计窗口为(-180,-11)。
- 使用Preholiday虚拟变量，并控制规模、B/M、反转、动量、机构持股、换手、非流动性、特质波动、星期、季节和行业。
- 用NetHappy、Facebook GNH、FEARS及其主成分衡量情绪，并调整事件窗口做稳健性检验。

## Key findings
- 全样本面板OLS中Preholiday系数为0.26，t=3.77；8类公告中有6类呈更正向的假日前效应。
- 分组结果显示，通常正向公告在节假日前正向反应更强，通常负向公告的负向CAR更弱；极端盈余或分红组差异更明显。
- 调整窗口后9个模型中仍有6个Preholiday系数显著。
- 假日前情绪上升、假日后下降，价格反应随后出现反转；摘要称该模式也见于多个国际市场。

## Quant takeaways
- 事件策略可把公告类型、盈余惊喜、节假日和情绪状态交叉分层，并严格按公告可得时间建仓。
- 需控制公告选择偏差、信息含量、交易日窗口和小价格股票流动性。
- 反转与交易成本、假日前流动性和公告拥挤有关，不能把CAR直接等同于可实现收益。
