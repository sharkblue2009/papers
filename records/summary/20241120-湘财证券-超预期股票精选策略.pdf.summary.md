# 研报摘要

- 来源文件：20241120-湘财证券-超预期股票精选策略.pdf
- 日期：2024-11-20
- 机构：湘财证券
- 类型：金融工程 / 量化选股策略

## 核心主题
围绕“超预期”现象构建选股框架，把盈利公告、净利润同比、分析师预期和研报标题等信息转化为选股因子，并在超预期股票池内做增强选股。

## 方法与数据
- 以 SUE（标准化意外收益）为基础，扩展到净利润同比超预期、分析师超预期、研报标题超预期等维度。
- 先在全市场筛选超预期股票池，再用增强因子做二次排序。
- 重点测试 TOP250 与 TOP250-500 的组合表现，并比较多种超预期因子。

## 关键结论
- SUE 因子本身具备一定解释力，但强度一般，IC 约 0.02，ICIR 0.27。
- 超预期信号可用于构建可交易股票池，并形成一定超额收益。
- 在超预期股票池中再叠加量价增强因子，能进一步改善组合表现。
- 报告展示了多空、分层与指数增强的组合回测结果，说明该思路具备实盘研究价值。

## 量化要点
- “预期差”比单纯看历史盈利更有交易价值。
- 事件型因子适合配合股票池过滤和增强排序，而不是单独裸用。
- 对公告、分析师与文本信息做结构化处理是核心。

## 局限性
- 盈利预期数据质量和时效性直接影响因子效果。
- 超预期效应可能受市场风格与信息扩散速度变化影响。
