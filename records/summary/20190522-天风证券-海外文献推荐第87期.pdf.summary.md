# 因子大陆上的爱丽丝梦游：纠缠因子投资的三大谬误

- **source filename**: `20190522-天风证券-海外文献推荐第87期.pdf`
- **date**: 2019-05-22
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
文章反思因子投资为何常常达不到历史回测预期，归纳三类风险：数据挖掘、因子拥挤和交易成本导致溢价衰减；非正态厚尾导致回撤被低估；压力时期因子相关性上升导致分散化失效。

## Methods / data
- 使用美国1963年7月至2018年6月数据，构建市场、价值、规模、盈利、投资、动量、低贝塔及其他流行因子多空组合。
- 按NYSE中位数划分大小盘，再取因子特征最高/最低30%，并将因子波动率标准化至年化10%。
- 比较全样本和2003–2018年近期表现，分析偏度、峰度、动量崩溃及不同Bootstrap假设下的组合最大回撤。

## Key findings
- 近期15年中，6个主流因子有4个接近零或负收益；流行因子组合、次八因子组合和其他33因子组合年化收益分别约2.35%、1.97%和3.78%。
- 在统一10%波动率后，三类组合收益约7.38%、7.28%和10.28%，但不能据此外推未来。
- 动量组合2009年从1.41美元峰值回落44%，单月跌幅24%，属于约8σ事件。
- 主流1–6因子组合最差月约-16%，最大回撤约33%；7–14因子组合出现至少42.9%回撤的估计概率为11.6%。

## Quant takeaways
- 新因子必须记录试验次数、经济逻辑、发表前后衰减、可交易市值和真实成本，不能只看t值。
- 风控应使用厚尾、时变相关和序列相关模型；正态VaR会明显低估因子崩溃。
- 因子仍可使用，但应降低预期、控制拥挤和杠杆，并做危机情景与块Bootstrap检验。
