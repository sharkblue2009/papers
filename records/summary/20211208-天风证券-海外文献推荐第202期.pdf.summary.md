# 目标资产的风险暴露模拟与组合构建

- **source filename**: `20211208-天风证券-海外文献推荐第202期.pdf`
- **date**: 2021-12-08
- **institution / author**: 天风证券研究所；吴先兴、王喆（分析师）；原文作者 Blitz、van Vliet
- **extraction confidence**: high

## Core question
研究如何用流动性强、易交易的资产构建模拟组合，使其匹配目标资产的普适因子暴露，同时尽量消除目标资产的异质风险。

## Methods / data
- 理论上通过带协方差矩阵的约束最小方差优化，使模拟组合对K个因子的暴露与目标资产完全匹配。
- 全球市场实证使用8只代表不同国家和资产类别的ETF，样本为2009年1月30日至2016年12月30日、1995个交易日。
- 从CRSP选取2009—2016年纽约证券交易所1634只股票，以过去300个交易日回归估计暴露，每月末构建组合并观察未来100天。
- 另以投资级公司债ETF LQD和国际房地产ETF RWX测试跨资产模拟。

## Key findings
- 个股模拟组合的残差方差约下降80%，同时因子beta在再平衡后100天内仍能较好匹配目标资产。
- 目标股票与模拟组合在调仓日的因子暴露完全匹配，随持有期延长逐步产生偏离。
- RWX的股票模拟组合通常降低特质方差且暴露匹配较好；LQD模拟组合的特质方差反而更高。
- LQD效果较差主要因其自身已高度分散且与债券代理ETF AGG高度相关，反映代理因子选择的重要性。

## Quant takeaways
- 可用模拟组合拆解主动基金、非流动性资产和组合历史风险来源，并检验真实分散化空间。
- 需滚动估计beta、限制权重和换手，并按资产类别选择代理因子；跨资产模拟不能默认优于同类资产替代。
