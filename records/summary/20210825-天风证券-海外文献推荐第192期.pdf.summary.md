# 小样本下的共同基金筛选

- **source filename**: `20210825-天风证券-海外文献推荐第192期.pdf`
- **date**: 2021-08-25
- **institution / author**: 天风证券研究所；吴先兴（分析师）、韩乾（联系人）；原文作者 Barras、Scaillet、Wermers 等
- **extraction confidence**: high

## Core question
研究基金历史观测较少时，如何区分真正具有管理能力的共同基金与仅因噪声获得高收益的基金，并比较七种基金筛选方法。

## Methods / data
- 先设定主动基金经理能力的连续或近似离散分布，模拟60个月等不同样本长度下的基金收益和筛选结果。
- 比较基准模型、bootstrap、FDR、结构化模型及不同显著性阈值下的筛选表现。
- 使用1481只美国股票型共同基金数据进行实证比较，考察样本规模、基金能力分布和筛选误差。

## Key findings
- 长样本模拟得到的筛选结论不能直接外推到短样本；样本长度变化会显著改变最终组合表现和被识别基金数量。
- 在60个月小样本中，bootstrap和FDR方法相对更能控制噪声筛选与多重检验问题；简单按历史alpha排序容易选中幸运者。
- 连续能力分布与近似离散能力分布、显著性水平变化均会导致方法排名和收益差异。
- 1481只基金的实证结果支持“筛选效果与样本大小直接相关”，而非存在对所有场景都最优的单一规则。

## Quant takeaways
- 基金选拔应使用滚动样本、bootstrap/FDR及样本外验证，并报告筛选后的数量、错误发现率和组合集中度。
- 短历史基金的alpha置信区间很宽；需纳入费用、存活偏差、风格暴露和基金合并/退出，不能把显著性当作持久能力。
