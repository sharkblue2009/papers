# 波动率与共同基金管理者能力

- **source filename**: `20190626-天风证券-海外文献推荐第92期.pdf`
- **date**: 2019-06-26
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
研究共同基金历史收益波动率是否预测未来业绩，以及低波动基金的超额收益是否真代表经理技能。关键是检验加入低波动异象因子、盈利因子和投资因子后，原有Alpha是否仍存在。

## Methods / data
- 使用CRSP无幸存者偏差共同基金数据库，筛选美国主动股票基金；基金至少80%资产投向股票、资产至少2000万美元、成立至少一年。
- 用1998年9月后每日收益计算年度总波动率和特质波动率，并按上一自然年波动率排序，每年初等权持有最低和最高10%基金。
- 用Fama-French/Carhart四因子模型估计Alpha，再加入LVH低波动减高波动因子，或Fama-French五因子中的盈利和投资因子。

## Key findings
- 2000–2013年低波动基金组合年化波动率13.5%、Sharpe约0.49；高波动组合波动率24.4%、Sharpe约0.10。
- 四因子Alpha低波动约每月0.15%，高波动约每月-0.27%，差异约年化5.0%；背景部分报告低、高波动组合Alpha约年化1.8%和-3.2%。
- 基金波动率增加一个标准差，下一年四因子Alpha约降低1%，经济量级明显高于规模、年限和费用等特征。
- 加入LVH，或加入盈利和投资因子后，高低波动基金Alpha在经济和统计上均不再显著。

## Quant takeaways
- 评价基金经理时必须控制低波动、盈利和投资暴露，否则会把因子收益误判为技能。
- 波动率排序可作为风险管理或基金筛选信号，但应处理年度更新、风格漂移、幸存者偏差和不可卖空约束。
- 结果依赖基金样本和因子定义；应在不同市场、费用口径和交易成本下复核。
