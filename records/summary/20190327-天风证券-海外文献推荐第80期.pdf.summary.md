# 回归模型中的过拟合问题

- **source filename**: `20190327-天风证券-海外文献推荐第80期.pdf`
- **date**: 2019-03-27
- **institution / author**: 天风证券研究所；吴先兴；原文作者 Babyak、A. Michael
- **extraction confidence**: high

## Core question
文章说明多元线性回归如何在变量筛选和自由度过高时拟合噪声，并给出提高样本外泛化能力的建模建议，尤其适用于因子和预测变量很多而样本有限的金融研究。

## Methods / data
- 模拟\(N=100\)、真实关系\(y=0.4x\)并重复10,000次，观察估计系数分布。
- 另生成16个互不相关的噪声变量，用其中15个预测第16个，在样本量50、100、150、200下比较R²分布；样本/变量比为3.3、6.6、10、13.3。
- 讨论逐步回归、先单变量显著性筛选再多元回归、调整R²、bootstrap和惩罚似然。

## Key findings
- 噪声变量在样本量相对自由度更小时会产生更高、但虚假的拟合优度；自由度接近样本数时可完美拟合纯噪声。
- 建议每个自变量至少准备10—15个样本；变量相关性高时需要更多样本。
- 文献回顾显示，自动回归筛选得到的最终模型中约30%—70%的变量可能只是噪声。

## Quant takeaways
- 因子研究应预先限定经济假设和变量集合，避免先看显著性再选因子；高度相关因子可合成为主题因子或固定已知权重。
- 应使用时间外样本、调整R²、bootstrap和正则化评估稳定性；金融场景还需加入purged验证、交易成本和多重检验控制。
