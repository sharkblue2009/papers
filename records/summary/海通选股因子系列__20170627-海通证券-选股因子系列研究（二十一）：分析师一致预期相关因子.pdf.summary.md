# 海通证券选股因子系列研究（二十一）：分析师一致预期相关因子

- **source filename**: `20170627-海通证券-选股因子系列研究（二十一）：分析师一致预期相关因子.pdf`
- **date**: 2017-06-27
- **document type**: 金融工程专题报告

## Core question
分析师一致预期因子是否有效，哪些一致预期因子、哪些行业更有效，以及不同数据源下表现是否不同。

## Methods / data
- 使用朝阳永续与 WIND 两套一致预期数据，构造约 20 个相关因子。
- 检验因子覆盖率、IC、逐步筛选结果，以及行业内选股效果。
- 重点比较盈利预测、目标价、PB/PE/PEG 及其环比增长类因子。

## Key findings
- 一致预期因子在全市场普遍有效，绝大多数因子的 IC 显著异于 0。
- 覆盖率上，盈利预测类通常最高，目标价相关因子最低；从行业看，银行、国防军工、非银金融等大盘行业覆盖率更高。
- 逐步筛选后，较有代表性的一致预期因子主要是 **一致预期 PB 环比增长率** 和 **一致预期 PE 环比增长率**。
- 行业内，**PB/PE/PEG 及其环比增长因子**在大部分行业都显著；银行和非银金融中，部分一致预期因子尤其突出。

## Quant takeaways
- 一致预期不是单一因子，而是“数据源质量 + 覆盖率 + 更新频率”的组合问题。
- 行业内做一致预期因子时，金融板块尤其值得重点挖掘。
- 覆盖率与准确率会共同决定因子的可交易性。

## Caveats
- 数据商差异不小，且覆盖与准确度会随时间变化。
- 目标价类因子覆盖率较低，使用时要小心样本选择偏差。
