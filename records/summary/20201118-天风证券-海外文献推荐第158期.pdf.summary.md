# 商品因子投资

- **source filename**: `20201118-天风证券-海外文献推荐第158期.pdf`
- **date**: 2020-11-18
- **institution / author**: 天风证券；吴先兴；原文作者 Sakkas A、Tessaromatis N
- **extraction confidence**: high

## Core question
本文筛选商品市场中具有定价能力的基本面因子，并比较多因子商品组合与常见商品指数的风险收益。研究还检验方差择时和收益预测是否能进一步改善被动因子组合。

## Methods / data
- 使用1970年1月至2018年8月38种商品期货月度数据，覆盖能源、谷物油籽、家畜、金属和软商品。
- 构造等权、基差、动量、基差动量、价值、通胀、对冲压力、波动率等因子组合，允许商品多头并另行分析多空。
- 以Barillas-Shanken、Fama-French和Harvey-Liu方法检验因子定价，并比较方差管理和收益预测策略。

## Key findings
- 综合低基差、高动量、高基差动量、高价值和高对冲压力的多因子组合，1970—2018年Sharpe约0.716；S&P GSCI约0.198，全商品等权约0.377。
- 因子组合年超额收益约10.62%，波动率约14.82%，优于S&P GSCI的3.90%年超额收益和约19.64%波动率。
- 允许商品因子组合多空时Sharpe约1.253。
- 方差择时对单一动量因子改善更明显，对动态多因子商品策略的增量价值较小；价值和对冲压力提供额外定价信息。

## Quant takeaways
- 商品配置可由基差、动量、基差动量、价值和对冲压力构成分散化因子篮子，而非直接复制GSCI。
- 应分别评估只做多、商品多空和方差管理组合，并纳入期货展期、保证金及交易成本。
- 结论依赖38种商品和1970年以来的历史样本；因子拥挤、容量及结构变化需样本外检验。
