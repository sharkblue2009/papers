# 全球化风险溢价

- **source filename**: `20190911-天风证券-海外文献推荐第103期.pdf`
- **date**: 2019-09-11
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
论文研究全球化暴露如何进入资产价格，并以运输成本（SC）刻画美国制造业对国际贸易和外国生产率冲击的敏感度。核心问题是：全球化风险是否形成可交易的横截面溢价，以及其经济来源是什么。

## Methods / data
- 覆盖439个制造业，按行业前一年SC或重量—价格比五分位排序。
- 构建等权行业股票组合及高SC减低SC多空组合，比较超额收益、波动和Sharpe。
- 用Fama-French三因子检验alpha，并按规模、ROA等进一步分组。
- 建立两国、两类行业的贸易与资产价格动态一般均衡模型并校准。

## Key findings
- 行业平均SC约为运费的5.9%，1%分位数0.2%、99%分位数22.7%；极端五分位的SC下一年仍有85%以上概率留在原区间。
- 低SC行业年均回报比高SC行业高7.8%，多空组合Sharpe约42%；按重量—价格比排序时差异约9.8%、Sharpe约43%。
- Fama-French三因子下多空月度alpha约0.79%，折算年化约9.9%；但价值加权差异不显著。
- 低SC相对高SC的溢价在小规模、低ROA公司中更强，模型将其归因于进口竞争淘汰低效率企业的替代风险。

## Quant takeaways
- 可用运输成本、关税或重量—价格比构造全球化暴露因子，并做规模、盈利和价值加权稳健性检验。
- 该溢价高度依赖等权组合与行业排序，价值加权结果较弱，需警惕小盘和行业构成偏差。
- 经济机制提示应同时检验外国生产率冲击、企业现金流和消费效用，而非把收益差异简单解释为市场无效。
