# 投资组合集中度与基金绩效

- **source filename**: `20200610-天风证券-海外文献推荐第139期.pdf`
- **date**: 2020-06-10
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告研究基金经理提高持仓集中度是否意味着拥有更有价值的信息，并能带来更高的风险调整后绩效。集中度提高同时增加特质波动和流动性成本，经理需要权衡alpha收益与风险。

## Methods / data
- 使用无幸存者偏差的CRSP主动美国股票共同基金及Thomson Reuters持仓，覆盖1999—2014年、1875只基金和45,912个季度观测。
- 以持仓权重平方和的HHI衡量集中度，样本均值205、标准差84，并按基准和季度z-score调整。
- 用基金alpha及其t值衡量绩效，控制基金特征、市场状态、机构持有比例和投资者情绪，做替代集中度与因子模型稳健性检验。

## Key findings
- 集中度提高1个标准差后，基金下一期风险调整回报年化增加约24bp；替代绩效模型中下一季度alpha增加约0.03%—0.08%。
- 集中度与绩效的正相关在低机构持有、低投资者情绪及集中成本较高的基金/时期更明显。
- 七种替代绩效模型中，使用alpha的t值时有六种显示显著正相关；结果支持单个经理的集中行为包含信息，但不意味着所有基金都应集中。

## Quant takeaways
- 基金筛选可把HHI变化而非绝对HHI作为主动信息信号，并与主动份额、流动性和规模约束联合使用。
- 需控制基准差异、基金流量、特质波动、换手和幸存者偏差；集中度信号可能伴随容量和冲击成本。
- 研究结果对绩效模型敏感，实盘应同时报告alpha、信息比率、回撤和交易成本。
