# 海外文献-6 Twitter情绪指数能用于预测加密货币走势吗？

- **source filename**: `20211213-银河证券-海外文献~6：Twitter情绪指数能用于预测加密货币走势吗？.pdf`
- **date**: 2021-12-13
- **institution / author**: 中国银河证券；吴俊鹏；原文作者Muhammad Abubakr Naeem等
- **extraction confidence**: high

## Core question
文献检验Twitter整体情绪能否预测主要加密货币收益，并特别关注线性关系无法捕捉的尾部和状态依赖。报告以去除周末、节假日季节性的Twitter Happiness指数作为投资者情绪代理。

## Methods / data
- Twitter Gardenhose随机推文中近10,000个情绪词构造HAP；以周末和节假日虚拟变量OLS残差去季节性。
- CoinMarketCap六种加密货币BTC、ETH、XRP、LTC、XMR、DASH日收盘价；2015-08-07—2019-12-31。
- 线性/非线性Granger因果检验及QQ（quantile-on-quantile）分析，考察情绪和收益不同分位数的依赖。

## Key findings
- 线性Granger因果关系总体不显著；非线性关系对BTC在10%水平显著，对其余五种在1%水平显著。
- QQ分析显示情绪对除DASH外的五种货币有较强预测力，但依赖市场状态和情绪尾部。
- ETH积极情绪与收益多为正相关，LTC方向相反；BTC、XRP存在分位数异质性，DASH仅少数分位数显著。
- 正常市场中预测力更明显，牛市和熊市的整体预测力较弱；未报告统一策略Sharpe或交易收益。

## Quant takeaways
- 测试社交情绪时应优先使用分位数、非线性和状态条件，而非只做线性回归。
- 可将情绪信号与流动性、波动率和市场状态交互，并以滚动样本外预测检验稳定性。
- Twitter样本、情绪词典、加密货币存续期差异和未计交易成本限制了结论，需其他情绪代理交叉验证。
