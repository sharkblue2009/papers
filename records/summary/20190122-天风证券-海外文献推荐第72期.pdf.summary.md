# 独立董事的价值

- **source filename**: `20190122-天风证券-海外文献推荐第72期.pdf`
- **date**: 2019-01-22
- **institution / author**: 天风证券研究所；吴先兴；原文作者 Ronald W. Masulis、Emma Jincheng Zhang
- **extraction confidence**: high

## Core question
论文利用独立董事在其他公司遭遇疾病、并购、危机或管理层变更等外生干扰，识别独立董事注意力下降是否削弱董事会监督、公司经营和并购决策。

## Methods / data
- 样本为2000—2013年S&P1500上市公司，董事信息主要来自BoardEx。
- 若外部干扰在财务年度超过50%时间（疾病/伤病为25%），定义为注意力分散；剔除客户、供应商、银行家等可能内生相关样本。
- 观察董事会缺席、公司股票个人交易、预期外离职，并以ROA和Tobin’s Q检验公司层面结果；按董事专业性、委员会职责和是否指派做异质性分析。

## Key findings
- 每年约21.9%的独立董事被识别为注意力分散，任职期间约每4.5年出现一次。
- 注意力分散使缺席至少25%董事会会议的概率增加1.2%，并显著降低个人股票交易频率。
- 分散董事占比越高，公司ROA和Tobin’s Q越低；非指派、具有并购经验或承担重要监督职责的董事受到干扰时，负面效应更强。

## Quant takeaways
- 董事外部事件可作为治理有效性的准实验变量，用于构造公司治理风险因子。
- 结论是相关性与准实验识别的结合，仍需注意事件定义、董事替换、行业冲击和公司自选择；报告未给出统一的经济效应幅度。
