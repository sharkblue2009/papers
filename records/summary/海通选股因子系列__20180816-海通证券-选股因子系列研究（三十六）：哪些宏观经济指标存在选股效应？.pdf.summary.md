# 海通证券选股因子系列研究（三十六）：哪些宏观经济指标存在选股效应？

- **source filename**: `20180816-海通证券-选股因子系列研究（三十六）：哪些宏观经济指标存在选股效应？.pdf`
- **date**: 2018-08-16
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、吕丽颖
- **document type**: 金融工程专题报告

## Core question
进一步筛选哪些宏观指标在 A 股上真的存在可交易的选股效应。

## Methods / data
以宏观敏感度系数的 T 值来定义高/低敏感股票，测试不同宏观指标在截面上的收益效应。

## Key findings
- 价格类与利率类指标（如 CPI、PPI、利率、期限利差、信用利差、波动率、大宗商品）更容易产生选股效应。
- 国民经济与货币供给类指标披露频率低、关联弱，实证选股效果很弱。
- 更新频率更高的宏观指标，通常更容易表现出正/负向的可交易信号。
- 宏观敏感性在收益预测模型里价值有限，但在风控中更有用。

## Quant takeaways
- 宏观指标不是越“宏大”越有用，频率和可交易性更重要。
- 宏观暴露更适合用于限制组合风险，而非直接押注。

## Caveats
- 敏感性指标的有效性依赖宏观方向判断和样本窗口。
