# 海通证券选股因子系列研究（二十七）：分位数回归在多因子选股中的应用

- **source filename**: `20171018-海通证券-选股因子系列研究（二十七）：分位数回归在多因子选股中的应用.pdf`
- **date**: 2017-10-18
- **document type**: 金融工程专题报告

## Core question
分位数回归能否比均值回归更适合多因子选股，尤其是在存在厚尾、异方差和分布不对称时。

## Methods / data
- 以中证 500 成分股为样本，对 **总市值、前一个月收益率、日均换手率** 做分位数回归与 OLS 对比。
- 分别考察不同分位点（如 0.1、0.5、0.9）下因子对收益分布不同位置的影响。
- 以 QR(0.1) 与 OLS 构造增强组合，比较等权和市值加权结果。

## Key findings
- 三个因子对收益分布不同位置的作用并不一致；均值回归只能看到“平均效果”，分位数回归能看到尾部差异。
- 对前一个月收益率而言，低分位点更能体现反转特征，且 90% 分位点可能出现相反方向。
- 在实际增强组合中，**QR(0.1) 明显优于 OLS**：不论等权还是市值加权，超额收益都更好，且波动和回撤接近，夏普更优。
- 分位数回归没有明显抬高换手率，因此在交易成本假设下较稳健。

## Quant takeaways
- 如果想抓“最有区分力”的那部分股票，分位数回归比 OLS 更合适。
- 低分位点常常比中位数更能代表 alpha 源泉，尤其在小盘/反转环境里。
- 可将分位数回归作为多因子模型的替代预测器。

## Caveats
- 最优分位点依赖样本和目标函数，不能机械照搬。
- 仍然受模型失效和因子失效影响。
