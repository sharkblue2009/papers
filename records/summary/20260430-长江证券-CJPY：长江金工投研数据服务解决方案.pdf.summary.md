# PDF总结

- **来源文件**：`20260430-长江证券-CJPY：长江金工投研数据服务解决方案.pdf`
- **文档类型**：金融工程深度报告 / 投研数据工具
- **核心主题**：介绍基于天软 TS-OPI 开发的 Python 投研数据服务工具 CJPY。
- **方法与数据**：将行情数据、表格数据、因子数据、实时订阅封装为统一 Python 接口；支持日频/分钟级行情、完整表格提取、多证券多日期多指标批量取数、自定义因子扩展，并附带简易组合回测。
- **关键发现**：CJPY主要解决投研“进入分析前”的数据准备问题，可显著降低数据调用门槛，形成从取数到回测的一站式闭环。
- **量化要点**：支持1/5/15/30/60分钟等高频行情；覆盖股票基本信息、股本、股东、机构持股、财务报表、基金持仓等常用表；适合选股、因子研究、组合回测。
- **局限/ caveats**：更偏工具说明而非策略实证，没有核心收益率或 IC 类结论；效果依赖天软数据源与接口稳定性。
- **关键词**：CJPY；天软TS-OPI；投研数据服务；行情数据；因子数据；实时订阅；回测
