# 通过分析因子暴露来获取ESG的Alpha

- **source filename**: `20210501-东兴证券-海外文献速览系列之三：通过分析因子暴露来获取ESG的Alpha.pdf`
- **date**: 2021-05-01
- **institution / author**: 东兴证券；高智威；原文作者 Madhavan、Sobczyk、Ang
- **extraction confidence**: high

## Core question
研究ESG评分与传统风格因子暴露的关系，并区分由因子倾斜解释的“因子ESG”和与风格无关的特质性ESG，判断二者是否对基金Alpha和主动收益有不同贡献。

## Methods / data
- 使用2014年6月30日至2019年6月30日美国主动型共同基金数据，样本为1312只基金、总资产约3.9万亿美元。
- 基于持股数据和因子模型做自下而上的收益归因，将主动收益分解为截面因子暴露、时序暴露变化和个股选择。
- 将ESG评分对传统因子正交化，回归基金Alpha及主动收益；比较E、S、G各分量与价值、质量、动量、规模、最小波动率等因子。

## Key findings
- 高ESG基金通常收益更高，并具有更高质量和反转暴露；环境评分尤其与动量、质量暴露正相关。
- 基金E评分变化的75%可由风格因子解释，而S、G评分的可解释度明显较弱。
- 因子ESG与基金Alpha和主动收益显著正相关；特质性ESG与Alpha或主动收益的关系不显著。

## Quant takeaways
- ESG组合构建应先识别传统风格因子造成的隐含ESG暴露，再决定是直接筛选还是通过因子配置实现目标。
- 持股归因比仅用收益时间序列回归更能识别暴露来源，但ESG评分历史较短、因子模型设定和美国样本限制外推。
