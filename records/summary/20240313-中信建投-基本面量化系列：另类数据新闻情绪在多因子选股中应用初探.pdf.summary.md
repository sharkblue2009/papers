# 报告摘要

- **来源文件**：`20240313-中信建投-基本面量化系列：另类数据新闻情绪在多因子选股中应用初探.pdf`
- **日期/机构/类型**：2024-03-13，中信建投，策略深度报告

## 核心主题
基于新闻数据与 NLP 情绪提取，构建 A 股新闻情绪因子，并进一步做时序拓展，评估其在多因子选股中的应用价值。

## 方法与数据
- 使用 ChinaScope 新闻数据库，覆盖 1000+ 站点、7000+ 版面、1700 个财经微信公众号。
- 通过 NLP 提取新闻标签、情绪值与关注度，构建基准因子 **SENTI** 和 **SENATT**。
- 对 SENATT 进行时序特征抽取，形成 **208 个**时序情绪因子。
- 采用 IC 测试与分层回测评估因子有效性。
- 文中提到测试区间为 **2018-01-01 到 2023-10-31**。

## 关键发现
- 基准因子 **SENTI** 日度 IC 为 **0.0730**，多空组合年化收益率 **30.37%**。
- 基准因子 **SENATT** 日度 IC 为 **0.0613**，多空组合年化收益率 **34.16%**。
- 208 个时序扩展因子中，IC 均值绝对值超过 **0.01** 的有 **24 个**。
- 说明新闻情绪不仅可作为横截面因子，也可通过时序扩展提升信息利用效率。

## 量化要点
- 新闻情绪适合作为事件驱动与另类数据因子的重要补充。
- 关注度与情绪结合后，因子对收益的解释力更强。
- 时序化处理为“情绪因子截面化应用”提供了可复制思路。

## 局限性
- 结果依赖历史新闻样本与 NLP 识别效果。
- 新闻情绪容易受宏观事件、舆情噪声和样本偏差影响。
