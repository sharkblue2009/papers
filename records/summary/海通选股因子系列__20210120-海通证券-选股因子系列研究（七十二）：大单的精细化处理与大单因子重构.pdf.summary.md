# 海通证券选股因子系列研究（七十二）：大单的精细化处理与大单因子重构

- **source filename**: `20210120-海通证券-选股因子系列研究（七十二）：大单的精细化处理与大单因子重构.pdf`
- **date**: 2021-01-20
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 金融工程专题报告

## Core question
如何更合理地界定“逐笔大单”，并据此重构大单因子，以提升其月度选股能力和组合增强效果。

## Methods / data
基于逐笔成交的买卖单号还原买卖单数据，重新定义大单筛选阈值；对比标准差阈值、绝对金额阈值等方案；检验正交前后因子表现，并在沪深300和中证500增强组合中测试。

## Key findings
- 传统按股票自身买卖单分布界定大单仍有改进空间，因买卖单分布偏度明显。
- 改进后的大单净买入相关因子在正交前后都具备显著月度选股能力。
- 因子月均 IC 约在 **0.03~0.05**，年化 ICIR 普遍 **>3.5**，月度胜率 **>80%**，部分因子 **>90%**。
- 大单净买入因子与个股前一个月涨幅正相关，说明其带有一定动量/资金追涨特征。
- 在不同选股空间中都能工作，且在 **沪深300** 内仍然较强；标准差阈值在 **0~1** 区间时较稳健。
- 叠加绝对金额阈值可进一步优化，但不是必要条件。
- 加入大单因子后，**沪深300增强** 的提升更明显。

## Quant takeaways
大单因子更像“大资金足迹”的代理变量；把极端交易与异动噪声处理干净后，信号纯度和稳定性都会更高。

## Caveats
事件异动、样本选择、公告窗口和交易成本都会影响可交易性；阈值设置对结果有一定敏感性。
