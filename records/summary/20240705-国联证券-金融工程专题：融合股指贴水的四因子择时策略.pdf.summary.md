# 核心主题
将宏观状态、中观景气、微观结构风险与股指期货贴水/基差信息结合，构建四因子择时策略，用于宽基指数配置。

# 方法与数据
- 从宏观、中观、微观三个维度分别构建择时信号。
- 宏观中观因子进行分域合成，将市场划分为 8 个运行状态。
- 利用股指期货基差与指数收益的相关性趋势构建日频择时信号。
- 将基差择时信号与三维度信号合成，形成四因子择时框架。

# 主要结论
- 基差信号可补充三维度择时在拐点处反应滞后的问题。
- 合成后的四因子信号在多个宽基指数上都能取得较稳健的超额收益。
- 策略对沪深300、中证500、中证1000、中证全指均有效。

# 量化要点
- 2017 年至 2024-06-21，超额收益分别为：沪深300 73.61%、中证500 69.90%、中证1000 61.61%、中证全指 65.00%。
- 年化超额分别为：9.86%、9.36%、8.25%、8.70%。

# 局限性
- 量化模型存在失效风险，历史回测不代表未来。
- 基差与情绪关系在不同市场阶段可能变化。
