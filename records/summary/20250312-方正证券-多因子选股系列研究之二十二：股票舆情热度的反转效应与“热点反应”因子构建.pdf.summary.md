# 股票舆情热度的反转效应与“热点反应”因子构建—多因子选股系列研究之二十二

- **source filename**: `20250312-方正证券-多因子选股系列研究之二十二：股票舆情热度的反转效应与“热点反应”因子构建.pdf`
- **date**: 2025-03-12
- **institution / author**: 方正证券；曹春晓、陈泽鹏
- **extraction confidence**: high

## Core question
研究股票舆情热度的绝对水平、变化幅度及异常变化是否包含可交易的反转信息，并在“凸显效应”阶段性失效后构建“热点漂移”“热点反转”和综合“热点反应”因子。

## Methods / data
- 使用同花顺高频股票热度与Wind/IFind数据，主要回测2022年至2025年2月28日，周频十分组并计算IC、ICIR、多空收益。
- “热点漂移”取每日热度绝对变化的周均值并标准化；“热点反转”识别热度剧烈变化与同期涨跌方向；两者等权合成“热点反应”。
- 比较全市场、行业、沪深300/中证500/中证1000及剥离常见风格因子后的表现。

## Key findings
- “热点漂移”周度IC 3.70%、年化ICIR 5.53、周胜率78%、多空年化27.3%、IR 3.74，最大回撤-5.55%。
- “热点反转”周频IC 4.54%、年化ICIR 6.14、周胜率80.99%、多空年化19.1%。
- 综合“热点反应”IC均值5.08%、年化ICIR 7.34、周胜率85.21%、多空年化20.05%、IR 2.9；与残差波动率相关性0.27，其余风格约0.1或以下。

## Quant takeaways
- 关注度快速上升可能导致过度定价，热度信号适合与价格反转及风格中性化结合。
- 2024年9月后高热度股票动量更持久，因子阶段性失效；同花顺热度存在实体映射噪声，需做数据清洗和滚动样本外检验。
