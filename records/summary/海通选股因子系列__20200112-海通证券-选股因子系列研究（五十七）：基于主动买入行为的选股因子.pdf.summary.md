# 海通证券选股因子系列研究（五十七）：基于主动买入行为的选股因子

- **source filename**: `20200112-海通证券-选股因子系列研究（五十七）：基于主动买入行为的选股因子.pdf`
- **date**: 2020-01-12
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 金融工程专题报告

## Core question
用逐笔成交数据刻画“主动买入”行为，能否构造出稳定有效的高频选股因子。

## Methods / data
把逐笔成交降频汇总为分钟级的主动买入金额、主动卖出金额，构造主买占比、主买强度及其日内/日间变体，并在正交低频因子后做月度截面回测，考察全市场、沪深300等不同范围和不同调仓频率。

## Key findings
- 主买占比、主买强度类因子在正交后仍有显著选股能力。
- 盘中主买占比因子月均IC约0.03、ICIR约2.51；开盘后净主买强度因子月均IC约0.04、ICIR约3.07，月胜率约80%。
- 日间版本也有效，但整体弱于更细的日内版本。
- 因子与前期涨幅、规模、换手、波动率相关性较高，但与盈利类基本面因子相关性较低。
- 在沪深300内表现更强，说明主动买入行为在大盘股中更能区分收益。

## Quant takeaways
主动买入是高频里最直接、最稳的“资金偏好”信号之一；若把它低频化后再做正交与分组检验，仍能提供可用 alpha。

## Caveats
高频因子对样本期、盘口质量和交易成本较敏感；日内计算要求更高，实际落地时需注意数据清洗与执行成本。
