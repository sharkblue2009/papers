# 长江证券：行业轮动（十二）——分析师篇
- Source file: `20260507-长江证券-行业轮动（十二）：分析师篇.pdf`
- Document type: 证券研究报告 / 金工深度报告

## 核心主题
从分析师预期变化、分析师超预期、分析师驱动三个维度构建行业轮动/ETF轮动因子，并评估其有效性。

## 方法与数据
- 使用 Wind 分析师一致预期明细数据
- 构造分析师超预期、预期增长、驱动（首次覆盖后的量价表现）等因子
- 在行业轮动与 ETF 轮动场景下做分组回测、相关性分析与时序加权合成

## 关键结论
- 分析师超预期因子主要体现为一致预期相对年报增速的变化，效果较稳
- 分析师预期增长因子对 FY12、FY2 预测更有效，但时序稳定性较弱
- 分析师驱动因子以换手维度更有效，收益率维度整体偏弱
- 由于 Beta 维度收益来源有限，简单等权合成提升不明显
- 时序上做信息侧重后，排序等权效果最好
- 排序等权合成因子在回测区间表现最好：行业轮动超额年化收益 12.04%，ETF 轮动 9.49%，信息比 1.06 / 0.92

## 对量化研究的启发
- 分析师预期是行业轮动的重要补充信息源
- Beta 类轮动更适合做时序加权而非静态等权
- 需关注 2022-2023 等弱势阶段的稳定性

## 局限与注意事项
- 模型存在失效风险，且对市场交易行为和主题行情变化敏感
- 历史统计结果不保证未来有效
- 轮动因子在弱市阶段容易出现收益磨损
