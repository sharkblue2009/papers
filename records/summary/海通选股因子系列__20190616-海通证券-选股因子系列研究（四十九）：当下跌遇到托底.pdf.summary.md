# 海通证券选股因子系列研究（四十九）：当下跌遇到托底

- **source filename**: `20190616-海通证券-选股因子系列研究（四十九）：当下跌遇到托底.pdf`
- **date**: 2019-06-16
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 金融工程专题报告

## Core question
把投资者“买入托底意愿”与股价下跌状态结合，构造委托成交相关性因子。

## Methods / data
用净委买变化率序列与高频收益序列相关性构造因子，并在不同时段、正交后、不同指数内和不同换仓频率下测试。

## Key findings
- “股价下跌、净委买上升”的股票未来收益最强；“股价下跌、净委买下降”的股票最弱。
- 因子月度 IC 和 RankIC 均较强，多空收益也显著。
- 因子与市值、换手、估值正相关，与系统波动占比负相关。
- 正交后在沪深300、 中证500 和不同换仓频率下仍有效。

## Quant takeaways
- 托底意愿是一个可交易的行为金融信号。
- “跌而有买”比单纯的价格下跌更重要。

## Caveats
- 与其他高频/低频因子存在相关性，需要正交处理。

## Keywords
托底, 委托成交相关性, 净委买, 高频收益, 行为金融
