# 海通证券选股因子系列研究（三十三）：预期调整类因子的收益特征

- **source filename**: `20180523-海通证券-选股因子系列研究（三十三）：预期调整类因子的收益特征.pdf`
- **date**: 2018-05-23
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、罗蕾
- **document type**: 金融工程专题报告

## Core question
研究一致预期“调整类”因子在不同观察期、预期稳定性与数据可靠性下的收益特征。

## Methods / data
围绕 dROE、dG 等预期变动因子，比较不同观察期、预期稳定性分组、时间序列标准化与不同预测类型下的表现。

## Key findings
- 预期调整类因子与次月收益显著正相关，但观察期并非越长越好：先改善、后衰减。
- 按预期稳定性分组后，因子效果更强；时间序列标准化后，IC、胜率与 IR 更稳定。
- 可靠预测类型（1/2）中，因子显著；类型 3/4 等低可靠数据会明显削弱信号。
- 用 0 值填充缺失或不可靠预测值，反而能获得更稳健的 IC/IR。

## Quant takeaways
- 预期调整因子的关键不是“有没有预期”，而是“预期是否稳定、数据是否可信”。
- 时序标准化能显著提高一致预期因子的可用性。

## Caveats
- 对低质量预测数据高度敏感，样本质量决定有效性上限。

## Keywords
一致预期, 预期调整, dROE, dG, 时间序列标准化, 数据质量
