# PE，成长，利率：对估值的再思考——最聪明的投资回收期

- **source filename**: `20190814-天风证券-海外文献推荐第99期.pdf`
- **date**: 2019-08-14
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
文章认为PE把未来盈利增长和利率变化简化得过度，提出收支平衡时间BET（break-even time），使不同盈利增速、PE和折现率的股票能够在统一的回收期框架下比较，并分析BET对价格的敏感性。

## Methods / data
- 令当前价格等于未来盈利现值，使用盈利增速g、折现率i和PE推导BET；近似公式为BET≈ln(1+rPE)/ln(1+r)，其中r≈g−i。
- 通过给定利率和BET绘制PE—成长权衡，并用案例比较PEG相同但BET不同的股票。
- 用价值、成长指数、利率变化和6个月盈利趋势做回归；全样本及1999–2008、2010–2018分段检验。

## Key findings
- 例示中，PE为21、盈利增速11.3%、利率3%时，BET约12年。
- PEG相同并不代表回收期相同：案例股票的BET可由13.9年升至19.7年，利率从2%升至6%也会显著拉长BET。
- 分段回归中利率系数为负但不显著，未发现稳定的传统“利率上升必然压低股票”久期效应。
- 简单盈利增长指标对成长指数未来收益更稳定地呈正向关系；价值股关系受宏观和行业结构影响。

## Quant takeaways
- 可将BET作为价值/成长比较和估值敏感性因子，避免直接用PEG跨公司排序。
- 需要明确盈利增长、折现率和负盈利处理，并用实时预期而非事后盈利替代。
- BET是估值框架，不自动产生Alpha；实盘应结合行业、利率状态、盈利修正和交易成本检验。
