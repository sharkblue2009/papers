# 规模效应隐藏于日历效应之中

- **source filename**: `20190724-天风证券-海外文献推荐第96期.pdf`
- **date**: 2019-07-24
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
文章重新检验规模效应是否已经消失，并考察小市值股票溢价是否被一月、万圣节、季节、月初、周内和年度周等日历效应掩盖。研究试图解释文献中规模效应衰减和结论不一致的原因。

## Methods / data
- 使用NYSE、AMEX和NASDAQ日、周、月组合收益，样本为1926年7月至2014年8月。
- 以SMB（小盘三组减大盘三组）及最小10%减最大10%组合衡量规模溢价。
- 采用OLS、Newey-West稳健误差和GARCH(1,1)，结合移动窗口、分段样本、等权与市值加权，检验不同日历虚拟变量。

## Key findings
- 规模效应在一月、五月至十月/万圣节、十月、其他一月、季节、月初、周内和年度周效应中仍普遍存在。
- 一月效应近年来幅度衰减，但小盘股相对大盘股的超额收益并未完全消失；不同收益定义、样本段和模型下结论一致。
- 年度第44周中，88个样本年份仅27年小盘股表现为正、61年为负，即正效应30.6%、负效应69.4%。
- 报告指出规模效应衰减很大程度由一月效应衰减带来，但仍可能具有投资指导价值。

## Quant takeaways
- 小盘因子回测应显式建模月度、周内和季节交互，不宜只看全样本平均SMB。
- 必须控制微盘股流动性、交易成本、权重方案、数据挖掘和多重检验；GARCH稳健性不能替代可投资性检验。
- 日历效应随时间变化明显，实盘需要滚动窗口和容量分析，而非固定历史规则。
