# 海通证券选股因子系列研究（八十三）：盈利加速的定量刻画与高增长组合的构建

- **date**: 2022-08-17
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、罗蕾
- **document type**: 金融工程专题报告

## Core question
如何把“盈利增速是否在加速”量化成一个可交易信号，并用于构建高增长股票组合。

## Methods / data
定义**盈利加速因子**，用标准化 EPS 同比变化衡量季度到季度的盈利增速变化；对比三种基准：EAA、EAP、EAV。再将盈利加速与 SUE、预期净利润调整等增长类因子复合，构建高增长、小市值+高增长、大小盘分层高增长以及偏成长风格组合。

## Key findings
- 盈利加速与市值、估值、价量类因子相关性较低，但与增长类因子关系更强。
- 2013-2022.07，原始 EAV 因子 10 组年化多空收益约 **9.7%**、月均 IC 约 **0.02**；正交后仍有约 **4.8%** 的年化多空收益。
- 高增长组合年化收益约 **34.2%**，相对 wind 全 A 年超额约 **25.4%**。
- 加入小市值后，小市值+高增长组合年化收益约 **43.4%**，相对国证2000年超额约 **32.1%**。
- 偏成长风格的小市值+高增长组合，在成长风格强势阶段更占优，但在价值风格回归时会明显回撤。

## Quant takeaways
海通把“增长”进一步拆成了“增速”和“加速”，并证明加速度本身也能形成独立 alpha，适合与 SUE、预期修正等一起做增长复合打分。

## Caveats
增长组合对风格切换敏感，尤其受小盘/成长风格主导；历史高收益并不意味着在价值风格环境下同样成立。
