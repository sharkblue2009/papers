# 劳动杠杆与股票收益的截面效应

- **source filename**: `20181121-天风证券-海外文献推荐第63期.pdf`
- **date**: 2018-11-21
- **institution / author**: 天风证券研究所；吴先兴；原文作者 Donangelo、Gourio、Kehrig 等
- **extraction confidence**: high

## Core question
论文研究劳动报酬在增加值中的比例是否可以作为公司劳动杠杆的代理，并解释股票预期收益的截面差异。核心机制是刚性的人工成本会放大生产率或经济冲击对营业利润的影响。

## Methods / data
- 构造三个劳动报酬比例指标：公开数据的LS、ELS，以及覆盖制造业上市和非上市公司的US Census指标CLS。
- 每年按劳动报酬比例分五组，比较等权和市值加权组合的超额收益，并检验市场、规模、投资、盈利、GDP和TFP等风险因子载荷。
- 进一步使用Q-factor模型检验多空组合的残差收益。

## Key findings
- LS、ELS和CLS相关系数均在0.55以上且高度显著，三种指标的实证结论一致。
- 高低劳动报酬比例组合的等权多空月均超额收益为0.35%—0.53%，折合年化约4.3%—6.5%；市值加权为0.29%—0.43%，约3.5%—5.3%。
- 劳动报酬比例越高，MKT、ME、GDP和TFP载荷越高；LS、ELS等权多空组合在Q-factor回归中的残差显著。

## Quant takeaways
- 可把劳动成本/增加值作为质量或风险暴露因子，检验其与经营杠杆、宏观状态的交互。
- 公开数据指标可作为CLS替代，但行业、制造业覆盖和人工成本估计会造成偏差；应控制规模、行业及交易成本。
