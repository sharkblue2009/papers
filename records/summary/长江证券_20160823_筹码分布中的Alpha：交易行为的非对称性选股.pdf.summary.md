# 筹码分布中的Alpha：交易行为的非对称性选股

- **source filename**: `长江证券_20160823_筹码分布中的Alpha：交易行为的非对称性选股.pdf`
- **date**: 2016-08-23
- **institution / author**: 长江证券金融工程团队；覃川桃
- **extraction confidence**: high

## Core question
报告把前景理论和处置效应转化为筹码分布因子，研究投资者买入成本分布的形状是否能解释股票未来收益。假设盈利筹码更容易卖出、亏损筹码更不愿卖出，从而形成供需和均值回复。

## Methods / data
- 通过成交均价、换手率及调整换手率估计筹码分布，用均值ARC、方差VRC、偏度SRC和峰度KRC刻画形状。
- 全部A股，2007-01—2016-08；月度调仓、十组等权组合、双边交易成本0.3%，剔除停牌和涨跌停。
- 先做单因子分组和Fama-MacBeth回归，再按全市场ARC中位数MARC划分盈利/亏损状态，滚动拟合综合形态因子P。

## Key findings
- ARC最小组年化超额9.2%、月胜率62.1%、IR 1.01；最大组超额-17.7%、胜率31.9%、IR -1.70；多空年化30.31%。
- VRC多空年化约10.71%，SRC约10.31%，KRC约6.01%，KRC单因子单调性较弱。
- 多因子回归中ARC系数-0.47（t=-2.78），KRC系数-0.39（t=-5.57）；ARC、KRC偏反向，SRC有较多增量信息。
- 形态因子P首组年化超额18.7%、月胜率72.2%、IR 1.96；相对沪深300年化超额35.92%。

## Quant takeaways
- 筹码因子可作为反转、拥挤度和行为供需信号，并应按市场整体盈利状态进行条件化。
- 需中性化市值、行业和传统反转因子，检验因子P是否只是小盘或均值回复暴露。
- 结果含较高换手且跨越股灾，样本外、容量、滑点和筹码估计误差是关键风险。
