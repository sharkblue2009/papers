# 文献启示录第2期：通胀预期指标

- **extraction confidence**: high

## Core question
讨论盈亏平衡通胀率（BEI）作为通胀预期代理的偏差来源，并介绍如何用期限结构模型和动态因子模型整合多期限、多来源的通胀预期信息。

## Methods / data
- 依据D’Amico、Kim和Wei的无套利仿射期限结构模型，将名义利率、实际利率、通胀预期及流动性溢价分解。
- 主要使用周度名义国债收益率、周度TIPS收益率、月度季调CPI，并加入调查类通胀预期和3个月国库券收益率。
- 综述官方预测、问卷调查和市场隐含指标，并介绍克利夫兰联储期限结构模型及动态因子综合指标。

## Key findings
- TIPS与名义国债利差并非纯粹通胀预期，还包含通胀风险溢价和TIPS流动性溢价。
- 流动性溢价约解释BEI变动的30%—40%，是历史上BEI波动的核心驱动，尤其影响2001—2004年上行和2008—2009年反转。
- 2020年3月后BEI回升初期主要由流动性溢价推动；2021年2月起通胀预期触及2%、通胀风险溢价转正并走高。

## Quant takeaways
- 使用BEI做宏观择时或资产配置时，应先剥离流动性和风险溢价，不能把利差直接当作通胀预期。
- 多期限、多来源融合有助于降低单一指标噪声，但隐含因子模型存在识别和实时修订风险。
