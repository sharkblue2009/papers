# 哪些选股因子具有行业配置能力？

- **source filename**: `20211229-天风证券-海外文献推荐第205期.pdf`
- **date**: 2021-12-29
- **institution / author**: 天风证券研究所；吴先兴（分析师）；原文作者 Bender、Mohamed、Sun
- **extraction confidence**: high

## Core question
检验价值、质量、动量、低波和规模五类共21个选股因子的收益，究竟来自行业内选股还是跨行业配置，并评估行业中性约束的代价。

## Methods / data
- 使用1994—2018年富时世界发达市场成份股，构建行业内（行业调整）与跨行业因子，并以权重w线性组合观察溢价变化。
- 用Fama-MacBeth横截面回归，控制其他风格因子和地区虚拟变量；每月末构建价值加权五分位组合并再平衡。
- 比较年化收益、波动率、夏普比率和最大回撤，忽略交易成本。

## Key findings
- 价值因子主要获得行业内溢价；行业调整后收益溢价增加0.19%，波动率由10.99%降至8.66%，夏普由0.88升至1.14，最大回撤由-29.24%降至-18.54%。
- 质量因子存在明显行业选择能力，限制跨行业暴露会损失约2.49%年化收益，行业内策略夏普0.94低于未调整的1.16。
- 动量未调整策略收益6.66%，行业内策略4.93%，去除行业配置约损失1.73%年化收益；低波跨行业溢价约0.99%。
- 规模因子主要在行业内定价，行业内溢价4.29%高于未调整的2.35%，最大回撤由-52.55%降至-18.5%。

## Quant takeaways
- 因子组合应按定义判断是否保留行业预算：价值、规模偏行业内，质量和动量的不同定义差异显著，低波兼具两类溢价。
- 行业中性可以降波动和回撤，但可能损失真实行业风险溢价；应纳入交易成本、国家/规模/Beta暴露及容量约束。
