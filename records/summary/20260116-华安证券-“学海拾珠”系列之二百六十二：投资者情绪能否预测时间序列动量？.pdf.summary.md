# 报告摘要

- 源文件：20260116-华安证券-“学海拾珠”系列之二百六十二：投资者情绪能否预测时间序列动量？.pdf
- 日期/机构/类型：2026-01-16 / 华安证券 / 金融工程 / “学海拾珠”系列之二百六十二
- 核心问题：投资者情绪对 A 股时间序列动量究竟是短期正向预测还是长期反向预测，情绪信号是否能作为可交易的择时因子。
- 方法与数据：基于 1997–2013 年月度数据，用 PCA 构建情绪指数（换手率、新开户数、PE 等），再采用偏差校正的预测回归和横截面分析，考察本地情绪与全球情绪对未来收益的多期限影响。
- 关键结论：结论呈现明显期限结构：本地投资者情绪在短期更像动量信号，而在更长期限转为反向预测；情绪冲击对小市值股票更强，全球情绪对长期收益也有负向预测作用。报告摘要还指出，情绪上升 1 个标准差对应的月度市场超额收益提高约 1.50%。
- 量化要点：情绪并非永远的反向指标，期限越短越可能表现为动量；做策略时要区分本地/全球情绪、短期/长期与市值分层。
- 局限性：样本区间较早，结论主要来自历史文献与实证回归，尚需结合新市场结构再验证。
- 关键词：投资者情绪；时间序列动量；PCA情绪指数；预测回归；行为金融；小盘效应
