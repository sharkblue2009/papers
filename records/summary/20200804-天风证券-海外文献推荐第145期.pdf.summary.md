# 预期管理与股票收益率

- **source filename**: `20200804-天风证券-海外文献推荐第145期.pdf`
- **date**: 2020-08-04
- **institution / author**: 天风证券；吴先兴；原文作者 Thomas L. Johnson、Jingjing Kim、Erik C. So
- **extraction confidence**: high

## Core question
本文研究公司是否在盈利公告前主动压低投资者预期，并由此制造公告期“惊喜”，以及这种预期管理如何解释盈利公告溢价和收益季节性。核心指标EMI用于事前刻画企业管理预期的动机。

## Methods / data
- 使用IBES分析师、CRSP月度收益、Compustat财务报表和Thomson Reuters 13F机构持股数据。
- 样本为1985—2015年约320,171个公司季度观测，约850家月度或2,500家季度公告公司。
- 将关注度、业绩压力和盈利信息相关性等变量做百分位排名，再以PCA第一主成分构造EMI；检验公告月、公告前月及季节性组合。

## Key findings
- 公告月高EMI与低EMI公司的等权收益差约64bp（t=4.03），市值加权差约80bp（t=3.49）。
- 高EMI公司公告前一个月收益低约50bp，形成公告前下跌、公告期上升的“V形”。
- 基于同步与非同步收益的季节性策略在高EMI公司中约每月50bp（t=3.17）。
- 高EMI公司更可能出现正盈利惊喜、公告前分析师预测下调和低于实际业绩的指引；内部人也倾向公告前买入、公告后卖出。

## Quant takeaways
- 可用EMI或其关注度、销售增长压力、偿付能力代理变量构造盈利公告事件因子。
- 回测时应严格用上一年公告月份预测本年公告月份，避免公告日期的前视偏差。
- 结果可能受小盘股、分析师覆盖和公告交易成本影响；需要控制规模、动量、波动率及公告风险因子。
