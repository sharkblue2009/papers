# 筹码减少的利与弊

- **source filename**: `兴业证券_20150901_筹码减少的利与弊.pdf`
- **date**: 2015-09-01
- **institution / author**: 兴业证券；唐跃、黄伟平、王涵；研究助理左大勇、李蕙荃
- **extraction confidence**: high

## Core question
报告分析分级A在集中下折后份额快速减少的短期稀缺溢价与中期流动性风险。核心问题是筹码稀缺是否足以抵消规模萎缩、成交集中和后续市场情绪反转的冲击。

## Methods / data
- 研究对象为分级基金A份额，使用Wind的场内份额、成交和价格资料。
- 比较下折前后规模、流通份额、成交集中度及折价套利机会，并结合分级B情绪、债券收益率和股市走势做机制分析。
- 报告为市场点评，未给出统一的可复制回测模型或样本外检验。

## Key findings
- 近期集中下折使分级A规模从超过1,000亿元锐减至不足700亿元，筹码稀缺在短期造成供需失衡并利好存量品种。
- 规模最大的20只分级A约占场内份额80%；本次约54%场内份额卷入下折，历史经验显示下折后份额可能只剩原来的约30%。
- 成交量前20只占市场总成交约80%，规模收缩会冲击成交活跃度并提高大资金参与难度。
- 报告认为部分分级A已明显泡沫化；股市大涨可能令B情绪回暖、股市大跌可能触发下折，均会冲击A份额。

## Quant takeaways
- 可将下折距离、A/B折溢价、份额变化和成交集中度纳入事件驱动与相对价值模型。
- 稀缺性信号必须和流动性、容量、套利冲击及尾部情景联合评估。
- 结论基于2015年点评和结构化产品制度，且未量化交易成本；不应直接外推到现行产品。
