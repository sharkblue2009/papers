# 海通证券选股因子系列研究（六十三）：剔除高频多因子空头组合后的沪深300指数增强策略

- **source filename**: `20200413-海通证券-选股因子系列研究（六十三）：剔除高频多因子空头组合后的沪深300指数增强策略.pdf`
- **date**: 2020-04-13
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、罗蕾
- **document type**: 金融工程专题报告

## Core question
如何把多个高频因子的空头组合合并起来，并用于沪深300增强策略的空头剔除。

## Methods / data
从因子复合和组合复合两条线，构造高频多因子空头组合：zscore加总、回归复合、单因子空头组合复合；再做事前/事后剔除，并以5%等阈值测试增强策略表现。

## Key findings
- 高频因子正交后空头效应更稳定，复合时更建议用正交后的因子。
- zscore复合、回归复合和组合复合都能提升沪深300增强表现，其中ICIR加权的zscore复合剔除在5%阈值下可把年化超额从15%提升到16.7%。
- 回归复合剔除可把年化超额提升到16.3%；组合复合剔除可提升到16.0%。
- 复合剔除普遍优于单因子剔除，且适度控制剔除比例更容易得到稳定增益。

## Quant takeaways
把多个高频因子的“坏票”聚合后统一剔除，往往比逐个因子单打独斗更稳，尤其适合指数增强场景。

## Caveats
阈值和复合方式都较敏感；建议优先在标的指数成分外构建空头组合，以免扭曲基准。
