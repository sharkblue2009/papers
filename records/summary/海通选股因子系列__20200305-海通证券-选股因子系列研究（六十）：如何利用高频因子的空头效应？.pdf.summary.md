# 海通证券选股因子系列研究（六十）：如何利用高频因子的空头效应？

- **source filename**: `20200305-海通证券-选股因子系列研究（六十）：如何利用高频因子的空头效应？.pdf`
- **date**: 2020-03-05
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、罗蕾
- **document type**: 金融工程专题报告

## Core question
当高频因子“多头弱、空头强”时，如何把空头端信息用进指数增强模型，而不是直接丢掉。

## Methods / data
围绕高频因子空头组合，梳理四种利用方式：事前剔除、构建示性变量因子、约束空头组合偏离、事后剔除；并用阈值（如最低5%）定义空头个股，回测其对沪深300增强策略的影响。

## Key findings
- 直接把高频因子空头信息引入模型，通常比完全忽略更划算。
- 事前剔除和示性变量因子最简单有效；约束空头偏离更保守，但收益提升通常最弱。
- 事后剔除收益提升往往最明显，但也最容易带来相对基准偏离和风险抬升。
- 以大单推动涨幅因子为例，最低5%个股定义为空头时，事前剔除可把沪深300增强年化超额从16.5%提到17.5%，示性变量法可提到17.8%。

## Quant takeaways
高频因子不一定适合直接做多头打分，但它们的“坏股票识别”功能常常很值钱；在增强策略里，空头信息本身就是 alpha。

## Caveats
阈值选择会显著影响结果；剔除成分股外空头个股更不容易扭曲基准，但仍需注意流动性与模型误设风险。
