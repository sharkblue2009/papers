## 核心结论
- tfdatatools 是天风金工团队开发的、基于 Wind 数据库的金融数据提取 skill，目标是让用户用自然语言描述需求，由 AI 自动生成 SQL 并返回结果。
- 系统采用六层架构：用户层、路由层、语义层、通用提取层、治理层、缓存与数据层；治理层负责字段、日期和报表类型校验。
- 工具包含十个模块，覆盖原始 SQL、清洗后的量价数据、港股数据、行业分类、ST 状态、时态分类、一致预测、通用提取、智能缓存以及因子与组合回测。
- 报告示例包括跨表筛选股票并提取资金流、多股票时间序列查询、行业分类、行业经营数据、一致预测数据和陆股通名单等，展示了从底层 SQL 到语义化 API 的多种调用方式。

## 方法要点
系统先根据自然语言识别任务，再优先调用 get_prices、get_financials、get_hk_financial_pit 等业务 API，或通过通用接口提取原始表格。量价模块可自动去重、转换日期并透视为“日期×股票代码”宽表；行业模块覆盖中信、申万、中证、国证、长江五种分类及一至三级行业；一致预测模块支持 FY0、FY1、FY2、FY3、FTTM、CAGR 等口径。缓存模块采用内存加磁盘两级缓存，以减少重复查询。

## 结果与局限
报告主要是工具架构与使用示例，并未提供统一的量化绩效评估。其价值在于减少找表、找字段、确认口径和编写 SQL 的重复工作，但使用时仍需注意数据库结构变化、数据口径核对和模型幻觉风险；文中股票仅用于工具演示，不构成投资推荐。
