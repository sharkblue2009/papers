# 20240221-广发证券-深度学习研究报告：基于Visibility Graph~CNN创新架构的高效股价预测模型

- **源文件**：`20240221-广发证券-深度学习研究报告：基于Visibility Graph~CNN创新架构的高效股价预测模型.pdf`
- **日期/机构/类型**：2024-02-21，广发证券，深度学习研究报告/金融工程专题报告

## 核心主题
- 将 **可见性图（Visibility Graph）** 与 **CNN** 结合，构建用于股价预测与选股的深度学习模型。

## 方法与数据
- 使用历史 **价量数据** 构建可见性图，把时间序列映射成 0/1 图结构矩阵。
- 将可见性图输入轻量化 CNN，再预测未来股价上涨概率。
- 以 **20 日** 和 **60 日** 价量窗口分别构建模型。
- 基于未来 **20 个交易日** 的截面涨跌概率进行分层回测，形成多空组合。
- 样本外区间为 **2020-2023**。

## 关键发现
- 可见性图能有效降低数据冗余、减轻过拟合，CNN 在此基础上能进一步提取价量特征。
- 20 日与 60 日模型在全市场及细分板块中均取得较稳定的分档收益。
- 两个窗口的总体表现接近，说明该架构对窗口长度不算特别敏感。

## 量化要点
- **20 日模型**：全市场平均 **RankIC 5.39%**，多头年化收益 **10.35%**，最大回撤 **17.85%**，相对中证全指超额年化 **9.57%**。
- **60 日模型**：全市场平均 **RankIC 5.61%**，多头年化收益 **10.24%**，最大回撤 **19.51%**，相对中证全指超额年化 **9.61%**。
- 分板块看，20 日博得中证500/1000/创业板多头年化收益分别约 **6.41% / 7.56% / 8.79%**；60 日模型分别约 **4.83% / 6.08% / 11.79%**。

## 局限性
- 模型效果依赖历史样本与市场结构，政策与交易环境变化可能导致失效。
- 仅基于价量数据，特征来源相对单一。
- 报告也提示模型之间可能存在差异，需谨慎外推。
