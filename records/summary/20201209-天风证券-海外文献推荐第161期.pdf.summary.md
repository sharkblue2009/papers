# 收益预期是如何形成的？——截面上的趋势外推

- **source filename**: `20201209-天风证券-海外文献推荐第161期.pdf`
- **date**: 2020-12-09
- **institution / author**: 天风证券；吴先兴；原文作者 Zhi Da、Xing Huang、Liu Jin
- **extraction confidence**: high

## Core question
本文利用Forcerank股票排序平台的直接信念数据，研究个体如何形成对个股未来收益的预期。结果显示投资者会把历史收益外推到未来，近期收益权重更高，且这种行为在非专业人士中更明显。

## Methods / data
- 使用Forcerank每周比赛中参与者对未来一周收益的排序，样本覆盖293只股票和多个行业。
- 将一致排序得分回归于过去1—11周收益，并估计指数衰减模型，比较正负收益、专业与非专业用户。
- 检验一致预期对未来收益的预测能力，并按排序得分构造交易策略；同时控制市值、账面市值比、波动率和换手率。

## Key findings
- 过去12周收益的回归系数均显著为正，近期收益系数通常高于远期收益。
- 负向历史收益获得更高权重且衰减更慢；非专业人士趋势外推参数更强，金融专业人士相对较弱。
- 一致预期排序与未来收益负相关，在机构持股低、趋势外推倾向强的股票中更明显。
- 基于参与者排序得分的策略能产生经济意义显著的收益，但可读文本未给出完整年化收益和风险指标。

## Quant takeaways
- 可将散户/平台一致排序作为反向情绪信号，并与历史收益、机构持股和流动性特征交互。
- 指数衰减权重适合描述近期信息过度外推；回测必须避免使用比赛结束后的评分或未来收益。
- Forcerank样本偏向大市值成长股，且参与者构成可能变化；交易成本和平台选择偏差限制外推性。
