# 常见选股因子在行业间的有效性分析

- **source filename**: `20160623-海通证券_金融工程专题报告：常见选股因子在行业间的有效性分析.pdf`
- **date**: 2016-06-23
- **document type**: 金融工程专题报告

## Core question
常见选股因子在全市场与行业内是否同样有效，哪些因子具有稳定的行业穿透力，哪些因子只在特定行业表现突出。

## Methods / data
- 使用两种经典评估框架：**筛选法**（按因子排序看首尾组合）与 **回归法**（横截面线性回归看边际解释力）。
- 对全市场及行业内分别检验：市值、BM、累计收益率、日均换手率、特质波动率等因子。
- 比较行业间因子有效性与回归拟合优度，并做因子相关性/补充性分析。

## Key findings
- **市值效应最稳定**：无论全市场还是行业内，总市值与未来超额收益显著负相关，小市值效应在 TMT 更强，在银行/非银金融较弱。
- **BM 在多数行业不强，但在金融板块有用**：估值因子在全市场和大部分行业不显著，但在银行、非银金融中有效，可作为风格补充。
- **累计收益率、日均换手率、特质波动率** 在全市场和行业内普遍有效，其中前两者在绝大多数行业呈显著负相关。
- 特质波动率在行业内更像“首尾分化因子”，线性关系不一定强，但多空效应仍明显。

## Quant takeaways
- 做行业中性或行业轮动策略时，不能直接把全市场结论平移到行业内。
- 金融行业里估值类因子更有价值，可作为其他行业风格因子的补充。
- 对“多空有效但回归弱”的因子，不应轻易放弃，说明其可能包含非线性或分位数信息。

## Caveats
- 行业内样本数差异大，部分行业回归稳定性有限。
- 未显式加入行业因子时，全市场回归的拟合优度偏低。
