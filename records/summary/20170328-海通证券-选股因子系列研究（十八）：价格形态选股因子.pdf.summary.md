# 海通证券选股因子系列研究（十八）：价格形态选股因子

- **source filename**: `20170328-海通证券-选股因子系列研究（十八）：价格形态选股因子.pdf`
- **date**: 2017-03-28
- **document type**: 金融工程专题报告

## Core question
能否把日内/短期价格形态直接量化成选股因子，并判断其在正交后是否仍具独立 alpha。

## Methods / data
- 构造多类 **价格形态因子**，如开盘冲高、盘低回升、均价偏离等，并比较半个月和一个月两个计算窗口。
- 用分组收益、IC/ICIR、正交处理、Fama-MacBeth 回归和 TOP100 组合回测评估。
- 进一步加入一阶项和二阶项，看非线性是否能提升组合。

## Key findings
- 价格形态因子整体有效，其中 **开盘冲高、盘低回升、均价偏离** 都具有选股能力，半个月窗口通常更强。
- 正交后，部分因子仍保留选股能力，尤其是 **盘低回升** 和 **均价偏离**；开盘冲高在更长窗口下较弱。
- 回归法显示这些因子及其二阶项能提供额外选股信息，说明存在一定 **非线性结构**。
- 加入价格形态因子的改进组合在年化收益、最大回撤、收益回撤比和信息比率上均有提升。

## Quant takeaways
- 价格形态因子适合与传统动量/反转结合，尤其是做短周期信号补充。
- 二阶项值得关注，说明价格形态里可能存在阈值/非线性效应。
- 正交后仍有效的因子更适合进入实盘因子池。

## Caveats
- 不同计算窗口的效果差异明显，参数选择敏感。
- 价格形态因子很容易受样本区间和交易结构影响。
