# 研报摘要

- **来源文件**：20260322-方正证券-专题报告：OpenClaw赋能金融投研应用进阶，多Agent协作、Token优化、Skills应用与开发——AIAgent赋能金融投研应用系列之四.pdf
- **日期/机构/类型**：2026-03-22，方正证券，专题报告
- **核心问题**：当 OpenClaw 使用频率提升后，如何通过多Agent协作、Token 优化和 Skills 开发提升投研效率并降低上下文污染？
- **方法/数据**：围绕多Agent架构设计、上下文拆分、Token 消耗控制、常用 Skills 推荐及两个自定义技能案例（基金新闻搜索、基金月报数据整理）展开；结合实际配置图示说明实施路径。
- **关键结论**：单智能体不适合长链条复杂任务，多Agent 分工更利于专注和稳定；把高频固定流程封装为 Skills 能显著减少重复劳动，是投研自动化的重要方向。
- **量化要点**：报告展示了 token-optimize 技能可节省 Token 的估算和多 Agent 同时处理不同任务的流程；基金月报技能可自动提取久期、收益率、区域分布、评级分布等字段，跨市场适应性较强。
- **局限性**：AI 结论可能幻觉或出错；OpenClaw 权限高、网络风险和本地系统影响风险存在；示例以测试为主，不代表实盘效果。
- **关键词**：OpenClaw、多Agent、Token优化、Skills、投研自动化、基金新闻、基金月报
