# 研报摘要

- **来源文件**：20260317-申万宏源-SmartBeta策略研究系列：成长风格指数，策略差异解构与配置价值.pdf
- **日期/机构/类型**：2026-03-17，申万宏源证券，SmartBeta策略研究系列
- **核心问题**：不同成长风格指数的构造差异、历史业绩分化有多大？成长因子叠加到不同宽基后，哪些场景最有配置价值？
- **方法/数据**：梳理中证、国证、华证三家指数公司发布的 121 只成长指数；对成长因子定义、宽基+成长增强、纯成长/复合成长/行业主题成长等分类进行对比；结合长周期收益、样本内外表现、相关性与风险平价组合回测分析。
- **关键结论**：成长指数内部差异非常大，指数公司对“成长”的定义并不一致；科创板、创业板和小盘风格更适合叠加成长因子；在大盘与中小盘中，部分标准成长/趋势成长/策略成长指数长期表现更优；低相关成长子策略可通过组合化提升稳健性。
- **量化要点**：近五年成长指数年化收益首尾差达 **31.62%**；成长趋势100年化收益 **22.46%**，最差约 **-9.16%**；科创成长在成长占优/劣势环境下年化超额分别为 **5.06% / -2.51%**；小盘+成长占优年化超额 **2.63%**、劣势亏损 **-2.12%**；风险平价成长组合年化收益 **8.14%**，优于中证800成长 **4.93%** 和国证成长 **2.71%**。
- **局限性**：结论主要基于历史样本和指数口径差异，指数发布时间、样本内外划分会影响可比性；市场风格切换后有效性可能下降。
- **关键词**：成长风格、SmartBeta、指数对比、成长增强、风险平价、多策略组合
