# 现金流久期因子

- **source filename**: `20200226-天风证券-海外文献推荐第125期.pdf`
- **date**: 2020-02-26
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告从现金流久期解释价值、盈利、投资、低波和股息等常见因子，考察这些因子溢价是否共同源于公司现金流回收时间的差异。理论上，短久期股票更早获得现金流，承担的短期现金流压力风险溢价更高。

## Methods / data
- 以股利贴现模型刻画久期，使用分析师预期增长率，并以`DUR=1/(r-g)`构造久期因子；缺失预期数据通过因子回归估计。
- 对美国及G7股票按久期分组，比较CAPM alpha，并在不同市值组、常见因子和Factor Zoo异象中进行回归。
- 检验25个文献异象在加入久期因子后的剩余alpha。

## Key findings
- 短久期组合相对长久期组合每月超额收益约0.54%，t值5.74；收益单调性较好，且多空收益并不集中在空头端。
- 高价值、高盈利、低投资、低波和高股息股票普遍表现为较短现金流久期，且该关系在G7市场同样存在。
- 25个异象中，加入久期因子后仅7个仍有未解释alpha，17个异象的alpha不再显著；久期因子显著解释常见五类因子溢价。

## Quant takeaways
- 可用分析师增长预期或稳健的盈利增长代理构造久期排序，检验其对价值、质量和低波因子的共同解释。
- 需关注增长预期缺失填补、贴现率假设及行业/市值暴露，避免把成长风格差异误判为久期溢价。
- 结论来自美国及G7历史样本，交易成本、预期修订速度和中国市场适用性仍需单独验证。
