# 海通证券选股因子系列研究（二十九）：因子降维1：底层因子降维方法对比

- **source filename**: `20171028-海通证券-选股因子系列研究（二十九）：因子降维1：底层因子降维方法对比.pdf`
- **date**: 2017-10-28
- **document type**: 金融工程专题报告

## Core question
当因子池越来越大、相关性越来越高时，底层因子该如何降维，才能既减少冗余又保留 alpha。

## Methods / data
- 提出三种降维思路：**选取类别内最强因子**、**按类别内因子表现加权**、**最大化解释类别内因子波动**。
- 对比降维前后复合因子选股能力、月度多空收益和正交因子 IC。
- 评估不同方法对因子池的信息保留与模型提升效果。

## Key findings
- **选取类别内最强因子**的效果最好，模型复合因子能力和多空收益都明显改善。
- **按类别内因子表现加权**同样有效，能更充分保留多个底层指标的信息。
- **最大化解释类别内因子波动**效果较差，提升有限，甚至可能没有改善。
- 从整体看，若追求最强选股效果，优先选“最强因子”；若想尽量保留信息，可用“加权法”。

## Quant takeaways
- 降维不是越复杂越好，很多时候“选最强”比“做最复杂的解释”更有效。
- 因子池过大时，优先用类别内压缩减少共线和噪音。
- 降维后再做正交和组合优化，会更稳定。

## Caveats
- 不同类别因子之间的信息含量差异很大，方法的可迁移性有限。
- 降维结果受样本期和类别划分影响。
