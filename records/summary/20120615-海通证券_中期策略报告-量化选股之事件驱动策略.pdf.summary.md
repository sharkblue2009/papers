# 海通证券中期策略报告：量化选股之事件驱动策略

- **source filename**: `20120615-海通证券_中期策略报告-量化选股之事件驱动策略.pdf`
- **date**: 2012-06-15
- **institution / author**: 海通证券金融工程团队；页眉可见郑雅斌、周雨卉、张欣慰
- **extraction confidence**: high

## Core question
系统梳理事件驱动型选股机会，按“长期价值型 / 短期信息驱动型 / 市场资金面驱动型”分类，判断哪些事件适合做多、持有多久、如何筛选。

## Methods / data
- 基于 A 股公开事件公告做历史回测。
- 重点比较不同事件的公告后收益路径、最佳持有期与择时退出点。
- 结合沪深300等基准评价超额收益。

## Key findings
- **股权激励**：首次实施公告后买入，持有约 1 年可获得最高约 **20pct** 的相对沪深300超额收益；公告后常有 **1–2 个月蛰伏期**，避开蛰伏期更省资金占用。
- **大股东增持**：公告后不同周期均有机会，**2 周左右超额收益达到峰值**；高管/个人增持、增持比例大的标的更值得关注；1 年持有期更稳定。
- **业绩快报 / 预告**：更适合短线；主板在牛市里“预减”可能是利空出尽，中小板对业绩敏感度更高，**预增**更强。
- **高送转**：关键在于提前布局，公开披露是最理想出货时点。文中 2012 年年报预测案例中，50 只里命中 41 只，命中率 **82%**，持有至送转预案日平均超额 **8.42%**。
- **ETF 停复牌套利**：可借一二级市场套利与融券工具提取绝对收益，核心在于权重与复牌后涨跌幅判断。
- **指数成分股调整**：每年两次、胜率稳定，尤其是沪深300调仓，资金流冲击带来交易型机会。

## Quant takeaways
- 事件策略的核心不是“买消息”，而是**按事件类型匹配持有周期**：长逻辑看股权激励/增持，短逻辑看业绩与高送转。
- 把事件拆成“预期形成—公告落地—价格兑现”三阶段，常可在公告后择机退出。
- 事件策略可作为多因子 alpha 的“热点补充层”。

## Limitations
- 强依赖公告时间与交易可行性，且部分套利受到停牌、涨跌停和券源限制。
- 事件机会具有时效性，历史可复制性受市场环境影响较大。
