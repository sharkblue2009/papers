# PDF摘要
- Source file: `20260202-华源证券-量化择时系列研究之一：基于稀疏自编码器的指数择时模型.pdf`
- 日期 / 机构 / 类型: 2026-02-02，华源证券股份有限公司，金工专题报告
- 核心问题: 基于指数量价数据与稀疏自编码器（SAE）的指数择时模型，能否在宽基指数上实现稳定、可迁移的择时效果？
- 方法/数据: 对时间序列做小波变换降噪，在 SAE 中加入自回归损失和稀疏惩罚；分析训练损失稳定性与不同随机种子相关性，并在中证 500 / 1000 / 2000 / 全指等指数上做样本外测试。
- 主要发现: 训练过程总体平滑稳定，随机种子预测值相关性大多在 70% 以上；在中证 500 和中证 1000 上多空年化收益分别为 43.86% 和 51.21%；只做多策略在中证 500 / 1000 / 2000 / 全指上年化收益分别为 23.30% / 26.00% / 32.56% / 18.83%。
- 量化要点: 信号切换与市场单边/震荡环境相关，适当阈值可显著降低换手并提高稳定性；模型在市值更小的宽基指数上表现更好。
- 局限性: 量化模型基于历史数据，极端市场环境可能冲击模型效果，同时存在一定随机性。
- 关键词: 稀疏自编码器, 指数择时, 小波降噪, 宽基指数, 多空策略
