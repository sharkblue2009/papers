# 海通证券选股因子系列研究（三十二）：因子择时在风险控制模型中的应用

- **source filename**: `20180321-海通证券-选股因子系列研究（三十二）：因子择时在风险控制模型中的应用.pdf`
- **date**: 2018-03-21
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 金融工程专题报告

## Core question
说明因子择时不一定只能通过收益预测实现，也可以通过风险控制模型中的因子敞口管理来实现。

## Methods / data
构建动态风险控制框架，通过设定因子敞口上限/下限、最大损失和投资者风险厌恶度，形成沪深300与中证500风控组合。

## Key findings
- 因子敞口约束会同时影响收益与风险，敞口上限越高，潜在超额收益与回撤通常都更大。
- 用“最大损失”反推因子敞口更直观，也便于投资者按风险偏好设定约束。
- 沪深300 和中证500 风控组合回测都较稳健；在较高风险厌恶度下，模型表现更稳定。
- 这一框架把择时从“预测收益”扩展到“管理暴露”，适合指数增强落地。

## Quant takeaways
- 因子择时可通过风险预算来表达，而不仅是预测信号。
- 实际使用时，更重要的是控制因子对组合风险的边际贡献。

## Caveats
- 组合表现仍会受市场系统性风险、流动性与政策变化影响。
