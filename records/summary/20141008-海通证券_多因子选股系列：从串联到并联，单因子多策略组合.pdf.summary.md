# 海通证券多因子选股系列：从串联到并联——单因子多策略组合

- **source filename**: `20141008-海通证券_多因子选股系列：从串联到并联，单因子多策略组合.pdf`
- **date**: 2014-10-08
- **institution / author**: 海通证券研究所；金融工程核心分析师吴先兴、金融工程分析师张欣慰
- **extraction confidence**: high

## Core question
单因子“极端组合”能否不要被压成一个总分，而是把多个单因子策略并联起来，以提升容量、稳定性和可解释性。

## Methods / data
- 选取历史入选率最高的 5 个因子：**总市值、日均成交额、过去1个月收益率、换手率、估值**。
- 每个因子单独取极端股票，构建 TOP100 与行业中性组合，再把多个单因子策略并联。
- 回测区间覆盖 2008 年以来。

## Key findings
- **总市值**：TOP100 年化超额 **46.40%**，月胜率 **71.60%**；行业中性 **26.93%** / **74.07%**。
- **日均成交额**：**41.54%** / **28.75%**。
- **1个月收益率**：**21.64%** / **17.00%**。
- **换手率**：**14.25%** / **11.89%**。
- **估值**：**11.85%** / **11.53%**。
- 进取组合年化超额 **26.91%**，稳健组合 **19.16%**；微观上 54.6% 的股票跑赢中位数。

## Quant takeaways
- 多因子策略未必一定优于“**单因子多策略并联**”；后者更适合做风格分散和归因。
- 并联方式能提高资金容量，并让每个子策略的 alpha 来源更清晰。
- 对于长期有效、但彼此风格差异大的单因子，组合并联是实用的工程化方案。

## Limitations
- 因子组合依赖历史入选率，未来可能随市场变化而变。
- 某些因子（如估值）单独胜率并不算高，组合效果有赖于搭配。
