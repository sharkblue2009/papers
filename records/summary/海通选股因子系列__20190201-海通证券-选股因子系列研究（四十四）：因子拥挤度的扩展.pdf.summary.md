# 海通证券选股因子系列研究（四十四）：因子拥挤度的扩展

- **date**: 2019-02-01
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 金融工程专题报告

## Core question
继续扩展拥挤度框架，加入资产集中度与机构持仓集中度等新指标。

## Methods / data
用资产集中度、公募基金前十持仓集中度等数据构造拥挤度，并在原始/正交因子集合和不同选股空间下做测试。

## Key findings
- 资产集中度对未来因子收益有一定预测力，但部分因子上会出现正相关。
- 机构持仓集中度在原始因子集合上较弱，但在正交因子上会更有用。
- 大多数拥挤度指标对选股空间变化不太敏感，配对相关性是个例外。
- 说明拥挤度并非单一维度，资金、持仓和资产集中都能提供线索。

## Quant takeaways
- 拥挤度监控框架可以从交易、持仓和资产三个层面扩展。
- 原始因子集合中的信号，常常会被共性暴露掩盖。

## Caveats
- 部分指标方向不稳定，不能简单视为统一的“好/坏”信号。
