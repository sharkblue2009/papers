# 基金持仓重叠分析Skill工具

- 系列：AI投研（四）

- 主题：risk, portfolio, and asset allocation、financial machine learning methodology

## 核心结论
- 报告构建基金持仓重叠分析Skill，名称为cj-portfolio-overlap，面向两只及以上基金组合，输入基金代码或名称，分析日、FOF权重和ETF目标映射为可选参数。
- 工具基于所有基金可获得的统一共同报告期，计算两两持仓重叠、共同证券、多种口径集中度、近两年收益相关性及风险收益特征。
- 一次运行产出HTML交互报告、Excel数据底稿、PDF可读报告和log运行日志四个文件，运行时间因LLM、电脑配置和Agent平台不同约为1—10分钟。
- 一季报和三季报只分析前十大持仓；中报和年报只有在所有基金均有第11名及以后持仓时才开放全部持仓范围。
- 风险收益区间覆盖近1月、3月、6月、1年、3年、5年、今年以来和成立以来，并展示实际值与年化值，计算最大回撤、正收益周占比、Sharpe、Calmar和Sortino。

## 方法要点
工具先保留不晚于分析日披露的持仓记录，再选择所有基金共同可用的最新报告期；同时分层处理持仓结构和净值行为，计算集中度、共同持有证券及近两年周收益相关性，最终生成可回溯的多格式产物。

## 结果与局限
该工具解决逐只查看基金持仓难以快速比较的问题，但报告没有提供实际组合的绩效或预测准确率，演示中的基金和证券名称、代码均为虚构。结果可能受数据接口和运行环境、持仓披露口径与样本、智能体调用及结果解释影响，不能将工具输出直接视为投资建议。
