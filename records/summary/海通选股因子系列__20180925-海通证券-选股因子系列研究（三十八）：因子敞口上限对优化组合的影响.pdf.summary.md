# 海通证券选股因子系列研究（三十八）：因子敞口上限对优化组合的影响

- **source filename**: `20180925-海通证券-选股因子系列研究（三十八）：因子敞口上限对优化组合的影响.pdf`
- **date**: 2018-09-25
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、罗蕾
- **document type**: 金融工程专题报告

## Core question
研究风险控制模型里因子敞口上限如何影响优化组合的收益、回撤和跟踪误差。

## Methods / data
在沪深300 与中证500 风险控制组合中改变因子敞口上限，并比较不同有效因子数量下的实际暴露与收益表现。

## Key findings
- 上限越大，组合超额收益通常越高，但回撤和跟踪误差也更大。
- 最终组合真正重要的是“实际暴露”，不一定等于预设上限。
- 沪深300 因行业/市值集中，增加上限对实际暴露提升有限；中证500 受约束较小，收益增幅更明显。
- 滚动用历史实际暴露来设定下一期上限，更灵活也更合理。

## Quant takeaways
- 敞口上限是风险预算工具，不是收益本身。
- 指数结构差异会决定同样的约束在不同标的上的有效性。

## Caveats
- 若有效因子很多，每个因子的边际贡献会被摊薄。

## Keywords
因子敞口, 风险控制, 超额收益, 跟踪误差, 实际暴露
