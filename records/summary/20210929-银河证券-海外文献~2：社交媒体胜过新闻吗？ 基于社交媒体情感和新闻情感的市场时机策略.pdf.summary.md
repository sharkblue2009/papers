# 社交媒体胜过新闻吗？基于社交媒体情感和新闻情感的市场时机策略

- **source filename**: `20210929-银河证券-海外文献~2：社交媒体胜过新闻吗？ 基于社交媒体情感和新闻情感的市场时机策略.pdf`
- **date**: 2021-09-29
- **institution / author**: 中国银河证券；吴俊鹏；原文基于Stan Beckers等研究
- **extraction confidence**: high

## Core question
比较新闻和社交媒体情感信号的投资相关性，判断社交媒体是否提供超越新闻的增量信息，并以全球股票市场月度择时策略检验其可交易性。

## Methods / data
- 使用Thomson Reuters MarketPsych TRMI，覆盖1998年3月至2017年12月月度数据；新闻来自2000多个出版物，社交媒体来自700多个论坛、推文、博客等。
- 构建新闻/社交媒体的情绪、股票基本面和政治风险六类指标，按月计算同比变化，并与下月MSCI World收益相关。
- 当指标变化绝对值超过10%时，下月配置130%或70%市场多头；比较单一信号、等权组合及不同子时期信息比率。

## Key findings
- 六个指标第一主成分解释42%的相关结构，说明新闻和社交媒体信息高度重叠。
- 新闻股票基本面信号最稳定；社交媒体信号通常被对应新闻信号主导，加入社交媒体一般不能改善新闻策略。
- 新闻股票基本面择时策略自2009年1月后累计表现超过42%，2008年下半年曾出现约-15%回撤；样本期内32个月跑赢、20个月跑输、56个月中性。

## Quant takeaways
- 在月度全球择时中，新闻基本面情绪可作为优先信号，社交媒体更适合寻找个股或短周期增量。
- 需要处理TRMI覆盖变化、阈值和杠杆设定；相关性和累计收益不等于扣除成本后的稳健Alpha。
