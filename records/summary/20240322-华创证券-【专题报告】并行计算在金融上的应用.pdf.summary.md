## 核心主题
介绍 CPU、GPU 并行计算及其在金融投研中的加速应用。

## 方法与数据
- 从 Flynn 分类、CPU 多核并行、GPU/CUDA 并行、PyCUDA、RAPIDS、Numba 等角度展开。
- 通过数据合并、分组统计、用户自定义函数等典型 DataFrame 任务比较 CPU 与 GPU 效率。
- 讨论多进程、多线程与硬件性能要素对效率的影响。

## 主要发现
- 并行计算可显著缩短金融数据处理时间。
- 任务规模越大，GPU 的优势越明显；小数据量场景下 CPU 更合适。
- 不同硬件、不同任务类型需要选用不同加速方案。

## 量化要点
- 合理使用并行计算，特定任务计算时间可缩短 80% 以上。
- GPU 对部分任务的加速可超过 90%。
- 数据量小于 100000 时更适合 CPU；超过 1000000 时更适合 GPU。

## 局限性
- 加速效果依赖硬件配置、驱动版本和任务结构。
- 数据拷贝和调度开销会削弱 GPU 在小任务上的优势。
