# 短期的Beta 还是长期的Alpha？

- **source filename**: `20190116-天风证券-海外文献推荐第71期.pdf`
- **date**: 2019-01-16
- **institution / author**: 天风证券研究所；吴先兴；原文作者 Avraham Kamara、Robert Korajczyk、Xiaoxia Lou、Ronnie Sadka
- **extraction confidence**: high

## Core question
论文研究系统性风险的定义是否依赖投资者持有区间。相同因子在短期投资者眼中可能是风险溢价，在长期投资者眼中则可能表现为alpha。

## Methods / data
- 使用CRSP全市场股票、Ken French的MKT/SMB/HML/UMD及Pastor-Stambaugh流动性因子，样本为1965年1月至2015年12月。
- 以1—61个月收益区间估计beta和风险溢价，重点比较市场、规模、价值/成长、动量和流动性因子。
- 用5因子模型在不同投资区间计算Jensen alpha，并按机构换手率倒数构造短、中、长区间投资者的持仓暴露。

## Key findings
- MKT月度风险溢价年化约0.17%且不显著，6个月和12个月区间升至3.8%和4.8%并显著。
- HML在24和36个月区间的收益约4.4%和4.9%；流动性风险在3—6个月短区间显著定价。
- 流动性beta组合alpha从短期q=1的2.2%升至q=36的8.6%，t=3.1；价值/成长beta组合在q=1和3分别约3.6%和3.3%。

## Quant takeaways
- 因子回测应同时报告形成/持有区间，避免把期限错配产生的alpha误当作普遍能力。
- 机构持仓可用于检验风险承担者，但换手率、流动性因子及区间重叠都会引入测量误差。
