# PDF摘要
- 源文件：20241113-海通证券-宽松环境下大类板块的演绎与轮动.pdf
- 日期：2024-11-13
- 机构：海通证券研究所
- 类型：证券研究报告 / 金融工程专题
- 核心主题：复盘历史宽松周期前后大类行业板块的演绎路径，判断宽松环境下的行业轮动规律。
- 方法/数据：以2007-2021年多轮政策宽松窗口为样本，比较宽松前后各大类板块的收益、波动、胜率、夏普和相对Wind全A的超额表现，并做月度累积收益与阶段性排序分析。
- 关键发现：宽松周期内大类板块整体表现显著优于其他时期，先进制造、消费、医药、TMT等板块在宽松阶段的收益更强；宽松后首月金融地产往往更早反应，随后更偏向成长和制造链条，6个月左右多数板块的累积收益趋于转正。
- 量化要点：样本中宽松时期先进制造年化收益约29.21%，消费约43.00%，医药约42.09%，TMT约41.64%，金融地产约36.66%；2008-2009年宽松区间里，医药板块夏普最高（约2.59），先进制造与医药相对Wind全A的超额更明显。
- 局限性：结论基于历史政策窗口回溯，存在样本有限、阶段划分主观和市场环境变化导致规律失效的风险。
- 关键词：宽松周期；大类板块；行业轮动；超额收益；夏普比；政策宽松
