# 海通证券选股因子系列研究（十五）：“博彩型”股票的预期收益

- **source filename**: `20160928-海通证券_选股因子系列研究（十五）：“博彩型”股票的预期收益.pdf`
- **date**: 2016-09-28
- **document type**: 金融工程专题报告

## Core question
过去一个月出现过极端单日大涨的“博彩型”股票，后续收益是否更差，且这一现象能否转化成选股因子。

## Methods / data
- 以 **过去一个月最大单日涨幅** 对股票排序分组，将最高组定义为“博彩型”股票。
- 检验等权与流通市值加权下，次月收益、分组单调性、多空收益和因子 alpha。
- 进一步做双变量排序，控制反转等常见因子，观察交叉效应。

## Key findings
- “博彩型”股票在次月平均收益最低，说明极端单日大涨后常有 **获利了结/过度乐观回吐**。
- 最大单日涨幅作为因子也有效：次月收益与该因子负相关，首尾组合收益差显著。
- 以该因子构建多空组合，年化收益约 **18.49%**，月胜率约 **65.19%**，夏普约 **1.11**，三因子/四因子 alpha 也显著。
- 控制反转后，该因子效果仍在，说明它包含的不只是简单反转信息。

## Quant takeaways
- “极端涨幅”可作为行为金融型信号，适合做短中期反转/情绪过热过滤器。
- 双变量排序很重要：它能检验一个新因子是否只是旧因子的影子。
- 该类因子适合与反转、情绪或波动率因子组合。

## Caveats
- 极端行情驱动的因子容易受市场风格变化影响。
- 主要是历史统计关系，样本外稳定性与交易成本仍需验证。
