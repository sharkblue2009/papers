# A-H 溢价：揭示A股的低定价效率问题

- **source filename**: `20210804-天风证券-海外文献推荐第189期.pdf`
- **date**: 2021-08-04
- **institution / author**: 天风证券研究所；吴先兴（分析师）；原文作者 Liu、Shao、Wang 等
- **extraction confidence**: high

## Core question
研究同时在A股和H股上市的公司为何长期存在A股相对H股溢价，并判断该溢价是由共同定价因素还是A股市场特有的定价低效率造成。

## Methods / data
- 使用2001—2020年A/H双重上市股票及市场交易、基本面数据，构建A-H溢价的普遍均衡与特有均衡两个成分。
- 按两类均衡分位数组合，检验投资者偏好、预测收益能力及与规模、价值等因子的关系。
- 构建基于A-H溢价的多空和只做多组合，并用Fama-French模型解释收益。

## Key findings
- A股价格通常高于H股，溢价在时间序列和横截面均持续存在；A-H溢价主要来自A股定价低效率，而非H股定价偏低。
- 基于普遍均衡和特有均衡构建的多空组合年化收益分别为28.0%和27.1%。
- 只做多增强组合相对基准的超额收益约为3.20%和1.88%（文本摘要所列），显示该信号不仅能做空对冲，也可用于A股选股。
- 结果与A股散户占比较高、投资者偏好差异及有限套利约束相一致。

## Quant takeaways
- 可把A-H价差拆成共同定价与特有偏离，测试其作为中国股票横截面收益信号的持久性。
- 需控制汇率、交易时段、流动性、涨跌停、融券可得性和跨市场交易成本；样本集中于双重上市公司，外推至全A股需谨慎。
