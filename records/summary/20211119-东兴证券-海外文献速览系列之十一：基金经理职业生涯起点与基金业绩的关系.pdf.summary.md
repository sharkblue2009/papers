# 基金经理职业生涯起点与基金业绩的关系

- **source filename**: `20211119-东兴证券-海外文献速览系列之十一：基金经理职业生涯起点与基金业绩的关系.pdf`
- **date**: 2021-11-19
- **institution / author**: 东兴证券；高智威；原文作者Jie Chen、Meziane Lasfer、Wei Song、Si Zhou
- **extraction confidence**: high

## Core question
文献研究基金经理进入劳动力市场时所处的经济周期，是否会形成持续的投资风格和业绩差异。重点比较在NBER衰退年份开始职业生涯的“衰退基金经理”与其他经理。

## Methods / data
- 美国主动管理股票共同基金，CRSP、Thomson持仓、Morningstar经理履历数据；1990—2016年，1,418只基金、960名经理。
- 以本科毕业年份匹配NBER衰退年份定义处理组；用两年滚动CAPM、Fama-French三因子和Carhart四因子alpha衡量业绩。
- 基金/年份固定效应、经理和基金控制变量；进一步检验衰退状态下择时、现金及防御性行业配置。

## Key findings
- “衰退基金经理”风险调整年化回报较高：CAPM高225bp，FF3高246bp，Carhart四因子高244bp。
- 交互项显示该优势在实际经济衰退期更强；经理更擅长衰退期市场择时，但没有繁荣期选股优势。
- 衰退经理管理的基金持有更多现金、增持防御性行业、降低周期性行业权重，并在衰退前提前调整。
- 2008—2009危机期间，相对2004年一季度基准，其防御性股票持仓增幅约为非衰退经理的5倍；公司类型渠道解释了部分群体效应。

## Quant takeaways
- 可把经理职业起点的宏观状态作为基金筛选或状态切换变量，结合持仓和择时能力分解。
- 需要控制经理教育、CFA、基金公司、风格、规模和生存偏差，并用经理更替事件做验证。
- 结果可能混入第一份工作分配和不可观测能力，且美国历史周期样本的外推性有限。
