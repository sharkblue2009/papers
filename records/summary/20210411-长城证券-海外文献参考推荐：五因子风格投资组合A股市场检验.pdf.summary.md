# 五因子风格投资组合A股市场检验

- **source filename**: `20210411-长城证券-海外文献参考推荐：五因子风格投资组合A股市场检验.pdf`
- **date**: 2021-04-11
- **institution / author**: 长城证券；于鹏；依据Israel、Jiang、Ross的研究
- **extraction confidence**: high

## Core question
将文献中的多因子风格投资组合方法迁移到A股，检验以盈利、预期盈利、估值和现金流指标构建的多空组合在不同持有期下是否存在稳定超额收益。

## Methods / data
- 股票池为中证800成分股；因子包括每股收益、未来12个月一致预期每股收益、市净率、经营现金流和市盈率。
- 按综合评分做多前33%、做空后33%，以流通市值配置组合权重；根据三季报和一季报每半年调仓。
- 回测2015年11月1日至2021年4月1日，比较半年、一年、三年和五年以上持有期与中证800基准。

## Key findings
- 半年持有期绝对和相对收益无明显优势；一年持有期绝对收益改善，夏普均超过0，但单期相对收益仍不稳定。
- 三年持有期波动率基本约14%，每期均取得超额收益，信息比率均高于0.8；绝对收益夏普最低0.45、最高1.46。
- 五年以上持有期仍优于中证800，绝对收益为正，夏普接近1，但相较三年未见明显提升。

## Quant takeaways
- 多因子综合评分和较长持有期可能比短期择时更适合A股风格溢价；可作为多空基金或融资融券的研究起点。
- 样本为滚动且起始较晚，三年、五年样本数量有限；33%阈值、半年调仓和市值权重需做敏感性分析。
