# 如何更好地复制对冲基金的业绩

- **source filename**: `20190529-天风证券-海外文献推荐第88期.pdf`
- **date**: 2019-05-29
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告研究如何用高流动性资产复制对冲基金收益。传统OLS在因子高度相关、样本较短和基金暴露时变时容易过拟合，文章改用岭回归并在时间序列上动态选择惩罚系数。

## Methods / data
- 先以线性规划说明如何构造目标因子暴露，再介绍Sharpe的RBSA收益风格分析。
- 岭回归在OLS损失函数中加入二次惩罚项，四个复制因子为MSCI美国价值、MSCI美国动量、Bloomberg高收益和ICE核心国债指数。
- 样本覆盖2006年1月至2018年12月；测试并购套利、可转债套利、股票多空、全球宏观、市场中性及标普500期权策略。
- 分别采用12个月窗口预测下月、36个月窗口预测未来12个月，并以SSE比较岭回归与OLS。

## Key findings
- 复制资产间存在明显多重共线性，OLS系数可能不稳定，岭回归可通过收缩降低方差。
- 两种战术/战略视角下，岭回归SSE基本都低于OLS。
- 报告定义的SSE胜率为岭回归SSE低于OLS的窗口比例，图示显示其“显著更高”，但未提供具体比例数值。
- 动态选择惩罚系数比固定参数更能适应基金暴露变化。

## Quant takeaways
- 复制策略应在滚动窗口内调参，并以严格样本外SSE、相关性和换手成本评价，而不是只看样本内R²。
- 岭回归适合处理相关因子，但收缩会牺牲无偏性；可进一步比较Elastic Net、稀疏约束和稳定性选择。
- 复制结果受因子池、空头/杠杆限制、基金非线性收益和流动性影响，不能等同于真实基金持仓。
