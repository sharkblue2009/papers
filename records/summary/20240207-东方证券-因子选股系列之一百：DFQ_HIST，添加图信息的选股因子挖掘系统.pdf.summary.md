# 摘要

- **源文件**：20240207-东方证券-因子选股系列之一百：DFQ_HIST，添加图信息的选股因子挖掘系统.pdf
- **日期 / 机构 / 类型**：2024-02-07｜东方证券｜金融工程专题报告
- **核心主题**：在 HIST 图神经网络选股框架上加入图信息、时序特征与双重残差结构，构建更强的因子挖掘系统 DFQ-HIST。
- **方法与数据**：模型融合基础特征与 alpha 因子，多输入、多标签（未来 5/10/20 日收益率）、时序特征提取、预定义概念与隐藏概念挖掘、注意力融合以及双重残差学习；在全市场和沪深 300 / 中证 500 / 中证 1000 增强组合上做回测。
- **主要结论**：引入图信息和概念信息后，模型选股能力明显增强；多输入、多标签、时序提取、概念修正、隐藏概念挖掘和双残差结构都对效果有帮助。HIST 在图模型比较中总体最强。
- **量化要点**：测试集（2020–2023）上 rankIC 约 **17%**，rankICIR **1.34**（未年化），20 分组多头年化超额 **29.31%**，月均单边换手约 **73%**；沪深 300 / 中证 500 / 中证 1000 增强组合年化信息比分别约 **2.27 / 2.09 / 3.6**，其中中证 1000 年化对冲收益约 **25.55%**、最大回撤仅 **4.55%**。
- **局限性**：模型较复杂、换手较高，对极端市场和过拟合更敏感；历史训练结果不保证未来继续保持。
- **关键词**：图神经网络、HIST、因子挖掘、深度学习选股、概念图、增强组合
