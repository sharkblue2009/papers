# 先锋核心+卫星策略指引

- **source filename**: `20200701-天风证券-海外文献推荐第141期.pdf`
- **date**: 2020-07-01
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告介绍以低成本、分散化的指数基金作为核心资产，再用主动基金或其他工具作为卫星的组合框架，讨论其相对纯主动管理的成本、税收和管理人风险优势。

## Methods / data
- 以资产配置、核心/卫星比例、基金筛选和再平衡构建组合；核心通常追踪市场beta，卫星承担有限的主动风险。
- 引用Brinson、Hood和Beebower研究，指出资产配置约决定94%的组合波动，择时和个股选择约占6%。
- 讨论澳大利亚指数基金的税收、换手和主动基金持续跑赢指数的难度，并给出先锋四类风险目标组合示例。

## Key findings
- Vanguard Australian Shares Index Fund在2016年前三年平均年换手率不足1%，体现指数核心的低交易和税收优势。
- 2000年澳大利亚排名前四的股票经理当年明显跑赢S&P/ASX 200（指数上涨6.4%），但到2010年四者均落后指数。
- 在成本和税收计入后，主动管理是相对零和博弈；核心+卫星可降低基金筛选风险、提高分散度并控制费用。

## Quant takeaways
- 组合设计应先确定投资者风险承受力和大类资产配置，再决定核心/卫星比例，而不是先挑主动基金。
- 卫星基金应考察主动暴露、费用、换手、税后收益及与核心资产的相关性。
- 这是投资框架指南而非可复制的超额收益回测；94%结论来自特定研究设计，不能直接当作所有组合的因果比例。
