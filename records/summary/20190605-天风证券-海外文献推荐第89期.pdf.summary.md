# 盈利、留存收益、账面市值比在股票横截面收益中的作用

- **source filename**: `20190605-天风证券-海外文献推荐第89期.pdf`
- **date**: 2019-06-05
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
文章拆解账面价值，检验账面市值比（B/M）的收益预测能力究竟来自留存收益还是投入资本。核心假设是留存收益包含企业过去盈利的累积和平均信息，比单年盈利更能代表潜在盈利能力。

## Methods / data
- 样本为1964–2017年美国上市普通股，收益和股息来自CRSP，年度会计数据来自Compustat，剔除金融公司。
- 将权益账面价值分为投入资本、留存收益和累计其他综合收益，分别构造其相对市值指标。
- 使用Fama-MacBeth回归、单变量及双变量分组组合，比较B/M、留存收益/市值、投入资本/市值、EP及累计盈利对未来收益和盈利增长的预测。

## Key findings
- 留存收益平均约占权益账面价值41%，投入资本约54%，累计其他综合收益约5%。
- 回归与分组结果表明，B/M的横截面预测能力主要来自留存收益/市值；投入资本/市值没有额外重要信息。
- 留存收益/市值相较B/M提高回归t值，并且在控制过去平均盈利后，最新单年盈利的增量信息减弱。
- 留存收益/市值在三个预测期均显著正向预测未来盈利增长，而B/M符号和显著性不稳定。

## Quant takeaways
- 可在价值因子中加入留存收益/市值，或用其替代B/M进行截面排序，并比较因子衰减和行业中性表现。
- 该结果支持“盈利能力代理”解释，不等于留存收益直接衡量内在价值；会计口径、回购和负账面价值仍需处理。
- 需在其他国家、金融股和实时财报可得时点上复核，避免前视偏差。
