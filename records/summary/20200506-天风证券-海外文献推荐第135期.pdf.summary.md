# 货币政策敞口因子MPE

- **source filename**: `20200506-天风证券-海外文献推荐第135期.pdf`
- **date**: 2020-05-06
- **institution / author**: 天风证券；吴先兴（分析师）、陈可（联系人）
- **extraction confidence**: high

## Core question
报告构造货币政策敞口因子（MPE），研究股票对扩张性货币政策意外的敏感度是否对应横截面风险溢价。高MPE股票在经济恶化时获得更强政策对冲，因此其长期预期收益可能更低。

## Methods / data
- 用财务约束、现金和短期投资、现金流久期与波动率、营业利润率等公司特征，结合FOMC政策意外估计MPE；估计期为1994—2008年，资产定价样本始于1975年。
- 每月按MPE五分位排序，构造低MPE多头、高MPE空头组合，并控制FF五因子、常见特征及市场beta。
- 用CPI和非农就业意外检验稳定器渠道，并进行Fama-MacBeth回归。

## Key findings
- 1975—2015年低MPE减高MPE策略年化价值加权收益9.12%（t=4.91），夏普比率0.77；控制FF5后alpha为4.68%（t=4.00）。
- CPI意外增加一个标准差，组合收益增加1.3bp；非农就业意外增加一个标准差，收益增加2.8bp。
- 控制规模、价值、盈利、投资和动量后，MPE对下月收益的负相关t值为−8.76；按beta条件双重排序时，最低多空收益仍为79bp。

## Quant takeaways
- MPE可作为宏观政策状态与股票横截面联结的风险因子，适合与beta、价值和久期因子联合测试。
- 需要处理政策意外定义、行业剔除、特征发布滞后和制度变化，避免把规模/价值暴露误当MPE。
- 高MPE的对冲属性意味着危机期可能承担较低收益，实盘应评估空头成本和政策 regime shift。
