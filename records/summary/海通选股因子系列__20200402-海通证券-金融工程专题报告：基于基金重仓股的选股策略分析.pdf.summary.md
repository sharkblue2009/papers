- **source filename**: `20200402-海通证券-金融工程专题报告：基于基金重仓股的选股策略分析.pdf`
- **date**: 2020-04-02
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、郑雅斌
- **document type**: 金融工程专题报告

## Core question
公募基金重仓股有没有稳定超额收益，怎样筛选基金池和构建方式，才能把“重仓股策略”真正做成可用的选股方法。

## Methods / data
基于基金季报构建重仓股组合，比较等权/市值等加权方式、不同基金池（规模、业绩、持仓延续性）和不同市场环境下的表现，并分析持有期收益衰减。

## Key findings
- 长期看，基金重仓股相对Wind全A和沪深300都有超额，且相对沪深300更强；等权通常最好。
- 重仓股在基金持有期内超额最明显，建仓后1个月约2%，持有一个季度约1%。
- 基金池选择很重要：高延续性、业绩较好的基金池更优；规模后50%的基金池因灵活性更高也常优于前50%。
- 市场环境会影响持续性：前期市场上涨时，重仓股短期超额最好但衰减快；前期市场下跌时，重仓股在随后一个季度更具抗跌和增厚收益特征。
- 2017和2019年重仓股聚集效应更强，热度提升型策略（如持仓个数比例提升）更稳定，长期叠加择时后可取得较高年化超额。

## Quant takeaways
基金重仓股不是简单的“跟随资金”，而是能提供带有披露滞后的持仓偏好信号；关键在于基金池筛选、组合构建和市场状态判断。

## Caveats
受季报披露滞后影响，信号有天然延迟；不同市场阶段和基金池下，策略表现差异较大。
