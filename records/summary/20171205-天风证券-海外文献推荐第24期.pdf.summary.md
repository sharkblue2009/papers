# 海外文献推荐 第24期

- **date**: 2017-12-05
- **institution / author**: 天风证券；吴先兴、阚文超
- **extraction confidence**: high

## Core question
本期研究股票流动性是否会因短期投资者压力促使管理层囤积坏消息，从而提高股价暴跌风险；同时将寿命风险纳入战略资产配置，分析寿命相关证券的对冲和定价价值。

## Methods / data
- 暴跌研究合并TAQ、CRSP、Compustat、13F、机构投资者分类和IBES数据，以相对有效价差的负值衡量流动性；用扩展市场—行业模型计算公司特有收益、Crash test和NSKEW。
- 以股票交易十进制化作为外生流动性冲击，检验流动性、坏消息囤积、机构持股与崩盘的因果关系。
- 寿命研究将死亡率冲击、标准年金价格和VAR动态加入Campbell-Viceira战略配置框架，比较全球股票、债券、传统资产和寿命相关证券。

## Key findings
- 更高流动性提高未来坏消息发布和股价暴跌风险，机制与短线投资者增加、管理层隐瞒坏消息有关；大股东效应并不相同。
- 总寿命冲击可预测寿命相关证券的长期回报；寿命证券可提供跨期对冲，并被估计为资产管理者的低成本融资来源。

## Quant takeaways
- 流动性因子不应只被视为交易成本变量，还可作为尾部风险和公告风险的条件变量。
- 寿命资产配置需显式建模死亡率、利率和相关性；年金价格和VAR估计存在模型风险，结论不宜直接外推。
