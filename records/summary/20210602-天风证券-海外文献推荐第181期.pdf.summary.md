# 美国战后经济周期实证研究

- **source filename**: `20210602-天风证券-海外文献推荐第181期.pdf`
- **date**: 2021-06-02
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告介绍 Hodrick-Prescott 对战后美国季度经济序列的趋势—周期分解，并检验总需求、生产要素、货币变量与实际 GNP 周期之间的波动、协动性和稳定性。

## Methods / data
- 使用 1950Q1—1979Q2 的美国季度数据，将观测序列分为平滑增长趋势与周期成分。
- 通过最小化周期偏差平方和与趋势二阶差分平方和，设定平滑参数 λ；基准选择 λ=1600，并比较 λ=400、6400 和无穷大。
- 用标准差、同期及领先滞后相关、回归 R² 和样本前后半段稳定性评价各变量与 GNP 的关系。

## Key findings
- 基准 λ=1600 下，趋势增长年化约 2.3%—4.9%；将 λ 调整为 400 或 6400，周期 GNP 标准差和自相关仅小幅变化，但 λ=∞ 会显著增强持续性。
- 实际 GNP 周期标准差约 1.8%；投资与 GNP 相关系数 0.661，耐用品消费 0.614，非耐用品消费 0.565。
- 工时与产出关系较强；生产率同期相关较弱，但纳入领先/滞后 GNP 后 R² 从 0.010 升至 0.453。
- 存货加入领先/滞后项后 R² 从 0.257 升至 0.622；货币与价格变量的相关性跨时期不稳定。

## Quant takeaways
- HP 滤波可用于宏观状态识别和周期因子构造，但 λ 决定趋势与周期的边界，应做敏感性分析。
- 领先滞后相关和滚动稳定性比单一同期相关更适合评估宏观变量的预测作用。
- 样本覆盖战后早期美国，且方法不适合识别长持续周期或大萧条等结构性事件，不能机械外推。
