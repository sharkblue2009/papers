# 报告摘要

- 源文件：20260110-东吴证券-金工专题报告：深度学习系列之一，AI重塑量化，基于大语言模型驱动的因子改进与情绪Alpha挖掘.pdf
- 日期/机构/类型：2026-01-10 / 东吴证券 / 金工专题报告 / 深度学习系列之一
- 核心问题：LLM + Prompt Engineering 能否构建一个自动化因子研究框架，并在低频量价、基本面、高频和文本情绪场景中持续挖掘 Alpha。
- 方法与数据：以 Alpha158 因子库和 Qlib 算子为基础，设计提示词驱动的因子优化与生成流程；对低频量价因子做迭代改进，对基本面与高频数据生成新因子，并用 Gemini 解析调研纪要构造文本情绪因子；以 RankIC、ICIR、分组收益与样本外跟踪验证效果。
- 关键结论：AI 不仅能识别原始因子的逻辑缺陷并给出改进方案，还能从零生成与样例低相关、ICIR 较高的新因子；基本面、高频和文本情绪场景也都能形成增量 alpha，说明“知识+逻辑驱动”比纯黑箱搜索更可解释。
- 量化要点：该框架把量化研究从“数据驱动”推向“知识与逻辑驱动”；最有价值的是把 AI 当作研究员的放大器，而非单纯的信号黑盒。
- 局限性：搜索空间受人类先验约束，LLM 可能幻觉、对提示词敏感，且 API 成本和结果复现性仍是现实约束。
- 关键词：大语言模型；Prompt Engineering；因子挖掘；Alpha158；情绪Alpha；自动化研究
