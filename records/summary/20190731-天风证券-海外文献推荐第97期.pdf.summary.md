# 机器学习时代的回测原则

- **source filename**: `20190731-天风证券-海外文献推荐第97期.pdf`
- **date**: 2019-07-31
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
文章讨论低频金融数据在机器学习时代为何更容易过拟合，并提出从研究假设、多重检验、数据、交叉验证、动态变化、模型复杂度和研究文化七个维度建立回测规程。

## Methods / data
- 用一个50年美股市值中性多空策略作反例：买入股票代码前三字母含S、做空含U的股票，展示纯数据挖掘也能产生漂亮表现。
- 讨论事前理论假设、记录所有变量组合、校正多重检验、预先确定样本和去极值方法、样本外与交叉验证。
- 强调交易成本、时变性、正则化、模型可解释性及委托研究中的激励偏差。

## Key findings
- 反例策略在1963–1988样本内和1989–2015样本外都表现出色、年换手率仅约10%，但没有经济逻辑，说明单纯样本外表现也可能源于大规模搜索。
- 测试20个随机策略时，凭运气得到t值大于2并不罕见；20个变量的两两交互就有190种组合。
- 文章不提供可推广的收益、Sharpe或回撤结论，重点是研究设计和回测纪律。

## Quant takeaways
- 建模前锁定数据、特征、异常值处理、交易成本和评估指标，并保存全部尝试以估计selection bias。
- 使用purged/embargoed交叉验证、现实成本和滚动样本外测试，但不要把历史“样本外”当作真正未来。
- 简洁、可解释和正则化优先；避免因短期失效而不断调参，也要警惕研究委托方诱导的确认偏误。
