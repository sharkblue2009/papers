# 20240227-广发证券-个股预期回报弹性的拆解：“防守反击”因子

- **源文件**：`20240227-广发证券-个股预期回报弹性的拆解：“防守反击”因子.pdf`
- **日期/机构/类型**：2024-02-27，广发证券，金融工程|量化投资专题

## 核心主题
- 将个股预期回报的上行与下行信息拆解，构建“预期收益上行贝塔”与复合后的“防守反击”因子，用于选股。

## 方法与数据
- 基于收益分布的头部与尾部信息，结合组合波动率估计、回归系数与相关系数转换，构建预期收益上行贝塔。
- 在预期损失下行贝塔基础上叠加上行信息，形成“防守反击”复合因子。
- 在全 A、沪深 300、中证 500、中证 1000 等股票池中测试，并进行行业/风格正交检验。

## 关键发现
- 预期收益上行贝塔具备选股能力，行业市值中性后全市场月度选股 IC 为 **-4.0%**，年化 ICIR **-2.44**，多空年化收益 **14.1%**。
- “防守反击”因子单调性明显改善：行业市值中性后全市场月度选股 IC 为 **-6.3%**，ICIR **-2.58**，多空年化收益 **20.1%**。
- 费后多头相对万得全 A 年化超额 **10.2%**，IR **1.04**，相对最大回撤 **23.2%**；优于预期损失下行贝塔的 **7.4%**、IR **0.75**。
- 在沪深 300、中证 500、中证 1000 内，费后多头年化超额分别为 **6.3% / 8.1% / 7.4%**。

## 量化要点
- 该因子的核心是把“防守”与“潜在反击能力”合成，提升多头组的区分度。
- 行业与风格正交后，复合因子的优势仍然存在，说明不是单纯行业/风格暴露驱动。

## 局限性
- 因子在 2018、2021 年多空净值曾放缓，存在阶段性失效风险。
- 2020 年下半年多头波动较大，需关注回撤。
- 结果基于历史统计，市场环境变化时可能失效。
