# 海通证券选股因子系列研究（八十九）：买入评级因子的改进及其在大盘股优选策略中的应用

- **source filename**: `20231025-海通证券-选股因子系列研究（八十九）：买入评级因子的改进及其在大盘股优选策略中的应用.pdf`
- **date**: 2023-10-25
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、罗蕾
- **document type**: 金融工程专题报告

## Core question
2023年买入评级因子为何明显走弱，能否通过筛选更优质的买入评级信息来恢复溢价，并用于大盘股优选。

## Methods / data
从报告类型、新增 vs 连续买入评级、是否有基本面支撑、分析师近6个月活跃度、同股覆盖篇数等维度拆解买入评级因子；再在全A大市值股票池中构建大盘优选组合。

## Key findings
- 买入评级报告中，深度报告和点评报告占比持续提升，至2023年合计已超 **90%**；其中深度报告的截面溢价最高。
- **新增买入评级**优于连续买入评级；2023年连续买入评级因子略负，而新增买入评级仍维持正溢价，正溢价月份占比约 **66.7%**。
- **有基本面支撑**的买入评级显著更强：2013.01-2023.09 月均溢价约 **0.95%**，无基本面支撑仅 **0.22%**；2023年同样前者为正、后者为负。
- 分析师更活跃、同股覆盖报告更多，通常对应更高的未来溢价，但全区间内都保持正溢价，因此更适合作为增强条件而不是硬性剔除条件。
- “新增且有基本面支撑”的改进因子在2023年月均溢价约 **0.55%**、月胜率 **88.9%**、ICIR **1.51**，但覆盖率只有约 **8%**。
- 用买入评级与其他因子做大盘优选，在全A市值最大的400只/500只股票中分别可得到年超额约 **14.6%** / **10.5%**，跟踪误差和回撤也较可控。

## Quant takeaways
买入评级因子不是失效了，而是需要更精细的“信息质量筛选”；它更适合大盘股、风格化的 Smart Beta 场景，而不是泛化到全市场。

## Caveats
因子覆盖度不高，且样本依赖明显；大盘优选的效果也依赖于组合构建与持有期设定。
