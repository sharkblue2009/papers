# 通胀错觉和股票价格

- **source filename**: `20210224-天风证券-海外文献推荐第170期.pdf`
- **date**: 2021-02-24
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告检验通货膨胀如何影响股票股息率，并区分长期实际股利增长、主观风险溢价与投资者增长预期偏离造成的错误定价，以评估 Modigliani-Cohn 通胀错觉假说。

## Methods / data
- 使用 1927 年 5 月至 2002 年 12 月的月度标普 500 数据，共 908 个观测；VAR 样本为 303 个季度观测。
- 将股息率分解为客观预期的长期实际股利增长、主观风险溢价和错误定价残差。
- VAR 状态变量包括标普 500 超额收益、横截面 beta 溢价、股息率和经平滑处理的通胀，并用回归解释各组成部分。

## Key findings
- 风险溢价与历史通胀率联合解释股息率约 49%的变化，且统计上显著。
- 错误定价是股息率对数分解中波动最大的部分，主观风险溢价波动最小。
- 1999 年末模型认为合理股息率约 3.3%，实际约 1.2%，约 2.1 个百分点缺口归因于错误定价。
- 通胀几乎解释股票市场错误定价的 80%；高通胀对应更高错误定价和相对低估，支持通胀错觉假说。

## Quant takeaways
- 估值模型可将通胀、风险厌恶和预期股利增长分开，避免直接用名义债券收益率解释股票价格。
- 可把通胀状态作为长期估值偏差或风险溢价预测变量，并检验其在不同持有期的修复速度。
- 结论依赖线性化 Campbell-Shiller 框架与历史美国数据；通胀制度、货币政策和投资者结构变化会影响外推。
