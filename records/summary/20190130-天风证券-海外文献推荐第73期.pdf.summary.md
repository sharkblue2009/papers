# 基于APB 指标的共同基金业绩评估

- **source filename**: `20190130-天风证券-海外文献推荐第73期.pdf`
- **date**: 2019-01-30
- **institution / author**: 天风证券研究所；吴先兴；原文作者 Hunter、Kandel、Kandel 等
- **extraction confidence**: high

## Core question
论文提出主动同业基准（active peer benchmark, APB），用同一投资目标组内基金的平均收益捕捉共同策略和未定价风险，从而改善单只基金alpha估计及未来业绩预测。

## Methods / data
- 使用CRSP美国共同基金月度数据，1980年1月至2010年12月；将股票基金按大、中、小盘及价值、总体、成长划分为9组。
- 在Carhart四因子模型中加入组内等权APB收益及其第一阶段残差，比较传统模型、APB扩展模型和经APB调整的alpha。
- 进行组间/组内残差相关性、样本外费用前后收益、被动指数、流动性因子和替代基准稳健性检验。

## Key findings
- 36对APB残差相关关系中35对在10%双尾水平显著为正，说明传统四因子模型遗漏了共同特殊风险。
- 加入APB后，组内基金显著正相关残差比例大幅下降，1998—2003年的相关性峰值消失。
- APB扩展模型显著改善对未来基金收益和管理能力的识别；报告强调其降低alpha估计方差，但未在摘录中给出统一的样本外Sharpe数值。

## Quant takeaways
- 基金筛选可先按目标和风格构造可交易的peer benchmark，再评估残差alpha。
- APB可能混入基金规模、指数重叠和共同风格风险；需避免用当期未来信息构造基准，并控制费用、存活和基准自选偏差。
