# 关于大宗商品投资的再思考

- **source filename**: `20210428-天风证券-海外文献推荐第178期.pdf`
- **date**: 2021-04-28
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告重新审视大宗商品作为资产类别的长期收益、通胀保护和分散化作用，并讨论除纯多头 beta 外，如何通过替代指数、主题表达、战术交易和风险溢价策略使用商品。

## Methods / data
- 将商品收益拆解为现货收益、展期收益和抵押品收益，讨论期货升贴水对总收益的影响。
- 比较商品与股票、债券的相关性，以及含商品和不含商品的多资产组合；考察不同通胀环境下 S&P GSCI 表现。
- 讨论风险平价/波动率管理的替代 beta、单商品主题与战术配置，并以商品市场参与者和套保压力解释风险溢价。

## Key findings
- 通胀水平与一揽子商品收益呈正相关，但这种关系同时性强，持续持有敞口可能拖累多资产组合。
- 55%股票/40%债券/5%商品组合自 2008 年危机后表现弱于 60/40 组合，虽波动略低，但风险调整收益未改善。
- 危机后跨资产和商品内部相关性曾明显上升，削弱短期分散化；长期历史仍显示商品具有一定分散价值。
- 商品期货总收益由现货、展期和抵押品构成，升水市场展期收益为负、贴水市场为正。

## Quant takeaways
- 商品配置应分解 carry、spot 和 collateral，不能把商品指数回报简单视为现货 beta。
- 可测试等风险贡献、波动率目标和单商品主题策略，并把期货曲线、流动性和宏观状态纳入。
- 通胀保护主要依赖供应冲击且难以预测；商品不产生现金流，估值和长期持有逻辑与股票债券不同。
