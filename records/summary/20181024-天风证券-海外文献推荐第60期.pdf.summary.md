# 海外文献推荐 第60期

- **source filename**: `20181024-天风证券-海外文献推荐第60期.pdf`
- **date**: 2018-10-24
- **institution / author**: 天风证券；吴先兴
- **extraction confidence**: high

## Core question
本文检验金融、会计和经济学论文发表后，已公开因子是否仍能预测股票收益，区分统计偏差、错误定价和套利活动对因子衰减的作用。

## Methods / data
- 汇总 97 个已发表横截面因子，比较原始样本内、样本结束至论文发表前、论文发表后三个时期的分组多空月收益。
- 以样本截止日和出版日虚拟变量估计收益衰减，并考察样本内收益、显著性、套利成本、换手率、美元交易量、卖空和因子间相关性。

## Key findings
- 97 个因子的平均月收益：样本内约 0.582%，样本外但发表前约 0.402%，发表后约 0.264%。
- 样本截止日后的收益下降约 0.150 个百分点，论文发表后的额外下降约 0.337 个百分点；相对样本内均值分别下降约 26% 和 58%。
- 样本内收益越高、t 统计量越大，发表后的衰减越明显；但出版后超额收益并未完全消失。
- 发表后换手率、美元交易量，尤其卖空股份显著增加；因子与已发表因子的相关性增强，符合注意力和联动效应。

## Quant takeaways
- 因子库应记录发现和发表日期，并把发表效应作为预期收益折扣，而不是直接沿用论文中的样本内结果。
- 需联合评估套利成本、容量、短卖约束、因子相关性和交易拥挤；发表后仍有收益不代表收益足以覆盖真实实施成本。
