# 因子溢价与因子择时：一个世纪的数据验证

- **source filename**: `20200513-天风证券-海外文献推荐第136期.pdf`
- **date**: 2020-05-13
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告用超长历史和跨资产数据检验价值、动量、利差和防御四类因子溢价是否真实、是否因公开后套利而衰减，以及经济环境能否支持因子择时。

## Methods / data
- 覆盖超过100年、6类资产；将样本分为因子发现前、原始发现期和公开后期，比较样本内外表现。
- 用近50年全球宏观、流动性、情绪和崩盘事件检验风险暴露，并测试估值价差、因子动量、宏观变量、CAPE和VIX等择时信号。
- 比较静态与择时策略的夏普、alpha和信息比率，并考虑信号滞后与交易成本。

## Key findings
- 四类因子在多资产样本外仍存在，但样本外溢价约下降30%，更像过拟合偏差而非公开后套利侵蚀。
- 多因子组合前样本期夏普约为原始样本期的64%，后样本期约69%；样本外下降p=0.009，前后样本差异p=1。
- 未发现因子溢价与宏观风险、流动性、情绪或崩盘风险有稳定显著联系；择时样本内信息比率0.45，样本外仅0.13。

## Quant takeaways
- 长历史、跨资产样本是检验因子可迁移性和数据挖掘偏差的重要基准。
- 因子择时必须使用真实可得的滞后信号，并把交易成本、换手和模型选择纳入样本外评估。
- 不能把短期宏观相关性直接解释为因子风险来源；更稳妥的是保留静态因子暴露并谨慎配置择时叠加。
