# 分析师预测与企业盈余管理

- **source filename**: `20211110-天风证券-海外文献推荐第200期.pdf`
- **date**: 2021-11-10
- **institution / author**: 天风证券研究所；吴先兴（分析师）；原文作者 McGuire、Omer、Sharp
- **extraction confidence**: high

## Core question
研究高管是否通过调整税收支出进行盈余管理，以击败一致预期、符合更多个人分析师预测，或满足明星分析师的预测。

## Methods / data
- 使用2000—2017年公司年度样本，共9023个公司年观测。
- 以有效税率（ETR）变化识别税收相关盈余管理，比较管理前盈利与一致预期、个人分析师预测和明星分析师预测的距离。
- 采用单变量、回归及补充测试，检验ETR调整方向与预测击败、达到或错过事件之间的关系。

## Key findings
- 管理者在盈余管理决策中不仅考虑市场一致预期，也会参考个人分析师，尤其是明星分析师预测。
- 即使管理前盈利已经超过一致预期，公司仍可能调整盈余，使结果符合更多分析师或某一明星分析师的预期。
- 当ETR下降时，击败增量预测的概率约为ETR上升时错过预测概率的两倍以上，支持通过税项平滑或调整实现预测管理。
- 结果表明“刚好达到预期”可能含有管理行为，而不是纯粹的经营信息。

## Quant takeaways
- 盈余惊喜策略应把ETR异常变化、分析师覆盖数量和明星分析师预测分歧作为质量过滤器。
- 需控制税法变化、亏损、递延税项、行业周期与预测修订，并避免把合法税务规划、真实盈利变化误判为操纵。
