# 谷歌搜索量和个人投资者交易行为

- **source filename**: `20201014-天风证券-海外文献推荐第153期.pdf`
- **date**: 2020-10-14
- **institution / author**: 天风证券；吴先兴；原文作者 Dimitrios Kostopoulos、Steffen Meyer、Charline Uhr
- **extraction confidence**: high

## Core question
本文研究基于谷歌搜索量构造的德国FEARS情绪指数是否影响个人投资者的买卖行为，并检验情绪冲击与股票市场收益之间的关系。重点区分风险资产交易、投资者特征和随后是否反转。

## Methods / data
- 用2005年1月至2015年12月德语经济与预期关键词搜索量，滚动180天选取负向显著性最高的30个词构造FEARS。
- 数据来自大型经纪商，覆盖101,223名投资者、约1,580万笔交易和约1,134亿欧元交易额。
- 以交易数量和金额买卖不平衡为因变量，按1—5级证券风险分类，并用时间序列回归和DAX VAR检验。

## Key findings
- FEARS上升1个单位时，金额口径买卖不平衡下降0.0198，表明买入减少、卖出增加。
- FEARS上升时投资者更倾向卖出风险资产；组合分散化程度越高，情绪影响越弱。
- FEARS与DAX收益显著负相关，FEARS上升1单位对应DAX下降约26bp（5%水平显著）。
- 市场价格冲击约6天后反转，但个人投资者卖出行为未出现同样反转；非专业投资者更易受情绪影响。

## Quant takeaways
- 可用搜索量构造动态情绪状态，和散户净买入、风险等级及市场收益联合建模。
- 回测应控制日历效应、市场变量，并剔除储蓄计划和限价单等自动交易噪声。
- FEARS是短期情绪冲击而非稳定alpha；关键词选择、Google地域偏差及经纪商样本代表性需重点检验。
