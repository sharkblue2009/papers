# 摘要

- **源文件**：20240205-民生证券-量化专题报告：红利策略优化，“高股息陷阱”与股息预测.pdf
- **日期 / 机构 / 类型**：2024-02-05｜民生证券｜量化专题报告
- **核心主题**：讨论高股息策略与股息增长策略的差异，并提出用股息预测和负向清单来规避“高股息陷阱”。
- **方法与数据**：使用近 5 年财务与分红数据，将公司分红类型归类为稳定每股红利、稳定分红总额、稳定净利润支付率和稳定现金流支付率；再通过平滑与偏离度判断稳定性，用时间衰减加权生成股息预测值，并结合负向清单构建组合。
- **主要结论**：A 股当前环境下，传统高股息策略比股息增长策略更稳定；单纯追逐极高股息率可能踩中“高股息陷阱”。股息预测可提升因子质量，且叠加风控后能稳定增强红利低波组合。
- **量化要点**：股息率预测因子市值中性化后 **RankIC 从 3.23% 提升到 3.82%**；预测高股息组合相对中证红利全收益年化超额 **4.47%**、信息比率 **0.67**；预测 + 负向清单 + 低波后的红利低波增强组合年化超额 **6.17%**、信息比率 **0.75**，其中 2023 年贡献接近 **9%** 超额。
- **局限性**：分红规则、盈利与现金流预测均存在不确定性；策略对样本期与市场风格较敏感。
- **关键词**：红利策略、高股息陷阱、股息预测、负向清单、红利低波、因子增强
