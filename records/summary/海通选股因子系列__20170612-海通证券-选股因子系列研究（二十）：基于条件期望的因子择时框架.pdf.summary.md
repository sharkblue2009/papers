# 海通证券选股因子系列研究（二十）：基于条件期望的因子择时框架

- **source filename**: `20170612-海通证券-选股因子系列研究（二十）：基于条件期望的因子择时框架.pdf`
- **date**: 2017-06-12
- **document type**: 金融工程专题报告

## Core question
如何用条件期望框架做因子择时：在不同市场环境下，动态调整因子收益和协方差的预测，从而改善多因子组合。

## Methods / data
- 以 **条件期望** 替代无条件均值，预测因子收益和因子协方差。
- 使用多种条件变量，重点考察 **波动率类、涨跌幅类、估值类、换手率类** 指标对因子择时的效果。
- 以 TOP100 组合检验不同条件变量下的区间和分年度表现，并引入 **AIC** 筛选构建多条件变量模型。

## Key findings
- 大部分 **波动率类** 指标、部分涨跌幅指标、个别估值和换手指标具有择时效果。
- 对未加入市值因子的多因子模型，择时能提升 TOP100 组合；但一旦加入市值因子，只有少数波动率类指标还能带来明显增益。
- 多数择时模型在 **2016 年**较容易战胜原始模型，部分在 2014/2017 年也有效，但 **2015 年**较少能跑赢。
- AIC 多条件变量模型在区间年化收益上未必最高，但收益更均衡，在风格剧烈切换期更稳；2017 年以来表现明显好于未择时模型。

## Quant takeaways
- 因子择时不是简单开关，而是对因子收益/协方差的条件化预测。
- 波动率、市场涨跌、换手、估值是最值得优先纳入的状态变量。
- AIC 可用于控制条件变量数量，避免过拟合。

## Caveats
- 条件变量选择和样本窗口对结果影响大。
- 回测中有“模型给出”而非人工调参，实盘落地仍要关注稳定性。
