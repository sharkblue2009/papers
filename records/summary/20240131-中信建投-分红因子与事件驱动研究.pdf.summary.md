# 摘要

- **源文件**：20240131-中信建投-分红因子与事件驱动研究.pdf
- **日期 / 机构 / 类型**：2024-01-31｜中信建投证券｜量化深度报告
- **核心主题**：同时从股息率因子和现金分红事件两个角度，研究红利策略的有效性与稳定性。
- **方法与数据**：基于 A 股上市公司 2014–2023 年分红数据，统计分红金额、行业分布和月度分布；构建股息率因子组合并做分组测试；另外以现金分红公告为事件窗口，估计事件后异常收益。
- **主要结论**：2023 年以来红利策略整体效果较强、波动更低，具备明显防御属性；高股息组合收益优势明显，但低分红组合未必优于不分红组合。事件研究显示，现金分红公告后大约 **40 天** 会出现约 **3%** 的累计异常收益。
- **量化要点**：2014–2023 年上市公司现金分红金额由 **7588 亿元**增至 **21364 亿元**；红利策略的收益来源主要来自分红与盈利，适合作为偏价值、防御型配置工具。
- **局限性**：分红制度、分红偏好与市场风格可能变化；事件窗口与正常收益设定对结果有影响，历史规律不保证未来继续成立。
- **关键词**：红利策略、股息率因子、现金分红、事件驱动、异常收益、防御风格
