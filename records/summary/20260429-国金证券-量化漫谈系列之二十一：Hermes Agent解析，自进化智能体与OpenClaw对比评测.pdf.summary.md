# 研报摘要
- 源文件：20260429-国金证券-量化漫谈系列之二十一：Hermes Agent解析，自进化智能体与OpenClaw对比评测.pdf
- 文档类型：券商 AI 智能体点评报告
- 核心主题：解析 Hermes Agent 的自进化闭环机制，并与 OpenClaw 做投研实测对比。
- 方法/数据：基于公开产品信息、GitHub 热度、阿里云无影云电脑部署环境，以及研报总结、个股分析和技能复用两类测试任务。
- 关键结论：Hermes 在执行效率、自主发现工具、技能沉淀方面更强；OpenClaw 在分析深度与研判颗粒度上更优，两者更偏互补。
- 量化要点：Hermes 发布首月 GitHub Stars 约 2.2 万，至 2026-04 约 11.4 万；实测中 Hermes 1 轮交互可完成研报汇总，技能闭环约 3 轮，而 OpenClaw 需 5-11 轮但分析更深。
- 注意事项：结论基于特定版本与测试环境；AI 智能体存在误判、权限和安全风险。
- 关键词：Hermes Agent、自进化、OpenClaw、技能沉淀、智能体、投研
