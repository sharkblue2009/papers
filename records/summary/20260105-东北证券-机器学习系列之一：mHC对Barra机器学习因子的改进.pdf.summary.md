# 报告摘要

- 源文件：20260105-东北证券-机器学习系列之一：mHC对Barra机器学习因子的改进.pdf
- 日期/机构/类型：2026-01-05 / 东北证券 / 金融工程研究报告 / 机器学习系列之一
- 核心问题：研究将 DeepSeek 的 mHC（Manifold-Constrained Hyper-Connections）引入 Barra 机器学习因子构建流程后，是否能提升因子的稳定性、可解释性与样本外稳健性。
- 方法与数据：基于 2014–2025 年 A 股全市场截面数据（剔除停牌与 ST），采用 24M/36M/72M 滚动训练窗口，对原生 Barra-MLP 与 mHC-MLP 做并行训练和对比；评估指标包括 IC、ICIR、换手率、分布尖峰肥尾、自相关衰减与极端分位数表现。
- 关键结论：mHC 通过双随机矩阵投影与非负约束抑制了输出分布的尖峰肥尾，使因子更接近正态；截面排序稳定性与自相关半衰期表现更好，换手率更低，说明其更适合低信噪比金融场景中的稳健建模。
- 量化要点：量化上更值得关注的是“稳健性改善”而非单纯追求样本内拟合；滚动训练窗口下结果较一致，提示几何约束可作为因子模型的降噪与抗外推手段。
- 局限性：样本外收益提升并非在所有情形下都显著，部分结论依赖 DeepSeek mHC 论文的工程设定；更适合稳定性约束，而非保证绝对超额收益。
- 关键词：mHC；Barra；MLP；因子改进；IC；ICIR；Sinkhorn-Knopp；稳健性
