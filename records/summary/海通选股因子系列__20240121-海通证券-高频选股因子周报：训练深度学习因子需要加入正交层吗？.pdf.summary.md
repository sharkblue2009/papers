# 20240121-海通证券-高频选股因子周报：训练深度学习因子需要加入正交层吗？

- **source filename**: `20240121-海通证券-高频选股因子周报：训练深度学习因子需要加入正交层吗？.pdf`
- **date**: 2024-01-21
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 高频选股因子周报

## Core question
训练深度学习高频因子时，是否需要加入正交层；以及本周各类高频/深度学习因子的短周期表现如何。

## Methods / data
- 基于 2024-01-15 至 2024-01-19 的高频选股周报。
- 跟踪多类微观结构因子（偏度、下行波动占比、开盘后买入意愿、大单净买入、改进反转、尾盘成交占比、平均单笔流出金额占比、大单推动涨幅等）。
- 对比多种深度学习因子：GRU(50,1)+NN(10)、GRU(50,2)+NN(10)、改进 GRU、残差注意力 LSTM、多颗粒度模型（5 日/10 日标签）。
- 还评估了周度调仓的中证 500 / 中证 1000 AI 增强组合。

## Key findings
- 本周表现较好的主线仍然是**加入正交层的深度学习模型**；无正交层的多颗粒度模型本周出现回撤。
- 多个高频手工因子在本周/本月/2024YTD 中仍有正收益，但分化较大；大单推动涨幅、开盘后大单净买入强度等因子本周偏弱。
- 深度学习高频因子整体保持较强的周度多空能力：
  - GRU(50,1)+NN(10) 2024YTD 多空收益约 **6.44%**，多头超额约 **2.00%**。
  - GRU(50,2)+NN(10) 2024YTD 多空收益约 **6.15%**。
  - 改进 GRU(50,2)+NN(10) 2024YTD 多空收益约 **5.35%**。
  - 残差注意力 LSTM(48,2)+NN(10) 2024YTD 多空收益约 **6.35%**。
  - 多颗粒度模型-5 日标签 / 10 日标签 2024YTD 多空收益分别约 **6.65% / 6.95%**，但本周回撤。
- 周度 AI 增强组合本周回撤，但 2024YTD 仍为正：
  - 中证 500 AI 增强：**0.19%**
  - 中证 1000 AI 增强：**1.39%**

## Quant takeaways
- 这篇是典型的**“周报式模型筛选”**：更重视短周期稳定性、样本外波动和本周胜率，而不是单纯追求长区间最大化收益。
- 从这期结果看，**正交层更像是短周期稳定性的保险装置**：它不必然让收益最高，但有助于避免某些模型在周度层面的失真与回撤。
- 多颗粒度模型并不总是最稳，提示深度学习因子仍需重视结构约束与样本窗口设计。

## Caveats
- 这是单周周报，结论更偏短期信号，不适合直接外推为长期规律。
- 文档以周度收益展示为主，完整训练细节与参数敏感性未在周报中完全展开。
