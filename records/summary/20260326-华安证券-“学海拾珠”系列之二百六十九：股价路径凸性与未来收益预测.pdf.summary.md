# PDF总结

- 来源文件：20260326-华安证券-“学海拾珠”系列之二百六十九：股价路径凸性与未来收益预测.pdf
- 日期 / 机构 / 类型：2026-03-26，华安证券，金融工程专题报告 / 专题研究
- 核心问题：股价路径的“凸性”是否能独立预测短期未来收益。
- 方法与数据：构造“中点价 - 日均价”相对中点价的凸性指标；市场层面用标普 500 与 Goyal 预测变量做样本内/外回归、预测包含性检验；个股层面用 CRSP/Compustat 数据做分组、零投资组合、Fama-MacBeth 回归及多种稳健性检验。
- 关键结论：凸性对未来收益具有显著负向预测力，且独立于短期反转、传统因子与流动性因素；更强的证据支持“错误定价 + 过度外推”机制，而非风险补偿。
- 量化要点：市场层面凸性每升 1 个标准差，未来 1 个月收益约降 0.40%；个股层面低凸性减高凸性组合月均收益约 0.84%，多因子调整后阿尔法约 0.81%~0.96%；控制全部变量后系数约为 -45bp/月。
- 局限性：主要基于美国市场与历史样本，短周期效应更强，海外外推需要谨慎。
- 关键词：路径凸性、短期收益预测、错误定价、过度外推、短期反转、Fama-MacBeth
