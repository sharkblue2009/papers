# 20241216-招商证券-“青出于蓝”系列研究之九：基于分钟数据的价变共振因子

- **来源文件**：20241216-招商证券-“青出于蓝”系列研究之九：基于分钟数据的价变共振因子.pdf
- **日期/机构/类型**：2024-12-16，招商证券，金融工程深度研究
- **核心主题**：从分钟级量价数据中提炼“价变共振因子”，衡量个股与市场在趋势和成交量上的同步性。
- **方法/数据**：使用个股与市场的分钟收益率、日内极值时刻的市场共振关系，以及成交量占比信息，构造CO_MAX、CO_MIN、PRE_AMT_MAX、PRE_AMT_MIN等因子；再做等权复合与正交化，并在沪深300/中证500/中证1000中测试指数增强效果。
- **主要发现**：当个股与市场形成更有效的价格和成交量共振时，未来收益通常更好。复合价变共振因子IC均值为6.32%，年化ICIR为4.64；正交化后ICIR略有提升。领先成交量异动因子比同步成交量异动更稳健，相关因子可用于宽基增强。
- **量化要点**：重点关注“走势与市场共振”的股票，而非仅看自身价格形态；分钟级特征在高频噪声中仍能提取稳定信号。
- **局限性**：高频数据噪声大，信号稳定性受市场状态影响明显，历史规律可能失效。
- **关键词**：分钟数据、价变共振、成交量异动、ICIR、指数增强
