# 持股的创新偏好与共同基金业绩研究

- **source filename**: `20210210-天风证券-海外文献推荐第169期.pdf`
- **date**: 2021-02-10
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告研究共同基金经理是否能凭借对技术创新的理解获得超额收益，并提出主动技术相似性（ATS）指标，衡量基金交易是否主动提高组合内公司的技术重叠程度。

## Methods / data
- 以公司过去一年在 642 个 CPC 专利类别中的分布计算余弦相似度，并按基金持仓权重聚合技术相似性。
- 用实际季度末组合与“不交易”被动组合之差定义 ATS；数据包括 194 万项 1926—2017 年专利、CRSP 基金收益和 Thomson-Reuters 持仓。
- 样本为主动国内股票共同基金，最终包含 2,895 只基金、1983Q4—2017Q4 的 87,804 个基金季度观测；按 ATS 五分位并做 Carhart 四因子回归。

## Key findings
- ATS 最高与最低五分位的下一季度月度收益差为 0.236%，总收益 alpha 差 0.240%，净收益 alpha 差 0.235%，均在 1%水平显著。
- 高 ATS 组下一季度月度总收益 alpha 约 0.187%；年化净 Carhart alpha 约 88bp。
- ATS 标准差约 2.775%；回归估计每增加一个标准差，下一季度年化净收益提高约 93bp。
- ATS 与行业集中度、主动份额、基金 R² 和滞后 alpha 基本正交；高 ATS/高滞后 alpha 组合相对低 ATS/低滞后 alpha 组合的年化净 alpha 差约 5.33%。

## Quant takeaways
- 专利技术相似性变化可作为基金筛选的交易型能力指标，与静态集中度和历史 alpha 组合使用。
- 实施时需处理基金合并、幸存者偏差、持仓披露滞后和专利分类映射。
- 结果说明创新信息可能被市场迟缓吸收，但 ATS 的换手、容量和样本外衰减仍需验证。
