# 20240402-西南证券-量化方法在债券研究中的应用二：换手率因子在股债中的差异性与增强作用

- **source file**：`20240402-西南证券-量化方法在债券研究中的应用二：换手率因子在股债中的差异性与增强作用.pdf`
- **日期/机构/类型**：2024-04-02，西南证券，金融工程专题报告/因子选股系列

## 核心主题
讨论换手率因子在股票、可转债及可转债正股中的表现差异，并基于可转债换手率构建增强型选券思路。

## 方法与数据
- 对沪深A股、可转债正股、可转债三个市场的换手率与后续收益做分组检验与相关性分析。
- 从可转债收益拆解角度解释“热度”与债性保护对收益的影响。
- 进一步构建两个因子：**转债相对换手率因子**、**转债正股换手率差异因子**。
- 组合层面采用 TOP N 选券，并与“双低”因子联用做增强。

## 关键发现
- 股票日均换手率在A股和可转债正股中通常是负向因子：换手率越低，后续表现越好。
- 但在可转债上，换手率并不简单呈负相关，高换手率反而可能对应更好的后续收益。
- 转债相对换手率越高，未来收益越强；转债正股换手率差异越大，未来收益也越强。

## 量化结果
- **相对换手率最高组**：年化收益率 **16.94%**。
- **转债正股换手率差异最高组**：年化收益率 **16.01%**。
- **TOP20组合（前50%换手率中选相对换手率最高的转债）**：
  - 年化收益率 **18.97%**
  - 夏普比率 **1.02**
  - 最大回撤 **12.16%**
  - 相对中证转债指数年化超额收益 **14.57%**
- **双低 + 相对换手率增强 TOP20**：
  - 年化收益率 **22.32%**
  - 夏普比率 **1.39**
  - 最大回撤 **11.02%**
  - 相对双低 TOP20 年化超额收益 **6.98%**

## 局限性
- 结论基于历史样本统计，市场风格变化后可能失效。
- 换手率信号在不同资产上的含义不同，跨市场迁移需谨慎。
