# PDF总结

- **来源文件**：`20260506-兴业证券-多因子选基五——从因子到模型，全新的定量选基策略构建.pdf`
- **文档类型**：定量研究专题报告 / 基金选基
- **核心主题**：从因子与模型两端优化多因子选基，解决权重僵化、风险集中和风格依赖问题。
- **方法与数据**：在因子层面引入中性化思想，构建赛道/风格/宽基暴露并剔除风格噪声；在模型层面用随机多准则可接受度分析（SMAA）和蒙特卡洛模拟优化权重；进一步用因子 ICIR 参数化狄利克雷分布，并构建 Sigma-Mu-Alpha 三目标模型。
- **关键发现**：中性化后因子稳定性明显提升；SMAA 框架能更稳健地处理多目标冲突，提升组合适应性。
- **量化要点**：综合模型年化收益率16.84%，年化超额收益6.54%，超额收益波动率3.47%，收益风险比1.89，月度胜率72.79%，季度胜率83.67%，近13年均为正超额。
- **局限/ caveats**：依赖历史基金与市场状态，风格切换可能影响稳定性；报告结论不等于未来表现。
- **关键词**：多因子选基；因子中性化；SMAA；Sigma-Mu-Alpha；ICIR；基金优选；稳健优化
