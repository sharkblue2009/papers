# 20240219-广发证券-多因子Alpha系列报告之（五十二）：基于融资融券因子研究

- **源文件**：`20240219-广发证券-多因子Alpha系列报告之（五十二）：基于融资融券因子研究.pdf`
- **日期/机构/类型**：2024-02-19，广发证券，金融工程|量化投资专题

## 核心主题
- 探讨融资融券数据在多因子选股中的应用，系统构建并检验融资融券相关因子。

## 方法与数据
- 构建 **20个** 融资融券相关因子。
- 在 **全市场、中证500、中证1000** 三个范围做实证分析。
- 对因子做方向调整、缩尾、市值/行业中性化、标准化。
- 检验维度包括IC、因子分档、多空收益、手续费敏感性等。

## 关键发现
- 表现较突出的因子主要是：
  - **融券余额占比因子**
  - **融资买入额占融资余额比因子**
- 这些因子在多个市场范围内都呈现较稳定的负向IC，意味着因子值越小，未来收益越高。
- 扣除手续费后仍可获得长期超额收益，但费率上升会明显压缩收益。

## 量化要点
- 全市场中，融资买入额占融资余额比因子在5/10/20天调仓下：
  - IC均值约 **-4.27% / -5.20% / -5.21%**
  - IC胜率约 **61.94% / 63.87% / 64.58%**
- 中证500中，融券余额占比因子IC均值约 **-3.39% / -3.69% / -4.15%**，IC胜率约 **64.95% / 65.98% / 65.98%**。
- 中证1000中：
  - 融券余额占比因子IC均值约 **-3.28% / -4.22% / -4.42%**
  - 融资买入额占融资余额比因子IC均值约 **-5.55% / -7.36% / -7.95%**
- 报告强调：手续费是使用融资融券因子时的关键约束。

## 局限性
- 策略对手续费和市场结构变化较敏感。
- 历史样本有效不代表未来持续有效。
