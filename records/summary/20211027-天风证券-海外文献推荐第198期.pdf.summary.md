# 分散化投资之死

- **source filename**: `20211027-天风证券-海外文献推荐第198期.pdf`
- **date**: 2021-10-27
- **institution / author**: 天风证券研究所；吴先兴、王喆（分析师）；原文作者 Rebonato
- **extraction confidence**: medium

## Core question
解释金融危机期间“所有资产一起下跌”的危机蔓延现象，判断相关性上升是否使传统跨资产分散化失效，以及分散化本身是否会放大共同风险。

## Methods / data
- 讨论危机蔓延、相关性和组合风险管理机制，比较正常时期与压力时期的相关结构。
- 回顾交易所股票市值、对冲基金行业及风险管理模型的演变，分析资产持有者趋同、杠杆和被动化对共同交易的影响。
- 以相关矩阵、尾部联动和组合层面风险为主要分析框架，强调危机状态下线性相关性的局限。

## Key findings
- 2007—2008年危机显示，名义上分散的资产可能在流动性冲击、去杠杆和风险限额触发时共同下跌。
- 危机蔓延并非完全新现象，但资产持有者趋同、指数化、风险预算和强制平仓使共同暴露更加明显。
- 低相关性在正常时期不能保证尾部独立；压力期相关性会跳升，使传统均值—方差分散化的保护能力下降。
- 报告提出，投资者追求相似的分散化组合可能反过来造成拥挤交易和系统性共振。

## Quant takeaways
- 组合构建应同时监控正常相关性、尾部相关性、共同流动性和拥挤度，使用条件相关、copula或压力情景替代静态协方差。
- 不应把资产数量等同于有效分散化；需测试危机期间的再平衡、杠杆、赎回和交易成本反馈。
