# 机器学习能用于基金组合构建吗？

- 原文路径：papers/classified/天风海外/20210407-天风证券-海外文献推荐第175期.pdf
- 系列：海外文献推荐系列
- 日期：2021-04-07
- 主题：risk, portfolio, and asset allocation、financial machine learning methodology

## 核心结论
- 机器学习可以利用多个公开基金特征，动态预测并筛选未来表现较好的主动股票型共同基金。
- 梯度提升和随机森林能够构建风险调整后正且统计显著的基金组合，样本外风险调整年回报最高约4.2%。
- 多变量预测优于只使用单一基金特征，特征重要性会随时间变化，因此需要动态重估。
- 所有组合的alpha在样本后期下降，机器学习只能在市场仍存在可提取alpha时发挥作用。

## 方法要点
研究使用CRSP无生存偏差美国共同基金数据库的月度数据，将基金份额层面特征转为年度目标和滞后预测变量，比较弹性网、随机森林、梯度提升与OLS，并通过样本分割和滚动再平衡进行样本外基金组合选择。

## 结果与局限
样本覆盖1980—2018年、6216只主动股票型基金份额类别；梯度提升和随机森林表现突出，但组合alpha随时间递减，且结果可能受交易成本、基金筛选规则、市场竞争和历史特征关系变化影响。
