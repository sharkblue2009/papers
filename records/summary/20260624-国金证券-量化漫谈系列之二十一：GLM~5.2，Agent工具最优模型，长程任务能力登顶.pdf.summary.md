# GLM-5.2：面向长程Agent任务的开源模型评测

- 原文路径：papers/broker/202610/20260624-国金证券-量化漫谈系列之二十一：GLM~5.2，Agent工具最优模型，长程任务能力登顶.pdf
- 系列：量化漫谈系列之二十一
- 日期：2026-06-24
- 主题：financial machine learning methodology、other / unclassified

## 核心结论
- 报告介绍智谱AI于2026年6月17日发布并开源的GLM-5.2；模型采用MIT协议，支持100万token无损上下文，定位于AI Coding和长程Agent任务。
- 在FrontierSWE、PostTrainBench和SWE-Marathon三项长程任务基准中，GLM-5.2均为开源模型最高；FrontierSWE得分74.4%，距Claude Opus 4.8的75.1%约1个百分点。
- 架构采用IndexShare索引共享和MTP推测解码等优化，在1M上下文下单token FLOPs降低约2.9倍，MTP acceptance length提升约20%。
- CFLUE金融应用评估显示其金融文本分类、信息抽取和阅读理解能力较强；实测还覆盖Parquet数据分析、研报网页爬虫和A股择时回测等端到端投研任务。
- 高频“金”组合中证1000指数增强策略年化超额收益8.28%、超额最大回撤12.21%；加入基本面因子的共振组合年化超额收益13.33%、超额最大回撤5.14%。

## 方法要点
前半部分按长上下文、Coding基准、架构机制和CFLUE金融任务评估模型能力，并用ZCode+GLM-5.2实测数据分析、网页爬虫和择时回测交付。后半部分跟踪价格区间、量价背离、遗憾规避和斜率凸性四类高频因子，再将高频因子等权合成中证1000指数增强组合，并与三个基本面因子等权合成共振组合。

## 结果与局限
年内价格区间和量价背离因子多头超额分别为6.89%和7.05%，遗憾规避、斜率凸性因子分别为-2.57%和-3.09%；模型和策略展示了长程工程交付与量化应用的结合。局限包括高频因子近期表现波动、部分因子长期稳定性不足，以及历史回测不代表未来。市场变化、交易成本、模型输出随机性和提示词变化都可能使实际效果偏离报告结果。
