# 期权交易信息聚合

- **source filename**: `20200408-天风证券-海外文献推荐第131期.pdf`
- **date**: 2020-04-08
- **institution / author**: 天风证券；吴先兴（分析师）
- **extraction confidence**: high

## Core question
报告研究如何把同一标的、不同执行价和到期日的期权订单失衡聚合为股票价格和波动率信息。关键是按期权对不同风险维度的Delta、Vega敞口加权，并控制信用或崩盘风险交易的干扰。

## Methods / data
- 使用OPRA期权交易报价和NYSE股票报价，样本为QQQQ期权，2006年2月1日至12月29日共231个交易日、1,087,778笔交易。
- 先按Lee-Ready方法识别交易方向，再构造ADOI（aggregate Delta order imbalance）和AVOI（aggregate Vega order imbalance）。
- 比较不同执行价、到期日和权重聚合方式与同期及未来股票收益、实现波动率的相关性。

## Key findings
- 期权交易中46.6%为买入、53.4%为卖出，79.91%在60天内到期；未分类交易仅0.86%。
- ADOI与同期及未来股票收益正相关，但预测窗口超过1分钟后大多不显著；Strike Discount（KD）聚合方法相关性最高。
- AVOI与实现波动率正相关，预测能力可持续至15分钟；到期日折现的Maturity Discount方法对未来波动预测最强，短窗口聚合反而噪声较大。

## Quant takeaways
- 期权微观结构因子应按Delta/Vega和期限加权，不能把所有合约等权相加。
- 股票方向信息适合超短周期，波动率信息可用更长聚合窗口；应分别设计预测 horizon。
- 结论仅来自QQQQ单一ETF和2006年样本，实际部署需处理跨交易所同步、报价延迟、跳跃和交易成本。
