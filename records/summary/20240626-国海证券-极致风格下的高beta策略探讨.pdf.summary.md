# 摘要
- 源文件：20240626-国海证券-极致风格下的高beta策略探讨.pdf
- 机构：国海证券
- 日期：2024-06-26
- 类型：证券研究报告/量化策略探讨
- 主题：在大小盘与成长价值框架下，梳理不同风格象限中最有效的特质因子，并构建高 beta/风格极致化增强策略。
- 方法/数据：将A股非ST股票按自由流通市值与价值-成长因子交叉分组，基于分组收益单调性、IC/ICIR筛选各象限强势因子，再分别构建大盘价值、大盘成长、小盘价值、小盘成长策略。
- 主要结论：
  1. 量价因子在价值风格中通常更优，低波动、低流动性、长期反转等对不同象限有明显差异。
  2. 基本面因子在成长/价值之间存在显著侧重：盈利能力更偏成长，分析师预期更偏价值。
  3. 四个风格象限的增强策略均能获得正向超额，其中小盘价值和小盘成长策略表现更突出。
  4. 2014-05-05 至 2024-05-31 区间内，四类策略年化收益约 15%-24%，夏普比约 0.54-1.00。
- 量化要点：
  - 不同风格象限应使用不同的因子池和剔除规则，不能用单一因子框架一把抓。
  - 风格极致化有利于提升单一象限的选股效率。
- 局限：
  - 结果依赖风格划分和样本期，历史风格轮动与未来不一定一致。
- 关键词：高beta、风格分层、成长价值、分组回测、增强策略。
