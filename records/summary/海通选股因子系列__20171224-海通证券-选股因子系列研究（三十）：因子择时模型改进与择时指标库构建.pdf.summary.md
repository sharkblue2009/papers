# 海通证券选股因子系列研究（三十）：因子择时模型改进与择时指标库构建

- **source filename**: `20171224-海通证券-选股因子系列研究（三十）：因子择时模型改进与择时指标库构建.pdf`
- **date**: 2017-12-24
- **document type**: 金融工程专题报告

## Core question
如何改进 2017 年前期的条件期望因子择时框架，使其更易理解、易操作，并构建更完整的择时指标库。

## Methods / data
- 回顾并改造前期 **条件期望因子择时模型**，强调回归法表达更清晰。
- 讨论现有模型问题：择时变量太少、同一指标套所有因子、筛选复杂、难与衰减加权结合、难扩展为风格择时。
- 从 **宏观经济、金融市场、因子表现** 三个层次构建择时指标备选库。

## Key findings
- 条件期望因子择时模型在 2017 年表现较好：截至 2017-11-30，择时组合 2017 年以来收益约 **11%**，不择时组合约 **-20%**，超额约 **31%**。
- 虽然有效，但原框架有明显改进空间，尤其是择时指标库过窄和扩展性不足。
- 回归法框架更适合落地，便于把因子收益预测写成标准化模型。
- 择时指标可从宏观、股票市场和因子历史表现三层扩展，为后续模型升级打基础。

## Quant takeaways
- 因子择时需要一个真正“可维护”的指标库，而不是几个固定信号。
- 宏观、市场、因子自身三层信息可以共同决定权重切换。
- 择时框架改进的重点是 **可扩展性与可操作性**。

## Caveats
- 本篇更多是框架升级与路线图，细节留给后续报告。
- 2017 年表现不错，但仍需防止风格极端切换时失效。
