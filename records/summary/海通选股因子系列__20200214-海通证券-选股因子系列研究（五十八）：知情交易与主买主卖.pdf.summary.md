# 海通证券选股因子系列研究（五十八）：知情交易与主买主卖

- **source filename**: `20200214-海通证券-选股因子系列研究（五十八）：知情交易与主买主卖.pdf`
- **date**: 2020-02-14
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 金融工程专题报告

## Core question
在主买主卖基础上，引入“知情交易概率”过滤噪音后，是否能得到更稳健的高频选股因子。

## Methods / data
基于知情交易概率模型，把逐笔成交中的主买/主卖拆成知情主买、知情主卖，并构造知情主卖占比、知情主买占比、知情净主买占比等因子；再做不同计算口径、不同指数范围和正交后的月度回测。

## Key findings
- 全天知情主卖占比与开盘后知情主卖占比最稳健，正交前后都较强。
- 开盘后知情主卖占比（占同时段成交）较强，月均IC绝对值接近0.03，ICIR绝对值约3.5，月度多空收益约0.94%。
- 收盘前知情主买占比较强，月度多空收益约1.28%，月胜率超过80%。
- 开盘后知情净主买占比也有效，月均IC约0.02，ICIR约2.8~3.0。
- 知情主卖类因子在中证800/500里更稳，在沪深300里弱一些；知情净主买随选股范围缩小而减弱。

## Quant takeaways
把“主买主卖”再按知情交易概率过滤后，能更接近真实资金动机；其中卖出端的可解释性和稳定性反而更强。

## Caveats
模型依赖知情交易概率估计，口径切换会影响效果；高频信号仍受流动性与样本期约束。
