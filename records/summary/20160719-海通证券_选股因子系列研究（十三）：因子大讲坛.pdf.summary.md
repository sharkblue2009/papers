# 海通证券选股因子系列研究（十三）：因子大讲坛

- **source filename**: `20160719-海通证券_选股因子系列研究（十三）：因子大讲坛.pdf`
- **date**: 2016-07-19
- **document type**: 金融工程专题报告

## Core question
海内外常见技术因子和财务因子，哪些在 A 股里真的有效，效果是否会随市场环境、风格与样本窗口变化。

## Methods / data
- 汇总 **18 种技术因子** 与 **33 种财务因子**，按月/按季构建多空组合并做单因子检验。
- 分别考察全样本、市场涨跌环境、市值/反转等风险因子剔除后的效果。
- 同时观察因子收益的持续性：是否能连续两期维持方向一致和显著性。

## Key findings
- **技术类因子整体强于财务类因子**：月度构建的技术因子里，有 **10 种** 平均年化多空收益超过 **8%**，最强的两类因子收益约 **23.90%/21.93%**。
- 多数技术因子的秩相关和持续性较好，说明其不仅“能赚”，而且“能持续”。
- 在 **上涨市** 中，因子组合下月表现普遍优于总体；在 **下跌市** 中则相反，说明市场状态会显著影响因子暴露。
- 剔除 **市值** 或 **反转** 后，很多技术因子仍保留有效性，只是收益和稳定性发生变化；财务因子整体更弱，仅少数有效。

## Quant takeaways
- 行情/技术数据在 A 股更容易挖掘到可交易 alpha，尤其是短中期月度信号。
- 因子研究要分层看：先看全样本，再看市场状态，再做风格中性化，最后才评估可交易性。
- 市值和反转既是风险因子，也是解释很多技术因子的“共因子”，处理后更容易识别真 alpha。

## Caveats
- 本报告样本区间长期偏牛，可能抬高了部分因子的表观有效性。
- 不同市场状态下结论会反转，说明择时和风格控制很重要。
