# 因子动量与动量因子

- **source filename**: `20190306-天风证券-海外文献推荐第77期.pdf`
- **date**: 2019-03-06
- **institution / author**: 天风证券研究所；吴先兴；原文作者 Ehsani、Linnainmaa
- **extraction confidence**: high

## Core question
论文重新解释动量：动量是否是独立风险因子，还是其他因子收益正自相关的汇总。研究进一步考察因子动量如何传导为个股、行业和各种股票动量。

## Methods / data
- 使用Kenneth French、AQR和Robert Stambaugh数据库；美国15个因子大多始于1963年7月，全球7个因子始于1990年。
- 对最多20个因子按过去一年收益构造时间序列和横截面动量，月度再平衡，并分解自相关、交叉协方差和平均收益差异。
- 将因子结构映射到股票横截面，加入Fama-French五因子和动量模型，按情绪状态检验稳定性。

## Key findings
- 20个因子在过去一年盈利后平均未来月收益52bp，亏损后仅2bp，差异t=4.67。
- 时间序列因子动量年化收益4.2%、t=7.04；横截面因子动量年化2.8%、t=5.74。
- 横截面策略优势中自相关贡献约年化2.9%，交叉协方差贡献约-1.0%；低情绪时赢家—输家差71bp、t=4.79，高情绪时仅18bp、t=1.32。

## Quant takeaways
- 可把因子收益自相关作为动量策略的核心状态变量，并在动量崩溃前降低暴露。
- 个股动量可能是因子动量和beta异质性的结果，不宜简单当作独立风险因子；需控制因子重叠、换手和情绪条件。
