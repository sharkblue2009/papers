# 海通证券选股因子系列研究（七十三）：使用基本面逻辑改进ROE因子

- **source filename**: `20210317-海通证券-选股因子系列研究（七十三）：使用基本面逻辑改进ROE因子.pdf`
- **date**: 2021-03-17
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、余浩淼
- **document type**: 金融工程专题报告

## Core question
如何用更强的基本面逻辑，缓解“最新披露 ROE”对当期真实 ROE 的滞后，进而提升 ROE 因子选股效果。

## Methods / data
比较最新披露 ROE 与当期真实 ROE 的选股能力；引入一致预期 ROE 作为增量信息；再结合历史 ROE 波动率做加权修正；回测时间覆盖 2013-2021 年。

## Key findings
- 最新披露 ROE 存在明显时滞，直接用于选股会显著打折。
- 叠加 **一致预期 ROE** 后，对当期真实 ROE 的预测精度明显提升。
- 再用 **ROE 波动率加权**，可进一步改善预测效果。
- 基于上述思路构建的新 ROE 因子，较传统最新披露 ROE 的 **IC 和月均溢价约提升 50%**。
- 作者强调：先预测“未公布的真实财务数据”，再用预测值选股，往往比单纯数据挖掘更稳。

## Quant takeaways
这是一条“基本面优先、统计修正辅助”的改进路径：先修正披露滞后，再谈因子增强。

## Caveats
结果依赖一致预期覆盖度、财报滞后假设和历史统计稳定性；模型误设与风格变化都可能削弱效果。
