# 海通证券选股因子系列研究（五十二）：基于回归树的因子择时模型

- **date**: 2019-08-06
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 金融工程专题报告

## Core question
用回归树放松线性假设，构造更直观的情景化因子择时模型。

## Methods / data
以市值因子等为例，用近 5 年/10 年历史数据训练回归树，并与因子收益动量和防御性择时组合结合。

## Key findings
- 回归树能找到区分因子收益的市场环境，规则直观、可解释。
- 在 2017 年因子转向时，择时组合回撤比长期持有更小。
- 但在因子强势阶段，纯回归树可能弱于长期持有。
- 防御性择时更稳健：当不确定性高时，关闭因子敞口比硬猜方向更合理。

## Quant takeaways
- 因子择时不必追求每个月都预测得很准，稳健的“少做错”更重要。
- 树模型更适合做环境划分，不一定适合完全替代动量模型。

## Caveats
- 情景规则容易受样本窗口影响。
