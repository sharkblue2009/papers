# 海通证券选股因子系列研究（四十）：预期因子的底层数据处理

- **source filename**: `20181019-海通证券-选股因子系列研究（四十）：预期因子的底层数据处理.pdf`
- **date**: 2018-10-19
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、郑雅斌
- **document type**: 金融工程专题报告

## Core question
比较一致预期因子的底层数据拼接/平滑方式，寻找最稳健的构造方法。

## Methods / data
围绕预期 ROE、净利润、净利润同比、复合增速等指标，对比平滑算法、锁定最近年度和锁定财务年度三种底层处理。

## Key findings
- 推荐对一致预期做时间序列标准化，先把“预期调整因子”做成统一口径。
- 锁定财务年度算法整体表现最好，尤其在因子溢价和多空收益上更稳。
- 平滑算法在单边做多场景里更有优势，信息比往往更高。
- 不同因子的最优处理方式并不完全一致，G 因子受未来多期预测影响更敏感。

## Quant takeaways
- 一致预期因子能不能用，底层数据处理方式几乎决定一半效果。
- 数据口径统一比后续模型复杂化更重要。

## Caveats
- 若预测数据本身噪声大，任何加工都有限。
