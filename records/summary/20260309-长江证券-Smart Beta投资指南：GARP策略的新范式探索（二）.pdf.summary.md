# 研报摘要

- **来源文件**：20260309-长江证券-Smart Beta投资指南：GARP策略的新范式探索（二）.pdf
- **日期/机构/类型**：2026-03-09，长江证券，金融工程深度报告
- **核心问题**：如何在A股环境中优化传统GARP策略，使其同时兼顾成长、估值和质量。
- **方法/数据**：构建PE-PEG九宫格分类体系，遵循“安全边际优先”；再结合生命周期理论与双维度盈利质量检验，通过成长约束、质量护航、权重重塑三阶段完成30组合构建。
- **关键结论**：优化后的GARP框架比传统做法更适配A股，能在牛熊环境中维持较强收益稳定性。
- **量化要点**：报告称自2015年以来相对中证全指分年胜率约92%，体现出较强稳健性。
- **局限性**：策略对估值、成长与质量口径较敏感，且高胜率主要来源于历史样本。
- **关键词**：GARP、PE-PEG、Smart Beta、盈利质量、A股适配、组合构建
