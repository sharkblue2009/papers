# 海通证券选股因子系列研究（八十八）：多颗粒度特征的深度学习模型，探索和对比

- **source filename**: `20230911-海通证券-选股因子系列研究（八十八）：多颗粒度特征的深度学习模型，探索和对比.pdf`
- **date**: 2023-09-11
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 金融工程专题报告

## Core question
不同频率下计算出来的同类特征，是否包含互补信息；多颗粒度深度学习模型能否稳定优于单颗粒度模型。

## Methods / data
比较两类多颗粒度建模方式：1）多颗粒度输入、一次性训练；2）单颗粒度训练、输出集成。进一步测试双向 AGRU+注意力、多颗粒度残差学习网络，并在中证500/1000 AI 增强组合中评估。

## Key findings
- 多颗粒度模型在不同标签长度、调仓频率和成交价格假设下，整体都优于单颗粒度模型。
- 实战中**输出集成**方式效果最好，10日标签对应的费前年化超额收益可达 **31.5%**。
- **双向 AGRU 多颗粒度模型**进一步提升 RankIC、ICIR 和多头超额，周均 RankIC 超过 **0.12**，Top10% 和 Top100 组合费前超额分别约 **33%** 和 **40%**。
- 多颗粒度残差学习的思路是把不同粒度中“重复的信息”剔掉，只保留每一层独有的信息，再做集成。
- 将双向 AGRU 输出用于 AI 增强组合时，2017.01-2023.07 无成分股约束下，中证500和中证1000分别可实现约 **15%-20%** 和 **25%-30%** 的年化超额；加上 **80% 成分股权重约束** 后，收益分别下降约 **5-6%** 和 **2-3%**。

## Quant takeaways
这篇报告把“同一信号在不同频率上的信息互补性”讲得很清楚：多颗粒度不是简单堆特征，而是把时间尺度差异转化成模型增益。

## Caveats
多颗粒度模型对约束条件仍敏感；约束越严格，组合收益越容易回落。
