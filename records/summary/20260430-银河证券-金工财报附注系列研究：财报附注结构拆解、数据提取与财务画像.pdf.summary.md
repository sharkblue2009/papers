# PDF总结

- **来源文件**：`20260430-银河证券-金工财报附注系列研究：财报附注结构拆解、数据提取与财务画像.pdf`
- **文档类型**：金融工程专题报告 / 财报数据工程
- **核心主题**：拆解财报附注结构，构建自动化数据提取与财务画像能力，并探索附注因子。
- **方法与数据**：数据来自巨潮资讯爬虫；通过语义定位、结构清洗、标题锚定和 LLM 语义归纳形成全流程提取；覆盖资产负债表、利润表、现金流量表、表外项目、管理层讨论与分析五大模块，提取23个核心科目、79个细分数据列；LLM默认模型为 gemma3:4b。
- **关键发现**：财报附注比三张主表提供更强增量信息；自动化提取可用于生成“财务综合画像”并封装为可安装 Skill；基于提取数据构建的附注基本面因子在科创板测试中表现出较高完整度、较低相关性。
