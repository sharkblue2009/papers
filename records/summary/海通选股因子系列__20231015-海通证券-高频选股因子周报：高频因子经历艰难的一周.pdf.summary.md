# 海通证券高频选股因子周报：高频因子经历艰难的一周

- **source filename**: `20231015-海通证券-高频选股因子周报：高频因子经历艰难的一周.pdf`
- **date**: 2023-10-15（周报覆盖 2023-10-09 至 2023-10-13）
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 金融工程周报

## Core question
本周高频因子和AI增强组合表现如何，短期波动是否改变中长期高频因子的有效性判断。

## Methods / data
跟踪多类高频手工因子与深度学习高频因子在本周、10月和2023年累计的多空收益，并同步观察周度调仓的中证500/1000 AI增强组合。

## Key findings
- 本周整体是“艰难的一周”：多数手工高频因子当周回撤，但年内累计表现仍不弱。
- 高频偏度因子、下行波动占比因子本周多空收益分别约 **-1.41%**、**-0.96%**。
- 开盘后买入意愿、买入强度、大单净买入等因子本周普遍为负，说明短期风格和市场状态对高频信号影响很大。
- 深度学习高频因子当周也有回撤，但年内累计仍显著领先：GRU类因子年内多空收益约 **29%-38%**，多颗粒度模型更高，约 **51.68%** 和 **53.85%**。
- 周度调仓的 AI 增强组合年内仍保持正超额：中证500约 **18.02%**，中证1000约 **21.81%**；只是本周短期波动分化，CSI1000当周为负。

## Quant takeaways
这类周报最大的价值是提醒：高频因子长期有效，并不代表每周都顺；短周期噪声很大，但累计表现仍能证明模型的稳定性。

## Caveats
周报口径受短期市场风格影响明显，不宜拿单周表现直接否定因子有效性。
