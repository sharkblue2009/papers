- **date**: 2020-06-23
- **institution**: 海通证券 / 金融工程研究
- **authors**: 冯佳睿、袁林青
- **document type**: 金融工程专题报告

## Core question
既然高频因子预测周期短，能否不改变组合换仓频率，而是在调仓环节利用它们做收益增强。

## Methods / data
用短周期高频因子（如尾盘成交占比、改进反转、下行波动占比、开盘后买入意愿强度）在不同回看窗口和调仓频率下回测；再构造单因子和复合因子调仓优化策略，检验对中证500/沪深300增强的增益。

## Key findings
- 因子预测周期越短，调仓频率越高，选股能力通常越强。
- 单因子调仓优化就能增强收益，但复合高频因子更稳健。
- 对中证500增强，调仓优化策略可带来约1%~2%年化收益增强；对沪深300增强，约0.5%左右。
- IC加权的复合方式通常优于等权复合。
- 组合调仓价格和基础组合换手率会显著影响增益空间，基础换手越低，留给调仓优化的空间越小。

## Quant takeaways
高频因子不一定要直接塞进主alpha模型，放在“调仓优化”这个环节，往往更容易拿到可实现的增益。

## Caveats
收益增强对执行价格、基础组合换手和回看窗口都比较敏感；落地时要把交易成本和调仓约束一起看。
