# 长期任职基金经理的业绩表现

- **source filename**: `20200826-天风证券-海外文献推荐第148期.pdf`
- **date**: 2020-08-26
- **institution / author**: 天风证券；吴先兴；原文作者 Andrew Clare
- **extraction confidence**: high

## Core question
本文研究管理同一基金至少十年的美国主动基金经理是否具有更好的风险调整后业绩，以及这种业绩是否可持续。报告同时寻找长期任职优秀经理与基金费用、持仓集中度、规模和风格之间的关系。

## Methods / data
- 从Morningstar获取截至2014年12月任期超过十年的美国主动基金经理和相关基金，样本为357个经理/基金观测。
- 使用基金2005年1月至2014年12月月度总收益、基准调整收益、资产、持仓数量、费用及团队规模。
- 以基准调整收益和Carhart/Fama-French因子回归衡量业绩，并做年度十分位持续性检验与经理特征横截面回归。

## Key findings
- 经理平均任期16年；样本基金平均月净收益0.79%，平均基准调整收益0.04%，年化约低于0.50%。
- 超过60%的经理十年期扣费表现优于基准，整体超过基准约每年0.40%。
- 业绩前十分位与后十分位年度月度基准调整收益差约1.32%—3.71%，但年度业绩在九年中没有显著持续性。
- 低费用、较少持股、相对小盘偏好及负价值偏好的基金表现更好；任期越长，超额收益趋于下降。

## Quant takeaways
- 基金筛选不能只看长期平均alpha，应同时检验滚动持续性、存活偏差和风格暴露。
- 可将费用、持仓集中度、基金与团队规模及SMB/HML beta作为候选横截面特征。
- 样本只包含存活且任期长的经理，存在明显幸存者偏差；性别等特征的统计结论也不稳定。
