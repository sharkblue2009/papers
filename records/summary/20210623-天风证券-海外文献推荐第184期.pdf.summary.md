# 市盈率、商业周期与股票市场择时

- **source filename**: `20210623-天风证券-海外文献推荐第184期.pdf`
- **date**: 2021-06-23
- **institution / author**: 天风证券研究所；吴先兴（分析师）；原文作者 Park, Sangkyun
- **extraction confidence**: high

## Core question
研究市盈率与未来股票市场表现、市场基本面和错误定价之间的关系，并检验依据估值或商业周期择时是否能获得可观收益。

## Methods / data
- 使用1871—2020年美国月度股市数据，覆盖149年。
- 以周期调整市盈率（CAPE）和传统市盈率（PERC）衡量估值，以2年、10年已实现股权溢价（REP）及历史市盈率一致价格下的REP-HH衡量未来表现。
- 构建由盈利增长、股息支付率、无风险利率等解释的公允市盈率，并比较衰退前后择时。

## Key findings
- 市盈率与2年、10年REP均呈反向关系；PERC对公允市盈率的解释能力较强，已实现价格模型中公允PE系数约0.45，部分模型拟合度超过0.3。
- 高CAPE前10%样本的10年REP仍为正2.27%，前5%约为-0.11%；短期T5择时两年平均可领先无风险资产约3.2个百分点。
- 衰退前3个月卖出、复苏前3个月买回，平均可避免约15.80%的跌幅；示例中11年累计额外收益约30个百分点。

## Quant takeaways
- CAPE/PERC可作为长期估值和低估买入信号，但高估卖出信号的收益小且受税收、错过上涨和预测误差影响。
- 可回测“估值分位数+衰退概率”的择时模型，并分开评估2年与10年持有期；商业周期信号的样本外稳定性和假阳性风险仍需检验。
