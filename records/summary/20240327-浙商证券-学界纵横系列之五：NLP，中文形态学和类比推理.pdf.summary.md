# 研报摘要

- source file: `20240327-浙商证券-学界纵横系列之五：NLP，中文形态学和类比推理.pdf`
- date: 2024-03-27
- institution: 浙商证券
- type: 金融工程深度

## 核心主题
围绕中文词向量与类比推理任务，分析汉语形态学、语义关系及表示学习方法的差异。

## 方法与数据
- 基于原论文构建 68 个隐性形态关系、28 个显性语义关系，形成平衡数据集 CA8，共 17813 个问题。
- 比较 SGNS 与 PPMI 两类词向量表示。
- 比较 N-gram、字符特征与不同语料库对类比推理的影响。

## 主要发现
- SGNS 更适合形态关系推理，PPMI 更适合语义关系推理。
- 字符特征对中文形态关系帮助显著，融合字符特征后形态问题准确率可接近翻倍。
- 语料库越大、领域越贴近任务，效果越好；组合语料表现最佳。
- CA8 可作为中文词向量评估的可靠基准。

## 量化要点
- CA8 包含 17813 个问题。
- 形态关系有 68 类，语义关系有 28 类。
- 最佳配置在 CA8 上的准确率可达 68.0%。

## 局限性
- 报告为文献解读与翻译，可能与原文存在理解偏差。
- 结论主要来自特定基准数据集，不代表所有中文 NLP 任务。
