# 异象策略的相关性结构

- **source filename**: `20201021-天风证券-海外文献推荐第154期.pdf`
- **date**: 2020-10-21
- **institution / author**: 天风证券；吴先兴；原文作者 Paul Geertsema、Helen Lu
- **extraction confidence**: high

## Core question
本文不把大量异象视为彼此独立，而是按收益相关性聚类，寻找当前资产定价模型遗漏的共同维度。研究进一步用降维搜索构建能够解释异象集群和显著alpha的精简因子模型。

## Methods / data
- 使用美国NYSE、Amex和Nasdaq普通股月度数据，样本为1963年7月至2019年12月。
- 从215种异象策略中按5%显著性筛得80种，再以相关性距离和层次聚类构造集群组合。
- 相关性阈值设为0.4；从41个候选因子中用Best-First Search分别最小化显著alpha数量和无法解释方差。

## Key findings
- 80种显著异象被聚为28个集群，28簇时3,160对相关的误分类最少，仅236对。
- 即使最佳五因子模型下，28个集群仍有10个（36%）alpha在5%水平显著。
- 最小化alpha的9因子模型包括EG、Accruals、SMB、IssuanceAndYield、市场、STREV、Seasonality、CapexGrowth和EPS consistency。
- 基准HMXZ5的最大平方夏普比约0.37，增强9因子模型约0.51；重抽样100,000次后结论仍保持。

## Quant takeaways
- 因子研究应按收益相关性做聚类，避免把同一经济维度重复计入有效因子数量。
- 集群组合可作为更平衡的模型检验资产，重点关注预期增长、应计、短期反转和季节性。
- Best-First Search存在数据挖掘风险，9因子是样本内上界而非唯一模型；需样本外验证和多重检验控制。
