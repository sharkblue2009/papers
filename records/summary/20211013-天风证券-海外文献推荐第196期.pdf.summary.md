# 低波策略的波动率择时

- **source filename**: `20211013-天风证券-海外文献推荐第196期.pdf`
- **date**: 2021-10-13
- **institution / author**: 天风证券研究所；吴先兴（分析师）；原文作者 Moreira、Muir
- **extraction confidence**: high

## Core question
研究低波动率组合的收益曲线是否包含市场状态信息，并检验根据波动率十分位收益分布斜率进行择时，能否改善传统低波策略。

## Methods / data
- 按历史收益波动率构建十分位股票组合，比较低、中、高波动组合的收益、相关性与市场状态表现。
- 以十分位组合收益率分布的斜率作为信号，在低、中、高波动组合之间切换；与简单低波、市场择时和CAPM/Fama-French因子进行比较。
- 评估年化收益、波动、夏普、累计净值，并开展不同持有期和因子调整稳健性检验。

## Key findings
- 波动率择时策略相较简单低波策略的夏普比率约从0.48提高至0.65，提升约30%。
- 双边波动率择时的累计收益提升超过1125%，呈数量级差异；策略在熊市偏向更分散的组合，在牛市偏向增长型组合。
- 高波动股票之间的相关性更强，低波组合并非在所有市场状态都具有最优分散化；收益曲线斜率能够识别这种状态变化。

## Quant takeaways
- 可把横截面波动率分布斜率加入低波因子模型，构建状态切换或动态风险预算策略。
- 回测应严格使用形成期可得信息，控制换手、空头约束、波动率估计窗口和市场冲击；超高累计收益尤其需要样本外与成本压力测试。
