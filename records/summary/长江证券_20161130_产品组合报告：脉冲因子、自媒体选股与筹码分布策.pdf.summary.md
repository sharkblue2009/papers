# 长江证券金融工程产品组合报告——脉冲因子、自媒体选股与筹码分布策略调仓

- **date**: 2016-11-28
- **institution / author**: 长江证券金融工程团队；覃川桃；联系人陈奕、杨靖凤
- **extraction confidence**: medium

## Core question
报告将事件脉冲、自媒体热度、行业交叉、资金流向和筹码分布策略产品化，公布组合规则、历史回测和调仓跟踪。目标是以标准化组合代码进行事前发布、事后跟踪和策略迭代。

## Methods / data
- 事件脉冲月初持有30只；社交自媒体沪深300增强月初50只；行业交叉周度20只；资金流向半月50只；筹码分布月初50只。
- 事件策略最多持仓、等权分配、排除ST/停牌/涨停延迟买入，所有策略考虑双边交易成本0.3%。
- 筹码策略以成交均价、换手率估计分布，结合均值、方差、偏度、峰度形成综合分数；Wind/天软用于回测和跟踪。

## Key findings
- 事件脉冲策略综合年化收益32.77%、Sharpe 1.0278、绝对胜率56.66%、最大回撤-48.85%；相对沪深300超额26.26%。
- 2016年3月起自媒体沪深300增强跟踪收益29.65%，超额沪深300为8.9%。
- 行业交叉策略自2016年8月起收益4.86%、超额0.61%；资金流向策略自年初收益14.74%、超额18.46%。
- 筹码分布策略自2016年11月跟踪收益2.47%，相对中证500超额-0.86%；图表型策略部分缺少统一数值。

## Quant takeaways
- 可复刻为事件、文本热度、分析师网络、资金流和筹码因子的组合库，分别评估信号半衰期。
- 事前公布调仓有助于减少回测偏差，但要记录滑点、成交可得性和容量。
- 历史回测与短期跟踪混列，且部分结果来自图表；需在统一样本、成本和基准下重新验证。
