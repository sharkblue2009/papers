# ESG 的Alpha, Beta 和Sigma:更好的Beta，额外的Alpha?

- **source filename**: `20210730-天风证券-海外文献推荐第188期.pdf`
- **date**: 2021-07-30
- **institution / author**: 天风证券研究所；吴先兴、惠政宝（分析师）；原文作者 Jacobsen、Wai Lee、Chao Ma
- **extraction confidence**: medium

## Core question
比较高ESG评级股票与非ESG股票的收益、因子暴露及残差风险，判断ESG约束是否带来不可避免的回报代价，以及能否构建更好的ESG beta。

## Methods / data
- 使用MSCI USA与MSCI EAFE及其ESG Leaders指数，分析美国和其他发达市场股票；美国样本含332只ESG、263只非ESG股票，EAFE含340只ESG、546只非ESG股票。
- 使用Fama-French五因子加动量模型，比较个股alpha、总波动率和残差波动率，并构建5—100只股票的随机组合。
- 另以Russell 3000治理评分组合检验供应商评分差异，月度再平衡、年度调仓。

## Key findings
- 美国ESG与非ESG个股平均月收益/标准差比分别约0.15和0.17；EAFE分别为0.108和0.11，差异有限。
- 因子调整后，美国ESG股票平均残差波动率5.49%，非ESG为6.15%；总波动率约7.05%，差异在统计上显著。
- 美国样本中正alpha比例为ESG 6.33%、非ESG 8.75%；对统计上不显著alpha的股票，ESG组合残差波动更低。
- 不同治理评分组合在2014年4月至2018年12月的月回报相关性仅0.23。

## Quant takeaways
- ESG组合应先做行业及风格因子中和，再比较alpha和风险；简单比较总收益容易把大盘、价值、盈利或低波暴露误当成ESG效果。
- 评分供应商、覆盖范围和更新频率会显著影响信号；需测试评分变化、组合容量、相关性和交易成本。
