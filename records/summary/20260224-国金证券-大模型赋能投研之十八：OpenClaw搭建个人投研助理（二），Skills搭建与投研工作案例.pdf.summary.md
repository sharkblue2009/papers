# 报告摘要

- 来源文件：20260224-国金证券-大模型赋能投研之十八：OpenClaw搭建个人投研助理（二），Skills搭建与投研工作案例.pdf
- 日期 / 机构 / 类型：2026-02-24，国金证券，金融工程专题报告

## 核心问题
如何把 OpenClaw 从“临时调用工具”升级为“可长期运行的个人投研助手”，并用可复用的 Skills、Workspace 与调度机制承接真实投研任务。

## 方法 / 数据
基于 OpenClaw 的底层架构拆解，说明 Workspace、Memory、Tool、Soul、Skills、CronJob 的协作机制；结合 Claude Code 命令行工具进行环境配置、维修与调试；并用四类投研场景做工程化演示：每日 A 股公告处理、迭代投研框架、个股投研分析助手、自动化研报复现。

## 关键发现
- OpenClaw 的核心不是单轮对话，而是“状态容器 + 能力模块 + 定时调度”的事件驱动执行网络。
- Skills 适合把临时任务标准化、模块化，沉淀为可复用工作流。
- Claude Code 等命令行工具可显著降低部署、排障与维护门槛。
- 在公告汇总、个股研究与研报复现中，OpenClaw 能把分散流程整合成可执行链路，提高效率与可追溯性。

## 量化要点
- 该文以工程方法论和案例演示为主，不包含严格的回测收益指标。
- 更强调流程自动化、可复现性与标准化输出，而非传统收益率评价。

## 局限性
- 结论较依赖大模型输出稳定性，存在随机性与误差风险。
- Skills 与工作流需要持续维护，模型升级或功能变更可能导致表现变化。
- 自动化复现仍受数据可得性、解析质量与外部接口稳定性影响。
