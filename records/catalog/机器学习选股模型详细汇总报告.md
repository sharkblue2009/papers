# 机器学习选股模型详细汇总报告

> 范围：基于我已经阅读过、且摘要页中包含明确数值的券商研报，整理机器学习 / 深度学习 / 强化学习 / LLM 相关选股模型的表现对比。
>
> 重要说明：不同报告的股票池、调仓频率、交易假设、基准指数和收益口径不同，本文**不做严格同口径排名**，只做“可参考的粗对比”。

---

## 1. 总体判断

这批文献里，机器学习选股模型已经从早期的“传统分类器/回归器”，演进到：

1. **传统机器学习集成**：提升树、随机森林、ExtraTrees、Ridge/Lasso、多模型池
2. **深度学习时序模型**：GRU、LSTM、Transformer、Multi-Transformer
3. **时序 + 截面融合**：双流网络、图结构、风格信息、订单簿/逐笔/资金流输入
4. **强化学习闭环**：把因子挖掘和组合优化连起来
5. **LLM/自动化因子挖掘**：把大模型用于因子生成、假设迭代和自动化投研

从结果看，真正拉开差距的，往往不是“模型名字”，而是：

- 输入信息是否更接近市场微观结构
- 是否把时序信息和截面信息统一起来
- 是否显式控制风格、行业、换手和交易成本
- 是否把选股和组合优化做成闭环

## 3. 分方法路线详细对比

### 3.1 传统机器学习 / 集成模型

这类模型的共同特征是：

- 以历史因子或结构化特征为输入
- 用分类 / 回归 / 集成学习做预测
- 主要优势在于稳、可解释、易控风险
- 通常通过多模型集成、调仓频率、样本切分来提升效果

#### 代表文献

| 文献 | 模型/框架 | 场景 | 结果摘要 |
|---|---|---|---|
| **广发证券｜多周期机器学习选股模型** | 多模型集成 | 选股 | 年化超额 **38.97%**，Sharpe **3.89** |
| **长江证券｜截面融合模型选股框架初探** | 提升树、ExtraTrees、随机森林、Ridge、Lasso 等融合 | 截面选股 | 年化超额 **20.03%**，信息比 **2.93**，超额最大回撤 **7.27%** |
| **申万宏源｜机器学习算法在选股模型中的应用** | 逻辑回归 / SVM 等 | 选股 | 摘要页数值未完整展开，暂不纳入精确对比 |
| **华泰证券｜机器学习选股模型的调仓频率实证** | 调仓频率比较 | 选股 | 摘要页未完整展开核心数值，暂不纳入精确对比 |

#### 小结

传统 ML 的强项不是“模型新”，而是：

- 在结构化特征上做稳健集成
- 通过频率和样本设计放大优势
- 对交易约束和回撤更容易做工程化控制

### 3.2 深度学习 / 时序模型

这类模型更强调：

- 从原始时序中直接学习表征
- 用 GRU / LSTM / Transformer 建模时间依赖
- 通过多粒度、多特征、多网络融合提升效果

#### 代表文献

| 文献 | 模型/框架 | 场景 | 结果摘要 |
|---|---|---|---|
| **华源证券｜StyleNet** | 风格信息多因子挖掘模型 | 选股 / 指增 / 行业轮动 | 中证全指 RankIC **15.51%**；合成后年化多头超额 **49.42%**；沪深300 / 中证500 / 中证1000 年化超额 **15.09% / 17.83% / 27.98%** |
| **方正证券｜基于可微 RankIC 损失函数的深度学习选股策略** | 可微 RankIC loss | 20日收益预测 / 选股 | RankIC **12.48%**；RankICIR **5.41** |
| **东北证券｜融合订单簿信息的深度学习选股模型** | 订单簿 + 深度学习 | 选股 / 指增 | 月度策略年化 **31.31%**；RankIC **16.16%**；ICIR **1.40** |
| **国海证券｜多模式合成的 GRU 深度学习选股因子** | GRU + 多模式特征 | 选股 / 指增 | 2024 超额 **5.8%**；2025YTD 超额 **2.4%**；信息比率 **3.24** |
| **财通证券｜深度学习因子选股体系** | 时序 + 截面多网络 | 选股 / 指增 | 沪深300 指增组合年化收益 **18.2%**；子组合超额 **17.2% / 24.5%** |
| **华泰证券｜基于逐笔成交的深度学习选股模型** | Transformer | 高频 / 逐笔资金流选股 | 多头年化超额收益率从 **20.43% 提升到 22.56%**；另一组从 **20.06% 提升到 22.38%** |
| **德邦证券｜基于分钟数据的 GRU 模型在选股策略中的应用初探** | GRU | 分钟数据选股 / 指增 | 日均 RankIC 约 **7.5%**；沪深300 / 中证500 / 中证1000 增强组合跟踪误差控制在 **5%以内** |
| **西南证券｜PINN信息约束与时序截面双流网络选股模型** | Multi-Transformer / 双流网络 | 选股 / 指增 | 月 IC 均值 **10.95%**；组合年化收益约 **32.88%** |

#### 小结

深度学习路线里，表现最稳定的结论不是“某个网络绝对领先”，而是：

- **时序 + 截面融合** 往往优于单一视角
- **订单簿 / 逐笔 / 资金流** 等高频信息能显著增量
- **风格、行业、基本面结构** 也可以作为网络输入的一部分
- 真正有效的提升往往来自**信息组织方式**，而不只是模型层数

---

### 3.3 强化学习 / 闭环优化

这类方法把“选股”与“组合优化”连接起来，目标是减少传统流程中的割裂：

- 先挖因子
- 再打分
- 再做组合

强化学习框架更倾向于直接优化最终组合结果。

#### 代表文献

| 文献 | 模型/框架 | 场景 | 结果摘要 |
|---|---|---|---|
| **西南证券｜T2RL，端到端深度强化学习因子挖掘与组合优化框架** | TFAC + TFSAC | 因子挖掘 + 组合优化 | TFAC RankIC ≈ **0.1119**；全A日频调仓年化超额 **50.36%**；相对因子多头年化超额 **31.06%**；沪深300 年化超额 **30.87%** |
| **西南证券｜强化学习驱动下的解耦时序对比选股模型** | 强化学习 + 时序对比 | 选股 / 组合优化 | 多头组合年化收益 **34.77%**，显著优于线性基线 |

#### 小结

强化学习路线的核心优势在于：

- 能把因子挖掘和组合优化做成闭环
- 更自然地处理换手、成本、约束
- 适合从“信号预测”走向“策略执行”

但缺点也明显：

- 训练与验证更复杂
- 对数据质量、奖励设计、约束设定更敏感
- 解释性和稳定性仍需更强工程支持

---

### 3.4 LLM / 自动化因子挖掘

这条路线更偏“投研自动化”，不是传统意义上的最终选股器。

#### 代表文献

| 文献 | 模型/框架 | 场景 | 结果摘要 |
|---|---|---|---|
| **东方证券｜QuantaAlpha，用大模型做量化因子挖掘** | LLM + 进化算法 | 自动化因子挖掘 | 沪深300 上 IC 约 **0.1501**，年化超额约 **27.75%**；复现版本因规模较小，稳定性略弱 |

#### 小结

LLM 在选股研究中的价值，当前更多体现在：

- 自动生成假设
- 辅助因子构造与代码实现
- 增强因子迭代效率

而不是直接替代传统模型。

## 4. 稳定结论

综合这批文献，可以提炼出几条稳定经验：

### 4.1 高收益通常来自“信息增量”而不是“模型炫技”

表现强的报告，往往都引入了更接近市场结构的新信息：

- 订单簿
- 逐笔成交
- 资金流
- 风格信息
- 交易行为
- 多源特征融合

### 4.2 深度学习最适合作为“融合器”

深度学习在这类任务里更像：

- 非线性映射器
- 多源信息压缩器
- 时序/截面融合器

而不是单纯替代手工因子。

### 4.3 成本、换手、回撤比名义收益更关键

很多报告最终能落地，靠的不是最高的回测收益，而是：

- 回撤可控
- 跟踪误差可控
- 换手可控
- 指增场景下可实施

### 4.4 不同模型在不同任务里有分工

- **传统 ML**：更适合结构化特征、稳健基线、集成优化
- **深度学习**：更适合高维时序和多模态融合
- **强化学习**：更适合闭环组合优化
- **LLM**：更适合自动化因子生成和研究辅助

---

## 5. 当前最值得优先复用的模型路线

如果后续要做进一步策略开发，我会优先关注下面几类：

1. **订单簿 / 逐笔成交 + Transformer / GRU**
2. **时序 + 截面双流网络**
3. **风格信息显式建模**
4. **强化学习闭环选股 + 组合优化**
5. **多模型集成 / 传统 ML + 深度学习混合**

这几条路线比单纯的“换一个更大的网络”更有复用价值。

---

## 6. 一句话总结

当前已读文献中，机器学习选股模型的真正优势不在于某个单一算法，而在于**把高频/资金流/风格/截面/时序信息做成可交易的融合框架**；其中，**T2RL、StyleNet、广发多周期集成模型** 是收益表现最强的一批，**方正可微 RankIC、东北订单簿深度学习、国海 GRU、长江截面融合** 则更偏稳健增强型。
