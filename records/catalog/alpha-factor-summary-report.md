## 2. 各类因子的核心结论

### 2.1 价值/估值类
常见做法是用 PB、PE、股息率、低估值、红利价值等构造多头组合，通常再叠加行业/风格中性。

**优点**
- 解释性强，适合作为底仓风格因子
- 在红利、价值、质量混合框架中常能提供稳健收益

**局限**
- 容易受行业暴露影响
- 单独使用时对市场风格切换敏感

**数据需求**
- 日频复权价格、自由流通市值
- 财务报表、分红数据、行业分类

### 2.2 质量/盈利/现金流类
核心是把“赚钱能力”从静态财务指标中提炼出来，例如 ROE、净利润、毛利率变化、现金流实现率、无形资产、企业生命周期、竞争力结构等。

**代表指标**
- ROE 稳定/提升
- 毛利率变化
- 现金流实现率
- 企业竞争力、波特五力类指标

**数据需求**
- 季报/年报财务数据
- 利润表、现金流量表、资产负债表
- 行业对比基准与历史滚动窗口

### 2.3 成长/景气/分析师预期类
这类因子强调“未来会不会比市场预期更好”，典型信号包括分析师一致预期、目标价、预增、业绩披露、路演、文本情绪等。

**典型因子**
- CDTR（去偏后的相对目标收益）
- 一致预期/Smart Estimate
- 分析师覆盖度、共同覆盖
- 研报文本情绪、预增因子

**代表性能**
- CDTR：多头年化超额约 **3.3%**，多空年化收益约 **8.2%**，月胜率 **65.9%**
- 分析师共同覆盖/GAT：RankIC **6.87%→7.29%**，IC_IR **0.46→0.55**
- 行业预期共振类策略：IC 均值约 **9.77%**，ICIR **4.11**，年化超额约 **12.03%**

**数据需求**
- 分析师研报、评级、目标价、盈利预测
- 覆盖度、报告发布时间、调研/路演记录
- 业绩预告、公告、行业景气数据

### 2.4 动量/反转/技术形态类
这是最常见的横截面 alpha 家族之一，但需要分清时间尺度：日频动量、短期反转、中期反转、技术形态、涨停首板回调、股价路径凸性都属于这个大类。

**常见子因子**
- 时间序列动量、截面动量
- 反转因子
- 底部技术形态
- 首板回调
- 路径凸性

**代表性能**
- 技术形态类样本中，某些形态胜率约 **35%~56%**
- 隐藏大单/首板类策略在部分样本中今年以来超额可到 **22%+**

**数据需求**
- 日频/分钟级 OHLCV
- 涨停跌停、复权、停牌、除权除息
- 事件标签、形态标签

### 2.5 资金流/交易行为/微观结构类
这是近年最强的 alpha 来源之一，也是当前文献中最密集的主题。

**常见因子**
- 大单/小单资金流
- 主动买入/主动卖出
- 订单流、撤单、挂单方向
- 知情交易、聪明钱、CNIR
- 逐笔成交、单笔金额、成交笔数
- 盘口/LOB 特征

**代表性能**
- 大单行业因子：年化超额约 **10%**，信息比率 **>1**
- 大单/资金流精细化后：多空年化收益可到 **25%+**，IR 可到 **4.61** 左右，最大回撤可压到 **3%~6%**
- 订单流/撤单合成因子：多空收益可到 **43.4%**，信息比率 **>4.6**
- CNIR 类因子：多头年化收益约 **27.86%**，IR 约 **4.91**

**数据需求**
- 逐笔成交数据
- Level2 盘口、委托簿、撤单数据
- 买卖方向标记、成交金额分布、订单生命周期
- 交易成本与冲击成本估计

### 2.6 分析师/机构行为类
这类因子介于基本面和情绪之间，实务上非常适合做中低频 alpha 或行业轮动增强。

**常见因子**
- 覆盖度、共同覆盖
- 目标价、目标收益率
- 分析师情绪、评级变更
- 预增、预期调整
- 基金持仓、北向资金、机构持仓穿透

**代表性能**
- 分析师覆盖/文本类策略常见年化超额在 **3%~15%**，部分增强组合更高
- 基金持仓/公募超配类组合在多个报告中可达到 **8%~10%+** 的年化超额

**数据需求**
- 研报全文、标题情绪、评级变更、目标价
- 基金季报、持仓穿透、申赎、北向资金
- 机构持仓变化、重仓股信息

### 2.7 行业轮动/风格轮动类
行业轮动不是单纯“选股”，而是把 alpha 迁移到行业层面。

**常见因子**
- 产业景气度
- 估值与风格切换
- ETF 资金流
- 分析师预期共振
- 微观资金流共振
- 宏观触底 + 微观领涨

**代表性能**
- 行业轮动类策略常见年化超额约 **3%~12%**
- 资金流共振类策略中，组合年化超额可到 **16.9%**，信息比率 **2.15**

**数据需求**
- 行业财务数据
- ETF 申赎与资金流
- 行业成分股资金流/持仓
- 宏观指标、风格因子暴露

### 2.8 深度学习/多源融合类
这类不是传统意义上的“单因子”，而是**因子提炼与融合框架**。

**典型框架**
- GRU / LSTM / Transformer
- GAT / GNN
- BiAGRU + GAT
- 正交层、SA 加权、多特征融合
- GFlowNet、StyleNet、SSPT、QuantaAlpha 等

**代表性能**
- 仅基本面特征：周均 RankIC 约 **0.039**，月均 RankIC 约 **0.067**
- BiAGRU-GAT：周均 RankIC 约 **0.141**，年化多头超额约 **32.9%**
- 中证500 增强年化超额约 **17.2%**，中证1000 增强约 **24.1%**

**数据需求**
- 量价、资金流、财务、分析师预期等多源输入
- 行业/基本面关系图
- 训练标签、样本权重、时间切分、成本假设

## 3. 文献中最常见的性能指标

在这些文献里，最常用的不是单一准确率，而是下面这些指标：

- **RankIC / IC**：看横截面排序能力
- **ICIR / RankICIR**：看稳定性
- **年化超额收益**：看策略是否真的赚钱
- **Sharpe / 信息比率**：看风险调整后收益
- **最大回撤**：看策略抗压性
- **胜率**：看收益分布是否稳定
- **换手率**：看交易成本压力

## 4. 最值得优先复用的“高 alpha 数据类型”

按文献共识，优先级通常是：

1. **逐笔成交 / Level2 / 订单簿**：最适合挖掘短周期 alpha
2. **分析师预期 / 目标价 / 研报文本**：适合中低频选股与行业轮动
3. **基金持仓 / 北向资金 / 机构行为**：适合做拥挤度、共识与跟随
4. **财务报表 / 业绩预告 / 无形资产 / 现金流**：适合做中期质量成长因子
5. **日频量价 / 技术形态 / 事件标签**：适合做基础多因子与事件策略
6. **行业/宏观/ETF 资金流**：适合行业轮动与风格切换

## 5. 结论

这批文献里，alpha 选股因子可以归纳为三条主线：

- **传统线**：价值、质量、成长、动量、反转
- **微观结构线**：大单、小单、主动买卖、订单流、撤单、逐笔成交、盘口
- **融合增强线**：分析师预期、基金持仓、行业轮动、多源深度学习

如果要真正落地，最关键的不是“因子名字”，而是：

- 用什么数据
- 什么持有期
- 是否中性化
- 交易成本和容量如何
- 样本外是否稳定

**一句话总结**：
> 近年的 alpha 研究已经从“找单因子”转向“找有效信息源 + 做结构化融合 + 控制交易与风格约束”。
