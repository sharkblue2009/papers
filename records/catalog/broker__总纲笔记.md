---

## 1. 这套目录到底在研究什么？

`broker/all` 不是单一系列，而是一条不断扩展的量化研究链条：

1. 先识别**什么信号有效**；
2. 再回答**为什么有效、何时有效、对谁有效**；
3. 再把信号做成**更稳、更可交易、更适合组合**的形式；
4. 最后走向**深度学习、图神经网络、资金流/订单流、交易成本、容量约束、市场环境适配**。

因此，这个目录的核心价值，不是“多”，而是把不同券商、不同阶段、不同方法的研究，拼成了一套可复用的量化方法论。

## 3. 演进主线

### 阶段一：基础信号与技术分析
关键词：**K 线、波段、反转、价值、动量、择时**

早期研究更偏向：
- 技术形态
- 价值与成长
- 反转 / 动量
- 行业轮动雏形
- 基础多因子组合

这一阶段的典型特征是：先找到“能不能用”，再谈结构化改造。

### 阶段二：因子工程化
关键词：**正交、分层、拥挤、组合、风格、分析师预期**

研究重点开始转向：
- 因子分解与正交化
- 分位数回归、条件期望、加权
- 拥挤度与失效预警
- 风格 / 行业中性化
- 分析师、一致预期、预期调整

这一阶段的本质是：从“单因子好不好”变成“因子在什么条件下好”。

### 阶段三：高频与微观结构
关键词：**资金流、订单流、大单小单、主买主卖、撤单、LOB**

之后研究开始明显向短周期和交易行为偏移：
- 逐笔成交和订单流成为重要信息源
- 大单 / 小单、主买 / 主卖被频繁用于构造 alpha
- 撤单、挂单、LOB、单笔金额等成为微观结构特征
- 高频信息开始低频化、组合化、执行化

这条线是整个目录里最稳定的 alpha 来源之一。

### 阶段四：深度学习与多源融合
关键词：**LSTM、Transformer、注意力、GNN、多颗粒度、混合特征**

深度学习不是简单“替代因子”，而是：
- 做多源特征融合
- 处理非线性和高维交互
- 引入多粒度输入
- 作为传统因子工程的增强器

更有效的路径通常是：
**结构化因子 + 深度网络 + 正交 / 注意力 / 多频特征**。

### 阶段五：落地约束与系统化策略
关键词：**成本、冲击、容量、约束、组合优化、市场环境、模型比较**

后期研究越来越强调：
- 交易成本和冲击成本
- 容量和换手
- 跟踪误差和约束
- 市场环境对因子表现的影响
- 单模型转向模型融合与策略系统

这意味着研究从“能否预测”走向“能否赚钱且能持续赚钱”。

## 4. 全库最稳定的结论

### 4.1 高频 / 微观结构因子是核心 alpha 来源
资金流、订单流、大单小单、撤单、主买主卖、LOB 等变量，通常比静态财务更接近短周期定价机制。

### 4.2 因子有效性高度依赖环境
影响因子表现的关键因素包括：
- 市场状态
- 风格状态
- 因子拥挤
- 交易成本
- 组合约束
- 样本区间

很多“失效”不是逻辑错了，而是环境变了。

### 4.3 因子工程比单因子崇拜更重要
全库反复强调的不是“找到一个神因子”，而是：
- 分解
- 正交
- 降维
- 加权
- 择时
- 切割
- 组合

### 4.4 深度学习更适合做融合器，不适合神化
DL 的最大价值通常体现在：
- 信息融合
- 非线性映射
- 噪声压缩
- 多模态整合

而不是单独替代所有传统金融理论。

### 4.5 可交易性比理论 IC 更重要
后期研究越来越接近实盘约束：
- 容量
- 冲击
- 成本
- 换手
- 约束
- 稳健性

这也是从研究到策略落地的分水岭。

## 5. 主题地图

### 5.1 因子选股
- 价值、质量、动量、反转、成长
- 分析师预期、预期调整、业绩超预期
- 因子正交、加权、择时、拥挤度

### 5.2 行业轮动 / 资产配置
- 景气度、估值、动量、资金流
- 宏观周期、风格切换、行业配置
- 组合约束、风险平价、资产配置框架

### 5.3 高频 / 微观结构
- 逐笔成交、订单流、撤单
- 主买主卖、大单小单、单笔金额
- 日内结构、低频化、高频到日频映射

### 5.4 基金 / 机构行为
- 基金持仓、北向资金、机构重仓
- 聪明钱、调仓行为、持仓穿透
- 分析师覆盖与机构预期

### 5.5 模型升级
- 机器学习选股
- 深度学习高频
- GNN / 多源融合
- AI / LLM 赋能量化
