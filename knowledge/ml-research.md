## 一句话结论

研报中的机器学习选股以“树模型 + 神经网络 + 时序模型”为主，大语言模型主要用于因子挖掘和投研辅助；多数结论来自历史回测，样本外稳定性和过拟合风险是共同的主要限制。

## 核心稳定结论

### 1. 树模型与循环网络是最常见的选股基线
- 随机森林、XGBoost、LightGBM 常用于横截面多因子打分
- GRU/LSTM 常用于日频量价的时序预测
- 报告普遍以验证集或滚动窗口挑选模型，而非固定参数

### 2. Transformer 类模型多用于时序和多因子融合
- 例：TFT 用于中证500 Alpha360 因子选股，回测年化约 19.6%、信息比率约 1.7（历史回测）
- 注意力机制也用于截面和文本信息融合

### 3. 大语言模型多用于因子挖掘与投研辅助
- LLM 驱动的“生成—评估—进化”闭环可自动挖掘因子，样本外 IC 约 2%–3%
- 主要问题是因子同质化、回测噪声大，以及对提示词敏感
- 另有报告将 LLM 用于研报摘要、问答（RAG）和代码生成，属于效率工具而非直接收益来源

### 4. 模型池与动态集成优于单一模型
- 用验证集同时筛选因子和模型，维护包含不同训练期和参数的动态模型池，结果较单模型更稳定
- 低频率再训练和较长记忆窗口对全市场选股更有利

### 5. 可解释性工具逐渐普及
- SHAP、PDP、ICE、ALE 等用于解释特征贡献，减少“黑箱”顾虑
- 解释工具在研报中主要用于说明因子驱动，而非证明收益来源

## 非 LLM 机器学习研究基线（2026-10 更新）

本节只总结传统机器学习与非 LLM 深度学习；LLM、ChatGPT、GPT/DeepSeek、
文本大模型和 NLP 因子仍按独立主题处理，不纳入本节的模型实现建议。

### 1. 先建设研究流程，再选择模型

综合德邦动态因子筛选、模型池和机器学习残差/反转系列，以及
`records/catalog/ml-models__INDEX.summary.md` 中的相关条目，稳定可复用的核心
不是某一个模型名称，而是：

- 以披露时点可得的因子和特质收益构造标签；
- 先做缺失率过滤、总量缩放、稳健去极值和横截面填补；
- 用滚动训练/验证、purge 和 embargo 处理重叠标签；
- 用验证集边际 RankIC、模型稳定性和换手/成本约束筛选因子与模型；
- 对模型输出做风格、行业和规模暴露检查，再评估组合表现。

### 2. 动态因子筛选和模型池比单模型更具迁移价值

德邦机器学习专题四、五显示，财务/风格因子动态筛选、不同训练窗口与参数的
异质模型池、低频再训练和验证集择优，是传统 ML 选股中最稳定的工程化组件。
模型输出仍随训练样本变化，不能当作固定公式；可复用的是输入预处理、滚动验证、
模型选择和输出中性化协议。

### 3. 残差、反转和复合分解提供经济解释

机器学习残差路线先用风格因子解释收益，再让 ML 学习线性模型遗漏的非线性和交互，
并将预测特质收益、反转残差和风格正交化组合。该路线比直接把模型分数称为
“alpha 因子”更容易审计，但需要明确：原始超额可能含有流动性、非线性市值等
隐含暴露，必须做归因和中性化。

### 4. 非 LLM 深度学习的增量主要来自信息组织

GRU/LSTM、TCN、时序 Transformer、注意力和 GNN 的有效案例，通常同时引入高频、
盘口、资金流、基本面、风格或股票关系信息。模型动物园和多模型集成的共同结论是：
结构不同的模型可能学习到相似但不同步的规律，异质集成通常比押注单一网络更稳健；
这不等于某一架构在所有市场长期优胜。

### 5. 固定公式与模型输出必须分开

- **可冻结并在线重算**：遗传规划搜索后冻结的表达式、明确的特征预处理、标签、
  风格中性化和验证统计。
- **离线研究输出**：RF/GBDT/XGBoost/LightGBM 模型池、ML 残差/反转预测、
  GRU/LSTM/TCN/Transformer/GNN/RL 网络输出。

后者应保存训练截止日、特征版本、标签定义、模型族、随机种子、验证区间、
中性化口径和模型工件，不应在日频 Beacon `compute` 中隐式训练。

### 6. 数据可得性决定实现边界

仅依赖日频 OHLCV、日频财务和已披露字段的研究路线最适合先落地；
分钟/逐笔/Level-2 路线必须遵守 packed 数据的两段式聚合和内存护栏；
宏观、新闻、分析师文本、基金持仓、转债和外部关系图缺失时，相关 ML 报告
应记录为 SKIP，而不是用不等价数据静默替代。

## 主要风险与局限（跨报告共性）

- **回测过拟合**：多数结论基于历史回测，参数和因子选择存在多重检验问题
- **市场结构变化**：风格切换和因子轮动会导致模型失效，尤其对小市值和科创板标的
- **标签与泄漏**：金融标签常重叠，普通随机 K-fold 验证容易高估效果
- **数据依赖**：结论依赖量价、财务和另类数据的可得性，部分样本期较短
- **大模型的不稳定性**：LLM 输出受提示词和模型版本影响，结果可复现性较弱

## 使用建议

- 引用研报收益结论时，优先看样本外区间、换手率和交易成本假设，再看年化收益
- 需要横向比较模型时，先在 `records/catalog/ml-models__INDEX.summary.md` 按模型族筛选，再打开对应 `records/summary/` 摘要核对原文路径
- 本卡片为统计归纳，不替代原文；具体数字以原文和逐篇摘要为准
